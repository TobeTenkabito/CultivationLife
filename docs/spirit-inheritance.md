# 灵域残解与上界传承承接

2026-10-15 纳入本体 v2.13.6 发行汇总。用户存档不自动编辑，仅支持结构 10；下文初验记录保留历史口径，发行证据另见对应版本的成品清单。

## 下界获取与修习

五个二级界面沿原黑市、交换会、商盟寻访与修士遗物入口获取残解。目录包含每档二十五门仙界传承和修罗、幽冥、轮回各两门本体传承，共三十一种。后三界残解引用已有本界领域定义，普通功法气源分别为魔气、妖气和阴气；不复制仙界随机目录，也不赠送 DLC 八部肉身、祖谱或魂因身份。

合参仍走同名玉简规则，Lv4 开域，Lv9 为残解理解上限。三界残解的 Lv4–9 对应原领域初成一层、初成三层、化境一层、化境四层、大成二层、至臻的弱化投影，统一仅取 4% 威能。残解等级不等于上界正式培养阶数。

## 分别承接

玩家须亲至对应三级界面、达到第九阶、存活且未被事件、劫战、拘禁、寄身、封印、压制或归墟困境占用。已学残解至少 Lv4。每份承接记录保存真实来源、原传承编号和承接时理解等级；不按玩家当前世界改写来源。

| 目的地与实际加载系统 | 承接规则 | 后续培养 |
| --- | --- | --- |
| 仙界 | 完成仙灵力转化，补全同门入门功法至 Lv4；保留已有更高功法。其它三界来源形成明确登记的异源仙解，不替换本土二十五道统 | 原功法、注解、道统参悟、唯一本源、十三阶、三轴温养与劫战入口 |
| 修罗本体 | 以本界材料适配为魔域，初成一层起步，保留原名称和有限攻守特色 | 原机缘、灵石、材料和十三阶培养 |
| 幽冥本体 | 以本界材料适配为幽域，初成一层起步 | 原幽元与本界十三阶培养 |
| 轮回本体 | 以本界材料适配为轮回域，初成一层起步 | 原轮元与本界十三阶培养 |

| 百鬼夜行鬼修 | 须完成本魂魂因试炼并确认魂相，寄身与被拘拒绝；融入魂相，不替换魂因、道路、魂痕候选或本魂身份 | 魂相原十三阶和阶段锁 |

## 代价与预算

Lv4 承接无减免；Lv5–9 每级减少承接付款 4%，最高 20%。仙界基础付款为六万灵石、六千机缘、八仙痕，不赠注解、不增加道统等级；对应前四层参悟时间减少 10%–30%，第五层及以后沿原规则。对异源传承，首次明确承接后才在原道统账本登记仙解定义和功法，不在查看或读档时自动生成。

三界本体及妖鬼融合采用原初成一层报价并消耗一份本界普通筑域材料；原机构补贴按真实府库结算，付款走经济账本。新适配领域从初成一层开始；已培养的本相／魂相融合不提升或降低原阶数。八部融合基础付款一百精魂，沿原精魂扣除入口，不改领域等级和威能滋养。

本体适配领域三维份额合计不超过三倍本界基础强度，最多两项基础权能和一项有限特征。妖鬼融合只调整原领域的三维份额，与原份额各占一半，保留原合法效果、特征和阶段资格；不会把下界残解直接兑现为新血脉能力或魂痕。每场仍只展开一个领域，恢复效果不生成元力。

## 状态、界面与性能

承接审计修复：仙元与煞元的战斗可用额度按当前界面相应转化阶段确定，未开放的原账本余量仍归本人，零轮或实际消耗回写均不吞掉余量。个人异源仙解只扩展查找目录，不进入 NPC 本土道统首次随机池；已学 NPC 不重抽。寄身期间原本魂仙界修持由共用入口冻结，现有面板同步禁用，旧页面拒绝后只恢复一次权威状态，离舍后继续原培养。新增回归见 `tests/test_inheritance_audit_fixes.py`、`tests/browser_inheritance_audit_fixes.py`。本轮未新增持久字段或年度钩子，仍不打包。

原残解永久保留。仙界补全按原传承一次；本体适配按所在世界与原传承一次；八部、本相和魂相各只能绑定一份来源。重复操作拒绝，不重复扣费、提升或发放玉简。返下界使用原残解弱化投影，上界修持沉寂保留；再次返界恢复，不改元力余额或劫期。

界面复用现有元府／仙窍面板中的「下界传承承接」折叠区，不新增导航项；上界后续修习复用现有领域、道统或八部面板。后端再次核对资格与资源，旧页面不能绕过。新逻辑只在获取、主动承接、面板投影和战斗投影调用，不增加年度 NPC 培养或全世界扫描。
