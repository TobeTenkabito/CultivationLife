# v3.5.0「万相争辉」

2026-11-03。本体3.5.0，Android版本码93。仅支持结构12；结构1–11拒绝加载／导入，不迁移、不覆盖。覆盖安装保留原文件，但不使旧结构角色变成可加载角色。Windows与Android仅在结构相同时互通存档码。

## 唯一双主题界面

从本版起停止支持松烟书院、月下观星、丹砂金阙、竹简纪年四套非像素界面，仅保留新版「山海图志」浅色与「沧海夜色」暗色。开始页、设置和外观弹窗都只提供这两项，删除“启用新版界面”开关；旧四套独立样式不进入发行物。

首绘、服务器偏好和布局统一固定新版。旧浏览器缓存与机器偏好的theme／pixel_art字段不再启用旧版或转换旧主题，pixel_theme缺失时采用新版浅色；已有新版浅暗配色、减弱动态、侧栏名称与导航偏好仍由原机器偏好账本保存。修改原偏好的关闭新版／选择旧主题请求返回400，不写文件。固定的内部布局标识a及pixel_art=true保留给共用绘景组件读取，不是旧主题入口。没有Player／GameState新增字段，不改变角色、资源或RNG。

## 高阶炼体与八部

本次发行前面积累的仙躯五色神光、魔躯五蕴、妖躯五蜕、鬼躯五法。各躯上限50层，每十层解锁一个机制，独立培养入口、专材与立绘、战报和已完成的神光环绕效果一并打包。五蕴材料仅修罗界，妖躯材料仅幽冥界，鬼躯材料仅轮回界产出，原入口与物品账本不复制。

实际目标、分段、回复、元力消费和死亡沿共同事件结算；同一角色同一机制不得沿自身因果分支重入，不同机制可以联动，照业兄弟段独立，全体攻击仍为全体。乾古静默涵盖全部高阶炼体，沸血解控后下一回合调息。

八部2／4／7级开放各自三项权能，培养页展示解锁，魔域页设置战前预案，紧那罗可选起曲。真实血祭、有限禁印、留招、听律及索元共用原费用／行动／因果入口，状态冻结入战。承压20%／15%修复和前轮数值调整保持。详细机制及历史抽样的局限见[八部权能](asura-eightfold-differentiation.md)、[轮首与五蕴](body-mechanisms-and-wuyun.md)与对应妖躯／鬼躯文档；本版没有追加平衡调整。

## 发行验收

`python scripts/verify_body_ui_release.py --workers 2`运行明确列出的四类炼体、八部、战斗、素材、界面偏好、教程、持久化、跨界／空间、211／212及发行相关上游，三项工程门禁和真实浏览器。此为相关领域回归，不宣称全仓回归。旧四主题测试不再作为当前主题覆盖，新页面按双配色与桌面／手机／横屏验证。

Windows以最终同一EXE在隔离目录执行`verify_release_exe.py --body-ui`，有／无DLC分别验证：双配色、旧入口缺失、旧请求拒绝、真实付费培养和战报；无DLC不授予其它道途专属机制。签名Android12通过`body-ui`原生阶段，在横竖屏实际触摸浅暗切换、四类培养按钮、离线素材及战报。只操作专用测试模拟器，不宣称实体ARM手机验收。

`verify_android_scoped.py emulator-5580 --body-ui`校验实际安装APK、测试APK、签名及原生日志；`package_scoped_release.py`要求相关回归、两种EXE模式、Android两种方向、Lint、签名、版本和源码指纹全部匹配后生成发行物。实际测试数量、产物哈希、签名版本以dist中3.5.0发行清单为准。三项道途DLC分别更新为修罗显圣1.4.0、万妖归宗4.20.0、百鬼夜行3.11.0，另附对应更新包。
