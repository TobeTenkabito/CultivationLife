# 《浮生问道》游戏设计与系统规格书

**版本：** V1.5 人界生态与境界事件切片  
**本体发行版本：** v1.0.0（自此版本开始独立编号）
**类型：** 单人、事件驱动、修仙人生模拟  
**核心原则：** 状态是事实，事件是转换，历史是因果；新增普通内容不改核心引擎。

## 1. 产品定义

玩家从一介凡人开始，每年选择修炼、游历、休养或寻宝。灵根决定成长倾向，机缘推动境界进阶，因果使过去的恶行回流成未来的风险。玩家不能只靠刷数值：夺宝需要战力，长生以后仍要面对不断增强的天劫。

单局目标时长为 20–40 分钟。首版体验支柱是：

1. 每个选择都改变未来可查询的状态或历史；
2. 境界提升显著改变寿元、资源容量和战斗力；
3. 因果不是善恶标签，而是一项会自我强化的长期风险；
4. 战斗结果透明、可预估，但同级对抗保留不确定性；
5. 固定随机种子下可复现一生。

## 2. 核心循环

```text
选择年度行动
→ 获得行动收益并推进年龄
→ 检查寿尽、突破、心魔和天劫
→ 按角色状态筛选并抽取事件
→ 玩家选择
→ 事务化执行效果或战斗
→ 写入不可变历史
→ 保存游戏
```

年度行动：

| 行动 | 定位 | 基础收益/代价 |
|---|---|---|
| 修炼 | 稳定成长 | 机缘较高，回复少量 MP |
| 游历 | 均衡冒险 | 机缘中等，提高稀有事件权重 |
| 休养 | 修复状态 | 回复大量 HP/MP，机缘很少 |
| 寻宝 | 资源换宝物 | 每年随机消耗 HP 或 MP，随后必得灵石或其他物品，并提高探宝事件权重 |

每次推进 1–10 年。内部仍逐年结算，避免跨过寿尽、突破和天劫节点。

## 3. 角色状态

### 3.1 核心属性

| 属性 | 含义 | 规则 |
|---|---|---|
| 灵根 | 天赋品级与属性 | 品级决定机缘获取效率；五行属性决定可修炼的五行功法 |
| 寿命 | 当前年龄与理论寿元 | 有限寿元到期后死亡；炼虚起不再自然寿尽 |
| 机缘 | 修为、悟性与运气的综合进度 | 达到当前小境界阈值即进阶，并扣除该阈值 |
| 因果 | 行为留下的恶性牵连 | 杀人越货、见死不救等提高；高值提高负面事件权重 |
| 煞气 | 猎杀妖兽留下的凶煞积累 | 成功猎妖时增长；当前独立记录，不等同于杀人因果 |
| 境界 | 大境界与层数 | 决定基础战力、资源容量、寿元及劫难 |
| 功法 | 主修类型、五行属性、品阶与等级 | 主修类型改变因果影响比例；五行功法必须匹配灵根属性 |
| HP | 肉身承伤能力 | 归零死亡；大乘五行劫主要检定项 |
| MP | 法力资源 | 战斗和事件消耗；大乘真雷劫主要检定项 |
| 战斗力 | 对战评定派生值 | 由境界、机缘、功法、HP、MP、物品共同计算 |
| 物品栏 | 装备与消耗品 | 装备提供战力/HP/MP，被动道具参与事件判定 |

### 3.2 主功法类型与因果影响

负面事件使用“有效因果”：

```text
有效因果 = 原始因果 × 主功法系数
负面事件权重倍率 = 1 + (有效因果 / 100)² × 2
```

| 主修 | 系数 | 设计解释 |
|---|---:|---|
| 道修 | 1.00 | 遵循通常天道反馈 |
| 魔修 | 0.80 | 能转嫁、驾驭部分业力 |
| 鬼修 | 0.75 | 与阴秽因果相容度最高 |
| 妖修 | 0.90 | 受人道秩序约束略低 |
| 佛修 | 0.60 | 擅长消业与心性守持 |
| 儒修 | 0.95 | 有教化能力，但仍深受人间秩序牵制 |

因果下限为 0，不设硬上限。高因果事件通常继续增加因果，形成“业债滚雪球”；赎罪事件稀少且需要付出资源、时间或战力。

## 4. 境界与寿元

| 境界 | 层数 | 寿元区间 | 特殊规则 |
|---|---:|---:|---|
| 凡人 | 1 | 80–100 | 无法运转高阶功法 |
| 练气 | 13 | 100–120 | 十三层后方可筑基 |
| 筑基 | 9 | 200–250 | 每三层对应初、中、后期 |
| 结丹 | 9 | 400–500 | 升元婴时触发心魔反噬 |
| 元婴 | 9 | 1000–1500 | 神魂质变 |
| 化神 | 9 | 3000 | 最后一个有限寿元境界 |
| 炼虚 | 9 | 无限 | 每 3000 年一次大天劫，威力每次 ×2 |
| 合体 | 9 | 无限 | 周期同上，初始威力为炼虚初劫的 10 倍，每次 ×2 |
| 大乘 | 9 | 无限 | 五行/真雷/心魔劫可混合；每次威力 ×3 |

筑基至大乘：1–3 层为初期，4–6 层为中期，7–9 层为后期。

寿元采用“只增不减”规则：突破新境界时，有限寿元更新为 `max(突破前寿元, 新境界随机寿元)`。因此凡人炼体积累到 260 年寿元后，即使练气境界通常只有 100–120 年，也仍保留 260 年；进入无限寿元境界后才改为无限。

筑基至化神的有限寿元境界还会在小阶段蜕变时增长寿元，而非只在跨大境界时更新。进入中期（4 层）和后期（7 层）分别立即增加一次寿元：筑基每次 12–20 年、结丹每次 25–40 年、元婴每次 70–120 年、化神每次 180–260 年。练气沿用独立的十三层体系，不套用初、中、后三段规则；炼虚以后寿元无限，不再叠加阶段延寿。

### 4.1 机缘阈值

机缘阈值按大境界逐步增大，境界内随层数增加：

```text
本层阈值 = 大境界基础阈值 × (1 + 0.12 × (当前层数 - 1))
```

有灵根者以凡人之身开局，达到阈值后停在大境界瓶颈；机缘封顶且不会自动跨境。玩家可继续整备 HP、MP、功法与物品，再点击“突破瓶颈”。无灵根者的机缘效率为 0，不能仅靠普通修炼进入练气，必须先从凡人事件链取得后天补灵根。结丹九层升元婴还必须额外通过心魔判定；渡劫境界则先通过相应天劫。

## 5. 战斗系统

战斗力只存计算依据，不把派生结果写入存档：

```text
综合战斗力 = 境界基础值 × 层数系数 × 状态系数
             + 机缘贡献
             + 物品战力
             + 炼体战力
             + Σ战斗功法独立战力

层数系数 = 1 + 0.08 × (层数 - 1)
状态系数 = 0.35 + 0.40 × HP比例 + 0.25 × MP比例
机缘贡献 = 当前机缘 / 当前阈值 × 境界基础值 × 0.15
单部战斗功法独立战力 = combat_bonus × 品阶等级系数
```

战斗结算：

- 双方战力比落在 `[0.9, 1.1]`：胜负随机，只造成受伤、退避或失去资源，绝不击杀；
- 比值高于 1.1：高战力方获胜；低于 0.9：低战力方失败；
- 玩家只有主动选择“下杀手”，且战力达到目标的境界击杀门槛时，才进入击杀判定；
- 击杀门槛从凡人的 2.0 倍起，随目标境界提高至大乘的 5.0 倍；达到门槛仍非必杀；
- 击杀成功显著增加因果；击杀失败可能让敌手逃走并留下复仇历史。

首版击杀概率：

```text
P(击杀 | 已达门槛) = min(0.9, 0.45 + 0.15 × (战力比 - 门槛))
```

修士阶段开放三种个人主动战斗：猎杀妖兽、同道切磋、灭杀修士。猎妖会主动寻找战力约为玩家 25%–58% 的适合目标，并使用独立简化判定：玩家战力严格大于妖兽战力的 1.2 倍即直接击杀，不再检查修士境界击杀门槛，也不进行二次击杀概率；未越过 1.2 倍则猎杀失败并受伤。成功猎妖掉落灵石、增加 2–5 点煞气，但不增加杀人因果。切磋和灭杀的修士目标使用下述独立世界基准；切磋不进入击杀判定，灭杀修士只有真正击杀时才增加因果并夺得灵石。凡人阶段不会显示可执行的修士战斗。

所有“修士对手”使用独立世界基准，不再用玩家实时战力乘随机倍率。系统先按事件权重抽取对手的大境界与层数，再取得该阶段期望战力 `E`，最后生成截断正态分布：

```text
对手战力 ~ Normal(E × 事件均值倍率, E × 标准差系数)
最终结果限制在 [E × 下界, E × 上界]
```

普通切磋以 `E` 为均值、标准差约 `0.14E`，截断于 `0.65E–1.40E`；劫修以 `E` 为均值、标准差约 `0.18E`，截断于 `0.60E–1.55E`；携宝弱者与主动灭杀会更偏向低境界或低于均值的目标，但仍不读取玩家装备。当前世界期望战力如下：

| 境界 | 初期/低层期望 | 中期/中层期望 | 后期/高层期望 |
|---|---:|---:|---:|
| 凡人 | 20 | 20 | 20 |
| 练气 | 1 层 100 | 每层 +15 | 13 层 280 |
| 筑基 | 600 | 1,000 | 1,150 |
| 结丹 | 2,500 | 6,100 | 8,800 |
| 元婴 | 20,500 | 42,500 | 64,500 |
| 化神 | 125,000 | 170,000 | 190,000 |
| 炼虚 | 705,000 | 1,070,000 | 1,400,000 |
| 合体 | 4,800,000 | 7,200,000 | 9,000,000 |
| 大乘 | 33,000,000 | 49,000,000 | 63,000,000 |

玩家只能看清不高于自身一个大境界的对手修为；高出两个及以上大境界时，事件只显示“无法看清”，战力气机仍可作为风险提示。角色栏战斗力支持鼠标悬停或键盘聚焦，显示当前阶段期望值，并按玩家战力/期望战力之比分档：低于 0.5 为“卑微如蝼蚁”，0.5–0.8 为“十分弱小”，0.8–1.0 为“稍弱但能自保”，1.0–1.25 为“稍强、不落下风”，1.25–1.7 为“十分强大”，高于 1.7 为“同阶无敌、可跨境斩杀”。恰好等于期望时显示平均水准。

## 6. 心魔与天劫

### 6.1 结丹升元婴

心魔压力：

```text
压力 = 有效因果 + 40
抗性 = MP比例 × 60 + 功法品阶 × 8 + 随机值[0, 40]
```

抗性不足时突破失败，机缘保留 50%，HP/MP 受损；严重失败可能死亡。成功后清除少量因果，但不抹除历史。

### 6.2 炼虚与合体

- 晋入对应境界时记录 `next_tribulation_age = 当前年龄 + 3000`；
- 炼虚初劫基础威力为 1000，合体初劫为 10000；
- 每次劫后下一次威力分别乘 2；
- 综合以 HP、MP 与战力判定，失败造成重伤或死亡。

### 6.3 大乘

每 3000 年发生一次，可独立或混合抽取：

- 五行劫：核心检定为最大 HP 与当前 HP；
- 真雷劫：核心检定为最大 MP 与当前 MP；
- 心魔劫：核心检定为有效因果，因果越高越危险；
- 第一次至少一种，之后混合概率逐次提高；
- 下一次总威力为上一次的 3 倍。

飞升渡劫不在 V1 范围内。大乘九层机缘满后进入“待飞升”状态，允许继续积累资源和承受天劫。

## 7. 灵根、凡人炼体与功法

### 7.1 灵根品级与机缘效率

灵根在本作中只直接改变机缘获得效率，不直接提供 HP、MP 或战力加成。效率严格遵循以下顺序：

```text
异世界灵根 > 法则灵根 > 变异灵根 > 极品灵根 > 天灵根 > 伪灵根 > 无灵根
```

非五行灵根维持原有效率。五行灵根以“三种五行属性 = 1.00”为基准，每多或少一种属性线性变化 0.15：

| 品级 | 具体灵根 | 机缘效率 |
|---|---|---:|
| 异世界灵根 | 异世界灵根 | ×2.00 |
| 法则灵根 | 时间、空间、因果 | ×1.75 |
| 变异灵根 | 风、雷、阴、阳 | ×1.50 |
| 极品灵根 | 单一金、木、水、火、土 | ×1.30 |
| 天灵根 | 任意两种五行属性 | ×1.15 |
| 天灵根 | 任意三种五行属性 | ×1.00（基准） |
| 伪灵根 | 任意四种五行属性 | ×0.85 |
| 伪灵根 | 五行俱全 | ×0.70 |
| 无灵根 | 无 | ×0.00 |

凡人后天补成普通五行灵根时效率为 ×0.60；补成风、雷、阴、阳变异灵根时效率为 ×0.70。角色永久记录 `acquired_root=true`，后续事件可据此区分先天与后天资质。

### 7.2 功法四维、装配槽与五行约束

每一部功法都是完整传承，必须至少同时定义以下四项正值；缺少任意一项的内容不能通过验证：

| 功法属性 | 含义 |
|---|---|
| `opportunity_bonus` | 作为主修时启用的机缘效率增益 |
| `hp_bonus` | 作为辅修时启用的最大 HP 增益 |
| `mp_bonus` | 作为辅修时启用的最大 MP 增益 |
| `combat_bonus` | 作为战斗功法时启用的独立战斗力 |

同一部功法可以被放入任意一种槽位，但只有对应槽位的属性生效：

- **主修功法：** 只能装配一部，只启用机缘效率；如果该功法另有 `karma_multiplier`，也在主修时启用；
- **辅修功法：** 只能装配一部，只启用 HP 和 MP 增益；
- **战斗功法：** 装配数量不限，每部只把自身 `combat_bonus` 加入独立战斗力区；
- 功法品阶与等级放大当前槽位所启用的数值，不会让未启用属性跨槽生效。

因此，“一部功法具有完整四维”与“槽位职责单一”同时成立。例如《太虚周天经》本身同时拥有机缘、HP、MP 和战力值；作为主修时只增加机缘，改为辅修时只增加 HP/MP，列入战斗功法时则只增加独立战力。

功法还具有“主修类型”和“灵根属性”两个维度。主修类型为道、魔、鬼、妖、佛、儒；当前主修功法的类型决定基础因果系数。属性为无属性、金木水火土或风雷阴阳，决定修炼和装配资格。

```text
无属性功法：所有角色均可修炼
属性功法：player 的先天及后天灵根属性必须包含 technique.element
```

例如：极品火灵根只能使用火属性或无属性功法；金木天灵根可以使用金、木或无属性功法；无灵根、时间灵根等没有对应属性功法时只能使用无属性功法。变异灵根不再映射到五行：雷灵根不能因此修炼金、木功法，只能修炼雷属性或无属性功法；风、雷、阴、阳均有各自独立功法。

角色创建、学习功法、切换功法和战斗前运功都必须执行同一资格校验，禁止出现“能够学习但无法解释为何战斗时失效”的双重规则。

功法对机缘的最终影响为：

```text
内层机缘 = 基础机缘 × (1 + 主修功法机缘增益) × (1 + 物品机缘增益总和)
最终获得机缘 = 灵根效率 × 内层机缘
```

灵根效率永远位于最外层。无灵根时外层为 0，任何主修功法、物品或内层倍率都不能将结果从 0 补起来。辅修功法分别乘算 HP、MP 上限；战斗功法的独立战力最后直接加入原有综合战斗力，不依赖 HP、MP、境界或机缘部分。部分特殊功法带有因果倍率，但只有将其设为主修时才会改变有效因果。

新角色的主修、辅修和战斗功法槽全部为空。初始灵根不附赠功法，玩家必须通过凡人事件、探索或传承事件取得第一部功法；没有主修功法时，内层修炼效率为 0。

### 7.3 无灵根凡人事件链

无灵根角色固定从凡人阶段开始，普通修炼不产生机缘，核心路线为：

```text
发现无法引气
→ 转修炼体
→ 反复打熬筋骨并承担伤病风险
→ 延长凡人寿命、提高炼体重数
→ 通过具体事件获得某一属性的《后天灵箓》
→ 触发独立的“补全灵根”事件
→ 按所持残书补成对应后天灵根
→ 寻得并主修一部功法
→ 开始积累机缘并进入练气
```

凡人基础寿元仍为 80–100 年。每次炼体事件可以提高寿元上限，但凡躯寿命硬上限为 300 年；达到上限后继续炼体只增强肉身，不再增加寿命。炼体寿元在补髓和进入练气后完整保留。补灵根存在死亡风险，成功后不会追溯补发此前错过的机缘。

功法仍具有 1–5 品阶与等级。品阶和等级只放大当前装配槽所启用的属性；改变主修、辅修、战斗功法、属性或补齐灵根都必须写入不可变历史。

### 7.4 凡人事件池与立志路线

事件池按境界硬隔离：凡人境界只能触发带 `mortal` 标签的凡人事件，劫修、宗门和修仙争斗不会找上凡人；进入练气后永久退出凡人事件池，普通修士事件也不得反向触发凡人生活事件。

无灵根出身者若在 25 岁时仍未达到炼体三重，强制进入一次“立志”事件，可选择：娶妻荫子、考试当官、沙场效忠或江湖驰骋。选择只改变后续凡人候选池，不封死仙途：家族、科举、官场、军功和江湖事件中仍可能获得后天灵箓，再转回逆天改命路线。

### 7.5 后天灵箓与后天补根

后天灵箓分为风、雷、阴、阳、火、水、木、金、土九种，每一卷都是具有稳定 ID 的物品。凡人无灵根路线必须分成两个事实节点：“获得某一卷后天灵箓”与“补全对应灵根”，不得抽到残书后立即随机生成另一种灵根。

凡人只能在“补全灵根”事件中使用残书。普通修士达到元婴期后，才可从物品栏主动参悟后天灵箓，为自身追加对应灵根；元婴前点击统一提示：“上面记载的法门或者材料不是你现阶段能集齐的”。追加灵根只扩充功法兼容属性，不重算原有灵根效率。例如雷灵根元婴修士补全木灵根后，可修炼木功法，但机缘效率仍为雷灵根的 ×1.50。

“获得后天灵箓”和“补全灵根”是两个独立事件阶段。残书获取没有 35 岁门槛，可以提前发生，也可以反复发生；现有来源包括荒祠夹页、鬼市交易、古战场遗页、梦中授页、族谱暗章以及既有凡尘路线文案。任意残书获取事件首次触发后，所有带 `jinque_acquisition` 标签的获取事件权重统一降至初始值的 20%。角色达到结丹期后，所有后天灵箓获取事件彻底退出候选池；已持有的残书不受影响。

只有第二阶段的“补全灵根”受年龄限制：35 岁以前绝不触发。角色年满 35 岁且持有至少一卷后天灵箓后，当年触发率为 1%；此后每增长一岁，年度触发率线性增加 1 个百分点，即 36 岁为 2%、37 岁为 3%，最高封顶 100%。每一岁独立检定，触发后只显示角色实际持有残书所对应的可用选项。

## 8. 物品栏

物品分为装备、消耗品、突破素材和因果物件。每个物品都有明确功效并引用稳定的内容 ID；不能存在只有名称、没有用途的占位物品。当前示例包括：灵石用于交易，回春丹恢复 HP，血参提高 HP 上限，蕴灵珠提高 MP 上限，引缘符提高内层机缘效率，灵剑直接增加战斗力，古玉同时提高 MP 与内层机缘效率，以及九种用于补全对应灵根的后天灵箓。同一物品 ID 会合并为一个库存堆叠：HP、MP、战力等常驻数值按数量线性相加，机缘增益按数量线性汇总后进入内层乘算；消耗品只叠加可用次数，每次仍消耗一件。

探宝不是免费抽奖。每次探宝先随机支付一种成本：最大 HP 的 7%–15%，或最大 MP 的 10%–22%；存活后必定获得灵石、丹药或一件其他物品，再进入可能发生的额外探宝事件。战力物品只提供加法加成；恢复物品通过主动选择使用；任务/因果物件不允许被普通丢弃操作移除。

## 9. 势力拓展系统

人界现有三个可加入宗门：天剑宗、万魔台与菩提寺。天剑宗偏重正道剑修，万魔台容纳魔修、鬼修与妖修，菩提寺侧重佛修、儒修及低因果修士。入门邀请属于修士普通事件；凡人事件池不会出现宗门招募。

每局开始时，三个宗门及其 NPC 名单同时初始化。NPC 保存姓名、职务、年龄、寿元、境界、层级与存活状态，并随每个游戏年度增长年龄、尝试突破或陨落。化神修士在人界极其罕见：初始三宗合计只有一名化神初期修士；元婴后期 NPC 只有在全局不存在存活化神 NPC 时，才以极低概率晋升。人界 NPC 最高只能到化神初期。玩家加入宗门后，本人也作为高亮记录并入本门名单，与存活 NPC 一起严格按境界和层级降序排列；NPC 的突破与陨落以宗门喜报、讣告写入生平纪事，为后续关系和实例交互预留稳定 ID。

玩家在人界同样只能修炼至化神初期三层。机缘再次圆满时进入“人界绝巅”阻塞状态，不能继续突破至化神中期；必须通过一次性偷渡事件链离开人界后才能解除世界上限。旧版宗门名单会按新版人界生态规则自动补齐世界与功法道路字段，不影响玩家属性、物品或历史。

宗门成员每年结算一次福利，并获得 1 点基础贡献。元婴初期以前，福利从悟道玉简、淬体灵液、蕴神灵露、护道法印中随机抽取，分别微量增加机缘、HP 上限、MP 上限或独立战斗力。进入元婴初期后，玩家成为拥有议事席的宗门股东，可在宗门界面固定选择一种年度奖励，之后不再随机。

享受供养必须承担义务。元婴以前，宗门任务出现后必须接取，只能选择执行方式；进入元婴初期并取得议事席后，普通任务新增“派遣门下弟子代办”和“拒绝任务”选项，分别损失 1 点与 2 点宗门贡献。宗门大战属于强制征召，任何境界都没有逃避选项。元婴初期及以下参加宗门大战会进行陨落判定，元婴中期及以上则以负伤、贡献与战果结算，不再进行随机陨落判定。首批内容包括 10 个三宗通用事件，以及天剑宗、万魔台、菩提寺各 5 个独特事件；数据位于 `content/faction_events.json`。

宗门每 5 个游戏年补充一名新成员。新成员的境界抽样固定为：1% 元婴、9% 结丹、40% 筑基、50% 练气；招募后立刻取得稳定 NPC ID 并加入宗门榜，之后同样参与寿元、突破和陨落演算。元婴初期以上玩家每年还可消耗 2 点宗门贡献派遣一次弟子，选择搜寻同阶物品或与自身灵根适配的同阶功法；任务有 72% 基础成功率，失败同样消耗本年度派遣次数。

坊市、宗门、世界 NPC 从主内容流中移出，统一由屏幕边缘的圆形策略按钮打开互斥悬浮窗，并支持关闭按钮和 Esc 收起；任何异步操作结束后，窗口入口及仍满足条件的购买、物品、功法和派遣按钮都必须立即恢复，不得要求刷新页面。左侧角色状态栏在桌面端限制于视口高度并提供独立纵向滚动，避免功法与物品较多时无法查看底部内容。

### 9.1 师徒系统

玩家可以通过随机事件建立师徒关系，也可以加入宗门后直接在宗门名单中操作。拜师对象的修为必须严格高于玩家，收徒对象的修为必须严格低于玩家；同一 NPC 的同类请求只能提出一次，NPC 按双方境界差与关系类型进行接受判定，也可能当面拒绝。NPC 主动拜师时不会直接成为弟子，而是先生成待决拜师帖，由玩家明确选择“收入门下”或“婉拒”。玩家最多有一名师父、八名弟子，待决拜师帖也占用名额；宗门名单会标注已经成立的师徒身份。

随机事件中的高人同样可能拒绝拜师。师父和弟子都记录年龄、寿元、存活状态与死因：事件人物每年增长年龄并可能寿尽，宗门人物则同步宗门 NPC 的年龄、突破与陨落状态。师父在世时，玩家每年可分别索要一次物品和一次功法；赐物基础同意率 60%，传功为 45%，拒绝也会消耗当年该类请求。获授功法只进入“已悟功法”。玩家可从物品栏选择一件实物赠予弟子，物品会真实扣除；也可向弟子传授一部已悟功法，传功不会使玩家失去功法，同一弟子不能重复受授同一部功法。当前仍不开放弟子自主养成、忠诚或继承玩法。异灵根功法传承事件只把对应功法加入“已悟功法”，不会自动装入主修槽，也不会顶掉玩家现有主修。

### 9.2 坊市与灵石经济

凡人无法进入修仙坊市。人界与灵界使用完全隔离的货物池，商品不能跨界出现，但下品灵石作为货币可随玩家跨界并继续使用。人界练气至化神、灵界化神至大乘分别拥有独立坊市，货架每个游戏年刷新 6 件货物。单个货位有 98% 概率生成当前大境界货物、2% 概率生成高一大境界货物，且最多只允许跨越一个大境界；货架不会向下出售低阶物品。化神是人界坊市上限，因此人界不会出现炼虚货物。

坊市同时出售有明确数值效果的物品与完整功法传承。购买即时扣除下品灵石；物品进入物品栏，功法进入“已悟功法”列表，之后可自由配置为主修、辅修或战斗功法。属性功法仍须通过灵根兼容校验，购买不代表能够立即运转。灵石来源包括探宝、普通/境界事件、宗门内容与“坊市委托”年度行动；委托按照当前大境界给出稳定的灵石区间，同时消耗少量 HP、MP。

## 10. 事件框架

### 10.1 内容与逻辑分层

游戏采用数据驱动内容仓库。`rules.py` 仅保存战力、机缘、因果、寿元、功法槽等通用计算与约束，不定义具体物品、功法、境界、宗门或坊市货物。具体数据分别存放在 `items.json`、`techniques.json`、`world.json`、`factions.json` 与 `market.json`；事件由各类 `*_events.json` 提供。`content_registry.py` 负责加载基础内容、转换为领域对象并校验跨表引用，`event_repository.py` 负责合并事件包并校验事件 ID、选项 ID及其物品/功法/宗门引用。引擎只消费校验后的仓库结果并调度状态变化。

这一边界意味着内容扩展原则上只新增或修改 JSON；只有增加全新的效果类型、条件运算符或系统规则时才修改 Python。内容文件必须声明 `schema_version`，加载阶段遇到重复 ID、缺少字段、无效数值或悬空引用时应立即失败，不允许错误延迟到玩家点击选项后才暴露。

普通事件位于 `content/events.json`，最小结构：

```json
{
  "id": "EVT_TRAVEL_HERB_001",
  "category": "encounter",
  "weight": 8,
  "conditions": {"all": [{"path": "player.alive", "op": "eq", "value": true}]},
  "choices": [{"id": "pick", "effects": [{"type": "add_opportunity", "value": 8}]}]
}
```

V1 条件：`all`、`any`、`not`、路径比较、`happened`。  
V1 效果：增加机缘/因果/HP/MP、添加/移除物品、炼体、延寿、补灵根、伤害、受控随机效果、战斗。  
突破、寿尽和天劫属于系统规则，不配置为普通随机事件，避免内容包覆盖世界不变量。

练气、筑基、结丹、元婴各配置 6 个专属事件，共 24 个，分布于 `content/realm_events.json` 与 `content/expanded_events.json`。专属条件必须使用严格境界相等判断：进入下一境界后，上一个境界的内容立即退出候选池，不允许通过“境界大于等于”继续触发。扩展内容另含 6 个修士通用事件，覆盖押运、丹房短工、残阵、灵兽、讲法与星华等题材，并增加灵石产出。主动拦路劫修仅能在练气、筑基、结丹阶段出现；元婴初期开始名震一方，不再进入该事件候选池。

## 11. 可解释性与历史

每条历史记录至少保存：事件 ID、版本、发生年龄、选择、结果、状态差异和标签。事件筛选器在开发模式下可输出“不符合哪条条件”。随机数发生器的 seed 和内部状态进入存档，保证读档后结果连续。

## 12. MVP 内容与验收

纵向切片完成标准：

- 能创建不同灵根、主修和 seed 的角色；
- 灵根机缘效率严格保持既定品级顺序，五行功法不能越过属性约束；
- 无灵根角色不能直接突破，能经由炼体延寿至最多 300 年并找到后天补灵根的方法；
- 新角色三个功法槽均为空，必须由事件获得功法；
- 凡人和修士事件池严格互斥，凡人四条立志路线均保留转入仙途的机会；
- 九种后天灵箓先获得、后补根；元婴前不可主动使用，追加灵根不改变原有效率；
- 凡人补全灵根在 35 岁前不可触发，35 岁起按 `年龄 - 34` 的百分比逐年独立检定；
- 三个宗门开局即初始化 NPC，名单按修为降序，NPC 可突破或陨落且最高不超过化神；
- 玩家本人必须进入所属宗门榜并参与统一修为排序；三宗初始仅一名化神初期 NPC，所有人界角色均不得越过化神初期；
- 宗门成员按年获得福利并承担任务，元婴后可固定分红，元婴初期及以下参与大战存在陨落风险；
- 宗门每 5 年招新且严格使用 1%/9%/40%/50% 境界分布；元婴后可拒绝普通任务并派遣弟子；
- 势力内容包含 10 个通用事件与每宗 5 个独特事件；
- 练气、筑基、结丹、元婴各有 6 个严格限期的专属事件，离开境界后不可再触发；元婴起不再触发主动劫修；
- 八类年度行动都有不同收益与事件倾向；修士可猎妖、切磋或灭杀弱敌，坊市委托是稳定灵石来源；
- 每个修仙大境界拥有独立坊市，只出售同阶或 2% 概率的高一阶货物，绝不出售低阶或跨两阶货物；
- 机缘满后能跨越所有已定义境界；
- 寿元会随大境界突破更新，筑基至化神进入中期和后期时还会额外增长；化神前会自然寿尽；
- 结丹升元婴必经心魔判定；
- 炼虚、合体、大乘的天劫按 3000 年周期与倍率成长；
- 战力区间、胜负与击杀资格符合第 5 节；
- 猎妖严格使用大于 1.2 倍战力的简化成功线，成功积累煞气而不增加杀人因果；
- 因果按六种主修系数影响负面事件；
- 师徒可由事件或宗门名单建立，NPC 拜师必须由玩家确认；人物拥有年龄、寿元和存活状态，并支持索取、赠物与传功；
- 同种常驻物品按数量叠加属性，消耗品按件使用；
- 异灵根功法事件只学习功法，不自动替换已有主修；
- UI 能显示角色卡、事件、选项、日志和死亡结局；
- 存档可在服务重启后恢复；
- 核心规则具备自动测试。

后续优先级：灵界宗门与种族势力实装 → NPC 深层养成与关系网 → 势力外交和战争演算 → 批量模拟平衡 → 真魔界内容。
# 追加规格：人界 NPC 灵根、剧情灵宝与灵界偷渡

- 宗门名单、师父、徒弟及待决拜师帖均显示灵根。人界 NPC 不生成异世界灵根、法则灵根或后天补灵根；结丹期伪灵根权重为 4%，元婴期降为 0.2%，化神期为 0。
- NPC 每年获得“境界基础进度 × 灵根效率 × 小幅随机波动”的修炼进度；积满后进行突破判定。中期、后期突破同步增长寿元，人界 NPC 仍受“化神仅限初期”和化神修士总量稀少规则限制。
- 结丹中期加入三段限期事件链“雷泽遗巢”。进入中期后每年以 20% 起始概率检定，落空一年增加 2%；承接青翎妖王遗留化形雷劫时同时要求比例判定及固定战力 8,500，最终脱离雷泽严格检定 MP。成功获得惊霄羽，提供 1,024 点独立战斗力。
- 元婴中期（4—6 层）加入五段限期事件链“天裂古台”。进入中期后每年以 20% 起始概率检定，落空一年增加 2%。所有 HP、MP 关除比例外均要求对应上限至少 4,000，战力关除比例外均要求战力至少 73,000；任一失败直接陨落。阵心及此前节点允许主动退出，退出者不计通关。完成后获得镇虚尺（8,000 独立战斗力）和灵界空间节点信息。
- 化神初期主页出现一次性“偷渡灵界”。三关依次检定空间节点信息、HP、战斗力；缺少节点信息必定陨落，后两关失败同样陨落。成功后世界标记切换为灵界，人界宗门、师徒和拜师帖信息清空，人界化神初期修为上限解除。

# 追加规格：多世界、世界 NPC、种族与时间尺度

- 世界 NPC 与宗门 NPC 分表定义。每名 NPC 记录灵根、功法道路、种族、年龄、寿元、修为、真实所在世界与离界原因。玩家不在同一世界时，只能看到“魂灯熄灭/已死亡”的认知状态；之后抵达 NPC 所在世界时，可重新确认其真实存活状态。道、佛、儒、妖修默认偷渡灵界，魔修偷渡真魔界。
- 顾长庚是开局固定存在的世界 NPC。玩家只要参与过天裂古台、没有通关且存活，便可从化神三层开始等待“顾长庚分享空间节点”：10% 起始年概率，之后每年增加 1%；顾长庚必须仍存活且尚在人界。若其先一步离界，在玩家尚处人界时按死亡处理，事件永久失效。
- 宗门和宗门事件均带世界标签；人界宗门只在玩家位于人界时运转、发放福利、招募或发布事件。跨界后旧宗门关系清空，灵界必须使用独立定义的灵界宗门。
- 灵界提供二十种可扩展种族定义，不包含魔族、鬼族或修罗族；系统生成的灵界修士必须显示种族。人族与妖族初期处于盟约状态，击杀对方种族修士时，原始杀人因果乘 3 后再额外增加 60。种族当前只开放数据、展示、盟约与因果钩子，尚不开放势力经营。
- 时间单位由数据表配置：凡人至结丹每次 1 年，元婴每次 5 年，化神 10 年，炼虚 20 年，合体 50 年，大乘 100 年。一个操作单位内部必须逐年推进正向收益、年龄、寿元、NPC 修炼、突破、陨落、招募、飞升和概率事件；但主动行动产生的 HP/MP 消耗等成本只在该操作单位开始时结算一次，不能把百年探宝误算成一百次致命消耗。跨度达到 5 年时额外写入时代纪要，概括期间主要人物突破、死亡、离界及重大事件；若剧情事件在中途触发，则时间停在准确年份等待玩家处理。
- 概率递增同样使用内部年度而非操作次数。例如元婴五年单位中的五次检定依次为 20%、22%、24%、26%、28%；若全部落空，下个单位第一年的检定为 30%，而不是五年只检定一次。

# 追加规格：快速开局与灵界宗门

- 主界面提供结丹、元婴、化神、炼虚、合体、大乘六档快速开局。预设从 `world.json` 读取年龄、灵根、道路、机缘、因果、煞气、威名、主修/辅修/战斗功法及初始物品；普通开局仍保持功法为空。炼虚、合体、大乘预设默认出生在灵界，并强制把缺少的金木水火土灵根加入后天灵根列表。大乘九层为当前终点，不显示更高境界突破入口。
- 灵界首批宗门为太玄门、万灵山、星河书院。太玄门负责跨界阵门，万灵山是人妖盟约下的百族盟宗，星河书院收录百族典籍。每宗拥有固定 NPC 名单、灵根、功法道路、种族、年龄、寿元与境界，并提供独立入门事件和首批宗门任务。
- 宗门列表、招募概率、NPC 道路和修炼速率均按世界读取。玩家进入灵界后只会看到并触发灵界宗门；人界宗门不再发放福利或发布任务。灵界宗门 NPC 同样逐年修炼、突破、陨落和招新，炼虚起寿元显示为无尽。

# 追加规格：世界投影、手动冲关与灵界经济

- 大事记保存真实的全局模拟结果，但普通显示层只投影玩家当前世界以及显式标记为全局的记录。跨界 Debug 默认关闭；开启后才显示人界、灵界和全局的全部大事。旧存档中无法可靠判定世界的混合时代纪要在普通模式隐藏，在 Debug 中保留原文。
- 所有大境界边界都改为主动冲关；筑基起的初期三层升中期四层、中期六层升后期七层也采用相同停关交互。普通阶段内层级仍可自动推进。瓶颈机缘圆满后显示对应突破按钮，准备期间玩家仍可正常行动，但机缘不再越过当前瓶颈上限。
- 化神九层冲击炼虚必须同时具备金、木、水、火、土五行灵根，后天补根计入条件。灵界化神坊市新增五卷《五行补篆》，化神起可以分别补全五行属性；补根只扩充兼容性，不改变原有灵根效率。
- 灵界坊市数值梯度：化神物品约提供 1,200–1,400 HP/MP 或 12,000 独立战力；炼虚约 8,000–9,000 HP/MP 或 85,000 战力；合体约 45,000–52,000 HP/MP 或 600,000 战力；大乘约 250,000–300,000 HP/MP 或 4,000,000 战力。对应通用功法分别配置四项必需属性。
- 境界期望战斗力保持阶段制，并与玩家推荐线、NPC 生成和动态事件统一：炼虚初/中/后期为 705,000 / 1,070,000 / 1,400,000，合体为 4,800,000 / 7,200,000 / 9,000,000，大乘为 33,000,000 / 49,000,000 / 63,000,000。装备梯度用于补足而非单件覆盖完整境界战力。

# 追加规格：概率冲关、心魔、丹药与劫数

## 概率冲关

- 练气十三层继续使用既有的自动进阶规则。从筑基开始，普通阶段内层级（如一层升二层）继续随机缘自动推进；初期三层升中期四层、中期六层升后期七层必须在机缘圆满后停留，由玩家手动发起概率检定。这两类小境界瓶颈的基础率按当前大境界逐阶下降：筑基 58%、结丹 48%、元婴 38%、化神 30%、炼虚 22%、合体 16%、大乘 10%。炼虚以前检定成功后直接完成阶段突破；炼虚起还须连续通过精气神、因果、心魔三关。
- 所有大境界冲关由玩家在机缘圆满后主动发起。练气升筑基的基础率按后天/伪灵根、天灵根、极品灵根、变异灵根、法则灵根、异世界灵根依次为 10%、28%、42%、58%、70%、80%；筑基升结丹依次为 5%、8%、11%、14%、17%、20%；结丹升元婴依次为 1%、2%、3%、4%、4.5%、5%。元婴升化神以及之后的每次大境界冲关均为 1%，不再按灵根品级区分。
- 结丹升元婴、元婴升化神、化神升炼虚在基础概率成功后，依次检定当前 HP 与 MP、有效因果、隐藏心魔。炼虚以前只有凝结元婴的三关失败会直接陨落；元婴升化神、化神升炼虚失败会中止冲关并保住性命。
- 任何概率冲关失败都会保留部分机缘并增加隐藏心魔；三关或天劫判定失败增加更多心魔。心魔会略微降低之后的冲关成功率，休息可缓慢消减，正常界面不显示，开启跨界 Debug 后才显示实际数值与惩罚。

## 突破丹药

丹药是物品数据而非写死逻辑。内部突破丹药只能在三层或六层机缘圆满、界面已经进入小境界瓶颈时服用；大境界丹药只能在本境界最高层瓶颈服用。效果保存到本次匹配冲关并在尝试时消耗，不可用于错误境界。成功率加成为百分点加算，之后再受心魔惩罚与成功率上下限约束。

## 三千年雷劫

- 玩家踏入炼虚后寿元显示为无尽，同时初始化距离下一次雷劫 3,000 年的倒计时。雷劫经历次数、下一次年龄和基础雷威都是持久化状态；晋升合体或大乘不会清零次数，也不会降低雷威。
- 每次周期雷劫由初雷、重雷、终雷三次独立判定组成，每一击同时要求当前 HP 与 MP 达到比例及随雷威增长的固定阈值，并在通过后扣除随机比例的 HP、MP。完整渡过后雷劫次数加一，下一次仍在 3,000 年后，基础雷威变为前次两倍。
- 雷劫或突破事件链进行时，普通操作和普通物品暂时锁定，但允许从物品栏使用带 `trial_restore_hp` 或 `trial_restore_mp` 的专属道具。首批包括恢复 30% 最大 HP 的渡劫生机丹，以及恢复 30% 最大 MP 的渡劫回元露。

## 炼虚之后的跨境界天劫

- 炼虚升合体、合体升大乘先进行统一的 1% 基础概率检定；通过后才进入五重天劫。五关顺序固定为：HP 与 MP 总量、战斗力、有效因果、煞气、隐藏心魔。主修功法道路为魔修或鬼修时，煞气关自动通过。
- 每通过一关都会随机按最大值比例扣除 HP 和 MP，玩家可在下一关开始前使用渡劫恢复道具；任一关失败都会陨落并增加心魔记录。天劫只负责当前这次跨大境界，不继承上一次大境界天劫的强度或次数。
- 炼虚、合体、大乘内部的小境界仍使用“概率检定 + 精气神/因果/心魔三关”，不采用五重天劫。周期雷劫与突破天劫是两套独立状态机：前者跨境界持续累计，后者随本次突破结束而销毁。

# 追加规格：NPC 社会关系、势力敌对、牢狱与组队

## 丹药与坊市

- 每件突破材料必须声明唯一作用域 `minor:n` 或 `major:n`。内部材料只在对应境界三层、六层机缘圆满的手动小境界瓶颈生效；大境界材料只在对应境界九层瓶颈生效。引擎按完整作用域匹配，内部材料即使已携带也不能计入大境界概率，普通层内自动推进也不得误消耗已准备的内部材料。
- 新增的化神、炼虚、合体、大乘突破材料全部进入与来源境界一致的灵界坊市。多种不同材料可以共同准备并按百分点加算，同一种材料在一次冲关中只能激活一份。大乘内部材料可用于三升四、六升七；大乘九层不开放突破。

## NPC 信息与可遭遇性

- 宗门 NPC 与世界 NPC 统一保存个人好感、灵根、境界、修炼进度、重宝 ID、真实世界和存活状态。宗门榜公开 NPC 当前战斗力、下一次突破成功率、对玩家的数值好感与态度、以及其携带的最高价值重宝。
- 世界 NPC 和各宗 NPC 都可进入修士遭遇池。一般遭遇不显示 NPC 突破率；每次遭遇独立检定是否出现“传闻中这个人携带了某件重宝”的信息。玩家成功击杀具名 NPC 后，该 NPC 真实死亡，重宝转入玩家物品栏，并影响其所属宗门或种族的整体敌对值。
- 若遭遇者是同门：玩家未取得本界宗门控制权时，击杀同门会立即被逐出并遭全宗通缉；已取得控制权但并非宗门顺位第一时，第一次触发顺位第一的交互警告事件，第二次再犯则被逐出并追杀；玩家已是顺位第一时，宗门无人敢公开追究。人界控制权门槛为元婴初期，灵界暂定为炼虚初期。

## 威名、敌对与通缉

- 威名是显式玩家属性。击杀修士按目标境界增加威名；普通事件可使用 `add_fame` 增减威名。适度威名带来尊敬，过高威名引起警觉，达到包围网阈值后自动形成当前世界的整体敌对势力。
- 玩家分别记录宗门、种族、世界包围网的显式敌对值。敌对值达到通缉阈值后，每个内部游戏年都有概率触发追杀；追兵从与玩家相近的境界起步，并随敌对值向更高境界和多人队伍升级。
- 追杀中可以对抗、伏法或突围。继续对抗与越狱会提高敌对值；敌对越高，战败后被直接处决的概率越高。较低敌对下战败或伏法会进入势力大牢。牢中每次服刑推进一年并承受 HP、MP 损失，且有概率修为倒退；刑期归零释放，也可提前尝试越狱。
- 势力敌对会统一修正该势力全体 NPC 对玩家的态度及组队邀请成功率，而不是为每个 NPC 重复保存同一份仇恨。

## 组队战斗力

- 玩家最多携带两名 NPC 队友。只有一名队友时，战斗场景额外计入该 NPC 战斗力的 50%；有两名队友时，两人分别只计入 25%。玩家本体始终按 100% 计入。例如玩家 100、队友 60 与 40，总战斗力为 `100 + 60×0.25 + 40×0.25 = 125`。
- 组队战力只供明确的修士或妖兽战斗场景使用，不改变角色卡基础战斗力，不参与普通属性事件、突破概率、进阶事件链、周期雷劫或天劫。
- 遭遇修士同样可能组成最多三人的队伍。敌方以最高战力者按 100% 计入；两人队伍的另一人计入 50%，三人队伍的其余两人各计入 25%。致命战斗逐个检查击杀门槛，只要玩家队伍战力满足其中任一成员的门槛，就有机会击杀该成员；未达到的其他成员仍可遁走。

本次系统更新将存档版本提升为 V2。V1 存档不再迁移或显示在续接列表中，以避免缺失 NPC 好感、重宝、敌对、牢狱和队伍状态造成逻辑污染。
## V2.2：修士遭遇、灵界天榜、道侣与三元镇劫山

- 主动猎妖、切磋、灭杀在一个行动单位内只生成一次目标。妖兽不组成修士队伍；修士有 28% 概率形成二至三人小队。多人出现后必须先展示人数、为首者修为、敌我队伍总战力，再由玩家确认交手。切磋固定为非致命结算。
- 灵界维护实时前二十天榜。所有存活的灵界世界 NPC、灵界宗门 NPC 与玩家共同按大境界、小境界、个人战力排序；榜单常态以大乘修士为主。玩家参与计算，但排名不足时不会挤入前二十。
- 新增多类修士偶遇：论道、阵法合作、丹药交易、古玉互易与残图交换。凡花费灵石的交易必定返还物品、功法或机缘。冷淡拒绝可能激发对方杀人夺宝；威名达到 50 后完全免除此类临时贪念。
- 道侣可由事件或固定 NPC 结缘。互动包括亲密交谈、缠绵共参、索取物品、索取功法、赠送物品和替换道侣主修功法。亲密与缠绵降低心魔；任一方主修合欢属性功法时，缠绵额外获得机缘。合欢属性不受灵根限制。
- 道侣存活、同界、与玩家处于同一大境界且主修同一功法时，当前突破率增加 5 个百分点；手动突破成功后，道侣同步进入目标境界或阶段。
- 人界结丹新增沧海宫四段事件链，最终平息沧溟遗魂后获得《玄潮冷焰》和沧海玄鼎。元婴中期新增寒月宫地脉事件，奖励寒魄山髓；元婴后期且无道侣时可触发天衡山二老请求，获得需五行齐备方可修炼的《五行转岳诀》及地磁元胎。

## V2.3：人物缓存、动态天榜与种族外交

- 随机生成的普通修士默认进入容量 36 的 FIFO 临时缓存池，不立即承担永久年度演算成本。再次遭遇、足以进入灵界天榜、结成队友/师徒/道侣或被剧情引用时，人物从缓存晋升至持久 NPC；未被引用且超出容量的最早路人被自动淘汰。缓存人物保留姓名、年龄、境界、战力因子、灵根、道路、种族、好感与重宝快照。
- 灵界天榜在每次界面投影时重新计算，不保存静态名次。固定世界 NPC、宗门 NPC、晋升后的偶遇人物、玩家和道侣统一按当前个人战斗力排序；足以挤入前二十的偶遇强者会立即持久化。道侣面板公开个人战斗力，并可直接邀请入队。
- 二十族采用稀疏的两两好感与外交状态表，支持宣战、结盟、停战、依附和断盟。每个种族都可点击查看当前关系和本族近期外交大事；外交记录标记为灵界信息，人界正常模式不可见。
- 交战关系会提高该敌对种族进入修士遭遇池的权重，并可能在年度推进中触发边境截杀；结盟或依附关系降低普通敌对遭遇权重，主动击杀友好族群仍追加高额因果。
- 多年行动账本、种族关系算法和 NPC 缓存队列分别下沉至独立基础模块。长期存档只持久化稀疏外交关系、有界路人缓存与真正重要的人物，避免把所有一次性生成结果都加入逐年演算集合。
- 灵界炼虚新增青冥洞天五段大事件链，完成后获得《太虚分神篇》和青岳灵胚。同时拥有寒魄山髓、地磁元胎、青岳灵胚后，可在任意世界触发合炼，消耗三材获得三元镇劫山。
- 三元镇劫山提供 720,000 独立战斗力、25% 雷劫/天劫实际伤害减免，并为大乘境以下的突破提供常驻 5 个百分点成功率。该减伤不降低判定门槛，只降低通过判定后的 HP、MP 扣除。

## V2.4：灵界高阶主线

- 合体期新增五段“裂界魔潮”主线。首年触发率 20%，未触发则逐年增加 2 个百分点；玄烬圣祖因真魔界北域灵脉枯死而入侵灵界，试图夺取界种。玩家可从守城、救援、侦察、追击等路线结识绯月圣祖，并得知天墟岛雷池能够洗去界种病根。完成合作可取得定魂丹及两界盟符。
- 合体期新增五段“天墟岛”主线。潜入路线包含盟符秘路、魔族伪装和界缝三种方案，后续需要横渡罡风海、解救受锁魂钉控制的守墟玄猿、选择万劫雷池或太初魂芝，并从玄烬圣祖的封岛追击中脱身。万劫雷印与太初魂芝分别提供高阶生命、法力、机缘和大乘以下突破加成，准备充分者可以同时带走两种造化。
- 大乘期新增七段“蚀天祖藤”主线。剧情依次覆盖多族联军、照脉天镜与锁根神钉、三路入根海、桑离残魂、枯神法相、焚界青焰和飞升天雷。最终关最低要求会随此前建立的战术优势变化，独自硬闯路线最高需要 68,500,000 战斗力及 500,000 HP/MP；成功可获祖藤道种与天雷道痕。
- 蚀天祖藤主线通关后，大乘期可继续触发九段“真仙洛天衡下界”主线：真仙坠界、万宗盟会、阵眼疑云、负山神猿破阵、太虚仙域、锁仙灯与九曜阵、界源反噬、天柱斩仙和仙炉遗宝。洛天衡因仙界重伤而以十个飞升名额诱使本界强者归附，真实目的则是用太虚仙炉抽取界源修补道基。提前让阵师叶归尘修改生门、切断仙炉与界脉的联系或守住锁仙灯会显著降低终战压力；误信暗藏献祭后手的原阵眼、直面仙域和最后斩仙均可能导致陨落。
- 四条主线共 26 个事件、104 个基础选项，每个事件均不少于四项选择。所有内容都以 `world:spirit` 和精确境界标签隔离；首次节点使用逐年递增的概率门，后续节点只由事件队列推进，避免普通事件池乱序抽出。事件系统新增煞气、心魔与威名固定阈值判定，以及“是否已悟指定功法”的条件检查。
- 新增高阶奖励包括定魂丹、两界盟符、太初魂芝、万劫雷印、祖藤道种、天雷道痕、九转还真丹、离火灵印、幽泉魔印及完整功法《太一真罡》。奖励继续由 JSON 内容表定义，事件执行层只负责通用效果与条件调度。

## 魔界与真魔界专属事件扩充

- 魔界与真魔界各新增六个专属日常事件。事件文件在文档级写入 `world`，由事件仓库自动附加唯一世界标签；触发境界也限制在对应世界的境界段，不能进入其他界面的候选池。
- 魔界新增“血河古鲸”“尸月封瘟”“裂谷界兽”三条连续事件链，共十四个节点。三条线分别处理资源采掘唤醒血河寄生物、古修以自身封存尸瘟、母兽为救受困幼兽撕咬界壁的因果；玩家可以救援、合作、强夺或利用局势，不预设单一善恶答案。
- 真魔界新增“黑日曜烬”“坠星遗胎”“渊极界柱”三条连续事件链，共十六个节点。剧情覆盖黑日神殿长期采火导致古魔禽濒死、三宗争夺护胎而死的星兽遗骸、三宗分别遵守旧约却共同耗死界柱等冲突。
- 六条链均以独立概率门开始，后续只通过 `queue_event` 顺序推进；完成标记、关键抉择与结局奖励均写入存档通用字段，因此不提升存档版本。固定战斗使用专属敌我编队与逐轮叙事，门槛沿用本体各境界的推荐战力基准。
- 新增八件剧情物品和六部魔道功法只由对应事件结局授予，不进入坊市、拍卖、私下交易或黑市货表，避免剧情奖励跨界泄漏。

## 本体 v1.1：鬼修基础路线

- 鬼修不依赖专属 DLC 即可游玩，沿用本体通用境界、机缘、大小突破、炼体、神识、宗门、家族、战争与人物关系规则；本阶段不增加血脉、进化或独立资源树。
- 鬼修可从人界或地狱界开局。人界鬼修达到化神初期三层后，通过现有破界事件进入地狱界；目的地由道路配置明确分流，不能落入灵界。地狱界上限为大乘九层，轮回界暂不开放。
- 地狱界开放幽关、忘川流域、铁树荒原与九重狱境四张地图。阴气获取效率显著高于其他气源，九重狱境要求炼虚修为方可安全进入。
- 鬼修入门时固定获得《引阴凝魂诀》与神识功法《听魂术》。功法库覆盖一至八阶，包含主修、神识与炼体门类；所有功法仍使用通用槽位、气等级门槛和灵根兼容规则。
- 地狱界坊市、拍卖、私下交易、黑市和探宝只读取 `world: hell` 货表。每个受支持境界均配置本地大小突破丹药，并提供阴阳返生露作为地狱界孕育药物。
- 初始宗门为幽关渡院、忘川书楼与铁树狱门，各有七名固定人物并参与通用宗门演算与地狱界天榜。事件内容包括三宗招录、宗门阴契、地狱界日常与战斗，以及三段“忘川失名舟”剧情链。
- 大乘鬼修可从地狱界下界人界，真实道果封存并压制至化神初期三层；返回地狱界时完整复原。此往返不等同于飞升轮回界。
