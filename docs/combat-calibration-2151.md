# v2.15.1 战力校准

本次不是统一加百分比。先录制未调整的真实开局、可交易功法配装与剧情战斗，再写入分阶段配置，最后复测。凡人不动，不重写旧玩家功法、装备、体修与其他养成，不新增持久字段或逐年处理。

## 样本与口径

`tools/calibrate_combat_2151.py` 使用原功法配置入口及 `PlayerCombatSystem.resolve`，覆盖练气至大罗37个境界／阶段点、道魔鬼妖儒佛六道途、单金／金水／单雷三类灵根。主辅修与战斗功法都校验原属性、气等级、品阶、本界与转化要求；分别比较三门低熟练、三门普通熟练、九门高熟练配置，另做六门配置和仅新增通用功法的敏感性对照。

样本使用满HP／MP、25%本层机缘、同阶同层对手、五轮普通交锋。无装备、军团、灵域、特殊掉落或血脉堆叠。它是有限玩法样本，不是战力上限；原战斗功法没有数量上限，本次不改变规则。每个最终本体／全DLC复测各47,952场，使用24个固定随机种子；求解前样本每配置12种子，另有二分探测战斗。

校准准则是让普通三门熟练配置在原六维战斗中接近55%胜率，但不降低旧标准，也不强行让尚未形成完整配置的角色越过旧门槛。筑基、结丹与元婴后期的原门槛不低，保留；新增功法令化神至合体原标准明显偏低，按实际结果提高。六门及九门配置仍有明确积累收益，不以极限全收集为普通NPC标准。

下表未加DLC标准加成。NPC、动态遭遇和玩家推荐线共用 `world.json / systems.combat_expectations`，`player_combat_recommendations` 保持相同，仍由原 `expected_combat_power` 读取。

练气一层140、每层递增12，十三层284；拟合模拟锚点而非统一倍增。真仙、金仙、太乙、大罗一层分别251,000,000／990,000,000／5,580,000,000／34,900,000,000；沿用每层8%原公式，以一、五、九层模拟结果拟合。DLC标准加成仍先相加再一次乘入，不重复叠乘。

## 快速开局与旧角色

`tools/calibrate_quick_starts_2151.py` 通过真实 `GameEngine.create_game` 创建每一预设与失落界面六道途变体，分别录制本体和全DLC。新目标保留原开局相对同阶标准的比值，通过最少新增可用功法、最低可满足目标的整数修习等级实现，不虚增势力或外王加成。

炼虚六道途与合体各补一门符合现有五行、气等级要求的本界通用斗法功法；其他需要加强的档位提高原斗法功法等级。`combat_technique_level` 与 `supplementary_combat_techniques` 只用于出生，后者独立于DLC替换的主列表。配置不重新套用到已有存档；自定义开局明确移除这两项，不继承预设培养。

## 剧情

`tools/calibrate_story_combat_2151.py` 将53个本体剧情战斗选项逐一送入原剧情适配器、真实能力绑定与回合结算，保留队友、地形、封印、选项排除与法力消耗。各用24种子检查满法力及七成法力的独立战力探针，共2,544场；这是固定战力变量的回归，不代表实际任意配装都能同样取胜。

42个选项按其原意境界的最近阶段基准重标，文本与 `combat_power` 判定一致；原普通剧情适配器只消费一次威胁，不再额外乘新基准。未受调整阶段的剧情数值保留。HP／MP、宝物、剧情标记、奖励与后续事件不改。金阙残书事件不参与此重标。

洛天衡攻炉推荐改为124,000,000，七成法力准备值135,000,000；原独立55,000,000敌方值不随推荐放大，锁仙灯第二轮保护、第三轮封域及盟友机制不变。其他敌方完整战力仍沿原逻辑读新境界基准，不额外叠加。

## 复现与证据

先运行校准脚本记录前态，再由一次性作者工具 `tools/apply_combat_calibration_2151.py` 将审核值及关联提示写入内容；该工具要求未改的2.15.0内容快照和出生记录，不属于运行时代码。JSON变更按解析后的标量位置回写，保留剧情原排版。

`build/combat-calibration-2151/` 保存本体与全DLC开局前后、三／六门对照、剧情前后与最终战斗结果；`tests/test_combat_calibration_2151.py` 覆盖标准、真实出生／读档、不重套培养、自定义隔离、NPC权威值与剧情单次威胁。百科由当前配置展示含已启用扩展的境界表。

`tools/verify_combat_upstream_2151.py` 只选择旧引擎测试中与开局／剧情有关的六项：固定剧情数值同步更新，化神开局允许最低足额整数功法等级带来的离散超额，其他配装、资源及判定约束保留；不借此运行整份引擎测试或全仓。

验收范围在原商品专项上增加战力、NPC、快速开局与剧情相关测试及真实开局浏览器，不运行全仓。最终成品、性能与原生证据须对应最终发行输入哈希。
