# 修罗王庭深化：派系、总督府与地方军权

整理日期：2026-11-11。状态：策划基线；已实现第一批[任职与总督府](asura-governorship-implementation.md)及第二批[派系深化与地方争议](asura-politics-and-disputes.md)。第三批[驻军、军令与举兵争位](asura-military-and-succession.md)已接入源码；具体容量与实施边界见各批记录，不代表全部发行功能。本轮不确定新版本号、不改变存档结构、不打包。

设计基于本体 v3.7.0 与修罗显圣 DLC v1.4.0 的现有系统。专属玩法归入「修罗显圣：无法无天」；通用 NPC 决策、授权、军事与机构执行能力按原分层原则归本体。本文将讨论中的方向合并为一套规则；费用、任期、容量及平衡参数仍须实现时验证。

## 1. 目标与核心原则

玩家可以作为廷臣经营政治关系，外任总督管理地方，作为修罗王协调中枢与地方，也可以从地方起兵争夺王位。长期经营地方与忠于王庭应当有完整收益，不以谋反或登基作为唯一终点。

王庭派系争夺决策、人事和资源；总督府使这些争夺拥有真实驻地、财政与军事执行能力。需要始终区分：

- 君主个人实力、实际参战兵力、地方行政能力。
- 人物私交、对在任君主的忠诚、对具体事项的支持。
- 法定职权、建筑产权、资产保管与事实控制。
- 战争胜利、占领维持、地方治理与王位交接。

高阶修士可以压倒一支军队；人数和政治影响力不得直接兑换为跨境界胜利。强大君主能够有效威慑反叛，但亲自作战不等于同时完成各地治理。准备充分的削权、交接和接防可以稳定成功，不为制造难度强制刷新叛乱。

## 2. 现有基础与需要改造之处

本节描述实施前基线；第二批已替换旧的哈希派系投影与势大自动挑战，现行细节见上述第二批实施记录。

现有王庭已有真实廷臣、爵位、三个官职、政令、府库、营建和换位血战。修罗 DLC 已有血裔诸族、征伐军府、万战城盟，以及派系政令与贡赋。

现有派系归属由人物 ID 哈希决定；当前政令持续改变影响力与忠诚；单派影响力达到 48 或忠诚低于 20、持续四政历单位后可能产生王位挑战。派系推进主要限于玩家在位。这些是现有实现描述，不能直接作为新设计的最终规则。

本轮应将固定调数值循环改造成「真实利益与经历 → 具体人物立场 → 有限行动 → 可追溯结果」。现有影响力可保留为摘要，但主要依据持爵、任职、履约及实际支持推导，允许展开来源，不再以势力壮大自动触发谋反。

现有战争可复用真实名册、军需、道路、战斗和归返清算；但主要面向宗门／家族，仍需补充总督府的正式授权与参与适配。现有建筑区分产权与使用权，城市没有完整人口／常年税收模拟，不能把辖区直接变成自动产币器。

## 3. 利益派系与私人党羽

| 派系 | 长期利益 | 现有系统接点 |
| --- | --- | --- |
| 血裔诸族 | 保持爵位、培养后辈、取得修炼资源与地方职位 | 爵位、养域使、养域坛、贡赋及总督任命 |
| 征伐军府 | 奖赏战功、军务预算、委托与军事任职 | 掌军使、王庭委托、血战武院与地方军令 |
| 万战城盟 | 稳定交易、减轻征调、争取采购与营建 | 府库总管、万战互市、原市场采购与地方供给 |

三派代表利益倾向，私人党羽围绕具体人物的提拔、担保、合作和履约关系形成。两者不等同：同派可以争权，跨派可以合作，总督及其部将也不必同属征伐军府。

派系判断结合任职经历、受益与受损、承诺兑现、个人关系及实际风险。对君主忠诚不代表支持每项政令，好感高也不能抹去欠款与失约。人物改变支持对象需要动机与行动记录；具体转变权重待标定，不能用刷新或赠礼瞬间改写全部政治关系。

势大且忠诚的派系可以成为执政支柱；不满但缺乏行动能力者可能请愿、退出合作或投靠他人。有明确夺位目标、实际支持与可承担代价时，才考虑挑战或起兵。

## 4. 中枢派系玩法

| 事项 | 玩家手段 | 真实结果 |
| --- | --- | --- |
| 官位争夺 | 举荐、担保、任免、协商支持 | 原职位换人，才干效果、俸禄及占用同步变化 |
| 预算争夺 | 安排优先级、调整额度、保留准备金 | 同笔府库款不重复使用，未获拨款项目延期 |
| 贡赋争议 | 减免、分期、查验、继续征收 | 原付款方实付，欠款和承诺留账，不生成贡品 |
| 结党与倒戈 | 招揽、保护、劝离、兑现承诺 | 具体人物调整支持，影响任职与执行 |
| 揭弊与追责 | 查账、申辩、追回、撤职 | 基于真实款物与履约记录，退款归原账户 |
| 联合施压与夺位 | 谈判、分化、换人、应战 | 参与者分别表态，武力结果沿原战斗结算 |

事项保存发起人、目标、理由、资源、期限、参与者和解决条件。缺货、道路受阻和执行失败不自动等同阴谋；派系关系提示动机，实际记录构成证据。页面展示已知事实、来源与时间，不泄露全部秘密计划。

君主保留最终裁决权，派系表态不是决定王位的多数票。亲办消耗时间，倚重能臣会形成其人脉，分权增加协调成本，任亲信可能牺牲才干；严惩有据的失职与无据清洗产生不同后果。

玩家未登基时也能完成派系委托、担保、争取举荐与经营支持。承诺限定当前权限，或明确写明取得职位后的条件；不绕过原功绩、境界及个人血战资格。失位后保留履历与关系，重新争位有持续基础。

## 5. 总督府、辖区与权力

采用「总督府是机构及其府署建筑，军区是其获授管辖范围」的统一设计，避免重复创建两套机构。一府引用具体驻地、辖区地点、原人员、原资金与军需。

划定辖区只表达授权与管辖主张。实际控制须有驻防、当地合作或有效协议，不因地图划区自动取得城池、宗门和产业产权。

总督职务与爵位分开。玩家可申请外任、接受任命或获得战功推荐；NPC 君主与玩家君主均按各自权限办理。任命需明确：

- 辖区、府署原址、任期、职责与考核条件。
- 可以自行任用和须报批的人事范围。
- 守备、抽调、讨伐或主动征战的授权界限。
- 中央拨款、合法地方收入、上缴与负担。
- 继任、撤职、续任、拒绝交接及失能处理。

本人沿原地图赴任，不因受任而移动。到任核对原款、原物、属员、驻军与未结事项。前任留下的欠饷、工程和政治关系可以持续存在，不重置为满库新府。

## 6. 接入现有建筑系统

总督府列入当地「此地建筑」，使用唯一建筑 ID、固定世界／实例／地点、原城市引用及所有者／许可字段。府署通常为王庭公产；任职授予有限管理和使用权，不授予私人产权。建造还须取得对应土地或城市的合法许可，不能把公开进入权直接视为设立军事机构的许可。

建造、改建、拆除、损毁、重建和报价沿原建筑入口。公费工程由明确付款主体与唯一货单提供工料，费用进入原营造账户。迁府须处理新址、人员行程与原资产交接，不遥移建筑、仓储或驻军。

| 府署功能 | 功能与衔接 |
| --- | --- |
| 议事厅 | 承办属员建议、争议、承诺和交接，复用机构提案与履约 |
| 军需署 | 组织采购、运输、军费调拨，引用原仓库及军需账 |
| 演武设施 | 安排原部众训练，沿原培养门槛、工时、资材与占用 |
| 守府阵位 | 安装并维护实际阵法，仅在合法所在地发挥作用 |

以上为功能候选，设施数量、等级和槽位尚未定值。已有适用城市、产业或阵法设施优先授权复用，不重复叠加同类收益。扩建改善承办能力，不自动增加人口、修士、库存或现金。

府署损毁暂停依赖该设施的办事能力；不删除人物、军队、账目、债务或未结承诺。原址重建实付并保留原 ID；损毁不能用来逃避交接。依法撤职取消法定授权，抗命者的实际控制则进入独立争议与处置流程，不能靠旧管理按钮继续合法支出。

## 7. 玩家作为总督的经营循环

循环为「接事 → 安排预算与人员 → 亲办或委派 → 核验交付 → 获得实际收益与履历 → 调整下一轮方向」。任职初期、稳定经营、危机处理与交接均应可玩。

| 方向 | 主要事项 | 结果 |
| --- | --- | --- |
| 地方治理 | 原建筑修复、征调争议、地方势力协调 | 恢复原设施与合作、减少失约和停办 |
| 财政经营 | 采购、公产经营、原货供给合同 | 原账户实收，提高军政支付能力 |
| 军备建设 | 军需补缺、驻防、修阵、部众培养 | 实际守备与战斗条件改善 |
| 人事经营 | 举荐、任用、培养、失职调查、派系协调 | 获得执行者并改变地方支持关系 |

初期经费接中央实拨、获授权的原公产收益、真实合同与明确的有限收入分成。新增征调必须指明付款方、库存、资金、权限和上限。中央与地方分账是原钱货的真实转移，不能各自记录同一收入。

府库是公款，玩家获得实付俸禄、批准的奖赏、原功勋与合作关系。侵吞若作为后续可选行为，须显式记录原款转移、实际损失与追责，不能默认为提款权。个人资助、机构拨款和借款也须区分，不因资助就自动取得公产。

长期总督通过续任、受封、扩权、地方建设和属员培养持续发展。政绩良好与合理服从可带来稳定信任，不设「势力增长必然反叛」规则。调回中央保留关系与履历，地方军队和公款按交接处理，不随任职者携带。

## 8. 地方军权与中央制衡

逐项记录「谁批准、谁日常指挥、谁任将、谁供饷、谁愿意跟随」。正式归属和私人依附分开，关系不生成额外人物或部队。

| 安排 | 优点 | 代价 |
| --- | --- | --- |
| 中央供饷、中央任将 | 中央掌握财政和人事 | 财政及协调负担较高 |
| 中央供饷、总督任将 | 地方用人响应较快 | 将领可能依附总督 |
| 地方筹饷、中央任将 | 减轻中央开支 | 任将仍受地方供给制约 |
| 地方筹饷、总督任将 | 地方自主处置能力较强 | 总督更有条件拒绝中央要求 |

地方筹饷必须来自已有合法收入与真实资源。长期共事、提拔、供养、战功与承诺逐步改变人员支持；不因任期长自动谋反，也不因换任立即抹掉关系。

总督可请增军费、申请保留守备、推荐亲信、截留应缴、拒绝交接、联合施压或武装抗命。每项均有实际依据与后果。正当防务不足和蓄意抗命需要查验，不统一用忠诚低解释。

中央可轮调、分权、保留直属力量、分批调将、兑现待遇、亲赴接管或讨伐。行动需要真实行程、人选、授权和钱粮；轮调会失去经验，直属力量需支付开支，抽兵会改变原防务。准备充分可以顺利交接，恐惧也不能凭空补足军需。

军队由原在场、自由、有效参战人员组成。同一人物不得重复驻防、出征、研究或办差；当前整组织闲置调度约束继续适用，不能借总督府把同一宗拆成几支虚假闲置部队。初期使用已有人员和组织；若需补充招募，沿合法招募、来源与有限容量，不随设施升级生成士卒。

## 9. 实力、战争与夺位

### 9.1 三类能力

打赢取决于实际人物、修为、装备、功法、阵法、伤势及补给；守住需要在场驻军和有效供给；管好需要人员执行和地方合作。

低阶部众可护送、守备、运输和控制据点，但不能按人数直接击败不可抗衡的高阶修士。高阶本人只有实际到场才参战，不能同时为多处驻军提供战力。原掌军使职衔也不直接生成军队。

### 9.2 两种争位路径

保留原「个人换位血战」：按原逐级资格、真实战斗与换位规则处理。

新增「总督起兵夺位」：明确登记为独立军政战争路径，目标可以直指王位；不复用旧挑战按钮绕过原逐级限制。该路径需要单独设计授权、参与者、失败及王位交接条件，沿唯一战斗和王位结算入口实现。

| 阶段 | 主要行为 | 必须核验 |
| --- | --- | --- |
| 准备 | 争取部将及地方支持、筹措原军需 | 支持不等于全员追随，经费和人员真实可用 |
| 举兵 | 明确夺位目标，各方分别表态 | 王庭、地方和朝中派系各有动机与实际能力 |
| 推进 | 沿道路部署、作战、争取归附 | 人物实际抵达，出兵减少原地防务 |
| 争夺王庭 | 击败抵抗力量或促成退位 | 现任王的真实能力、所在地与抵抗状态 |
| 登位 | 按已成立条件交接王权 | 唯一王位原子变更，不重复奖赏或改写其他战果 |
| 收束 | 处理其他战役、盟友承诺、地方继任 | 未归顺者独立处置，军资和撤军正常清算 |

攻入万战城不自动登基；击败旧王不自动取得全部地方控制。旧王若已有效退位或失去抵抗能力，不另造一场最终战。不得用单一民心／影响力条直接判胜。

军队可能推进顺利却无法抗衡旧王，玩家可求援、改变部署、和谈或撤回；个人也可能足以胜王但需要依靠旧总督治理。失败按实际情况形成撤退、削权、交辖、被俘或死亡，不统一清空角色。胜利后由玩家承担中央治理与兑现承诺的责任。

## 10. 连续事件示例

中央计划扩建血战武院，同时要求某总督抽调部众。该府总督出身军府，军需由城盟合作方供给，一名重要将领受血裔人物支持。

总督以辖区守备不足申请缓调；供货方要求先结欠款；将领希望领兵入朝摆脱总督控制；中枢政敌要求撤换总督。

玩家作为君主可核查缺口、调整军令、安排接防、付款或换人；作为总督可出示实际防务、履行部分合法军令、提出方案或明确拒命；作为廷臣可担保、举荐和争取合作。结果改变原兵力、原账目和人物立场，并延续到下一件事项。

若总督被撤，愿意支持旧任的部将可能抗命，其余人员可以交接；若旧任起兵，原供货债务和盟友承诺继续存在。赢得血战不会修复建筑，也不会清除欠款。

## 11. UI 与信息范围

不增加新的侧栏入口；沿两套像素主题，保持修罗 DLC 赭红主色、独立 DLC 标记，三派辅以不同徽记，避免只靠颜色辨认。

| 现有入口 | 展示与操作 |
| --- | --- |
| 此地建筑／总督府 | 当地办事、设施、军需、人事、交接 |
| 王庭·爵位 | 人物派系、支持关系、担保与外任履历 |
| 王庭·政令 | 派系诉求、支持理由与在办争议 |
| 王庭·内政 | 中央任命、有限预算、各府职责与来报 |
| 王庭·纪事 | 按事项关联提案、协商、执行和结果 |
| 原地图 | 府署位置、辖区主张、已知实际驻防与控制 |
| 原战争页 | 部署、军需、战报、和谈与撤回 |

默认摘要、按需展开，手机单列呈现关键状态。勘看与办事权限分开；异地不能通过切页取得现场操作权。中央可在合法机关办理任免与军令，但执行人和部队仍需实际行动。

情报按知情主体、来源、时点投影，辖区主张与控制明确区分。秘密计划和精确敌情不得由 API 全量下发后仅用前端隐藏。总督府画稿应属于修罗 DLC，并沿原建筑展开立绘方式展示。

## 12. 本体与 DLC 分层、状态及生命周期

本体提供通用 NPC 决策、原人物占用、授权、提案与履约、军费／军需、建筑和战斗结算；通用改进不能只在修罗 DLC 开启时才修复生效。DLC 提供三派诉求、党羽规则、总督任职、王庭专属争议及夺位内容。

DLC 专属配置、文案与素材归修罗包；运行模块按既有扩展装配方式接入。复用本体基础能力，不强制依赖瑶池、诸天或合纵连横 DLC 的专属玩法，不借用其开启资格。

人物、建筑、原财产、原府库、库存、战役和王位保持唯一权威。派系与任职记录只存关系、授权、承诺及原实体引用，不建立镜像资源池。新增持久字段实施前逐项登记状态合同。

职权、地点、参与者、期限与付费在提交时复验。王庭政历、地方实际年、战争会战及工程工时分别衔接，读取页面不推进、不采购、不投骰；短工时不得误算完整高阶行动收益。

死亡、拘禁、失职、离界、建筑损毁、机构失效和 DLC 停用均需处理占用及未结责任。关闭 DLC 后不再发起专属行动，但保留原资产、债务与履历，通过合法收尾路径交接或撤军，不利用开关撤销战败、退回已耗军费或复制奖励。具体可关闭阶段与收尾白名单在实现前明确。

沿现有跨界与冻结规则，不新增远程移交物资、跨界军队运输或玩家移动例外。当前仅结构12；本方案不授权旧结构迁移或用户存档修复。

## 13. 实现依赖、待标定项与验收

建议按依赖顺序交付，分批实现不删减完整目标：

1. 明确原状态归属及军政授权，补齐可独立运行的本体共用能力。
2. 落地总督府建筑、任职、赴任、交接、预算和基本地方经营。
3. 接入三派、私人支持、承诺及六类争议，NPC 与玩家均可参与。
4. 落地驻防、供饷、调兵、轮调、拒命与中央制衡。
5. 落地总督起兵、地方战役、王庭争夺、退位／登位及后续收束。
6. 完成 UI、专属素材、关闭态、对抗测试及发行验收，再确定版本和打包。

尚未确定的参数包括：总督府数量与辖区划分、设施槽位和工料、任职门槛与任期、拨款和分成、承诺期限、行动评估周期、最大活跃事项与战局、威慑与政治判断权重。须以现有经济量级、真实行程和战斗样本标定，不能沿用讨论举例作为固定值。

验收至少覆盖：

- 无 DLC 的本体机构、战争与人物逻辑仍正常；修罗专属操作关闭时拒绝，其他 DLC 不成为隐性依赖。
- 公私资产分离，拨款／采购／运输／消耗／退款对账；无重复收入、库存、部队或人物。
- 总督无越权征调和占产，撤职与实际交接分开，继任不重置关系和债务。
- 同人／同组织多重占用、死亡拘禁离场、旧报价、重放、重复年份与保存重载。
- 忠诚强臣可长期稳定，NPC 君主在位时仍有政治活动，正常经营不是必然反叛。
- 弱军不能凭人数保证击败高阶修士，主将不在场不得提供战力，缺粮与伤势照常生效。
- 个人逐级血战与起兵夺位分别核验；占城不自动登位、失位不吞军资、并发战果不重复换王。
- 设施损毁与重建不刷新人物／资源／责任，停用不清除战争后果，跨界与空间不绕过权限。
- 真实 HTTP、事件加载与页面点击，覆盖过期页面恢复、奖励保留、忙碌解除和仍应禁用的操作。
- 两主题桌面／手机／横屏，不堆叠导航按钮，信息披露与颜色标识正确。
- 对最终源码执行适用领域回归、三项门禁及发行脚本要求的浏览器、Windows EXE、签名 Android 原生验收。未跑全仓不得声称全仓通过。
