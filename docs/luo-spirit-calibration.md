# 洛天衡首次灵域战校准

> 维护基线：本体 v1.57.0 开发源码，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名保留历史编号以维持链接；历史采样不是本轮实测。

攻炉路线推荐战力 **105,000,000**；法力仅剩七成时建议准备到 **115,000,000**。
这里是有锁仙灯、云海老人和金犀大圣相助时完成破炉目标的准备建议，不是独力斩仙要求。

## 剧情流程

1. 洛天衡展开太虚灵域，封禁盟军神识、身法与退路。
2. 持续支配造成战意与战斗态势损失。初燃灯辉抵抗第二轮的终结效果，不解除支配。
3. 锁仙灯完全燃起，在邻域结算前封停洛天衡的灵域。损失保留，恢复普通交战资格。
4. 六轮总时限内完成破炉目标。其余剧情线路和后续交锋不自动获得这套邻域配置。

普通大乘无法仅凭战力扛过第二轮终结，因此锁仙灯的及时保护是这条路线成立的前提。
去掉灯辉保护，即使战力十亿，也会在连续支配第二轮被终结；测试覆盖这个边界。

## 固定条件与结果

运行 `python scripts/calibrate_luo_spirit_battle.py --samples 200`。脚本调用正式剧情适配器、能力绑定和回合结算，
每个配置使用随机种子 0–199；共九档战力、三种状态，5,400 场。
基准角色为大乘后期七层、道修、极品金灵根、神识等级 26、满气血，无额外装备词条、战斗功法或自带邻域，
仅携带剧情配置的两名盟友。通过固定战力加成调整显示战力，不添加装备能力。
敌方本次总投入固定 55,000,000，编队比例为洛天衡 62%、仙炉 18%、神猿 12%、魔影 8%；
盟友各投入该基数的 6%，总回合仍为六轮。

| 玩家战力 | 炼体百层、满法力 | 未炼体、满法力 | 炼体百层、七成法力 |
| --- | ---: | ---: | ---: |
| 55,000,000 | 0/200 | 0/200 | 0/200 |
| 85,000,000 | 1/200 | 0/200 | 0/200 |
| 95,000,000 | 148/200 | 102/200 | 46/200 |
| 105,000,000 | 200/200 | 199/200 | 195/200 |
| 115,000,000 | 200/200 | 200/200 | 200/200 |

表内为完成战斗目标的次数；未完成者在这些样本中均为僵持，不等同于死亡。
这是指定条件的样本结果，并非任意功法、道途、伤势或预案下的必胜承诺。
基准编队前两轮约损失 20.29% 战斗态势与 16.23 点战意，第三轮不会自动补回。
旧战力提示同时定义敌方强度，本次将敌方投入与玩家推荐值拆开，以免调高建议时同步强化敌人。

后续斩仙一幕针对已经受灯阵压制、重伤的洛天衡，不能直接用它的旧提示反推这次完整灵域的威胁。
