# 洛天衡首次灵域战校准

> 维护基线：本体 v1.58.0，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名编号仅用于保持链接。

攻炉路线推荐战力 **105,000,000**；法力仅剩七成时建议准备到 **115,000,000**。
这里是有锁仙灯、云海老人和金犀大圣相助时完成破炉目标的准备建议，不是独力斩仙要求。

## 剧情流程

1. 洛天衡展开太虚灵域，封禁盟军神识、身法与退路。
2. 持续支配造成战意与战斗态势损失。初燃灯辉抵抗第二轮的终结效果，不解除支配。
3. 锁仙灯完全燃起，在邻域结算前封停洛天衡的灵域。损失保留，恢复普通交战资格。
4. 六轮总时限内完成破炉目标。其余剧情线路和后续交锋不自动获得这套邻域配置。

普通大乘无法仅凭战力扛过第二轮终结，因此锁仙灯的及时保护是这条路线成立的前提。
去掉灯辉保护，即使战力十亿，也会在连续支配第二轮被终结；测试覆盖这个边界。

## 校准方法

使用 `scripts/calibrate_luo_spirit_battle.py` 在临时角色上复现。固定境界、功法、战力、炼体、法力和同行队伍后比较结果；战斗僵持不等于死亡，指定配置的通过率不保证其它存档获胜。敌方投入与玩家推荐战力分别定义，修改推荐值不能同步提高敌方投入。
