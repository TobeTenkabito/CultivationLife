# 诸天开拓第一批：跨界立足

2026-10-29 源码开发。首批交付原势力授权、固定路线、异界分驻地、真实门人派驻、施工、当地仓储与经费、补给、个人往返及撤回。第二批的地方影响扩张和第三批的跨界征服未在本批开放。沿用本体结构 11，只接受结构 11，不迁移结构 1–10，不修改原游玩存档。

## 入口与权限

入口为“诸天 → 诸界 → 跨界开拓”，详情独立分为授权与往返、派驻与补给、驻地与仓储、开拓纪要。各页用事务选择器展示一项操作，复用原导航、报价、当前修订和唯一命令序号；HTTP、Debug 共用 `heavens-preview/heavens-command`，不新增旁路。进行中的亲自行程从“行程”续办，异界停留时该处也提供返程链接。

人界或魔界宗门、家族的实际控制者须亲自在原总部批准开拓；个人开拓通行要求未封印、未压制的结丹至炼虚修为，并服从目的界面的实际修为上限。总部仍是原 `SectState.world/location_id`，分驻地引用同一势力编号。总部批准的当地文书允许原成员处理该处派驻与经营，失去控制权或成员身份不能继续发新指令，不向旧组织经营接口授予远程权限。已付款的本人返程保留，不因失权、停办或撤回消失。

本批作为本体诸天玩法，不要求开启合纵连横；不会借开拓生成地方影响、生产加成、税收或战争权。未开启诸天新发现时，已有文书、行程、施工和返程继续可办理；新文书不生成。每个原势力一份文书，最多八份记录，不覆盖旧档和旧许可。

原权限规则增加已签发文书的成员归属判定，避免离界准备仅因创立者不在总部就替换其控制者，或删除仍有效的原掌门席位。它不放开异界议事、府库采购等旧入口的位置限制；失去原成员身份、势力灭亡或真实控制条件改变仍失权。

## 路线、人员与时间

| 项目 | 明确语义 |
| --- | --- |
| 人界至魔界 | 无棣原 → 赤髓城；`expedition:human:demon`，横向 `expedition`，8 个实际年 |
| 魔界至人界 | 赤髓城 → 无棣原；`expedition:demon:human`，横向 `expedition`，8 个实际年 |
| 单人容量 | 两方向共用一条民用通道；已有亲自行程优先，否则已在途门人优先。冻结异界行程不占实时通道，入界恢复后重新排队 |
| 总部集结／返乡 | 原总部与本界通行端点之间的真实地图道路，按原门人实际境界报价；本人须自行沿地图到通行端点 |
| 派驻人员 | 同一原势力的自由、无其他职责、无研究／旧战争占用且在总部的原门人；每驻地最多三人在途或驻守。私人同行、师徒等既有职责不征用 |
| 原人物归属 | 从原宗门名册交接到原权威 `world_npcs`，保留编号、宗籍、资源、伤势；不复制。跨界沿 `npc_lifecycle.move_world`，同界只改实际地点 |
| 玩家移动 | 独自通过正式 `WorldTransitionRequest → plan → apply → finish`。同伴与本人持有的俘虏须先安置；不改变原总部，不触发永久飞升离宗 |
| 地区归属 | 集结、去程及返乡归原总部界面；施工、驻守、返程归目的界面。每人及驻地保存实际年度游标，冻结并在入界时补算；不另开年度循环 |

人物在原 NPC 年度先经历成长、生死等结算，再推进行程；受控、离位、原宗籍改变、道路或路线关闭时暂停，不扣该年路费，不传送。真实死亡终止，随身未交货物与资金按原损失规则结清，不复活或生成替身。原任务占用接入公共人物占用，不能同时研究、出征或建立冲突职责。

## 费用、施工和仓储

派驻从原总部仓库装运真实二阶普通矿材：构材6、导灵2、储能2。须先在原府库采购备齐，不从异地提货；装运即扣原库存。首次施工劳务10000灵石、初始当地经费10000灵石，加往返每实际年100灵石，全部从原势力府库实付封存。无道路的最小初次派驻预留21600灵石。到达前原款在该门人唯一运输账户，到达后扣留本人返程路费，余款交入当地账户。

当地有实际自由驻守者时施工10个当地年，每年支出1000灵石；首次施工投入上述原矿材，完工成为分驻地。运营每当地年100灵石，亏空暂停，无免费收入。暂停保留原仓库、人员与剩余经费，停止经营养护；恢复须有自由驻守者和至少100灵石当地余额。负责人可从当地原驻守名册任命。

补给使者由总部另派原门人，携10000灵石及实际往返费用；本人抵达交付后，仍须实际返乡。收款不直接到玩家行囊。驻地只持原进口普通材料，不重建目录、资源池或总部库房。前端只在实际当地显示当前库存及当地余额；远方显示已存纪要和传讯延迟提示。

“人员抵达”与“当地交货”分开登记：来源年度可先记录原人员到达，但其钱货仍在本人唯一随身账本及库存中。目的地区实际年度到达该人的抵达日期之后，才将原物交入当地仓库和账户；此前的历史施工、欠费或停办不得挪用未来到货。`units.delivered` 和逐年游标共同保证只交付一次。

## 停办与撤回

普通召回保留已耗路程及费用，原人循路线返乡。撤销驻地停止施工与运营，最后一位可用驻守者携回剩余当地资金和物资；全部归返结清才关闭。没有可搬运人员时，当地资产保留，可从原总部派补给使者回收。原仓库满载则保留原随身货物并等待卸货，不补造另一个仓库；总部迁址不把旧仓库和行程一起移动。

个人启程8年、返程8年，首次实付1600灵石，其中800独立预留返程。取消未抵达的启程退未耗路费及返程款，不移动玩家；暂缓返程保留原任务进度和预留款。末年事件或单位收尾改变资格时停在出发端，正常处理事件后可零补时续办。普通事件及后续奖励不被开拓吞掉。
