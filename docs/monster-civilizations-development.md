# 万灵争衡：百族兴衰

独立 DLC `official.monster-civilizations`；不依赖血脉 DLC。本次不接入商品需求、产业、库存、战争军需、人口工资或府库收支。野生种群不是新 NPC，氏族是文化归属，不覆盖原宗门、家族及其权益。

## 状态与时间

结构 10 增加 `GameState.monster_civilization_state`，缺失为 `{}`；未知 DLC 子版本保留并禁止执行。每界最多六处原地图栖地、八类种群、十六个永久氏族编号；近事最多 192 条、历史摘要最多 24 段。关闭 DLC 完整冻结，无历史补算。显式当地考察才激活本界；读面板不激活、不推进时间。

原年度结算调用生态入口，使用独立确定性季候、不读取游戏随机流。生态迁徙仅沿原地图同界道路，先计算，再对两端提交；目的地容量不足则留在原地。政治每五十年结算一次；幽冥王庭每百年，仅玩家实际身处本界时推进。独立空间不能执行当地操作。

## 操作与归属

玩家在当前真实地点考察、护育或疏导捕食压力。后两者消耗既有机缘并有冷却，不增加物品或缩短原行动时间。氏族活动仅妖界、幻冥界及幽冥界的当前栖地；创建、分支、并族、复兴均使用真实玩家或现有人物编号、转移既有份额。分支不得复制人物，并族保留原编号及祖源。

万妖宫仍为唯一上境机构；五门阀稳定绑定原人物编号，议权仍为 5/4/3/2/1。王庭正统是政治承认，不等于取得万妖宫席位、府库或号令。需议决的政体提案按原席位、原支持和现行政策进行真实计票，至少八议权；失败不提交政体、扣机缘或改变财政。血裔继承只认明确记录的创始人/分支，不能把同种修士当作血亲。

血脉与本相联动仅引用已有有效记录；关闭血脉 DLC 后祖源标记沉寂，文化氏族仍存在。发现记录保存观察日期与范围，离开当地后不泄露未考察的最新种群；万灵志只展示已考察栖地与已知氏族的事实。

已考察过的栖地也不会自动提供远程消息：自然变化须玩家当时身处该栖地才进入公开近事；亲历氏族行动另有自己的记录。

## 界面与性能验收

既有“诸界”导航增加一个“万灵”入口，四页签为生态、氏族、王庭、万灵志；图表随打开面板才加载。地图节点与选择框切换栖地记录，一次仅展开一张详情卡，默认所在栖地；点图不移动、不改存档。所属氏族卡置顶，移动端操作就近，按钮文字含代价与限制。保留现有六类导航和万妖宫入口。全部 192 条近事可按每页十二条查阅，共十六页。

验收覆盖两 DLC 四种启停组合、独立加载失败隔离、关闭冻结、观察权限、邻接迁徙守恒、氏族无环与成员唯一、现有人物死亡继位、王庭票重和离界冻结、存档往返、千年与五千年有界状态、真实浏览器点击及签名安卓验收。性能按同输入开关对比，年度 DLC 结算五千次目标一秒以内，百年完整行动增幅目标不超过 5% 或 50 毫秒（取较大值）；以实测为准，不以机器负载下的单次耗时代替结论。

## 最终代码性能记录

`tools/benchmark_monster_civilizations.py` 在 Windows 宿主上使用三个种子、每种子三组交替开关对照，四界全部激活；沿用正式百年休息、年度结算、读写存档。仅关闭归墟打断并固定新实例编号，以便逐字段核对结算。每组本体持久状态及随机流完全相同，排除的字段只有 DLC 自有状态和实际更新时间。这组时延不代表安卓设备时延；安卓另做签名 APK 的真实触控及读写验收。

| 种子 | 关闭中位数 | 开启中位数 | 额外耗时 | 增幅 |
| --- | --- | --- | --- | --- |
| 315 | 3333.31 ms | 3463.45 ms | 130.14 ms | 3.90% |
| 7701 | 3519.85 ms | 3502.43 ms | -17.43 ms | -0.50% |
| 9003 | 3477.62 ms | 3558.64 ms | 81.01 ms | 2.33% |

三组均通过完整行动的主要性能阈值；负差值属于测量波动，不据此承诺 DLC 使游戏加速。四界同时推进五千年生态耗时 **1.41 秒**，该场景未达到一秒软目标；不是完整游戏五千年结算耗时。对应 DLC 状态为 **179624 字节**，保留既定记录上限。生态优化减少重复分类、求和和迁徙临时表分配；另一组固定输入的五千年结果与优化前逐字段完全一致，见 `build/ecology-2100-equivalence.json`。原始对照样本、控制条件与最终生产代码指纹保存在 `build/performance-2100/civilizations.json`；耗时受宿主机器负载影响，不承诺每台设备得到相同数值。

## v2.10.0 发行验收

2026-10-11 完成 3881 项全仓回归、33 组浏览器验收及 49 项签名 Android 原生验收。DLC2 浏览器覆盖四种主题、四种窗口尺寸、实际考察与氏族操作、过期页面恢复、全部十六页近事及原万妖宫议权；安卓覆盖四种主题的横竖屏真实触控、栖地只读切换、所属氏族置顶和两款妖修 DLC 的四种启停组合。百科按九款官方扩展的 512 种启停组合核对显示内容。

Windows EXE 使用同一最终程序验证本体与启用 DLC 两种运行方式，并另验仅血脉、仅万灵两种组合。Android 版本为 `2.10.0-android.48`，正式包签名、非调试模式、Release lint 和打包源码一致性均通过；原生测试设备为独立 Android 12 / API 31 / x86_64 模拟器，未作实体手机验收。Windows→签名安卓→Windows 存档往返逐字段一致，含新增 DLC 状态，未读取或修改玩家实际存档。

全仓初轮有一项旧鬼道版本断言受临时加载报告影响；修正测试隔离与正式报告引用后，以原顺序重跑完整 588 项受影响批次，其余七批最终生产源码相同且均通过。Windows 曾出现一次未复现的服务器错误，随后同一产物完整复测通过。原生首轮检查脚本缺少导入，修正并重建测试 APK 后，重新执行全部 49 项；这些原始失败日志均保留，不计为通过证据。

最终回归、浏览器、Windows 程序、原生包与测试 APK、性能样本均绑定生产源码指纹；原生各项另绑定实际安装包及日志哈希。原始证据见 `build/release-2100-source.json`、`build/browser-2100-source.json`、`build/native-2100-source.json`，发行产物及汇总见 `build/release-2100-acceptance.json`。
