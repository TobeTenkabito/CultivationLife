# 立体地图与道路拓扑（v2.13.1）

先读[跨界开发规范](world-transition-development.md)和[当前跨界审计](world-transition-audit.md)。本次仅改同界道路、只读展示与小版本；存档结构10、Player/GameState字段和时间结算入口不变。

## 权威道路

人界、魔界及五个二级界面保留既有道路与地点，新增安全腹地环路和近路；三组偏远支线各新增一条两端间隔一个地点的道路，形成三个小环，仍保留末端和大多数桥边。新增耗时按当时既有最短路的82%向上取整，为正整数；进入目录后是固定内容，不在年度或页面重算。中心配置独立于默认地点、当前位置与宗门影响等级。四个三级界面原有道路保留，最新追加的近距离悬空绕行可补充下方通路。按后续用户要求，十一界部分普通岛屿之间的远海路线耗时提高35%并向上取整，至少增加一年基础路线耗时；同岛道路、悬空/海渊路线不加此远海耗时。仍由原移动速度和运输入口计算实际代价。

按最新要求，近距离悬空节点两侧普通地区增加固定的下方绕行道路；内容设计上两端展示距离不超过1000、仍保留偏远地点度数上限，悬空地点本身的进入门槛不变。判定仅在本次内容设计中使用，运行时不以展示坐标授予通行权；远距离悬空段保留，未来改坐标不会凭空新增道路。实际寻路和展示读取这些固定道路，同岛或下方通路不会被画成必须登上悬空地点。

全部旅行、商队、运输和地方邻接继续读取MapCatalog的同一双向图。短路使经营和旅行距离真实变化，不另造视觉道路，不免除地点门槛、忙碌、拘禁、受控与死亡限制。路图缓存仍在目录重新核验时失效。

## 可选地貌配置

世界可提供atlas.profile（地貌名称）和atlas.centers（真实地点ID数组）；地点可提供atlas.region（core/border/outer）、atlas.terrain（land/sky/deep/snow/fire）、atlas.island（可选非空岛屿分组ID，最长120字符）及atlas.position（三个有限数字，绝对值不超过10000）。这些是内容字段，不是持久玩家状态；不写存档坐标，不移动人物。缺失配置仍合法。未知地貌采用云海默认配色，不把未知世界映射成人界。

新增地点未提供坐标时，MapScene依据实际邻接、地点ID和已有坐标稳定安置，并避免与已有地点重合；完全无坐标的内容依据图的度数与稳定ID布置。布局不读取当前位置或出生点，不消费游戏RNG。图、地点名称、地貌或坐标变化后更换缓存键，最多保留24份模型；普通状态、影响数值与年度响应不重建静态布局。

MapAtlas使用现有地图页导航，增加立体/平面模式；地区列表、议事、势力过滤、唯一颜色和原旅行按钮保留。SVG绘制全部权威道路，选点强调真实最短行程，转动后标签重新避让。不能保证三维投影的线条在每个观察角度都不重叠；用路线描边与明确地点节点区分通路，不把交叉点变为路口。平面模式仍使用无交叉连线和同号路标。

相机和缩放仅为当前页面状态。绘制由显示、选点与输入触发，拖动合并至一帧；暂停/销毁时取消待绘制帧，隐藏窗口无连续绘制。缩放扩大可滚动SVG，不裁去外围地点；按实际地图边界自动取景。SVG和Pointer Events兼容Android12系统WebView；旋转按钮与键盘可替代手势，无WebGL和外部依赖。空间实例沿用原地图入口。

## 生态景观

主大陆增加成片林地、山脊、河流、湿地或荒土纹理；各界依地貌选择植被和色调。画面边缘展示其他大陆的部分海岸与山脉，保留世界向外延伸的空间。各岛岸线依稳定ID采用海湾凹口、狭长岬角、碎岩锯齿、缓坡沙岸或弯月湾，伴随岸边岩块、沙岸宽度与断崖厚度差异；海岸不是同一椭圆轮廓换色。岛屿间留出更宽海域，群岛沿不同方向错落展开；同岛两地区保留紧凑布局。主大陆采用各界稳定变化的非对称岸线，包含大小不同的深湾、狭长岬角与错落海岸转折，并向群岛之间的空白海域延展，群岛方向保留海湾与水道；新增岸地区配山脉、林地和延长的河流。大陆尺度设有基础占比并按真实地点边界自适应，不更改地点坐标。外围按真实地点配置共享岛体：部分较大岛容纳两个相连地区，其他地区位于大小不同的单岛；悬空地形与海渊不会并入普通岛体。新增地图可继续省略地貌，也可指定岛屿分组复用。海域增加近岸浅滩、礁群、水草与珊瑚式枝丛，轮回界为莲丛，幽水与荒界采用各自色调。景观仅为只读装饰，不增加地点、NPC、资源池或年度演算；可点击节点与道路始终来自真实地图。
