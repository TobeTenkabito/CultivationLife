# 师徒第二批：传承、化身与叛师

后续[对抗审计与修复](mentorship-bug-audit.md)补齐已故师父换师、旧关系收尾、永久离界归档、叛师胜败与凡阶化身伤势结算。

沿用第一批个人师承名册及原人物身份。记名无义务、无福利；NPC只在玩家正式拜师后建立少量同门，不自动补满。

- 亲传每周期一次、嫡传三次「传承精修」：在独立NPC培养窗口选择原有方向和机缘/专材，沿用原1/5/10轮报价及实际成长，机缘减半、专材折半向上取整（至少一份）。不增加免费突破，不绕过界面、道途DLC、师徒修为、神识、肉身或实例校验。额度随师门固定周期，换位与读档不重置。化身不享受在籍福利。
- 嫡传成年、忠诚至少85可商议夺舍/化身契约，每种每周期一次；实际耗费心得，忠诚至少95必同意，85至94有拒绝可能。降位、离门、忠诚低于60或失去自由时契约不能履行。夺舍只在玩家神游时、同一实际地点执行，复用原夺舍资格、次数和失败存续结算，不自动复活。自愿宿主仍有最高95%的融合成功率。
- 元婴及以上魔修可以炼化不高于自身境界的在籍成年嫡传为唯一身外化身。消耗一次自身阶段10%突破机缘；已有有效自愿契约力量系数1.2，否则1.0。需二次确认不可逆的炼化；结束在籍名额并将原NPC纳入独立拘管类型，保留原培养、原资源、原寿命、原立绘，没有第二份人物/库存。可切换出战，培养继续使用原NPC培养入口。化身死亡、肉身崩毁或控制失效则停止出战；不自动复生。
- 化身按受控人物既有跨界路径处理：暂时跨界由统一迁移入口移动原人物，永久飞升解除控制并退场，不享受第二元婴随身例外。跨越承载上限、封印、独立空间或归墟亲自副本时不出战/主动培养。它不占普通同行名额，实际出战直接绑定原NPC完整战斗能力、元力、伤势和动作立绘。原人物按受控时钟增长年龄、承受原周期天劫；伤势按普通NPC年度35%概率恢复一层，元力沿原人物资源账本恢复。
- 忠诚低于25的在场非记名弟子可结盟反叛，最多四人；合力达到玩家当前战力70%时预警，经过一个原师门周期且仍满足条件才形成事件。事件仅在双方同界同实例同地点、没有其它忙碌状态时触发，不跨界追杀。预警可用真实利益化解；每次事件后有周期冷却。玩家可认输解散这些师徒关系，或真实战斗；应战时只有玩家自身战斗属性降至60%，原培养数据不减。
- 玩家可当面挑拨同门（每人每周期一次，实际机缘成本；失败增加师门不满），忠诚低于30且对玩家好感至少30者可以结盟。记名无交流权，不能利用此入口绕过。最多三位同门参战，逐人复核身份、地点、忠诚、身体和任务；敌我原ID去重。挑战为真实致命战斗，师父受到同等60%属性衰减；胜利后只接管个人师承，不夺宗门职位、仓库或领地，不自动补齐高位名额。原师父的死亡/元婴逃生仍由统一战斗结算。

师门动作仍通过同一修订号保护的接口、普通界面和Debug能力清单；事件加载与提交使用正式事件入口。名册只读不抽签、不推进周期。第二批状态是结构12可选扩展，不兼容旧结构1–11、不修改用户存档。
