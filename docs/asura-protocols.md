# 修罗第二轮：议政、军权与地方整合

本体3.9.0与修罗显圣1.6.0。第一轮经营内容见[地方经营](asura-local-development.md)，既有驻军和争位见[军政](asura-military-and-succession.md)。本轮不新增侧栏入口，使用原建筑府务和王庭列表中的折叠事务选择器。

## 本体与内容边界

本体 `institution_deliberation` 处理有限预算的原人物决策、联署和具名案卷；`institution_mandates` 处理供养/任将权限、真实轮调及固定地址交接；`institution_arrays` 只引用原镇地阵并复用原修阵资源、阵法估值和损耗。原 `institution_garrisons` 保存付款来源分解，营务余额仍只有一个原账户。修罗适配器的章程、派系偏好、赔款和许可来自DLC world配置；本体不导入修罗规则。

个人驻军与整组织战役分别占用。独立部将可在不同总督府履职，但同一原NPC仍由person_assignments唯一占用；任何未结整组织战役仍阻止拆分征募。整组织出战仍检查全部原驻军，不因个人服务入口放宽而绕过战争占用。

## 联合呈案与追责

联合请款必须有原工程或三十年守备缺口、至少两名真实在场自由修士联署；玩家亲赴王庭，NPC君主使用本体有限预算决策，批准才扣原府库。原廷臣转投需要可信履约关系、实际会面与百年冷却，只改变议政立场，不改人物所属组织、公职或战力。

侵吞行为实际将公款转入个人并留下欠款凭证；具名抗命可以由王庭立案，不能凭空定罪。独立原调查人须在案发地完成十个实际年，每年实付1000灵石，死亡、占用、离场、停用或公款不足暂停。本人申辩后由王庭按原转账及守备事实裁断；有责撤任并追偿，可分次退赔，超额/重复结算拒绝。撤任、辞任、DLC关闭均不清除欠款，回到原址仍可退赔。

## 四类军权与轮调

供养权和任将权各有中央/地方，共四种组合。中央服务拨款由已获地方承认的现君在普通王庭签发，部众必须仍实际驻在原府；这是原账劳务预付款，不运输物资。两种来源独立记账，营务真实耗用后未耗部分退原付款账户，不因改章程转成地方私产。NPC供养和任将同样读取章程、君主在场资格、真实预算和原人占用。

轮调预留第六个名额。接防者先在原府入册，实际沿路抵达旧将驻地，双方均可执行且同地时才能交接；旧将继续沿原路返乡，途中保持占用。取消只召回接防者，不瞬移旧将或抹除军费。

## 府署阵位、迁署与立绘

先经原阵法入口把九宫阵布到原府所在地，再登记其原ID；原材料实例不复制。常规守备使用原阵法估值，单次只计一份防御，战斗扣原完整度。高阶交战仍由原境界/元力/能力裁定，军队与阵法不会授予虚构境界。维修一次实耗一份原资源，撤原阵后府署效果立即消失。

迁署先交接原驻军、属员、项目、供货合同、地方争议、议政债务和公款；玩家亲赴王庭取得一百年内的新址许可，再沿原地图抵达合法未设府城市。只改变机构固定地址，旧建筑、公产留原地；新址按原营造价格建设，人物不搬运、库存不复制、任期和履约次数不重置。

总督府新立绘为1254×1254透明PNG，使用imagegen生成，保留原图副本，SHA256和尺寸登记在DLC视觉registry。完整建筑为赤铜、赭红和铁黑像素画；毁坏状态沿原城市遗址显示。素材路径为 `dlc/asura-manifestation/assets/visual/buildings/governor-office.png`，生成源为2026-11-12的 `exec-338c55e5-7592-44b8-bc17-c027a1f7e48f.png`。提示要求独立总督堡垒、三层黑瓦、赤铜柱、无文字旗帜与透明背景。

## 诸府盟约与战后

当面与另一实际总督交涉，按原私人支持或共同抗命事实决定是否结盟。玩家须先以个人原款担保至少三十年对方营务；同一总督不可多约重复出借军队。举兵才激活盟约并撤销盟友法定任职；盟军仍保留各自名册、经费和道路，显式协同军令出发后，只有实际到场者参加据点战。中央不能直接召回敌对盟军。成功按约从原托管实拨给原府，解约/到期/原任变化退回未耗担保，原撤任与战争消耗不撤销。

双方实际会面才可议和。玩家举兵者须真实支付一百万赔款，旧追偿另计；NPC举兵者仍有实力和抵抗意愿时会拒降。唯一王位交接后，其他原总督得到地方承认待议案，新君不自动拥有他们的军队、建筑或公账。新君须亲赴原府，按人物关系与一百万实际安置拨款争取承认；被撤职者还须走原任命/赴任流程。

## 对抗与发行验证

新增 `tests/test_asura_protocols.py` 通过真实引擎命令测试调查、申辩、分次退款、冷却、四军权、轮调、迁署、盟约托管、阵法原材料及过期请求。`tests/browser_asura_protocols.py` 在两主题桌面/手机与横屏点击原建筑事务，验证过期页面恢复、原款退赔、结案禁用、立绘资源和无横向溢出。原生验收同样增加实际侵吞留痕与退赔操作。

完整仓库、三项门禁、原事件212、Windows及签名Android的最终结果，以[发行说明](release-390.md)及对应build/dist证据为准；不得使用第一轮或旧版本通过结果代替本轮。

## 追责与交接补充

未清侵吞凭据暂停本人的公款权限及重新任命，不能以辞任再申请绕过；未裁断前全额退赔结案可解除原权限暂停，已经撤任则不恢复。原NPC君主在普通王庭可依真实府库预算委派原府现场调查人，逐年支付劳务，不移动人物或实物；无钱/缺人/原君主失效暂停。固定申辩期限内等待当事人，逾期才按原证据裁断。新旧部将均归返后辞任，会收束待交接的旧轮调记录。案卷显示原当事人、调查人和盟府名称，避免多府盟约混淆。
