# v2.1.1 跨界全量审计

审计方法：搜索所有玩家／NPC 世界写入、统一转场调用、内容路线、空间实例入口、远程任务和 Debug 快照；逐项阅读调用方、提交器、会话恢复、资源与时钟结算。自动清单由 `python tools/check_world_transition_contract.py` 生成至 `build/world-transition-audit-211.json`，包括配置全部路线、移动调用和全部持久字段。自动扫描不是行为正确性的证明，下表是结合玩法语义作出的判断。

## 本轮发现与处理

- 常规永久离界清零威名、裂缝保留全局威名，导致同一玩家因不同入口得到不同追杀结果。统一改为界面／实例分别保存威名，初访零、返访恢复。
- 种族敌意共享 `race:*`，跨界同族可能继承敌意。保留现有活动键以服务战斗系统，但在统一边界归档、恢复各界族群敌意；宗门与家族按真实唯一主体继续留档。
- 妖界、地狱界在情报模块被错误归入第一层，和实际配置不一致。改为第二层，并增加一致性检查；系统战争层级仍以实际配置为准。
- 人界魔修需要初期三层才显示入口，与用户预期的初期即可偷渡不符。前后端统一改为初期一层。
- 未转化玩家随机进入仙界时，可用法力上限直到后续加载才纠正。改为落地立即生效；阶段和进度不重置。
- 转化等待用总年龄差计算，离开仙界的多年也被算作仙界等待。新增离界暂停锚点，返界平移等待起点，保留此前进度。
- 旧的未知界面恢复直接写 `world='human'`，绕过敌意、封印和人员处理。改为明确拒绝，原文件保留。
- 同类失落实例间移动因世界字符串不变跳过提交。地址加入实例，实例指针和威名作用域由提交器管理；进出有限异象同步迁移。
- 跨界计划只检查世界、修为和封印，源地点改变后仍可复用。新增源地点与源实例过期校验，先拒绝再退款／改状态。
- 炼体圆满后仍扣完剩余行动年份，归墟也有相同问题。统一在圆满年份停下；神识逐年真实积累且保留多余经验，无需改成重复乘时间单位。

## 审计后的边界

规范要求新系统遵守统一合同，不表示所有历史子系统已经合并成一份状态机。玩家、NPC、运输、任务有不同的合法执行器；不能为了“统一”让人物移动调用玩家离宗清理，或让远程信息打开物理通道。完整字段分类见 [状态合同](world-transition-state-contract.json)，合并门禁与例外规则见 [开发规范](world-transition-development.md)。

测试应同时检查状态不变项和变更项。扫描器覆盖已识别的玩家字段赋值及 `setattr`，无法证明任意动态插件不存在间接写入；插件仍需人工按合同审查，不能用“扫描通过”替代行为验证。
