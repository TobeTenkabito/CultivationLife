# 固定4258部功法的实战接入

本轮按2026-11-13用户要求实施。固定目录为 `content/techniques.json` 中4258部原书；运行注册表另外含系统功法，不将它们混入4258条设计数量。设计来源为[逐书设计稿](technique-design-4258/README.md)，编译入口为 `tools/compile_fixed_techniques.py`。运行时只解释经过验证的有限数据，不解析描述中的中文，不执行内容脚本。

## 配置与结算

先在原功法页用“战”装备成功，再加入原七部斗法栏。修仙、炼体、神识、变化功法共用七个位置；主修、辅修和专属槽的原培养收益不变。NPC沿原固定书目和 `technique_levels` 取等级，复验实际境界、灵根、肉身、转化与当前世界条件；培养的战斗传授可替换原位置。

炼体效果要求实际肉身，神识效果遵守禁神识环境，变化效果要求本人已有并维持的合法形态。装备变化功法不授予真灵材料、形态或空间；没有原形态记录的NPC不自动抽取变化书占用斗法位置。

低阶固定功法从本人普通法力付款，高阶原书从实际高阶元力付款。玩家复用原MP与战斗结算，即使剧情免除常规战损，主动运转功法仍须付款。NPC在原人物上保存 `ordinary_mana`，原境界、层数和炼体决定本征容量；连续战斗与读档不回满。已知同界经过一年恢复旧容量20%，未知跨界时段不恢复；境界提高只提高容量，不赠送满法力。所有人物独立扣款，不共享队伍余额。

2026-11-13按用户后续要求改用[混合费用](combat-resource-costs.md)：品阶低于本人实际境界时固定扣费，同阶按开战容量比例扣费，越阶为比例加固定。普通配方同阶费率通常为2%—3%；低阶固定法力费用由本书品阶初层本征法力标准乘该费率确定，不随本人最大MP增长。每书每战最多3次；五式轮转最多5次，强度沿设计缩额。Lv.1—9对本次总费用最多减费16%。攻伐、护持和恢复从原始交锋或开战基准计算，同次付款的分包共用一份预算；追加伤害不再触发原始受损、观招和准备链。退款只能来自本书实付，真实减损才允许防御退款，过量致命伤不制造退款。

## 机制覆盖

转赠同伴、分额支援与尸傀护持仍使用施法者的绝对预算，按双方原始战力换算为受益者的态势额度，不借受益者战力放大护盾或恢复。分给多人、多轮兑现与续战共享同一份实付预算；极小护盾按自身额度计算消耗，实际耗尽才触发破盾。快照校验沿用同样的换算与相对误差界限，拒绝伪造转赠额度。

27类原设计效果分别执行：守御返费、同敌隙印、可打断续芽、受损回澜、分期余焰、有限护持、变手身法、蓄雷、重招应对、短效驱散、破持追击、受损分期恢复、攻息择一、弃伤换盾、碎盾反攻、变手雷引、攻息轮换、后手识招、变手净除、先后手择式、重付识招、四向择式、破持回生、余焰换盾、护持后续式、预定下一轮和五式轮转。

12种兑现方式与各道途代价独立组成原书配方。370条具名条款编译为门槛、来源绑定、分额援助、有限监听、顺序护持等操作，或引用共同的资格、回执和预算约束。编译时输出 `build/fixed-technique-clause-audit.json` 供逐条核对。

自动斗法只根据本人态势、真实先后手、实际收据及已见招式选择分支，不预读敌人下一招。每书单独记录付款、成功、冷却、剩余包、过期时间与本场观察。护持耗尽才算破持，自然过期不算；恢复不复活、不解拘禁、不修复肉身；驱散仅限敌方施加的短效普通数值减益，不触碰领域、永久状态或行动资格。收锋窗口若发动终结处决，尚未兑现的本书收益清除。

延迟余焰仍经过原肉身减伤和有限护盾，不能穿过这些防御，也不制造新的原始受损或观招回执。分段道统招式按同一付款回执只观察一次；受损转化在准备时锁定原回执，后续更大伤害不能替换额度。弃攻换盾会取消本次全部普通攻击，包括其他功法的追加；目标离场后的合法未用退款在本轮结束结清。

原功法卡片的长篇说明可就地展开，七部斗法选择仍使用原导航；没有新增系统入口。两套主题沿用各自配色。

## 太元归墟剑

保留原ID `TECH_COMMON_GUI`、品阶、获取方式和原升级入口。剑意按本人的当时普通交锋计算，因而能随元婴至大乘的战力继续成长，而非依赖固定低阶伤害。

Lv.1至Lv.9，下一次同敌攻击的剑意加成为8%至16%；期间实际击破该敌临时护持时，改为12%至24%，两档不叠加。Lv.1费用为：元婴使用支付开战法力容量4%，化神至大乘使用固定55.68点法力，越阶使用为两者之和；升级对总费用最多减费16%。每战最多3次，冷却一个完整轮。仍要经过真实交锋、付费、目标绑定、期限与仙凡资格核验，不增加攻击次数、不免费处决，不因价格公式允许越阶装备。

## 保存与验收

结构仍为12。会话准备仅为原固定书更新 `description` 和 `combat_effect`，保留已学等级、数值、装备和七书名单；当前身体与保存的原身功法同步采用目录元数据。既有种子道统、自创功法以及已开始的冻结战斗不被重抽或替换。新增资源与战斗记录归属见[状态合同](world-transition-state-contract.json)。

测试入口为 `tests/test_fixed_technique_combat.py`，覆盖4258条编译一致性、逐书真实交锋与续战、27类效果非零兑现、12种时序、法力结算、原NPC持久记录、七书配置、升级、超额退款及恶意快照。并运行原功法、战斗语义、跨界与事件回归；浏览器沿原装备按钮和七书栏实际点击，检查两套像素主题、窄屏、过期提交和事件锁。执行结果以本轮实际测试输出为准。

`tests/test_fixed_support_budget.py` 另覆盖跨战力转赠、分额与尸傀支援、部分消耗后的续战、极小护盾破持时机及伪造快照额度。

低阶NPC接入完整结算后，战斗目标同时传递到生死回写：活捉、切磋不因态势归零被提前记为死亡；真实肉身损伤换算为原伤势等级时保留轻伤。普通战役使用普通AI战报标签，实际战死保留战争死因与相关成就结算。

普通攻击及其余焰造成致命败退时，元婴以上NPC仍沿原身魂入口离体；真实禁逃、镇压不会被此路径绕过。原战斗的12%态势撤退阈值、明确逃脱与元婴离体同步反馈原战役退场名册，不能在下一次会战被当作满状态守军重新使用；不改变NPC世界或地点。驻地占领仍须按原规则实际控制并供应五年才结算战果，不提高和约分数或免除军需。
