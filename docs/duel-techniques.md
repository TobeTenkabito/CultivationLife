# 七部斗法功法与人物固定配置

2026-11-13。复用本体功法、人物和战斗入口，不新增 DLC 状态、导航入口或资源池。存档结构仍为12。

## 玩家配置

原 `combat_techniques` 继续承担战斗功法装备及既有属性加成。新增个人字段 `duel_technique_ids` 只引用其中至多七部不同功法，默认空。仅学习、主修或辅修不能代替成功装备战斗功法；原灵根、气等级、炼体、仙灵力和世界资格继续生效。炼体、神识、变身的专用栏不能绕过战斗装备前置。

在原人物详情的“功法配置”中选择或移出，沿 `equip-technique` 命令的 `duel / duel_remove` 操作提交。服务端复验资格、唯一性及七部上限；未处理事件、试境战斗、囚禁或死亡时不可调整。满额、重复、资格失效和过期页面提交不会替换已有书目。移出不遗忘功法、不撤下原战斗配置、不退还材料。

新效果投影只读取所选七部，重复引用不重复生效。跨界、气等级或肉身资格变化使不合格功法暂停效果，保留名单和占位，返抵且资格恢复后重新生效。夺舍沿原肉身快照保存配置，宿主不借用原身书目；恢复原身时恢复相应配置。

既有普通属性、已创功法规则和战斗其他能力沿原系统处理。本次不代表4258部专属效果全部启用；无额外效果的书在选择时提示，低阶普通MP适配仍在后续范围。

## NPC 初次配置与固定

`SectNpc.duel_technique_ids` 的 `None` 表示尚未初始化，空列表表示已确定无书；原 `technique_levels` 记录所学书目和等级。初次可见人物在会话准备时落到原存档；随机相遇在原人物缓存生成/重遇时登记，尚未接触的参战者在公共战前能力准备入口登记。后续读取投影不抽书、不改状态，不创建另一份人物。

选书只用真实境界与灵根，不用对玩家展示的伪装修为。功法品阶不得高于实际境界，同时遵守世界、炼体及仙灵力资格。优先保留已学且合法的书，随后从普通取得目录补足，优先本道途及较高合法品阶，允许高阶人物使用低阶书；专属受限来源和双修书不随机赠予。没有记录灵根的剧情人物只选无属性且无额外灵根门槛的书，不赋予虚构灵根。关系映射沿 `PERSON_FIELDS` 引用同一名原人物，不另存配置副本。

随机流仅从原人物ID派生，不消耗游戏、名字或战斗随机流。再次见面、交战、读档、自然突破都保留已定名单，凡人后来突破也不自动补书；这是“见过的人物固定”优先于重新按境界配书的明确规则。培养入口可提升原书等级，明确传授到战斗位时替换该位原选书，满额时替换末位，不重抽其他书。现有培养按钮默认传授类别不变。

新字段不用于透露隐藏境界；未识破修为时公共投影去除斗法ID及所学等级明细。未观察的派驻人员、异界/其他空间人物不借此提前初始化。
