# 仙脉机缘费用与历史校准

> 维护基线：本体 v1.57.0 开发源码，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名保留历史编号以维持链接；历史采样不是本轮实测。

本次修复的核心是三脉贯通后的手动冲关仍收旧体系高额费用。玩家反馈每十个行动单位收入约十八万，而真仙首层手动冲关要求一百八十万，单此一项就需一百个单位、一万年，且还要另付开脉费用。

现在真仙首层手动冲关降为一万八千；前三脉合计两万七千，一次成功的总费用为四万五千，按反馈收入相当于二点五个行动单位。将开脉失败及保底纳入后，前三脉期望费用约三万一千五百，另加一次冲关为约四万九千五百。这里没有承诺二点五个单位一定升层：仙痕积累和手动冲关失败还须另计。

开脉费用由 `60000 + 30000 × 已开总脉数` 调整为 `6000 + 3000 × 已开总脉数`。总脉数按真仙起的四个大境界连续计算，每境二十七脉；仍是线性递增。报价不随玩家当前装备和效率浮动，提升功法与收集增益仍能缩短积累时间。

| 境界 | 首脉机缘 | 末脉机缘 | 含失败保底的二十七脉期望消耗 |
| --- | ---: | ---: | ---: |
| 真仙 | 6000 | 84000 | 约 238.3 万 |
| 金仙 | 87000 | 165000 | 约 613.7 万 |
| 太乙 | 168000 | 246000 | 约 989.0 万 |
| 大罗 | 249000 | 327000 | 约 1364.4 万 |

以下积累年数为 v1.51.2 历史校准，不是当前收益预测。当前仙痕概率已提高到 15%。当时基准是真仙快速开局的配置：每年潜心修炼直接收入平均约 106.99 机缘，一百年约 10699；每次正向机缘获取有 7% 概率获得一道仙痕。四境使用同一初始修炼效率进行对照，不把后期升级功法的收益提前算入预算。

原来真仙二十七脉的期望机缘消耗为约 2383.3 万，仅靠直接吐纳收入要约 22.28 万年；同一批开脉尝试所需仙痕约 1681.5 道，对应约 2.40 万年的正向获取次数。调整后机缘积累时间约 2.23 万年，与仙痕积累接近。其它三境两种积累时间的比值约为 0.960、0.968、0.972。

以上是资源预算的期望比较，不是实际通关时间预测：未计事件、额外来源、已有余额、其它养成开销、突破失败或劫战。真实游玩也会受功法与灵根等因素影响。仙痕费用、失败消耗及保底概率均沿用现有规则。

三脉贯通后的手动冲关采用独立费用，不再复用旧境界的机缘进度基数：

| 境界 | 原首层冲关机缘 | 新首层冲关机缘 | 新第九层冲关机缘 |
| --- | ---: | ---: | ---: |
| 真仙 | 180 万 | 18000 | 35280 |
| 金仙 | 900 万 | 90000 | 176400 |
| 太乙 | 4500 万 | 120000 | 235200 |
| 大罗 | 2.5 亿 | 150000 | 已达境界上限，不再冲关 |

每层加基础费用的 12%。金仙及以上一次修炼时间为五百年，因此金仙基础费用按真仙的五倍衔接，随后平缓增加。费用由内容配置集中定义，界面与实际结算统一调用。小境界失败仍保留费用的 72%，原有概率与适用层级的保底不改；真仙升金仙仍要求二十层仙躯并经历人五衰。上述二十七脉预算表只计开脉，不包含这些独立冲关费用。

旧进度基数仍用于原有百分比奖励等计算，以免降低费用的同时削减收入；下界及未采用专属养成的其它三级界面继续使用普通门槛；修罗显圣启用后的魔修上境另用对齐仙界的冲关费用。

受支持的结构 6／7／8 存档读取当前报价，已开脉和累计失败保底保留，不扣除已有余额，不回溯退还历史消耗。校准脚本使用临时存档，不触碰玩家存档：

```powershell
python -X utf8 scripts/calibrate_immortal_veins.py
```

期望尝试次数通过逐次累计“前面全部失败”的概率计算，每层的失败保底最终达到必成；每次尝试都计入机缘和仙痕费用。
