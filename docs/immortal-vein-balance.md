# 仙脉机缘费用与校准方法

维护基线：本体 1.58.0，存档结构 8。

开脉机缘费用为 `6000 + 3000 × 已开总脉数`，总脉数从真仙起的四个大境界连续累计，每境二十七脉。报价不随当前装备与效率浮动；每次尝试同时按正式报价消耗仙痕，失败保底沿用配置。

三脉贯通后的手动冲关使用独立费用：

| 境界 | 首层冲关机缘 | 第九层冲关机缘 |
| --- | ---: | ---: |
| 真仙 | 18000 | 35280 |
| 金仙 | 90000 | 176400 |
| 太乙 | 120000 | 235200 |
| 大罗 | 150000 | 已达境界上限 |

每层增加基础费用的 12%。费用从内容配置读取，界面与结算调用同一规则；小境界失败保留费用的 72%。真仙升金仙仍要求二十层仙躯并经历人五衰，养成费用不能替代这些资格。

普通机缘进度基数继续用于百分比奖励等计算；下界及未采用专属养成的界面使用普通门槛，修罗 DLC 启用后的上境魔修采用对齐仙界的费用。结构 6／7／8 的已开脉与失败保底保留，不回溯退还已消耗资源。

```powershell
python -X utf8 scripts/calibrate_immortal_veins.py
```

脚本使用临时存档，按逐次失败概率计算期望尝试次数，并计入每次机缘与仙痕成本。当前数值必须基于当前配置重新采样；预算期望不等于通关耗时，还需计入仙痕来源、修炼效率、其它养成和劫战。
