# 空间裂缝、符箓与失落界面

适用本体 **1.59.2**。本体配置见 `content/world.json`；分阶符箓见 `cultivation_life/talisman_content.py`；失落界面人口规则见 `cultivation_life/system/spatial_population.py`。

## 符箓与交易

左侧“符箓”打开独立工坊。先选阶数、学习本界制符法，再选同阶的两份符材和注灵属性。每个界面按现有阵法、傀儡的阶段范围生成配方：一级界面一至五阶，二级界面五至八阶，三级界面九至十二阶。每阶七种组合：三种单项强、三种双项强、一种三项强。成品及材料名称均带中文阶数。

仅能使用当前界面与配方同阶的符材；携带外界材料不能在当地炼制。独立空间按本实例生成符材和配方，探索可取得，不能从外界市场或商盟获取。旧版护身、破敌、三元制符法对应人界一阶配方；旧符纸和朱砂可在人界作为一阶材料使用。已有成品保留原属性。

自行注灵须有对应灵根并扣法力；可请本界自由、友善且灵根匹配的 NPC 注灵并支付灵石。两份同名材料扣两份。成功率复用百艺制符经验：等级、当前等级内的经验越高，成功率越高；高阶配方更难，最高 98%。成功和失败均扣材料及注灵消耗，分别获得每阶 12、5 点基础制符经验，适用百艺经验加成。随机结果与随机状态一同保存。

品级为下品、中品、上品、极品，影响三项属性及总次数。战斗维度仍只有 `power`、`protection`、`assistance`、`uses`，阶数、品级、产地和制作者是分类与来源信息。新符默认停用；战斗开始按威力、防护、辅助调用，每个被调用的非零属性扣一次，单项加成最多 8%。预览不扣次数，进入裂缝才消耗防护次数。

坊市独立符材货架供应本界当前可用阶数，支持锁定一件；坊市可出售成品。黑市可检索并购买本界符材、成品符箓，也可出售成品。报价冻结品级、四维和次数，批量购买的每件成品有独立 ID。成品估值统一取决于品级、投入材料价值、三项属性和剩余次数，耗尽的成品不能出售。坊市回收为估值的 55%，黑市沿用其回收比例；出售立即移除唯一实例，不能重复出售。

商盟新增符材提交任务和符箓炼制任务；后者必须在接单后亲自制成，保留完整次数且停用后交付。玩家可委托收集符材或委托本界工坊炼符。代炼预览包含配方、品级及四维，交付严格按报价验收；代炼不增加玩家制符经验，不可冒充亲制品交任务。符箓跨界代炼不可发布。

## 地图中的空间裂缝

元婴初期（四阶）之前服务端不提供裂缝信息，直接请求进入也会被拒绝。裂缝显示在地图区域内的对应地点卡片中；只有身处该地点才能进入。同一地点也可同时有多条。

普通空间每 120 年以 55% 概率刷新一至三条，同时最多六条；每条持续至少 800 年，且覆盖最长行动单位再加 100 年。生成时有 35% 概率成为“空间节点”：跨界 80%、秘境 10%、本界落点 10%；普通裂缝的比例依次为跨界 30%、秘境 25%、本界落点 45%。去向在进入时结算，节点只是更可能跨界。

护持评分为符箓防护 × 0.65 + 随身阵法生势 × 0.35。以已消耗生命周期比例 t 计算当前要求：基础要求 × (1 + 3t³) + 25t³。越接近崩溃要求越高，最后四分之一寿命标记“濒临崩溃”。界面预览和进入判定使用同一函数；不足立即死亡。自行开辟的裂缝初始要求为零，但同样随衰变变得危险。

化神后期可消耗四分之一法力上限自行开缝。秘境每隔 160 年有 35% 概率重开出口，也可能多次不开。通道为单程，跨界不检查通常飞升资格；落地后仍判定界面排斥。本界随机落点忽略普通地图的境界准入风险。

## 独立空间与三种上限

不世秘境独立于界面层级，修炼收益六倍，魔修免自然修炼折损；保留寿元、魂蚀、突破和雷劫。失落界面为零级，首次抵达才生成，之后保存；未占用的实例暂停模拟。

失落界面的三个概念独立：

| 规则 | 当前生成方式 | 对玩家的影响 |
| --- | --- | --- |
| 界面之力承载范围 | 60% 为大乘后期九层；40% 随机为化神、炼虚、合体后期九层 | 超限道果会排斥至对应上界；不按资源或 NPC 上限降境界 |
| 当地修炼资源上限 | 另行随机资源支持的境界后期，不超过本实例界面之力上限 | 抵达较低上限后不能继续当地修炼或冲关，已有更高境界保留 |
| NPC 初始生成上限 | 独立人口规则，受界面之力约束；普通人口以修炼上限为基准，12% 的界面降至元婴至修炼上限之前的境界后期 | 仅限制初始人口，绝不削减玩家境界；匮乏界面自然修炼收益为 35% |

NPC 人口使用保存的生成规则：领袖达到普通人口上限，其余修士按权重偏向低境界。生成规则允许单个 NPC 以 5% 概率超过修炼上限若干层，但必须仍处于同一大境界且不超过界面上限。若修炼上限已是后期九层，则没有超出空间，例外概率为零；当前失落界面正是这种情况。人界“化神初期可修炼、化神后期可生成 NPC、化神后期可承载”说明三个上限不能混用；本轮没有重抽既有人界人物。既有实例不重抽、不改变原有人物。名字使用共享扩展姓名库，同一新实例内去重，无数字姓名。宗门招募、随机相遇和生成关系人物复用该名字库。

快速开局新增“奇遇开局 → 失落界面”，先选六种道途之一，妖修另选种属；以结丹初期进入按种子生成的独立世界。各道途配置对应功法，元婴以前无法感知裂缝。每个实例生成四个不重名地点、完整连通路径、地形及四种正数气源与气经验效率；界内移动耗时一年，修炼使用当前地点效率。显示、结算和读档复用同一份保存数据，旧地点缺失或无效的气字段采用明确默认值，查询不改写存档。

失落界面可探索、拜宗、交流与委托当地 NPC 注灵。人物接入统一权威 NPC 注册表，实例只保存 npc_ids；旧内嵌人物在模型装载时转换为引用。人物仍会衰老、经历雷劫；外界人物、市场、商盟等交互由服务端隔离。空间内允许个人修炼、制符、随身物品、功法和阵法操作。妖修血脉蜕变保留入口，并遵守本地修炼上限；进入独立空间后不生成外界坊市货源。

## 界面排斥

人界自然修炼仍止于化神初期。未压制的化神后期道果显露超限力量时，按道途排斥到对应上界；真正压制至化神后期以内可停留。二级界面承载大乘后期；零级失落界面按首次生成并保存的承载范围判定排斥，可能低至化神后期。收敛气机不能代替压制。失落界面的低资源上限仅限制继续修炼，不强制降境界，也不改写此处独立生成的界面之力承载范围。

在普通界面，九阶真实道果且已秘法压制至八阶九层以内，可定向重访失落界面或随机生成新界面。独立空间内不能借“下界”绕过裂缝出口。控制台修改境界也经过排斥，只作用于隔离副本。

## 开发与工具

`system/talismans.py` 管理炼制、统一估值与消耗；`talisman_content.py` 为无引擎依赖的确定性目录。`system/spatial.py` 管理实例、可见性和衰变；`spatial_population.py` 生成独立人口规则；`world_boundary.py` 决定排斥。通过冻结的 `ExplorationDependencies` 接入正式流程，没有新增 Mixin。不得把实例专属物品、功法或符材加入外界全局货源。

只读预览不能消耗随机数或符箓。新交易入口必须复用估值并校验所在地、存活、事件、拘禁和实例隔离。修炼资源上限须同时接入手动突破与自动推进；不能写成修改玩家境界的读档补丁。

```text
game view /talismans
talisman action learn talisman_human_1_protection
talisman action craft talisman_human_1_protection talisman_human_1_paper talisman_human_1_ink metal
game view /spatial
spatial action enter rift_1
spatial action explore
spatial action descend lost_2
```

交易使用具名参数，例如 `{"command":"talisman action","arguments":{"action":"sell","talisman_id":"talisman_1"},"session_id":"..."}`。商盟和黑市复用 `merchant preview`、`merchant action`、`black market sell`；参数名与正式 API 一致。修订号、幂等键约定见 [Debug 开发规范](debug-development.md)。

回归入口：`tests/test_spatial_talismans.py`、`tests/test_talisman_economy.py`、商盟与交易测试。浏览器：`tests/browser_spatial_royal.py`。Android 签名包另验 `spatial-talisman` 横竖屏，不能用源码测试替代二进制验收。

## 1.59.2 规则与开发契约

- 符材基础价为 `round(6 × 3.2^(阶数−1))`，再乘材质倍率；成品另计 `24 × 4^(阶数−1)` 的制作价值，合计乘 0.85、品级倍率、属性倍率与剩余次数比例。材料降幅大于成品。旧货架按新目录重估，旧成品保留属性，仅在估值时换算材料成本。
- 魔修未炼化元神占用同时容纳名额：炼气 0、筑基 1、结丹 2、元婴 3，此后每个大境界加 1。阈值内不会产生年度元神反噬；超额 n 道时年度概率为 `min(95%, 2.5% × (2^n−1))`。已炼化元神不占名额；强度仍影响伤害。普通行动、闭关与独立空间年度结算复用 `demonic/soul_risk.py`，查询不抽随机数。
- `spatial_capabilities.py` 明确列出独立空间可用的个人操作与面板。“缘”支持当地人物交往；人物访问必须检查实例归属，相同 lost 世界代码不表示同一空间。实例只保存 NPC ID，禁止再维护人物快照。
- 个人炼魂、炼器、灵田、本命法宝、鬼修拘魂附灵和轮回、妖修血脉、儒修内圣外王等沿用各自开启条件与正式操作。失落界面另开放当地儒教学说和佛修寺院法会。学说与信众网络以实例 ID 分域，不复制外界学派、寺院或人物；年度推进只结算当前空间。突破类道途能力仍检查当地修炼资源上限。
- 归墟之潮、巧夺天工的固定世界探索入口、外界市场、商盟和机构保持隔离。当地师父仅赠送本实例材料与功法。
- 专项回归见 `tests/test_update_1592.py`。浏览器与 Android 签名包的 spatial-talisman 检查覆盖黑市成品购买和失落界面人物交往；源码测试不能替代二进制验收。
