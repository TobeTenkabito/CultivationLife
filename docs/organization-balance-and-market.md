# 势力收支与本地市场检索

本轮只调整既有消费与显示入口，不新增人物购物循环、年度商品扫描或财政账户。结构10既存存档从下一次正常结算采用新规则，不追扣历史府库，不转换旧结构。

## 收支原因与数值

原门内产能为 `Σ人数×(60+60×境界³)×5^(界面层级−1)`，基础供养却仅为 `Σ人数×(25×层级+8×境界²)`，高境界／高界的差距不断扩大。产业扩建的年度维护也未随界面提高。此外，供养请求受高阶实货价格和当地供给限制，预算不会保证花完；玩家控制的组织不自动投资，积累比自主组织更加明显。生产收入已经扣除配方原料和生产劳务，不能再按毛收入重复扣这些费用；产权仓储与投产工料另在原产业账本结算。

自动经营原先只验证报价毛利，没有验证当前收购现金与同类库存；受托产业未售出成品时也可能沿用旧配置继续开工。新增规则在既有规划／投产入口检查至少5%工料利润、本批收购毛额不高于当前经销商现金、本批数量不超过目标库存1.5倍后的缺口。受托产业有未售成品时停止新采购投产，继续尝试出售；售清后再规划。手动开工仍允许玩家承担未来市场变化和囤货风险，原限价、仓储欠费、真实工资与原料支付不变。

基础供养改为 `Σ人数×(25×层级+8×境界²+境界³×层级)`。65%仍支付基本服务、其中15%进入原研习津贴账户，35%仍作为实物供养额度。固定维护的界面倍率仅1／2／3，避免把生产1／5／25倍直接变成不可承担的刚性账单；大额经营开销随实际盈利承担。

在基本养护、旧家族债务及外姓工资之后，经营盈余的40%预算用于阵法运转、共用设施和事务劳务。实际支出最多为府库扣除三年65%基本养护储备后的可用现金；亏损时为零，不以旧府库余额为计费基数，不形成新增家族债务。额外供养可使用剩余经营净盈余的40%（原25%），实际采购才扣钱。供养占比随新增经营服务同步提高，防止高阶法宝采购因预算受挤占而失去可行性。家族主动经营使用同一经营养护入口；重复同年经营仍由原入口拒绝。

产业扩建年度维护从 `100×(等级+1)` 改为 `100×5^(层级−1)×(等级+1)`，仅扩建等级大于零时支付，先保留既有境界统计对应的三年（或较长结算区间）基本养护现金；少付仅按支付比例缩减扩建提供的额外产能，原基础劳动继续生产，避免零府库导致永久无法恢复经营。基本修炼、玩家福利规则、战争实物后勤及原有限市场付款保持权威入口。

组织产权亦使用同一经营养护规则：原组织财务记录新增一个非现金的 `estate_cost_credit`，累计实际已付产权原料、劳务与仓储开支，销售到账先收回这些成本，只有新增净收益支付经营养护，并为下期实物供养留出剩余净收益的40%。一个原府库仅一个成本余额，组织内部产业间移交实物不丢失成本；成本已支付才记账，未付欠费不提前抵扣。首次采用只登记既有未收回成本，不追扣旧利润，不把成本余额当现金。个人或商盟产权不额外收此组织经营养护。

财政面板新增经营养护实付及储备说明，组织净经营收益包含产权收回成本后的净收益。产权完整工料、销售、仓储仍在原产权账本，地方维护在地方账本，各账本使用同一原组织府库；跨账本的经营养护是同一笔支出，不能再相加扣款，也不能将单个账本的收入−支出当作整个府库变化。

## 显示与检索

坊市提供精选货架／本地市场两个页签；地图保留本地市场页签。两入口搬移同一个 `local-market-content` 节点、共用当前权威地图投影、交易修订号和原 `local-market-trade`，不重新结算、不复制库存，搜索与数量在同一玩家同一市场之间保留。换玩家或市场清空查询。隐藏页签按原导航延后构建；忙碌及不可交易状态仍禁用按钮。

默认按名称文字查找，开启正则支持 JavaScript Unicode、不区分大小写匹配，表达式上限80字符。正则在同源 Web Worker执行，匹配阶段250毫秒预算、启动阶段3秒上限；格式错误／超时关闭该次结果，不回退成意外文字匹配。输入180毫秒防抖，重输入、更新权威投影或切换玩家终止旧任务并丢弃旧结果。搜索不写档、不改变行动时钟或随机序列；购买仍校验当下原余额、库存、权限、报价和过期页面。

## 验证

`tests/test_organization_balance.py` 覆盖经营储备、亏损／空府库不扣费、现金守恒、存读档、控制宗门三界百年事务预算和同年不重复结算。`tests/browser_local_market_search.py` 覆盖四主题桌面／手机布局、道途切换隐藏、两入口切换、搜索错误与回溯超时、真实搜索后购买、只读切换和页面宽度。既有经济、家族、传承、事件与导航回归继续执行；长期测量是固定名册的独立经济对照，不代表完整游戏百年或实体安卓耗时。

本轮领域与跨界回归共422项通过，10个不同的浏览器验收程序通过（含事件真实加载／提交、产权经营、组织财政和新增市场搜索）；跨界状态契约、模块依赖、文档检查全部通过。新入口覆盖四主题的桌面与手机宽度，正则回溯超时后仍可恢复普通搜索并真实购买。验收日志保存在本地 `build/economy-ui-final-tests.log`、`build/economy-ui-browser-report.json`、`build/local-market-search-browser.log` 及最终组织／产权浏览器日志。

固定名册、种子315、逐年推进100年的经济对照中，灵界五宗门期末府库中位数从1,865,897降至678,654灵石，三界百年对照均无基本养护欠付；控制宗门的三界百年测试亦保有至少三年基本养护的事务储备。这个结果用于检查积累速度和恢复能力，不是对所有存档的固定收益承诺。固定高阶名册延长到千年时，部分自主宗门仍会出现阶段性缺口，尤其是偏远市场；后续调参应结合真实人口变动、战争与当地供给，不应仅为保证所有组织永久盈余而继续提高产量。

同一初始存档、Edge 155.0.4283.45、灵界大乘、九项DLC开启，各进行3次真实页面百年修炼：当前代码端到端中位耗时6.53秒，经济改动前对照7.43秒；接口中位耗时分别5.67／6.04秒。对照仅在进程内载入Git HEAD的六个经济模块，其他代码及页面保持相同，不代表旧版整包。样本少且有一次较大波动，只据此判断未观察到本轮规则增加明显开销，不宣称固定加速比例，也不外推安卓设备。原始报告为 `build/balance-performance-current.json` 和 `build/balance-performance-before.json`。
