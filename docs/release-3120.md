# 3.12.0 探幽寻宝与同行博弈

本体3.12.0，Android版本码106（3.12.0-android.106）。存档继续仅支持结构12；结构1—11拒绝加载与导入，不迁移或覆盖。十二个DLC随包提供，独立版本与配色保留。

- 主界面“探幽寻宝”接入种子副本，替换原普通寻宝。各地图使用独立参数，入口、事件与奖励在生成时冻结；每地探索次数有限，各界分别限制传奇生成次数。
- 普通、稀有、史诗、传奇四档品质。史诗与传奇引来多方宗门争夺，传奇奖励按本界顶阶定标；高阶参与者按实际界面法则压制。
- 双入口信箱和未读提示接入NPC邀约；威名与凶名分开，威名参与同行评价，凶名承担杀戮代价。
- 补齐威名事件条件的权威读取，修复普通行动遇到威名判定时的请求错误；Android同步支持副本危险配色中的变量回退混色。
- 调试工作台接入副本操作，使用正式探寻与结算入口，保留地图、修订、冷却与原存档隔离约束。
- 同行修士可途中加入、离队、交易、翻脸与互相争夺。队伍状态、具体博弈数值和“实证／据说／听说”日志同步呈现沿途线索。
- 随机传承接入原学习及升级入口；六道途十二阶万能玉简按界面层级流通，可合成并升级对应传承。遗宝共鸣及灵药收益采用有限预算。
- 修复副本带出物品的详情、服用与研习按钮，以及战斗窗口被副本覆盖的问题。副本布局适配桌面和横竖屏，四档品质使用不同配色。
- 炼体、神识、变身功法用于各自专属修持，修仙类功法参与直接斗法。已学功法与培养成果保留。
- 重写4258部固定功法正文，同步校正秘术来源书、随机传承、自创书及战报用语；副本新增526条地形、事件、举止、势力冲突、传闻和命名素材。

本次发行执行完整发现的全仓回归、开发合同／依赖／文档检查、真实浏览器操作、同一Windows EXE有／无DLC验收，以及签名Android 12横竖屏原生验收。最终数量、源码指纹、包哈希与设备范围记录在Release附带验收清单。APK包含arm64-v8a与x86_64；原生操作验收使用专用Android 12模拟器。

安装包、更新说明、验收清单和SHA-256校验文件发布于[GitHub Release v3.12.0](https://github.com/TobeTenkabito/CultivationLife/releases/tag/v3.12.0)。正式包位于Release；根目录启动器为此前的本地试玩版本。

规则与历次实施记录见[副本实施](seeded-dungeons-implementation.md)、[策划验收](seeded-dungeons-acceptance.md)、[功法斗法](duel-techniques.md)及[发行流程](release-workflow.md)。
