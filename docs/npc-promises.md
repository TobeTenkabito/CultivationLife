# 故人笺要求承诺与凤仪亭

2026-10-29 源码增量。本体功能，沿用结构11、故人笺及全局功业录，不更改发行包。

## 操作与资格

缘界面故人笺新增“要求承诺”，展开指定交战目标及“确认约战”。人物好感达到原 `friend_affinity_required` 门槛后可要求；同一人物每个原 `diplomacy_unit` 最多履行一次，读档、切页、换地点不刷新。

双方须为已知、存活、自由、同界同实例且位于同一实际地点的原人物；地点来自原人物地址或实际所属势力驻地的只读解析，不猜测未知地址。被囚、持有任务／部署／访学行程者拒绝。不同地点须实际会合后再约战，本功能不创建迁移或远程击杀。原道侣、师父、道友、弟子及当前正主可按原编号列入重要人物，不生成替代人物。

本次为同地点即时交锋，玩家与两名NPC均不移动，经过年份为零，无额外钱款。双方使用原战力、装备与战斗资源，目标均为致命交战；承诺不保证胜利。沿共享 `resolve_local_engagement` 与 `resolve_npc_engagement`，保留普通交锋、邻域、金光、语义效果、伤势、镇压及元婴逃体规则。新增目标参数默认仍为原驱离，既有调用不改行为。实际死亡再经 `kill_person` 同步原人物、关系和队伍，击杀不向玩家发战利品或个人击杀计数。

服务器在投骰、缓存人物正式登记、资源扣除和保存前重新校验双方及行动单位。过期、非法或忙碌请求不消耗次数；成功交锋无论胜败均记录本单位已履行。HTTP、Debug及按钮均走 `contact_action` 原单档请求锁，不另开结算入口。失败页面复用原 `mutate` 的一次权威刷新，禁止自动重发。

## 凤仪亭

本体成就“凤仪亭”：要求承诺时玩家确为他人侍妾，受托者为当时的真实道侣，指定目标为当时的真实正主，并在该场交战中实际杀死正主。按原人物ID和共享战斗的真实死亡清单核对，不按姓名、旧关系、胜利文本或肉身崩毁推断；元婴逃脱、仅负伤或镇压不算。双方同归于尽时，只要真实完成斩杀也算。无须玩家亲手攻击。

确认正主真实死亡后解除原侍妾状态；成就事实记录在原 `milestones.fengyi_pavilion`，随个人历史跨界保留并全局只解锁一次。既有随机NPC斗法和旧死因不回填这个玩家促成的成就。

## 状态与验证

不新增Player/GameState顶层字段。原 `governance_actions.npc_promise:ID` 为个人单单位使用历史；原交战历史保存双方ID、真实死亡／镇压及最多8轮实际结果；归属已登记字段合同，无新NPC、资源池、时钟或跨界例外。

专项：`tests/test_npc_promises.py` 与 `tests/browser_npc_promises.py`。包含真实加载／提交、原人物死亡及元婴逃脱、身份反例、界面／实例／地点与拘禁资格、过期及重复请求、后续奖励、忙碌解除、四主题与桌面／手机横竖屏。关联检查使用故人笺、NPC战斗生命周期、侍妾、成就、模块依赖、跨界和旧事件专项及三个项目门禁。
