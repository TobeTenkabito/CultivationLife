# 浮生问道 v3.15.0 · 诸宗会商与故人来信

- **本界宗门名录**收录各族山门，入宗前后均可翻阅。宗门可以改换盟书，创始人与门人保留各自血缘。尚未登场的山门按需加载。
- **诸宗会商**可议荐徒名额的轮分、主办和调让，也可筹议同地宗门之间的周济。议簿记下各宗回函，周济成议后由出资宗门府库交割。
- **修士游历**为 44 位固定人物安排了开局地图。自由活动的修士会沿本界道路游历，择地受境界和路程约束。
- **修士来信**共用原有信箱。写信时可选「询问行踪」或「邀请同行」。故人笺显示当面所见或上次回信提到的地点，旧信保留当时的年岁和落脚处。

Windows 本体 v3.15.0，Android 版本码 110，存档结构 12。万妖归宗 DLC 更新至 4.21.0。发行资产包含 Windows 包、签名 Android 包和两端验收清单。Android 原生验收设备为 Android 12 x86_64 模拟器。
