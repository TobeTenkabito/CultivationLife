# v3.2.4 猎杀妖兽形象

猎杀按钮的权威名称表仍在 `content/world.json` 的 `hunt_beast.combat.target_names`：裂岩妖狼、青翎灵鹫、噬金妖猿、碧甲刀螳，四项等概率。此次核对未发现重复词，保留原难度、奖励、时间和随机结算。

此前三类通用形象无法准确表示四个名称，尤其妖猿使用四足兽。现在 `combat_visuals.beast_asset` 精确匹配四个专属资源；未知名称沿旧类别回退，旧战报引用的通用资源继续有效。复用共享形象选择与战报快照，不新增人物或存档字段。妖猿立绘为双臂双腿猿形，近战时序复用已有近战兽类；不改真实命中。

四种各有八张绘制姿态（待机、蓄势、出击、收招、防御、受击、退避、倒地），共32张，以及各自立绘、头像和缩略图。原稿及完整提示词在 `design/hunt-beasts-20261029`，由内置 image_gen 生成；`scripts/prepare_hunt_beasts.py` 仅分离透明原稿、等比缩放和排图。离线资源、来源与哈希在 `web/assets/pixel/hunt-beasts`。动作沿既有接触时钟采样，无新增伤害或随机数调用。

发行范围包括此前源码更新的人生故事／玩梗成就、历史人物皮肤及专属特效、圣诞雪花关键帧。存档结构仍为11，版本3.2.4，Android版本码87。使用 `scripts/verify_scoped_release.py --profile soul-lifecycle` 的领域与上游回归，并加入猎杀、历史皮肤及故事成就测试；实际猎杀点击覆盖四种妖兽及窄屏，Windows有／无DLC和签名Android12横竖屏验收对应最终源码。最终通过证据以本版本发行清单为准。
