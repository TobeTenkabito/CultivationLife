# 3.8.0 王庭与地方军政

本体3.8.0，修罗显圣：无法无天1.5.0，Android版本码102。仅支持结构12；结构1—11拒绝加载、导入，不迁移或覆盖。瑶池西望及其他DLC版本与配色保持各自定义。

## 玩法与归属

本体提供原机构任职、地方权责、具名案卷、原人物驻军占用、军饷托管、道路与真实归返、唯一王位交接。修罗规则复用这些入口，详细范围见[总督府](asura-governorship-implementation.md)、[派系与地方争议](asura-politics-and-disputes.md)、[驻军与争位](asura-military-and-succession.md)。原世界、原人、原建筑、原资源账户唯一；不新增复制军队或远程传送。

总督府接入原建筑；派系、中央军令在原王庭，地方事务在原府务。三派利益、具名支持、六类原账争议及真实驻防相互衔接。起兵撤销法定职务但保留地方责任；到达王庭、击破守备及实际对抗旧王分别结算，不能凭占城自动登位。

## 本轮修复

- 联合守备不再截取前六人，后列高阶修士仍须实际参战。
- 据点失利只召回该处实际参战者，同府异地未参战部众保持原驻防。
- 调兵地图服务恢复原装配约定，在使用时读取当前服务，避免缓存旧对象及破坏独立回调适配。
- 对抗测试覆盖合并守备、跨地驻军、人数与境界、原款守恒、重复／过期请求、停用收尾和王位唯一交接。
