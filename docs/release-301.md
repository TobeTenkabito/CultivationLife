# 3.0.1 形貌与修行

本体3.0.1、Android版本码81、万灵争衡DLC1.0.1。结构仍为10，不兼容结构1–9。本次按用户要求仅验证修改领域及必要关联，不执行全仓回归。

## 规则与结算

3888部通用功法使用独立系列名，功法ID、等级、能力和获取渠道不变；旧持有记录沿已有目录同步入口更新名称。共享姓名池增加复姓与双字名，既有人物姓名不重抽。

凡俗无灵根炼体事件的寿元上限按道途区分：普通300，妖修900。该入口不会降低已有寿元。侍妾年度入口不再扣除机缘；获取效率80%与原突破奖励仍保留。元婴以下妖修仅接受妖修发起的纳妾请求，提交时复核，旧提议不能绕过。

普通炼体等级0–100沿既有修行坐标匹配境界及层次，战力贡献为同层标准的80%；凡俗0–3层仍按每层8计。该贡献进入原combat_power及真实BattleUnit，不消耗法力，按气血比发挥；不授予修为、领域或跨界资格。

## 形貌与界面

人物详情皮肤入口提交原请求事务中的character-skin命令。Player.character_skins只保存已解锁素材编号与当前选择，归属personal；真实境界、封印原始境界、已走过的血脉节点决定解锁。查询不投骰、不推进时间；加载协调器保存新解锁记录。关闭DLC时保留编号但隐藏不可用形貌；寄身、附身、变化期间使用既有形态且禁止换肤。跨界保留皮肤，不改位置、物资、NPC与实际战力。

本体新增元婴／合体、道修／魔修、男女8套人物；24张静态图、80个关键姿态、56组动作。初阶本体4人补齐12张头像／立绘／缩略图。动作沿现有回放时序使用关键姿态与运行时动效，并非每帧单独绘制。第一版衣褶、站姿优先，缺脚只局部补鞋，元婴道修女性按最终确认保留裸腿。

素材运行目录为web/assets/pixel/characters-301，清单在content/visual_assets.json；离线导出脚本为scripts/prepare_character_301_assets.py，采用的内置image_gen提示词与原图在design/characters-301/adopted-prompts.json及同目录。运行和发行不依赖design目录。

宗门头像使用该名册已公开身份，避免被其它列表投影覆盖；原版界面也显示，DLC人物注册表按需加载后补绘。妖修DLC2保留生息、氏族、王庭、史志四页导航，增加概览与栖地并列布局；远方仍只读历史，所有操作复用原资格、费用、修订号及失效页面恢复。
