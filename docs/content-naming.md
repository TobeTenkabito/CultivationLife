# 物品与功法命名约定

本次检查本体与已安装官方 DLC 的固定目录、归墟宝物、十一界经济成品、傀儡部件、符箓及神机命名入口。保留已有成形的器名和药名，调整境界拼接、功能直译、重复套词与不通顺的名称。

## 命名规则

- 功法以道途、修持意象和传承文体命名，不用当前适用境界代替书名。秘术效果写入说明，名称不直白罗列夺舍、寄生或使用次数。
- 法宝、装备保留可辨认的器形，如剑、甲、鼎、舟；灵材结合材质、来源和意象。丹药不强行嵌入元婴、化神、大乘等使用门槛。筑基丹、洗髓丹等已成形的常用药名保留。
- 同一植物及种子采用一致名称。品阶、境界限制、用途与数值仍由独立字段、标签和说明表达。
- 批量商品按各界工艺传统命名，品阶置于括号中；同系不同品阶不必伪造完全不同的药名。傀儡使用阵枢、灵枢、蕴光晶、凝元髓等部件名。
- 内部物品与功法标识随实际名称调整，不再以已经失真的境界标签代指内容。境界枚举、突破范围、品阶字段、事件阶段和测试场景中的真实境界名称保留。
