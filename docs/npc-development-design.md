# NPC培养系统策划案

策划版本：0.2；日期：2026-11-04；基于本体v3.5.1、存档结构12。

0.2补充用户要求：四大道途按道（上界为仙）、魔、妖、鬼设计NPC专用培养材料；培养不以灌注玩家机缘为唯一方式；获取渠道不限定为某一种玩法，但保留界面限制；同等成长下NPC培养成本必须低于玩家自修。以下保留策划提出时的定义／标定目标，实际实现进度见下方说明。

状态：策划基线保留；2026-11-04开始首轮源码实装，具体开放能力、原接口差异和未完成验收见[NPC培养实现说明](npc-development.md)。本文中的数值目标与42项验收不能自动视为已经实现／验证。文中的“首版”不指定本体发行版本号。

## 1. 目标与范围

把散落在御傀、神识禁制、家族、师徒、道侣中的培养行为接到共同的对象解析、资格校验、费用预览、成长结算和人物界面。玩家能看清培养的是谁、提升什么、需要什么、为什么不能培养，以及结果怎样进入真实战斗。

共同核心负责成长事实；培养方式负责效率、材料、上限、时间和风险；关系负责操作权限。后代、弟子、道侣是可叠加关系，不是互斥的人物职业。道途与身体形态独立于关系。

首版必须包含NPC头像和全身立绘、统一培养详情、已有培养方式接入、四道途NPC专材及合法获取／使用闭环、低成本约束、禁用原因、实际扣费及结果反馈。首版不做离线收益、跨界遥控、自动买材料、多人批量培养、无限托管队列、自动灌顶或自动渡劫。邻域先完整预留成长接口，已有真实数据只读展示，未完成规则的培养按钮不开放。

## 3. 对象、身份和权威状态

### 3.1 培养对象

统一对象引用由“对象类型＋原唯一ID”构成；命令另携带培养方式、方向、投入参数及版本信息。类型由服务器解析，不能由前端自报从活人切换成炼尸以绕过条件。

| 对象 | 权威主体 | 首版处理 |
| --- | --- | --- |
| 后代、弟子、道侣等自由人物 | 原NPC | 同一ID合并显示关系标签；成长只写一次 |
| 受神识禁制等控制的活人 | 原NPC及其拘禁／控制记录 | 控制权限与身体／心神资格分别核验；单纯囚禁不等于所有培养方式开放 |
| 活傀 | 原人物生命事实＋原活傀资产的明确培养字段 | 先适配现行归属，统一解析及释放回写；不得同时培养原人和活傀两条记录 |
| 炼尸 | 原炼尸资产 | 仅开放该形态定义的淬炼能力，来源人物保持真实死亡 |
| 机关傀儡 | 原机关资产 | 首版保留原御傀入口已有的打造／培养／维护；其既有数值通过资产适配器解释，不继承活人培养资格 |
| 第二元婴、魂仆、神游人物 | 原专属主体 | 首版可显示可公开资料，专属培养仍走原入口；未适配的动作明确锁定 |

同一个人从自由变受控、解除控制、转为活傀时，人物身份不重建，培养次数、已消耗物资、真实寿命和已得成长不刷新。炼尸是死亡后的资产，不通过解除控制还原活人。无可信来源ID的资产保持自身资产身份，不按姓名、头像或相同境界猜来源。

### 3.2 字段归属

| 类别 | 内容 | 规则 |
| --- | --- | --- |
| 人物成长 | 修为、进度、功法、炼体、神识、适用高阶体系 | 一处权威写入，关系列表只引用；适配阶段沿既有活傀例外逐字段登记 |
| 人物生命 | 年龄、寿元、存活、伤势、身魂状态 | 使用原生命周期入口；培养不能复活、重置年龄或清除永久停滞 |
| 关系／控制 | 师徒、亲属、道侣、控制类型与控制度 | 决定方式资格，不重复保存一份人物修为 |
| 资产状态 | 尸体完整度、机关耐久、形制及材料构造 | 属于实际资产，不能被人物寿元或好感代替 |
| 战斗资源 | 当前元力、容量、转化及已结算时间 | 容量增加不自动回满；保留战损、续战及历史结算边界 |
| 界面数据 | 当前选人、分页、方向、折叠、图片加载 | 会话状态，不写人物、世界时间或游戏RNG |

第一阶段不新建一套“NPC培养经验池”复制原进度，也不以新的全局人物列表取代原名册。后续如调整持久结构，应先列出字段归属、读取／写入者和释放／跨界处理；同步更新字段合同及校验。当前仅支持结构12、拒绝结构1–11的政策继续有效。策划不自行规定新结构号或隐式迁移方案。

## 4. 核心玩法与数值语义

### 4.1 培养方向

| 方向 | 培养结果 | 禁止混淆 |
| --- | --- | --- |
| 修为 | 积累进度、达到瓶颈、合法升层／升境 | 积累满不等于自动越过所有大境界条件 |
| 功法 | 学会、提升等级、选择配置 | 赠送玉简、掌握功法、装备功法分别结算 |
| 肉身 | 普通炼体及该人物实际具备的高阶身体分支 | 没有肉身不能炼体；普通百层与高阶机制分别记录 |
| 神识 | 神识成长及相关能力 | 不等于控制度，也不自动增加魂仆、第二元婴名额 |
| 邻域 | 领悟、等级、配置及对应资源能力 | 领悟不等于已上阵，容量不等于当前储量，培养不刷新战斗次数 |

战斗力是展示结果，原则上由原战斗属性构建入口计算。首版适配现有数值，不同时重写所有NPC战力公式；以后替换直接乘战力的旧规则时，单独比较同境界、同装备、不同伤势的真实战报。

### 4.2 培养方式

| 方式 | 条件与投入 | 成功／失败语义 |
| --- | --- | --- |
| 现有受控培养 | 原方法规定的机缘、法力、轮数及施教者上限；新增能力／在场校验 | 沿已定义的确定性增益；到上限停止，不扣空轮费用 |
| 家族灌顶 | 原血亲资格、年龄、根骨、界层上限、严格修为差及机缘费用 | 保留该方法的升层规则，不能借通用入口取消其上限 |
| 传授功法 | 施教者确实掌握，受教者满足功法、道途、形态和版本条件 | 已掌握则不重复学习获利；换配须明确，不暗中废除原配置 |
| 赠予资材 | 实际持有并允许转移的物品或装备 | 从来源移到目标一次；赠予本身不自动按所有培养方式重复兑现 |
| 消耗丹药／材料 | 对应方法明确允许使用、实际有库存 | 扣除后给出特定效果；丹药的突破率加成与费用折扣必须分名展示 |
| NPC专材培养，首版新增 | 道／魔／妖／鬼专材，匹配目标方向、品阶、所在界面及真实身体条件 | 以材料承担培养投入，不再额外灌注玩家机缘；仅推进已支持节点，不能代替传承、择路或渡劫 |
| 指点／共修，后续 | 有效关系、可接触、能力差及方法定义的时间与资源 | 增加明确进度或效率；不得成为免费重复点击的永久战力来源 |
| 自主修炼 | 原NPC资质、环境、资源及实际年度 | 使用NPC自己的成长上限；不统一封顶于玩家境界 |
| 炼尸淬炼 | 实际炼尸、完整度与形制资格、对应材料 | 增强资产能力；不得增加来源人物寿元、复活或学会活人专属能力 |

现有方式先登记现有报价公式、成长量、失败结果和调用点；未登记的方式不能默认复用最接近的一套公式。A阶段先保留旧数值以确认等价；B阶段统一按4.6节下调或限制不满足成本要求的方式，不能以“旧接口兼容”为理由保留公开可用的高价培养。首次新增指点、共修等玩法的具体数值应另给数值表和对照战报。

后续新增的长期、概率及高阶方式初次开放时不支持跨关批量。已有1／5／10轮确定性培养可保留，但每轮检查上限；到达新高阶门槛、需渡劫／迁移／择路节点立即截停，展示实际轮数与剩余投入，不默默越关。

### 4.3 路线与上界

路线由实际道途、身体、所在地址及本次加载的内容共同决定。亲属或控制身份不授予道途能力。

- 普通路线沿原NPC突破、寿元、雷劫与世界承载规则。
- 仙、修罗、妖、鬼的高阶路线分别定义转化、脉络、血脉、魂体、身体和劫关要求；复用共同规则原语，不能直接拿玩家命令作用到NPC，也不能伪造玩家推进。
- 尚无完整NPC规则的高阶节点，只开放已验证的节点前培养，显示“该阶段培养暂未开放”；不允许通用加层跳过它。
- 若原方式已经能越过拟收紧的门槛，将其列为独立规则修正，说明前后差异并测试，不把平衡变化藏在等价重构里。
- NPC已有邻域事实复用原`transcendence`及对应战斗适配。创建默认模板只用于创建，不能靠重新打开页面、重新生成战斗资料补发成长。
- 转道、化形、夺舍不属于通用培养命令；完成这些动作后重新解析能力，失效方向关闭，原成长的保留／失效由原路线规定。

### 4.4 四大道途NPC专材

专材是原行囊、交易与奖励体系中的真实物品，标记为NPC培养用途，不新建独立兑换货币或抽象培养点账户。材料投入后的修为／身体／神识进度直接写入目标原成长记录。施教者自己的道途不限制其替别人购买或投入专材；受教者的实际路线、身体和所在地决定能否使用。

首版设置四道途、三方向，共12个材料系列，每系列分凡、灵、上境三档，共36个物品定义。只对已完成NPC成长规则的档位开放使用和自然投放；目录可以预留未开放定义，但不得售卖当前无法使用且没有明确用途的材料。高阶身体的独修机制沿各自规则另行接入，不由一枚“养躯材料”同时升满全部机制。

| 路线 | 修为专材 | 肉身专材 | 神识专材 | 高阶名称示例 |
| --- | --- | --- | --- | --- |
| 道／仙 | 养元丹 | 淬玉髓 | 明神砂 | 仙品养元丹、仙品淬玉髓、仙品明神砂 |
| 魔／修罗 | 凝煞丹 | 炼煞髓 | 镇念晶 | 修罗凝煞丹、修罗炼煞髓、修罗镇念晶 |
| 妖／幽冥 | 血蕴丹 | 百骸髓 | 灵慧露 | 幽冥血蕴丹、幽冥百骸髓、幽冥灵慧露 |
| 鬼／轮回 | 养魄丹 | 冥骨髓 | 澄魂砂 | 轮回养魄丹、轮回冥骨髓、轮回澄魂砂 |

命名为拟定，实施时检查与现有物品冲突，使用独立稳定ID，不能按同名自动复用玩家丹药。凡／灵档以品阶前缀区分；上境档采用表中路线前缀。物品详情明确“NPC培养专用”、方向、允许的对象形态、目标阶段、可用界面及单份作用。

功法仍以真实功法／玉简和传授规则为依据，不用修为丹替代学法。邻域阶段另接四条路线的悟域资材，须在邻域培养本身实现后才投放，禁止提前卖一个只有描述没有效果的物品。

儒、佛的现有合法培养保留；首版新增材料不凭“都是人族”直接映射为道修。若需要让儒佛共享某个基础材料系列，须在方法表登记其基础用途和高阶禁用点，不能修改人物道途来适配。

活傀只要实际路线、身体及控制资格满足条件，可以使用对应活人专材。炼尸只能使用其资产适配器明确登记的淬炼配方，不能因来源NPC曾是某道途就自动吞服该道途所有材料；机关、第二元婴与魂仆也必须各自登记适配，不从物品标签自动获得新能力。

材料投入的普通成长部分采用确定性效力，预览写清单份收益与距离下一瓶颈的差额；根骨、功法适配和材料品阶可影响效率，最终仍须满足4.6节成本上限。材料不会自动更换血脉、选择魂相、开启邻域或发起劫战。到瓶颈后保留合法进度，后续材料不继续消耗。

专材路线与机缘灌注是并列选择。纯材料路线不扣玩家机缘，也不暗收同额的法力、神魂、服务费作为替代。已有方法的法力等费用继续明示并纳入总成本校验。首版不做前端任意比例混合付款；未来若开放混合，必须由服务器给出等效替代配方和总价，不能把完整材料费与完整灌注费相加。

### 4.5 获取渠道与界面限制

“不限制获取途径”指不把专材绑定为某个副本、商店、关系或DLC活动的独家掉落。凡原经济系统允许承载该类物品的渠道，都可以按统一物品规则接入，包括坊市、拍卖、黑市、行商、真实运输、探索、战利品、任务、宗门／家族配给、NPC赠予，以及有实际配方的炼制／生产。不是要求每个渠道每次必出，也不新增无库存的凭空领用。

所有新自然投放共用“当地界面、品阶、有效内容、渠道承载能力”的检查，不能只限制坊市却让任务或刷新黑市在低界生成高阶专材。新材料每个已开放档位至少提供一条可重复的常规供给和一条非商店途径；不以随机拍卖的最高成交价作为唯一获取成本。

| 材料档位 | 对应成长阶段 | 自然生成／常规货源 | 使用界面 |
| --- | --- | --- | --- |
| 凡档 | 第一级界面承载范围内的目标成长节点 | 人界、魔界；更高普通界面可以供应低档材料 | 实际普通界面能承载目标节点，且该节点允许在当地修炼 |
| 灵档 | 第二级界面承载范围内的目标成长节点 | 灵界、真魔界、妖界、幻冥界、地狱界；对应上界可供货 | 第二级或更高普通界面，仍检查道途及具体节点条件 |
| 上境档 | 第三级界面的对应路线节点 | 道／仙材在仙界，魔材在修罗界，妖材在幽冥界，鬼材在轮回界 | 在对应的第三级界面使用；所在上界不匹配时不能培养 |

阶段判断复用原世界承载与成长坐标，不在物品中另抄一套易漂移的境界分界。材料同时匹配“目标正在培养的方向等级”，不能仅看人物主修境界：高境界人物补普通炼体时，应使用对应低阶段配方，不能强制收取上境价。

首版不开放高档材料向下折算，也不允许堆低档材料突破高档门槛；专材库存和培养结果都不因切界转换品阶。凡档、灵档的跨道途世界可获取不代表在该地所有培养节点均合法；上境仍严格按路线所属世界检查。

自然产地、持有、运输、转售和使用是不同规则。已经合法取得的真实材料可沿原背包、携带、物流和交易规则流通；低界出现一件有真实运输／持有来源的高阶材料不等于低界自然生成。带到低界可保留或合法转售，但不能在低界使用高阶材料培养。不得为了守住产地限制，跨界时删除库存或禁止所有正常贸易。

特殊空间不默认继承人界或原出发界的材料使用资格。只有已有空间规则明确支持该阶段与路线的培养时才可用；未定义时显示环境不支持。获取渠道多样化不新增遥控培养、无许可运输或空间传送例外。

供给遵循现有库存、刷新周期、可购买限额及账本；预览／切页不刷新货架。因新增36种物品导致掉落池稀释时，使用按档位和适用方向组织的权重，而非把全部定义等概率塞进每张表。常规供应应能支撑一个同阶段NPC的可持续培养，具体补货量与原时间尺度一并标定，不能靠极低出率抵消低价承诺。

### 4.6 NPC培养低成本硬约束

“NPC培养比玩家自修便宜”是系统验收条件，覆盖所有公开培养方式，包括原机缘灌注、家族灌顶、专材，以及之后新增的方式。折扣针对同等实际成长，不比较“一个NPC低阶层数”和“当前高阶玩家的一整层”，也不以玩家当前财力决定价格。

建立参考成长单元：同道途、同身体资格、同培养方向、同起始等级／进度、同环境与有效DLC，取得同样的基础成长。多方向同时受益的效果，要按实际收益分别计量；不能把相同战力数字当成不同属性完全等价。参考玩家取该状态下合法可重复的有效培养方案，纳入可同时成立的正常折扣；不把一次性剧情赠送、Debug、无条件奖励或偶发掉落当成日常标价。

设玩家参考投入为`C_self`，NPC该方法投入为`C_npc`。设计建议目标如下，均为等效资源成本比：

| 方向／方式 | 目标区间或比例 | 发布硬上限 |
| --- | --- | --- |
| 普通修为积累 | 玩家同等成长的30% | 不超过60%，且严格低于玩家参考投入 |
| 普通／适用高阶肉身成长 | 35% | 同上 |
| 神识成长 | 30% | 同上 |
| 功法等级培养（不含物品所有权转移） | 40% | 同上 |
| 后续邻域培养 | 40% | 同上；具体路线实现时单独标定 |
| 原灌顶／机缘培养的便利方式 | 40%–50% | 同上，禁止保留超限旧配方 |

校验要求：`C_npc <= 0.60 × C_self`且`C_npc < C_self`。同样检查单步、完整小阶段及跨境准备的累计账本，避免用前几步便宜掩盖最后一步天价。60%是推荐上限，不是已测得数值；实施须用真实费用表验证，超限配方下调成本或提高合法成长效力后才能开放。

计价边界如下：

1. 机缘、灵石、材料、必需法力／神魂、固定手续费和前置消耗分别列账。不同单位不可直接相加；平衡工具用显式、版本化的参考获取／恢复成本换算，游戏本身不提供这套汇率兑换。页面保留真实物品与真实单位，不能只显示模糊的总培养点。
2. 专材的定价与单份效力共同受约束：按参考常规货源实际买够完成同等成长所需份数后，总成本仍须低于上限；将物品标价压低但消耗量翻倍不算达标。材料配方中不隐藏第二笔玩家机缘。
3. 取整和最低一件的粒度也需检查。若最小一份会让低阶培养超过上限，应调整该材料最小规格／效力和合法进度结算，不能简单向上取整强收。到瓶颈不多吃材料，保留完整未用份数；材料普通积累在合法范围内按原进度承接，不新建无限兑付余额。
4. 对存在随机失败的等效培养，除单次成本外还比较达到相同目标的预期累计消耗和成功率；不能靠降低NPC成功率抵消折扣。专材基础积累为确定性，高阶真实劫战另保留风险：无法承诺每个随机失败轨迹都比一次成功的玩家更省，必须把“培养投入”和“可能战损／死亡”分开披露，不能宣称保成功。
5. 时间单独显示并比较。材料吸收／培养所需净时间原则上不超过玩家参考同等成长，不能用强制多年等待补回资源折扣。可重复常规供给应有可测的取得周期；随机掉落等待、路途战斗和玩家自愿竞拍溢价不伪装成固定培养配方费用。
6. 玩家参考方案只耗时间、不耗物品时，不能把NPC新收费拿来与“0资源”声称更便宜；须提供资源同为0且用时更少的对应成长方式。若玩家同等成长的资源与时间都为0，则保留免费成长，严格更低在数学上不可实现，该节点不得靠编造正基准证明折扣，也不能加收NPC费用。
7. NPC自身根骨差、功法不适配、道途DLC开关及正常折扣均进入匹配条件。没有真实可比玩家路线的资产淬炼或尚未实现的高阶能力，必须先定义可审查的能力基线；不得临时取最高价玩家方法来通过校验。生命风险、传承资格、唯一物所有权不折算成可以付钱免除的成本。

赠予一件已有装备是实物转移，不把其完整价值重复记作“学会同等能力”的培养费；新方式若强制先购买专用器具、入场券或高额服务，必须纳入完整阶段成本。拍卖竞价、自由议价可保留原机制，但必须同时有合规低成本常规路线；不能承诺用户主动无限抬价后的成交总价也低于自修。

专材不能直接给玩家、本尊宿身或当前玩家控制的实际身体服用来冒充NPC。合法NPC培养后经原夺舍、继任等机制继承成长，仍沿原规则处理，是需单独验证的策略联动；不暗中清零已得成长、不追加未经设计的“补差价”，也不以防套利为由取消用户要求的低成本。原人物生命、唯一身份、继任次数、装备及消耗均应守恒。

## 5. 权限与可操作边界

### 5.1 关系权限

| 关系／状态 | 可申请的培养 | 不自动取得的权限 |
| --- | --- | --- |
| 弟子 | 合法传法、赠物，后续指点 | 随意改变道途、代替本人承担劫关、使用宗门府库 |
| 家族后代 | 原资格下灌顶、赠物、传法 | 培养同姓陌生人、强行变更族人任务 |
| 道侣 | 合法赠物、分享功法，后续共修 | 直接抽取对方资源、任意强制改修 |
| 普通宗门门人 | 可见资料；已有明确授权的培养方式 | 仅同宗便拥有个人培养、强制控制或府库支出权限 |
| 自由朋友／陌生人 | 维持原交往入口 | 由高好感或可见头像推断培养授权 |
| 受控活人／活傀 | 当前有效控制类型允许的方法 | 囚禁直接等于活傀；他人控制的对象可培养 |
| 炼尸／机关 | 实际持有资产的适用方法 | 通过来源ID访问或修改原人物的全部状态 |

同一对象多种关系可提供多个合法方法，但同一个动作只选择一种方法、一个付款方和一次效果。不能叠加师徒折扣、家族灌顶及道侣共修的同一份奖励。不同方法的有意叠加须在数值表明确允许及上限。

### 5.2 操作资格硬边界

下表是首版公开入口完成接入后的目标规则；旧入口与新入口须同样执行，不能保留旧按钮绕过收紧。

| 场景 | 处理 |
| --- | --- |
| 玩家或目标实际死亡 | 禁止培养；历史资料可按原可见性查看，不执行恢复或复活 |
| 待处理事件、活动劫战、玩家被拘禁或原业务行动锁 | 拒绝培养提交；保留阅读、关闭及返回原事件入口 |
| 永久修为停滞 | 禁止修为积累／突破；其他方向只有原身魂规则明确允许才开放 |
| 神游、肉身毁坏、宿身或附身 | 按实际身魂及资产归属决定方向；不能培养远处原肉身，不混写宿主和本魂 |
| 真正毁坏的傀儡、炼尸完整度归零、机关耐久归零 | 不允许培养或用喂丹复活；原已定义的清理／修理边界保持 |
| 控制度不足 | 按方法的原控制门槛处理；0控制度不自动当成死亡，反噬与加固仍归原系统 |
| 玩家封印／压制 | 施教方法沿当前可调用能力及原禁用规则，不借真实高境界越过当前限制 |
| 目标封印／压制 | 成长上限与实际可用能力分别校验；所有应同步的原真实／封存状态由原规则统一处理 |
| 目标在访学、运输、开拓、战争、调查或其他排他任务中 | 主动培养拒绝；不自动取消任务、召回、移动或退还任务资金 |
| 仅知道名字、旧情报、历史关系 | 可显示已有记录；不返回精确实时属性、位置、可用材料或远方状态变动 |
| 引用失效、来源不明或出现多个权威对象 | 拒绝提交并记录诊断，不能复制或默认创建NPC来修复 |
| 年龄不足 | 按培养方法的明示年龄要求拒绝；不得因为有少年立绘而授予培养资格 |

可见、可查看精确资料、可接触、可培养必须是四个独立判断。服务器先裁剪信息，再构造页面；不能先把全量隐匿字段送到前端再隐藏。

### 5.3 地点和跨界

主动传法、灌顶、共修、使用资材的目标应与施教者在同一实际地址`(world, instance_id, location_id)`，或由已有系统证实是当前合法随身资产。两个`lost`实例不等于同一地点；同一世界或同一宗门不证明已经在场。

当前部分旧NPC没有精确地点。培养预览不能补写地点、默认与玩家同城，也不能因加入同行列表便制造到场事实。该对象先使用已有会面／移动行为确立合法在场状态；若没有这类入口，培养暂不可用，并作为实施依赖明确列出。空间访问仍须通过原空间人员校验。

首版不新增远程培养。冻结异界NPC不因查看培养页而补算、恢复或变更任务。跨界后清除旧页面的可提交预览，按新地址重验；即使关系保留，也不自动拥有远方培养权限。

NPC因突破需要迁移时，必须经现有NPC移动入口和世界时钟结算，更新实际地点、实例和原任务归属；不能直接改`world`。第二元婴已有随身跨界例外不扩展给普通俘虏、魂仆、炼尸或其他对象。

## 6. 时间、费用、失败与重复提交

### 6.1 预览与执行

预览是纯读取：不调用会写入默认能力的初始化函数，不消费RNG，不触发年度补算，不保存图片选择。报价必须列出付款方、币种、具体材料／实物实例、轮数、时间、瓶颈、风险和停止条件。

命令只接受服务器已注册的方式和方向；轮数使用允许值，数量必须是有限正整数，拒绝负值、小数、NaN、未知ID和任意字段补丁。前端传回的价格、收益、成功率、人物种族和所有权均不可信，提交时由服务器重新计算。

提交绑定当前存档、目标引用及状态版本；目标或付款状态改变则旧预览失效。服务器在现有单档命令锁内重验并原子提交。两次快速点击、两个标签页或断线重试不能扣两次或拿两次收益。

建议提交带操作ID及预期版本。相同操作ID只返回原结果；相同ID不同请求内容拒绝；过期版本拒绝后读取权威状态，不能自动重发副作用命令。若现有命令层不能持久覆盖跨进程重试，需要在实施时登记有界操作回执字段、保留期及存储合同；回执过期后仍靠旧版本拒绝重放，不能以扩大无界日志解决。零耗时动作也必须使版本前进。

### 6.2 费用来源

首版主动培养默认使用玩家实际个人资源，包括所持NPC专材，并不等于每次都扣玩家机缘。专材培养、原机缘培养、赠物及后续指点等各自列明投入。对象自有资源仅在该方法已具备明确授权和真实库存接口时可用。通过原任务获得配给是已有真实物品来源；直接从宗门／家族府库自动扣款培养则属于后续独立授权方式，不因玩家有职位或亲属关系而自动启用。

实物以原唯一物品实例转移／消耗，不能按名称复制。本命、托管物、任务物及不可转移物沿原限制。培养不从冻结地区虚构借款、不自动购买缺材、不把NPC装备同时留在玩家背包。

### 6.3 结果分类

| 结果 | 消耗与成长 |
| --- | --- |
| 提交校验失败、旧预览失效、资源不足 | 零扣费、零时间、零RNG、零成长；刷新一次页面状态 |
| 有效尝试且培养成功 | 支付该步实际费用，结算已过时间和明确成长 |
| 有效尝试但概率失败 | 按预览中声明的规则耗费资源／时间、保留进度或造成损伤；不能把它报成校验错误 |
| 尚未开始的后续轮因条件改变而取消 | 不收费、不投骰，不发放未完成轮收益 |
| 已开始的时间段被事件、死亡、失控等打断 | 保留真实经过时间与已开始步的明示消耗；未满足完成条件不发完成奖励；不得回滚世界已发生事件 |
| 重复提交 | 返回既有结果或拒绝过期版本，不追加任何消耗或成长 |

首版以单对象即时／原有确定性批量方式为主。以后加入长行动时，每个原时间单位使用已有时间推进流程，明确训练对象的当期成长来源：被专注训练占用的同一时段不再额外领取一份自主修炼收益。世界其他人物仍按原规则推进。

年度、行动和惰性资源恢复各沿自身已有时钟，不新增一个全局“培养年”。NPC生理年龄不能代替世界时钟；地区冻结、任务补算和空间时间仍由原系统决定。增大元力容量前先按旧容量／旧恢复率结清旧区间，再使用新上限；不得追补过去收益或无条件回满。

## 7. 培养界面与NPC立绘

### 7.1 入口与布局

沿现有“同道”导航增加培养入口；后代、师徒、道侣、受控对象详情中的“培养”直达同一详情组件，御傀保留原导航入口。返回回到来源页并恢复选中人物，不层层叠加弹窗。

培养名册以稳定对象ID去重，显示头像、姓名、关系标签、已公开境界、可培养状态及主要阻断原因。先看可培养对象；用户可切换查看受限／历史记录。普通同宗成员不能因出现在列表就获得培养权限。

桌面使用“对象名册＋人物培养详情”：详情上部放完整立绘和身份资料，下部按修为、功法、肉身、神识、邻域切页，右侧或底部呈现单个所选方法的投入预览和提交按钮。移动端先选人，再进入详情；头像和核心信息保持紧凑，全身立绘可展开，展开时完整显示。横屏限制立绘容器高度，给费用与提交留足空间。

文字线框：

```text
同道 / 培养                         返回来源页
[对象搜索与筛选]  [完整立绘] 姓名 · 已公开身份
[头像 姓名 标签]             后代 / 弟子 · 当前可接触状态
[头像 姓名 标签]             当前能力 · 身体状况 · 培养限制
                 修为 | 功法 | 肉身 | 神识 | 邻域
                 当前进度 → 本次预计结果
                 培养方式、所需资源、时间、失败代价
                 [投入选择]       [执行所选培养]
                 最近一次结果与实际消耗
```

禁用方向显示具体且可公开的原因和解除条件。尚未开发的能力显示“暂未开放”，不能伪装成缺材料。未知远方状态只显示“当前无法确认或接触”，不泄漏对方已经死亡、被俘或换址等新情报。

培养提交后刷新原对象事实、公开战力和立绘；返回原师徒／家族／道侣页必须一致。动画只呈现已提交结果，不能根据动画结束发放收益。失败和中断给出实际消耗，保留返回事件入口。

每个方向首先选择“专材培养／机缘灌注／其他已开放方式”，页面按所选方法显示真实投入，不默认勾选额外机缘。专材卡显示同源像素物品图标、档位、所需／持有数量、目标单份收益、可用界面和已开放获取渠道；缺少某一种来源时仍展示其他合法途径，不能写成“只能去某副本获得”。没有实装渠道就不显示可点击的虚假入口。

默认推荐当前合法且成本较低的方法，玩家可查看便利方式的价差。费用对照区显示“同阶段玩家参考投入”及NPC实际配方，说明比较方向、阶段和基准，不用玩家当前最高境界作宣传对照。跨币种仅标示参考成本比例，并保留明细；市场溢价和真实劫战风险单列。任一方式超过4.6节成本上限，应由内容校验阻止发布，不能只在页面隐藏高价。

新材料图标沿用现有物品像素风格，四路线以丹、髓、砂／晶等形制和颜色区分，档位使用文字与图案共同标识，不仅靠颜色。立绘周围不堆叠材料图标；材料展示属于投入区，不将吃丹结果画成NPC随身装备。实际素材制作属于后续实施，本次策划不新增图片。

### 7.2 立绘是首版验收项

沿用已采用NPC风格、原头像／全身像及v3.5.1新增素材，不在本轮另建一套画风。共用`NpcArt`选图规则与DLC素材注册；培养页新增可复用的展示接口，不依赖复制名册DOM或先打开另一页来初始化人物。

| 情况 | 立绘规则 |
| --- | --- |
| 固定NPC | 使用其真实ID及种族、道途、性别相符的已采用固定稿；待审固定稿不回退随机通用脸 |
| 已公开身份的普通成年NPC | 使用合法道途、种族、性别、年龄／境界条件下的现有通用池 |
| 16–17岁人族门人 | 使用专用少年男女素材；年龄变化跨过素材门槛时允许按新资格换图 |
| 更低年龄、未覆盖异族 | 保留名字、身份徽记和资料，显示“暂无适用形象”；不能硬套成年、人族图片 |
| 活傀／受控活人 | 原人物当前公开形态符合现有选择器才显示原人物图；控制状态放在独立文字区域，不改变性别或面貌 |
| 炼尸 | 只使用明确适用于该形态的已采用静态素材；不得把来源人物生前图默认当成当前炼尸，也不截取不完整动作帧凑立绘 |
| 机关傀儡 | 适用的机关形制素材或资产徽记，不能展示来源／操纵者的人像 |
| 神游、宿身、附身、变形 | 延续现有严格形态限制；没有经过登记的当前形态素材就回退资料，不展示错误本来肉身 |
| 未探明或仅旧记录人物 | 只依已公开外观选图；不能用真实隐藏境界选高阶服饰、神光或图签泄漏事实 |
| DLC未加载或素材失败 | 不请求停用DLC路径；使用合法本体回退或无图资料，培养按钮和文字正常可用 |

同一身份、相同合法素材集合与公开状态下，名册、培养页、人物卡和重载选图一致。不承诺在人物成年、转道、形态改变或DLC集合变化后仍保持旧图。已有有限通用池允许不同NPC共用图，不宣称每个NPC都有专属面容。

显示须等比完整容纳全身，采用最近邻采样，禁止非等比拉伸、裁去头足或用容器遮罩截断肢体。既有不同尺寸素材统一按容器适配，不能把固定人物强制重制成通用图尺寸。身体／手脚／道具分辨不清的新图不列为已完成接入。

装饰、控制标签和已公开神光避让面部与手脚；不因背包物品自动画出装备。头像与全身像来自同一套合规素材，均具替代文字。点击立绘可查看完整人物卡；关闭、Esc和Android返回先关闭当前层，恢复焦点且不触发培养。

名册按现有分页／懒加载机制加载头像，仅当前选中对象加载全身图。先完成合法素材目录加载再确定候选；切换人物、读入另一存档或开关变化后，旧异步回调不得把上一人的图写回来。缺图重试有界，不循环请求。素材选择、预览、放大和主题切换均不写档、不消耗游戏RNG。

山海图志、沧海夜色两套主题都须验收；Windows和Android离线包携带实际运行素材，不依赖本地design原稿或网络图片。

## 8. DLC和内容边界

- 统一培养核心属于本体，关系身份不依赖道途DLC才存在。
- 四路线基础NPC专材及普通成长用途归本体，关闭道途包后仍可在合法界面用于本体已支持的普通路线；DLC专属高阶配方／独修效力由该包提供。某档位关闭包后完全没有合法用途时，停止其新自然投放，原库存按既有物品保留规则处理，不折算、不补发；不能为了卖材料而绕过DLC专属节点。
- 方法、功法、材料、路线、邻域和图片分别声明归属；素材存在不证明玩法开启。
- 只读取本次实际`loaded`状态，待重启偏好不能提前更改资格和报价。
- 关闭包后，停止其新增培养和素材访问；已保存能力的战斗生效／停用／保留按该包现行契约执行，不由培养页擅自删除、折算成机缘或回填普通成长。
- 启停导致旧预览失效；重启后重验内容定义版本。首版没有跨重启长培养队列，因此不引入队列退款问题。
- 动态创法必须存在有效定义、来源权限及受教条件，不接受前端伪造功法属性；不复制原作者人物或物资。

## 9. 系统实现边界

建议新设`system/npc_development/`，以下为拟议职责，不代表文件已经存在：

| 模块 | 职责 |
| --- | --- |
| 对象适配 | 解析人物／受控／资产引用，读取及写回明确字段；拒绝模糊身份 |
| 资格与能力 | 聚合可见性、关系、身体、任务、地点和DLC限制，返回结构化原因 |
| 方法定义与报价 | 纯计算输入、费用、时间、增益范围、上限、失败和停止条件 |
| 成长规则 | 各方向共用结果结构，具体道途规则通过明确接口接入 |
| 命令结算 | 锁内重验、去重、扣费、时间推进、应用结果及原存档提交 |
| 公开投影 | 裁剪后的资料、方法、报价、阻断原因及原立绘所需公开字段 |

通过现有依赖契约和引擎装配调用。不把整个引擎传给底层规则，不反向导入旧入口，不另建NPC战斗引擎、年度调度器、世界移动器或人物死亡系统。

旧API应薄转发到同一业务入口，保留明确的方法ID以区别原玩法；新UI和旧按钮都不能直接修改境界或乘战力。跨方向成长由一个结果集应用一次，不能由页面同时提交“提升修为”和“同步战力”两次命令。

公开预览建议包括：目标公开摘要、可用方式、当前方向状态、费用、时间、结果区间、风险、停止条件、版本和阻断原因。精确未来随机结果、隐匿人物状态、未加载内容路径、内部诊断不发给客户端。
