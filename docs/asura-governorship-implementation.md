# 修罗地方任职与总督府实施记录

2026-11-11，第一批源码实现。依据[完整策划](asura-court-governorship-design.md)第13节，先交付任职与公共建筑基础；未增加版本号，仍仅结构12。第二批[派系深化与地方争议](asura-politics-and-disputes.md)已接续实现；第三批[驻军、军令与举兵争位](asura-military-and-succession.md)已接入，尚未进行发行验收。

## 本体与扩展边界

本体 `system/institution_authority.py` 管理原机构任命、赴任、撤权、交接、公款实转与原项目退款，不导入修罗模块。`institution_authority_schema.py` 独立验证任职、原资金账户和责任记录。既有 `institution_ai` 负责原人物占用、有限提案、预算托管、实际年度履约和退款，不新增第二套AI。

修罗资格、城市许可、任期、工程规格和玩法适配分别位于 `dlc/asura-manifestation/content/world.json` 与 `system/asura_governorship/`。中枢入口及年度装配只调用适配层；基础授权和基础建筑控件修复无需启用修罗内容。

## 当前流程

王庭内政申请外任：战将以上、累计功绩100、恩宠20，且有自由在世的修罗王。玩家在位时可任命原廷臣；不得兼任中枢官职、其他地方任职或任务。任期500年，赴任路程计入期限。签任不移动人物、不发钱、不生成建筑。

设府许可限修罗关城、赤刃城、千垒城的原背景产权；私有化、损毁或其他城市不授予许可。本人须沿原地图抵达，在当地建筑列表的原城市办理赴任；NPC仅在原人物已到场且自由时接任，不自动传送。

府署为原建筑系统的 `public_office`，产权归王庭，公开可进入。建成前从宿主城市进入府务，建成后入口归府署，无新增侧栏导航。营造实购原市场九阶结构矿12、导灵矿6、蓄灵矿3，工费同阶基价×400（当前5.6亿）；提交复核实际库存、总报价、权限和原资金。采用原即时营造语义；损毁后原址重建，不重置任期或历史。

本府公账零初始，只接受原王庭拨款或玩家明确资助。拨款支出与到账是同一笔账；玩家资助不可取回私囊。上缴只将未耗款退原王庭。取消项目先退回本府，再办理交接，已耗劳务与工料不退。

现阶段登记一名原址执事，复用机构经营控件设置预算与代办。项目仅针对真实、同址、王庭产权的损毁建筑，不制造遗址、NPC或物资。修缮10个实际地区年，劳务每年1000灵石；离场、拘禁、死亡、许可或产权失效暂停，逾期按原机构规则退余款。无真实需求时不生成项目。

撤任立即终止法定权力，原控制人另行交接；前任未交接不能重新任命。辞任后建筑、资金和记录仍归原机构。升为修罗王终止原地方授权；退出王庭前须交接本人责任。关闭DLC拒绝专属新行动，保留原资产与交接路径；原建筑访问及依法自费修复属于本体资产维护，不开放公款支取、任命刷新或专属经营收益。

## 界面、状态与验证

王庭内政集中任命、拨款、撤任；当地建筑事务集中公款、工程、属员、交接，折叠明细，采用修罗独立配色。两套像素主题沿原导航及手机绘景抽屉；府署暂复用现有城署像素素材，专属新立绘尚未交付。

没有新增跨界路线或人物迁移。原城、建筑、账本、任务留原地；读页不推进时间、不采购、不投骰。专属命令拒绝异界、途中、试境、归墟，并复验当前令牌。新增嵌套状态已人工登记于[字段合同](world-transition-state-contract.json)。本体补齐主页建筑入口的忙碌同步，恢复时仍保留原禁止选项。

验证入口：`tests/test_institution_authority.py`（本体独立授权及原款守恒）、`tests/test_asura_governorship.py`（真实引擎、原NPC、旧报价、产权、撤权、停用、畸形请求和重载）、`tests/browser_asura_governorship.py`（真实HTTP、按钮、过期页、原建筑事件、两主题桌面／手机／横屏）。另运行适用王庭、派系、机构、建筑、跨界与事件回归及三项门禁。结果以日志为准，不声称全仓、Windows或Android发行验收通过。

2026-11-11验证结果：最终本体授权及总督府专项19项通过（`build/asura-governorship-final.xml`）；王庭、派系、机构、建筑和事件领域组175项通过（`build/asura-governorship-first.xml`）；权限、跨界、空间符箓及211组108项通过（`build/asura-governorship-boundaries.xml`）。这些分组有重叠，不累加为唯一测试数。新增流程五种主题／屏幕组合通过，原212事件浏览器回归及本体／瑶池机构三种布局兼容回归通过；三项门禁通过，依赖无循环，未发现禁止的玩家world写入。新边界还覆盖待赴任期间升王、原任身故、NPC正常撤任交接和原府库实际拨款。
