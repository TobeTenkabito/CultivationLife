# 仙界修行与天庭体验

> 维护基线：本体 v1.57.0 开发源码，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名保留历史编号以维持链接；历史采样不是本轮实测。

## 天庭选举

每席从当选时起执政十四个仙界时间单位。七曜不再每单位无条件重选；每单位最多启动一席空缺选举，在任席位只有任满或官员无法履职才腾出。

投票、弃选和关闭提示均不推进年龄。玩家可继续修行，尚未完成的选举视为放弃参选，由 NPC 结算。在设置中勾选“关闭天庭选举提示”后，新选举自动进行，玩家已有职位仍保留至任满。前两轮须达到十三票，第三轮以最高票定选，避免无限重投。

争取前四席时增加玩家的选票权重；掌握四席后，继续争取席位受到更强阻力。瑶池议定的支持票仍在本次选举中有效。

承诺先记在本次竞选中，只有当选才转为执政承诺，七单位内兑现。落选、弃选不产生承诺惩罚；离任后不再追究失去权限的承诺。旧版本无法判断是否当选的承诺一律免除，避免继续误罚；不猜测或重算历史支持度。

## 天条与俸禄

互斥组如下，玩家与 NPC 使用相同校验。旧档同时生效时保留最近通过的一项；时间相同或无记录时按组内顺序保留第一项。

| 制度 | 互斥制度 |
| --- | --- |
| 职官制 | 辅官制 |
| 天官直授法 | 天官察举法 |
| 广域制 | 行宫制 |
| 寰宇庇护法 | 仙域生杀法 |

须先废除旧制，再表决新制。废除前置天条、施行禁止性天条或减少决议槽位时，同步清理不再合法的临时决议。天庭公务、官办演武、自卫、讨伐通缉者不按私斗处理；未经许可主动与修士斗法仍受寰宇庇护法约束。

每个仙界时间单位领取一次俸禄，不通过反复打开界面、投票或读档领取。九品至一品分别为：3,000、6,000、10,000、16,000、22,000、30,000、38,000、48,000、60,000 灵石。俸禄与瑶池功勋、天庭功德分别记账。

每次实际取得正数机缘，获得一道仙痕的概率由 7% 提高为 15%；退款、刷新和单纯时间流逝不触发。现有仙痕储量及随机序列继续沿用，仙脉费用不因此提高。

## 道门与界面

寻找同道不消耗时间或灵石，随机显示 Lv1—Lv9 的访客。未确认者只是一个待选记录，不生成固定 NPC，不加入年度模拟，也不累积历史。继续寻访替换该记录，读档保留当前访客，不自动重抽。

确认结识后支付原定的 1,000 灵石，才创建有真实功法与道统修为的同道。高层同道可指导低层内容，无需从 Lv1 逐人结识。每门最多保留九位，旧有同道不清除。

道统、邻域和道门均改为可搜索的缩略条目。邻域可按名称、所属道统和能力搜索；展开后才显示培养与操作内容。变更资源或执行操作后保留展开状态，切换存档重置筛选。六主题适配桌面、竖屏与横屏。

## 瑶池经验

经验只记在瑶池账户，显示于瑶池界面，不列入人物百艺。每交付一份完成的委托获得 100 经验；每 300 经验升一级，Lv1 起步，每升一级为以后接取的委托增加 10% 功勋收益。等级和加成没有上限。

经验不因买卖、兑换、刷新或重复领取增长。中断履约保留既有进度，实际完成并交付后才发放经验。旧委托与在途求取订单按原约定交付；不根据旧功勋余额反推经验。
