# v3.5.5 景中问法

本体3.5.5，Android版本码98。存档仍仅结构12；结构1–11拒绝加载和导入，不迁移、不覆盖。DLC版本不变，界面继续使用山海图志、沧海夜色两套像素主题。

## 坊市与工坊

NPC培养材料及傀儡能源进入原坊市的独立分类，原当地库存、预约、防重复购买和境界时间单位自然刷新保持。坊市、阵法、炼器与御傀优化顶部分类；无专用分类的长列表使用共用分页，保留原控件值、禁用态与交易入口。双主题工作台及窄屏布局一并整理，详见[坊市与分页](market-pages.md)。

## 风景秘法

原六门灵石占位解锁改由真实风景建筑剧情获得，复用镜湖及鹿鸣景色，增加四处适配传承建筑。重复传承不重复发奖。道途转换详情只在发动秘法后出现，确认绑定原境界、资源、身魂与空间地址，过期页面在扣费前拒绝。普通特殊区域限制仍保留，详见[身魂系统](soul-lifecycle.md)。

## 第二元婴与死亡结算

炼化、计龄及消散使用同一原NPC，失效引用不能覆盖其他拘管身份。寄身死亡按原本魂资格处理，承接先还原原身份再继承第二元婴修为及剩余寿元。修复跨界无效功法仍加战力、请求槽位未更新、缺失功法报错、交付最后一件寄魂装备后附身残留及恢复后枯竭标记未重置。

特殊区域原地抵御已有夺舍危机使用已登记紧急资格，不移动、不解除原封印或副本限制。神魂侵蚀触发替死后停止原行动后续年份。炼化前后核验俘虏寿元和神游期限，禁止将已消散元婴重新炼成；候选列表复用正式资格。神游期限当天及鬼修原有豁免保持。

## 验证范围

采用扩展后的 `soul-lifecycle` 发行配置，覆盖身魂、风景剧情、坊市分页、NPC培养和相关战斗、跨界、空间、事件、存档领域，不宣称全仓回归。浏览器使用真实加载、按钮提交、旧页面恢复、后续奖励及双主题多尺寸验证。Windows同一最终EXE分别有／无DLC验收；签名Android12专用模拟器执行横竖屏真实风景传承、身魂及现有外观流程，不声明实体手机验收。

正式产物、测试数量与源码／包哈希以 `dist/release-3.5.5*.json` 为准；不将开发阶段或旧版本证据替代最终发行验收。测试只使用隔离存档。

本轮原生验收发现旧服装测试仍点击已退役的“启用新版”开关；相关原生及浏览器脚本改用真实浅暗主题按钮，保留服装资格、战斗特效、读档与原状态不变断言。原失败日志保留，测试APK重新签名构建并重新验收，不因此恢复旧界面或更改游戏规则。

发行回归另发现师父请教接入新师门入口后遗漏原互动好感和天机线索。成功请教沿原人物好感入口增加1点，并沿原天机回调与RNG持久化生成线索；同地、同界、师门位次、年度和周期额度检查仍先执行，拒绝请求不触发线索。旧测试补齐同地夹具，保留机缘、好感和线索断言并增加失败请求不调用线索的检查。游戏成品及发行范围以此修复后的代码重新构建、验收。

新增低价材料还暴露出零预算边界：单件卖价向下取整为零时，原额度搜索会授权零现金经销商继续收购和生产。共用交易额度入口现在对非正预算直接返回零数量，保留原报价、手续费和有预算的批量交易规则；实际组织生产无现金时不得改变库存、供给或市场修订号。
