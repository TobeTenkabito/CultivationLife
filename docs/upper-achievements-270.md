# 成就维护

## 典故成就增补（2026-10-19，源码增量）

本轮新增四项本体成就，沿用现有跨存档功业录、一次解锁与弹窗设置。玩法、版本及结构 10 不变；没有更新发行包。

| 名称 | 实际判定 |
| --- | --- |
| 先帝还在创业 | 成功炼制实际掌门为炼尸后，该炼尸在实际战报中出阵，且原宗门参与该场战役。原宗门可以是任意一方主宗、任意一方盟宗或实际部署的参战宗门；不要求玩家继任、胜利或炼尸战后仍完好。仅携带、查看战役、非战役斗法与没有实际交锋均不算。 |
| 教父 | 当前至少两个不同、存续宗门的实际掌门为玩家后代。按原后代编号与亲代编号核验，不按同姓或普通族人猜测；有职务记录时不以控制者冒充掌门。死亡、被囚、受控、客卿或异界失效职务不计，家族／机构不计作宗门。 |
| 满门忠烈 | 玩家家族至少有一名本家成员，除玩家外全部本家成员均已战死；外姓成员不计。沿用本家 kin／后代资格，不按姓名首字猜姓；异地、受控及未入册未成年后代仍存活时阻止解锁。死亡读取原人物，未知死因、寿尽、渡劫、处决、炼尸成败均不能代替战死，不要求同一场出征。 |
| 黑钱洗白 | 向自己已加入的本盟成功付款发布一次委托即可，不要求完成或领奖。沿用商盟原网络成员资格；商盟不存在玩家所有权机制，不另设所有权。报价与失败提交不解锁。 |

掌门拘禁前的职务来源存于原 NPC 的 `roster_origin.*.leader_sect_id`，成功炼尸才转记 `puppets.*.former_leader_sect_id`。实际战报及成功建单各登记一个现有 `milestones` 整数键，不新增顶层持久字段。身份变化和历史证据由原入口保存，不增加人物、物资、随机抽签或年度扫描。新只读查询位于 `achievement_facts.py`，不调用 ensure，不恢复远界职务或唤醒冻结地区。

已有存档的家族生死及掌门记录充分时可直接判定；既有炼尸和旧委托没有可靠行为证据时，不依据当前身份倒推历史。所有验证使用隔离档，覆盖入口为 `tests/test_story_achievements.py` 与 `tests/browser_story_achievements.py`。

本轮验证：65 项新增专项、734 项关联回归通过（复测不重复计数），涵盖实际生擒／读档／炼尸、先锋选项真实提交、主力会战及双方盟宗、最后本家成员实际战死、正式委托付款建单。事件浏览器与新增成就浏览器通过；后者真实点击入盟、报价及发布，验证重载不重复提示、四主题和桌面／手机横竖屏。状态归属、模块依赖、文档三项门禁通过；未改写游玩存档，未升版、打包或推送。
