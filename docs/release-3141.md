# 3.14.1 斗法战报与遗境行记

- 战报首屏并列呈现双方态势、交锋画面与关键战况。功法运转、双方阵容与战力、逐轮演算均可按需展开。
- 探幽寻宝在桌面常驻舆图，右侧处理眼前局势、队伍与见闻。手机可切换舆图和名册，行动选项留在下方。已封的入口收进单独列表。
- 接触其他修士后，可从「队伍 → 双方交锋对照」比较境界、相对战力和夺宝意向。「见闻」可按宗门与消息来源筛选，遭遇争夺时在「眼前局势」决定援助谁或趁乱脱身。
- 润色功法与秘术、宗门事件、产业与佛寺游历、轮回提示、妖修血脉和游戏手册。4,258 部固定功法沿用原有数值。

Windows 本体 v3.14.1，Android 版本码 109，存档结构 12。发行资产附 Windows、Android 安装包及专项验收清单。
