# 高阶大境界突破通过率测试

这是调整前的历史基线。后续妖修本体邻域、沸血和魔修第二关已经调整，当前数据与复现命令见[沸血调息与劫战平衡](feixue-and-trial-balance.md)。下文“当前源码”指本次基线测量时的源码；新源码重跑会得到新规则结果。

2026-11-03，按用户要求，在四道途缩差平衡之后测量九→十、十→十一、十一→十二三道大境界的劫战通过率。本轮只增加诊断脚本、测试和报告，不调整突破敌人、炼体系数、资源、奖励或存档；没有读写用户游玩存档。

## 口径与角色

入口为`scripts/calibrate_upper_breakthroughs.py`，复用正式仙境、修罗、妖鬼劫战初始化与`combat.trials.run_batch`，不另写胜负公式。主统计是在前置条件满足、已经进入劫战后的战斗结果，不包含赚取机缘、购买材料、飞升九关、普通小境界概率或养成所需年份。

仙修前两关人五衰、天五衰，妖修前两关蜕形、祖性，鬼修前两关辨魂、前尘，均须生存完整五轮。仙修三尸、魔修三关、妖鬼末关须实际击杀全部对手；镇压、逃跑或预算耗尽不算通关。脚本对击杀类胜利额外核验`enemy_killed()`。

四道途相关DLC全部启用。使用两个内容种子930211／930212，固定极品金灵根、普通炼体100层、同阶神识；仙修每境仙脉27条，魔修每境魔脉27条。仙／魔／鬼使用九层关口，妖修按现行血脉进化的一层关口及真实返祖血脉准备。每人配一件本界同阶普通经济目录攻击法宝，资格为仙，不使用自创功法、神机、合体、同伴或专门克制装备。

仙修道统等级为4／6／8，三轴温养均为5；魔修八部传承等级为4／7／9、魔域威能温养5，未额外绑定生成分支或额外权能。这些条件在同关各准备组中固定，不冒充该角色所有系统的最优配装。

总战力沿旧仙劫校准工具的约定，使用明确的离线基准补差，使其等于本关口`expected_combat_power`的1倍；这是控制角色，不是自然成长存档。其余六维、储量、身体能力和装备资格仍由正式人物投影生成；镜像的倍率、复制内容及上限全部使用当前源码。故下述百分数是这套准备条件、目录与随机序列下的结果，不能推广为所有玩家账号的胜率。

## 目录、随机与长战

基础矩阵覆盖仙修25种生成道统、魔修八部、妖鬼各两种本体邻域。每配置两个内容种子、每个内容种子32个战斗种子6000–6031，七组准备×三关，共49728场。补充矩阵覆盖八种返祖本相和全部36种魂因／道路魂相，每组两个内容种子、16个战斗种子、ready／peak／low_energy三组×三关，共12672场。合计62400个配置与战斗随机组合。

本相统一守中调校，辅权能选首个合法不同效果；魂相辅权能和魂痕取目录首个合法候选，逐阶段设置合法锁定记录，至臻记录完整。未遍历所有辅效、调校、魂痕组合、自创祖谱及一切额外系统。静态目录在两个内容种子下可能相同；重复内容种子不提供独立世界的统计证据。本报告不把样本量当成人口统计置信度。

先以240轮作为仿真工作量预算，未决结果保留为`ongoing`；再仅将未决样本扩至960轮，已完成的样本保留。重算会从相同快照与同一战斗RNG开始；只有快照、战斗内状态和RNG种子完全相同的重复样本复用结果。960轮仍只是诊断预算，游戏本身没有新增轮数上限。

通过率使用胜场／全部样本；仍未决的比例另列，不把未决算成实际死亡，也不只用已分胜负样本夸大通过率。完整逐场CSV与分组JSON在`build/upper-breakthrough-rates/`，扩展后结果在`build/upper-breakthrough-resolved/`。

## 已复核的异常交互

**空元力降低三尸威胁。** 同批1600个阶段准备样本，满储量通过929场（58.06%），空资源通过1050场（65.63%）。成对反例为内容种子930211、道统索引0、战斗种子6006：满储量四轮失败，空资源二十二轮获胜。源码复制当前元力至三尸，却保留其普通攻击资格的原投影；该反例中，玩家有无耗仙级法宝资格2，三个空元力三尸的实际普通攻击资格均为1。三尸仍有复制的神光，故并非绝对不能造成效果，但这一资格不对称构成可利用点。

该反例另做MP／元力四格隔离：MP和元力均满时四轮失败，仅清空MP仍四轮失败；保留满MP而只清空元力时二十轮获胜；二者都空时二十二轮获胜。确认影响来自元力与攻击资格的交互，而非仅因同时改变普通MP。记录为`build/upper-trial-energy-isolation.json`。

**鬼修训练收益逆转。** 两仪轮转域在十→十一关的同批64个ready样本全部通过，peak全部失败；无领域对照也全部通过。相同种子6000下，ready存活五轮，peak第四轮失败。36种魂相中有14种也出现该关ready通过率高于peak；目录合计从84.55%降至48.61%。敌方复制玩家高阶炼体已在源码及快照确认，因此不能用普通对抗的强度排名推定引劫难度；具体事件链仍需在后续机制修订时单独处理，不能据此把所有高阶炼体效果一并削弱。

**长战会歪曲通过率。** 恢复型魔域抽查36场，均在扩展预算后结束，其中部分乾闼婆需要约433–435轮才失败，紧那罗末关需要约389–390轮才获胜。因此首轮240轮内未决不能直接记为失败或卡死。成对反例与长战记录分别见`build/upper-trial-investigations.json`、`build/upper-trial-long-battles.json`。

## 复现

基础矩阵按四道途分别运行：`python scripts/calibrate_upper_breakthroughs.py --family immortal --samples 32`，family可改为demonic、monster、ghost。妖鬼补充矩阵增加`--catalog dynamic --samples 16 --profiles ready peak low_energy`。

对未决样本扩展：`python scripts/calibrate_upper_breakthroughs.py --family demonic --extend-csv build/upper-breakthrough-rates/demonic-base.csv --max-rounds 960 --output build/upper-breakthrough-resolved`。动态目录扩展还应保持原`--catalog dynamic --samples 16 --profiles ready peak low_energy`。脚本不建立新资源或世界对象，临时配置不保存到游戏存档。

当前代码与内容的SHA256、Git基线、完整分组及样本总数在`build/upper-breakthrough-resolved/summary.json`。魔修扩展可用`--profiles entry`、`ready`、`peak`、`no_body`分批并行，按family／realm／profile／variant／内容种子／战斗种子唯一键合并；已经结束的案例不改变。初轮妖修九层夹具已排除，最终矩阵使用一层真实血脉进化关口。

## 判断与验证

这组控制准备下，首关较宽松，主要问题是魔修中关断点、妖修本体域末关零通过、鬼修中关成长逆转，以及三尸空元力削敌。优先复核镜像复制与攻击资格／新炼体机制的交互，再讨论普遍升降关卡倍率；本轮没有据此直接改规则或数值。

原仙魔及妖鬼进阶领域146项回归，加上26项测量工具、蓝图、复制、资源隔离与预算检查均通过；结果分别见`build/upper-trial-final-tests.xml`及`build/upper-trial-calibration-final.xml`。三个仓库门禁继续执行。没有修改事件加载、选项提交或界面按钮，无需把这份数值报告当作发行或原生客户端验收。
