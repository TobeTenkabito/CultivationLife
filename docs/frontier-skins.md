# v3.2.2 牛仔时装与合体泳装

新增本体男女「荒原逐日」牛仔时装，按用户确认采用1890年代经典西部风格：牛仔帽、皮革枪套、左轮手枪；全道途默认解锁。男女「沧溟曜金」泳装采用翡翠绿、金白配色，达到合体期（realm_index 7）解锁，沿既有真实／封印原始境界和个人历史记录判断，降境后仍可使用已解锁形貌。

人物详情立绘旁的「衣橱」小按钮打开换装窗口；兼容不开启新版界面的原布局。头像、立绘、缩略图和战报身份由原 character-skin 命令更新。寄身、附身、变化禁用规则不变。时装不授予战力、化形或新武器道具，不消耗游戏时间，不改变战斗结算。

牛仔拥有绘制的拔枪、瞄准、开火、后坐、恢复瞄准及收枪关键姿态；沿原4秒攻击时序、2.1秒接触点组合播放。专用 `cast_effect=revolver` 只在对应角色攻击时启用枪口焰、短促弹道、火药烟和命中火星，发射点按实际开火图枪口位置记录。左轮不抛出弹壳。绘制只读既有接触时钟，有限粒子、无随机数消费、无独立计时器，双向沿原目标裁剪，结束后清除。旧时装及普通角色使用原特效。

四套共12张静态图、48个绘制关键姿态和28组动作，不宣称逐帧独立绘制。原稿使用内置 image_gen；最终提示词、哈希和裁切记录在 `web/assets/pixel/frontier/provenance.json`，工作区原稿在 `design/frontier-swim-20261027`。运行资源全部随包离线提供；导出入口 `python -m scripts.prepare_frontier_assets`，仅保留透明度、等比缩放和排图，不重画人体。

同时交付此前的元婴离体入口调整：各道途元婴期自动解锁，移至秘法页的身魂秘法，使用扣除10神魂；归体仍在人物详情并验证原肉身地址。存档结构保持11，无新Player／GameState字段、移动方式、资源副本或跨界例外。
