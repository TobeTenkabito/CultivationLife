# 操作教程：亲手问道

> 维护基线：本体v3.3.1，2026-10-30。仅支持存档结构11，结构1–10拒绝加载，不迁移、不覆盖。文件名编号仅用于保持链接。双端成品证据见[3.3.1发行说明](release-331.md)。

## 新版界面导览

入口为游戏内“新手教程 → 新版界面导览”；原修行实践的第一步也提供直达按钮。导览复用同一聚光、箭头、暂停和键盘操作框架，与修行实践分开运行。新旧界面均可进入；已完成实践教程的角色仍可反复重看界面导览。

导览按真实布局讲解人物详情、行动分类与耗时、山海绘景、侧栏或六分类底栏、行囊、地图、诸天、设置、存档和百科。在手机上亲自打开“百艺”分类并输入“行囊”查找；桌面沿原侧栏打开。缩放、旋转或主题变化会重新选择当前可见的原控件；只看当前已开放的诸天入口，空间限制不被导览绕过。

界面导览不发送游戏命令，不改变年龄、RNG、物品、人物、奖励或修行实践进度。打开面板仍走原导航与延迟绘制，最近打开记录沿既有本机偏好保存。导览本身不增加Player／GameState字段，暂停进度只保留在本次页面；刷新、返回开始页或换人生会重置。遇到当前事件时先暂停处理，不代选事件或自动行动。

维护入口为 `web/tutorial-interface.js` 与 `web/tutorial.js`。真实页面验证见 `tests/browser_tutorial_interface.py`；原32步实践仍由 `scripts/verify_tutorial_ui.py` 全程点击复核。

2026-10-30发行前源码验收记录：界面导览12个场景通过，包括新版浅暗配色的桌面／手机横竖屏、四套文字主题、已完成教程的真仙角色、事件中断，以及原实践续接与缩放重定位；面板关闭步骤暂停后能恢复待关闭窗口。逐场比较存档字节，导览期间不提交游戏命令。`build/tutorial-interface/report.json`绑定生产源码指纹。原32步实践分别在四套文字主题、新版两种配色的桌面和手机走通；教程与事件领域71项测试、桌面导航、事件过期恢复／后续领奖浏览器及三项工程检查通过。该轮仅验源码，3.3.1最终双端证据另见[发行说明](release-331.md)。

## 修行实践引导

开启教程后，提示直接出现在游戏界面中。周围稍微变暗，当前目标保持高亮，箭头指向真实按钮；点下按钮、看见结果，才进入下一步。文字说明不再代替玩家的实际操作。

路线为：人物详情与灵根 → 亲自修炼 → 机缘变化 → 探宝与行囊 → 配置主修功法 → 游历与拜师事件 → 师徒关系 → 选择宗门并入门 → 门内身份 → 地图与行路 → 设置与修行说明。

新手这次试行运气固定得到 5 点机缘，探宝得到 3 枚灵石与可用的入门传承。拜师前会说明接受和谢绝的结果，宗门引荐也会说明加入后的归属。这些教学操作不消耗岁月、不触发其他随机事件；以后正常游玩仍按界面的耗时与条件执行。无灵根角色的运气演示不会改变资质，高境界角色不领取入门物资。

入门环节可先选择一座能够接纳自己的宗门，箭头会指向那座宗门的真实引荐按钮。接受后即成为该宗门门人，后续正常享有福利、积累贡献并承担门内事务。已有宗门不会被更换，已有师父也不会被替换。

随时可点「暂停引导」，安卓还可按系统返回键暂停。主界面教程入口可以续接；刷新或读档会回到当前步骤。教学收获、师承和宗门归属按角色保存，不会因重复点击或续接而重复发放。全部完成后不再自动弹出；完整修行说明始终留在设置中。
