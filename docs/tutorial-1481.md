# v1.48.1 · 亲手问道

开启教程后，提示直接出现在游戏界面中。周围稍微变暗，当前目标保持高亮，箭头指向真实按钮；点下按钮、看见结果，才进入下一步。文字说明不再代替玩家的实际操作。

路线为：人物详情与灵根 → 亲自修炼 → 机缘变化 → 探宝与行囊 → 配置主修功法 → 游历与拜师事件 → 师徒关系 → 选择宗门并入门 → 门内身份 → 地图与行路 → 设置与修行说明。

新手这次试行运气固定得到 5 点机缘，探宝得到 3 枚灵石与可用的入门传承。拜师前会说明接受和谢绝的结果，宗门引荐也会说明加入后的归属。这些教学操作不消耗岁月、不触发其他随机事件；以后正常游玩仍按界面的耗时与条件执行。无灵根角色的运气演示不会改变资质，高境界角色不领取入门物资。

入门环节可先选择一座能够接纳自己的宗门，箭头会指向那座宗门的真实引荐按钮。接受后即成为该宗门门人，后续正常享有福利、积累贡献并承担门内事务。已有宗门不会被更换，已有师父也不会被替换。

随时可点「暂停引导」，安卓还可按系统返回键暂停。主界面教程入口可以续接；刷新或读档会回到当前步骤。教学收获、师承和宗门归属按角色保存，不会因重复点击或续接而重复发放。全部完成后不再自动弹出；完整修行说明始终留在设置中。
