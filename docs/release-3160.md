# 浮生问道 v3.16.0 · 特质传承与属性斗法

- 玩家与 NPC 共用绿、蓝、紫、橙四档特质。先天特质与存档种子绑定，指定功法大成、神光精修及法宝参悟也能授予特质。人物详情可查看来源、等级与兼容关系。
- 地区年度模拟按各界自己的出生次序抽取 NPC 先天特质，逐年推进与离界后补算可得到相同结果。
- 昊天之仙使各境界突破概率提高 25 个百分点，沿用原概率上限。太元归墟剑大成可得「剑道阑珊」，开战时敌方全体各损失自身最大态势的 10%，随后仍可回满。
- 功法、法宝及相应生成物拥有伤害属性。五行顺克、阴阳互克增伤，五行逆克、风雷互抗减伤。物理攻击单独结算倍率，功法出招属性与灵根门槛分别判定。
- 固定特质、传承来源、劫敌、守阵机关和秘境生成素材改由 JSON 目录提供。修罗显圣、诸法无我、百鬼夜行、万妖归宗同步更新。

**存档结构升为 13。** 结构 1–12 的存档及存档码不能在本版加载或导入。升级前可保留原版本游玩旧角色，已有文件不会被自动覆盖。

Windows 本体版本为 3.16.0，Android 版本码为 111。发行附 Windows 本体、签名 Android 安装包、四个 DLC 更新包及验收清单。Android 原生验收使用 Android 12 x86_64 模拟器。
