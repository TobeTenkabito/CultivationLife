# 3.14.0 遗境山水与初行新装

从主界面「探幽寻宝」入境，舆图会先展开脚下的一带山水。水府、山岳、火脉、冰宫、古塞、幽冥、药圃和废墟各有底画。拖动舆图可环顾已知方位，点选地点可查看探明的修士行迹、阵势与斗法余波。选「前往」或「遁向」才会动身，神识足够时可展开全境。

- 基础道修换上石青宽袖道袍与水青裙装。基础魔修也换上各自定稿的新装。四位主角的头像、人物详情、换装缩略图与场景动作同步更新。
- 四向待机、行走、打坐、斗法与倒地沿用各自的新装。施法从伸出的手掌起势，战败从屈膝到倒地分四段衔接。
- 修整元婴与合体女道修站姿的裙摆和双靴，调整元婴女修膝前布料的垂褶。

Windows 本体 v3.14.0，Android 版本码 108，存档结构 12。本次验收聚焦副本地图、人物素材及动作，并核对 Windows 有／无 DLC 和签名 Android 12 模拟器横竖屏成品。安装包与验收清单见[本次发行](https://github.com/TobeTenkabito/CultivationLife/releases/tag/v3.14.0)。
