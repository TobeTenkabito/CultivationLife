# 宗门战意、种族和约与战役地图

2026-10-16 源码增量，尚未升级版本或打包。基于[首期战争实现](strategic-war-implementation.md)，遵循[跨界开发规范](world-transition-development.md)与[当前审计](world-transition-audit.md)。仅结构10、灵界与真魔界同界种族战争；宗门包含原家族实体。

## 战争持续与宗门战意

原动员必须同时找到两组指定顺序的可执行战役，三十年无计划即撤销；现改为最多6×6组有界配对，找到一组即可开拔，仍最多两场。未能成军的安全收束期限为六十年；已经开拔者不受该期限影响，以实际最晚初始抵达后两百年为战时授权上限。目标全部结束只登记谈判窗口，不立即白和；二十年后非玩家政治代表一方可以按战果提案。玩家只有宗门权限、没有本方族议资格时由 NPC 继续办理总体交涉，原本方出资分配与对方玩家组织的明确确认仍保留。期限届满仅安全停战，不强收未批准赔款，已出发者仍真实返乡。

每份原组织承诺保存0–100战意，初值70。每十个实际年一次评估任务敌我潜在战力、两边实际承诺组织总战力、原府库与可支撑场数、本宗原人物伤亡和新增伤势；使用至多24个原编号／伤势起点，不复制人员。每次最多下降8、恢复5，避免单次缺货导致未集结就退兵。正常战场士气继续由原军需和战斗入口结算。

本场任务胜算以原实际部署名册中仍在赴战或驻扎的自由修士计算；保留可抵达援军的潜在战力，排除已撤回组织、返乡／归营／失联、败逃、镇压、关押、异界及空间内人物，也不把未选入名册的留守修士当作本场部队。全军态势仍反映本案已承诺组织的整体潜力，两项不混用。计算每十年有界更新，不增加年度人物扫描。

NPC 宗门仅战意低于35才消极守备，不主动出击但保留防御和消耗；低于20且所在战役已发生至少三轮交锋才请求撤回本宗，盟宗继续。低战意预备队不由 NPC 统帅优先派出。玩家有权组织仍使用本部进攻／固守／撤回军令，不被后台强改意图；战意及四项依据在联军卡和议事页投影。新的统帅调度仍仅接受整宗闲置组织。

## 可执行和约

| 条款 | 前提 | 实际结算 |
| --- | --- | --- |
| 无条件停战 | 对方代表批准 | 一千年日历停战，约十次百年行动，原路撤军 |
| 长期休战 | 对方批准 | 三千年真实日历停战，约三十次百年行动 |
| 战争赔款 | 本方至少50态势且有真实获胜战役回执 | 一倍本方原账战争损耗＋败宗现款25%；实付最多败宗现款75%，不再以动员预算封顶 |
| 加重赔款 | 本方100态势且有真实获胜回执 | 两倍本方原账战争损耗＋败宗现款50%；实付最多败宗现款90% |
| 拆除战区据点 | 至少50态势、获胜战区原敌宗据点存在、合纵连横启用 | 复用 `territory.peace.apply` 拆除一处明确据点，保留剩余影响 |
| 退出争议战区 | 100态势、获胜战区原敌宗影响存在、合纵连横启用 | 复用原影响移除；山门位于此处时经既有强制同界迁址，原资产不随人搬运 |
| 移交战败宗产业 | 100态势、实际败宗原产权可交接 | 复用 `economy.war_assets.transfer` 接管一宗现存产业、市税、可承接商队；原库存、储量、在制品、运单与地点保留，产业暂停待安排 |

损耗依据原战役的已消耗／毁损军需、被夺军需、已付动员与逐年驻军服务；不把调拨本金、采购后仍持有的商品、退款重复算成损耗，不为伤亡凭空生成财政支出。补偿需求按可支付败宗现款占比分摊，实际赔款按本方原实际出资分配给至多六家原组织，不由主战宗独吞。页面分别列损耗、索赔总额、实付额度、缺口与分配明细；签约接受实付不足即豁免缺口，无虚构无资金债务。资金不足可以改谈原产业或战区权益，不保证所有战争都有足额可收的战利品。

每次选择一项主条款，明确展示目标组织、战区、金额或资产数量，不以分数直接生成现金／领地，也不处死、吞并整个种族。领地／产权条款限一个有实战回执的原败宗；没有实际目标或 DLC 未启用时不提供对应选项。产权交接沿用原商队容量，超额原商队转为独立经营，详见原产权回执。

获胜资格按原真实联军核验，不要求最初的主战宗门一直存续。原主战宗门灭亡后，存续、仍支持原阵营且实际参加该获胜战役的盟宗保留战果资格，现金仍沿原全案实际出资分配；全无出资权重的历史回执只在该战役实际存续胜方中均分，不把旁观预备队补成胜者。产业／战区条款的接收方优先原主战宗门，否则按该役原出资与稳定编号选择存续盟宗，重新报价后才可执行；无存续真实胜方仍不能索取财产。

日历停战同时约束原参战组织；族议宣战、独立战役、战略配对／增援、普通盟军加入、NPC 随机外交与内政宣战候选共用原条约年份，不能靠推进几次旧行动单位或换成盟军身份绕过。战争页显示剩余年限，完结战争的历时停在原终战年。

子战役归营但总战争尚未签约／结清时，原双方承诺继续约束组织，不能另开独立战役或借盟军重打同案。初始子战役通过明确的 `strategic_war_id` 授权建立，核验原动员阶段、两边实际组织与剩余战役容量；仅关闭军需准备或传入无效父编号不能绕过。NPC 随机外交／内政先排除这些对象，不把拒绝异常带到年度推进。

和谈复用族议资格、原代表与有效组织授权。涉及玩家作为对方政治代表或有权参战组织时，提案保留二十年由玩家确认或拒绝，不后台扣款。玩家接受条件后重新核验当前原代表及多数票；本宗确认不能替代全族政治批准，有本方族议资格的玩家只增加本人一票，不凭宗门身份补票。多数未通过保留战争并记录拒绝，不付款、不交产权。提案不冻结战役；过期及付款／目标失效则重谈。NPC 只自动提出赔款或白和，不自动生成领地夺取条件。双方战果、厌战和可执行代表参与回复；无真实合法代表不得凭空补票。

命令走单档事务工作副本、当前修订号、唯一编号及递增序号。非白和须核对服务端原报价指纹；旧页面的金额、组织、产权或据点发生变化时拒绝并刷新，不自动重发。赔款无部分静默执行，无个人行囊征收，不把退款或赔款记为经营收入／商品成交额。同一和约仅执行一次，原撤军军需退款另走原回执。

旧独立宗门和谈与会战使用相同的当前人物状态限制：原事件、劫数、死亡、关押或拘魂存在时，在投票与经济结算前拒绝；原事件及后续奖励保留，拒绝不扣费、不消费 RNG、不保存。页面按相同原状态收起和谈与作战操作；旧页面提交失败后读取当前权威投影，不自动重发，正常处理原事件后恢复合法操作。

## 战役界面与地图

沿用“经营 → 战争”的态势／战役／议事／战报导航。战役页按战场、行军／交锋／撤回／归营进度、两侧联军和宗门战意、战场士气与补给分区；敌方军需仍按原可见性裁剪。议事页采用单选条款卡与履约明细，四主题和手机横竖屏复用现有色彩与布局。

补给情报使用原会战参战身份判断，不以是否拥有宗门指挥权判断。普通宗门成员、家族成员、负责人及已登记的防务客卿同样隐藏敌方实时补给；无参战组织身份的本界旁观者沿原规则查看双方。身份查询只读原成员与客卿义务，不因查看页面初始化内政职位或人物性格。操作授权仍单独核验，不因能看到本方补给而取得指挥权。

原人物属于唯一参战方、本人实际到场且自由时，战略战役页提供“亲自参加会战”，调用原详细会战和反击，按本人境界加入当轮实际军需，实扣商品与能源、保存伤亡与资源；普通成员亲征也计入。出阵参数只在该次调用栈传递，不登记第二份玩家或永久编入名册，成功或异常退出均恢复原 NPC 需求及驻军参照，后续后台会战不重复计算玩家。每十年一次，提交后将下一次日历会战安排到十年后，禁止连点或普通旧入口刷轮；未亲自到场不能遥控本人战斗，不自动编入玩家。

军需与战略出阵共用按原编号解析的参战人物查询，兼容宗门、家族、世界、重要人物和关系人物登记，不按保存容器遗漏人数或复制人物。实际交战与当轮军需只计已到真实战场的原驻扎成员；初始动员、在途潜力与到场出阵分别使用原行程。附庸调人与页面候选共用资格：本人自由、同界同实例、无任务，源宗和接收宗均须完全闲置；先校验收录门槛再改原宗籍，拒绝不改名册、府库、RNG 或行程。合法调人保留原地址，不借此瞬移或重开任务。

双方同时断粮或士气归零时按相持收束：原战役无获胜方、无败方、战果归零，不进行已溃阵后的额外交锋或生成胜利索赔。单方溃败仍沿原胜负规则。战略战役继续原路归返和唯一退款；旧独立 AI 战役仅执行白和，玩家指挥的独立战役仍可沿原和谈入口办理白和。

地图读取原 `game.wars` 的实际地点与阶段。平面／立体节点均有独立“集结／交锋／撤军”标记，即使当地另有山门也不覆盖；选点和活动名录显示联军宗数与实际交锋数，可跳到指定战争的指定战役。未到场的集结不冒充已交锋，归营完成移除标记。纯投影不移动、不耗时、不消费随机数、不保存相机或战役副本。

战区遭遇候选复用原会战有效人员入口。战略战场须原驻扎行程与实际地址同时成立；未抵达、撤回、返乡、归营、败逃、镇压、关押及其他失效人物不再按历史名册触发遭遇，实际在场部众仍可遭遇。只读取原人物，不移动或复制部队，原遭遇概率与冷却保持不变。

## 状态与性能边界

原 `strategic_war_state` 增加战意因素、当前提案、唯一和约和谈判时钟；原子战役增加消极组织编号与亲征冷却。归属已人工登记[状态合同](world-transition-state-contract.json)。所有权仍留原人物、组织、经济与领地服务，未新增跨界通道或迁移例外。

无战争时不评估战意或谈判；战意每十年最多十二宗，父战争仍最多两案、每案两战役，动态组织终身十二家上限不变。配对最多36组、条款七项，产权与领地投影只在查看／提交时按原有限状态构造。地图每次按原战役一次分组，不新增年度扫描或持续动画。

专项入口：`tests/test_strategic_peace.py`、`tests/browser_strategic_peace.py`，并复验原战争／调度／审计、军需、组织经济产权、领地、跨界、空间与旧事件领域及三项门禁。浏览器与 Python 分阶段、单实例运行，使用隔离新档，不修改用户存档。
