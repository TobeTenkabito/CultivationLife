# 斩三尸与合练规则

维护基线：本体 1.58.0，存档结构 8。

至臻邻域采用统一增强 25%，三尸的超我尸复制培养境界最多化境四层。斩三尸要求实际击杀全部对手，没有总轮数上限；单次请求分批保存战斗现场。

## 玩家建议

1. 优先有实际杀伤能力且能续战的邻域；封锁、镇压与拖延本身不是通关。
2. 可从进逼预案开始准备，不照搬天五衰的纯守御方案；实际效果取决于所选邻域。
3. 大成四层比化境四层更可靠，能利用超我的培养上限；最终版至臻三维再提高 25%，仍不保证胜利。
4. 温养会被复制，对普通战斗有益不等于提高三尸通过率。
5. 多修邻域提供战前选择，副修四级道统不一定胜过主修八级；开战后不能换域。
6. 补足气血法力、仙窍留余量，按自身展开、维持、施权费用准备；续战不重置损耗。

## 合练规则

六至八部原始功法的道统，集齐并学会全套、修为达到最高品阶后，以 24 仙痕生成唯一 Lv1 合练功法。保留原功法，合练结果不反过来加入收集条件，不能重复刷新。

在道统界面独立参悟至 Lv9，不需同名玉简或新的外部注解。升 Lv2 至 Lv9 消耗 8、12、16、20、24、28、32、36 仙痕，共 176；每层开始时付一次，中断保留已付状态与实际年数。一次行动最多升一级。道统自身仍需原有等级前置与注解，唯一本源限制保留。

已激发邻域冠以“真·”，保留原 ID、培养与温养。加持按合练功法和道统中较低的等级生效：沿特色强化稳固、侵夺、权能、既有杀伤／恢复，节用类减少仙力成本。不产生仙力恢复，不增加上阵槽。未合练旧档不会被自动标记为真传；至臻的统一增强同样适用于旧档。

瑶池委托显示总功法数和当前可求数，并按道统分组；高于自身境界的功法暂不列入可求清单。多数全套含大罗品阶，因此合练不是太乙渡三尸的普遍前置。

## 校准方法

```powershell
python -X utf8 scripts/calibrate_three_corpses.py --profiles r13-t10 --output build/three-corpses-current
python -X utf8 scripts/calibrate_three_corpses.py --worlds 8 --seed 903001 --profiles r13-t10 --max-rounds 960 --output build/three-corpses-holdout
```

比较时固定世界、道统、培养、温养与战斗预案；抽样轮数上限不等于游戏内判败条件。重复战斗不算独立世界，样本通过率不能作为任意存档的胜率承诺。
