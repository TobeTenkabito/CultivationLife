## 能源阶位

九阶及以上能源为仙级。十二个具体阶位可从原NPC资材渠道购买、交易、探宝；原机关能源组件仍可安装。原三档能源晶ID分别明确为一、五、九阶，另补其余九个阶位，不把已存耐久转换为高阶能源。未标定来源按一阶处理，不补发。

| 能源相对傀儡主修阶位 | 一次自供的耐久消耗 |
| --- | --- |
| 同阶 | 5 |
| 低一阶 | 20 |
| 低两阶 | 60 |
| 低三阶及以上 | 无法驱动，拒绝安装 |
| 高一阶 | 2 |
| 高两阶 | 1 |
| 高三阶及以上 | 0.5 |

仙级能源不能安装到一至八阶傀儡，即使只准备发动凡阶攻击也不允许。已有不兼容组合不删除原能源，但不能自供；实际耐久保持，玩家可更换。九阶能源可驱动九至十一阶傀儡，分别消耗5／20／60；无法驱动十二阶。五阶能源无法驱动八阶。八阶能源可驱动九阶傀儡，但只能支持凡阶攻击；若开启供能且玩家有元力，仍按原优先策略垫付仙阶攻击，每次只扣一个来源。

剩余耐久不够一次消耗时保留残余值。供能开关、玩家垫付凡阶5 MP／仙阶10至40元力、卸下能源保留耐久等规则延续[傀儡能源](puppet-energy.md)。界面显示每件备选能源的阶位、每次消耗或不兼容原因；普通界面一层可安装至五阶，二层至八阶，三层至十二阶，与原机关能源组件界层一致；特殊空间不兜底。

## 邻域培养

培养窗口开放“邻域”：普通NPC、受禁NPC均须九阶以上、元力完全转化、位于道途对应上界，继续受同地点／原拘禁归属、封印、事件、任务与真实身份检查。机关、炼尸、活傀仍是能源驱动资产，不把来源人物邻域复制进资产战斗。

- 仙界沿原NPC `transcendence.doctrine`，每轮提升一个道统等级；初次选定当前目录中的稳定本土传承，不重抽。原活动道统优先，本源选择及非本源上限保留。Lv4起实际形成邻域，九／十／十一／十二阶修为最多Lv5／7／8／9，直接读取原配置。已有脚本传承不覆盖。
- 修罗、幽冥、轮回沿原本界邻域配置，在同一个NPC `transcendence.world_voisinages`记录实际等级；初次修习各界首个基础邻域，不伪造八部、本相或魂相资格。十三阶进度与原玩家配置一致，境界未达则停止，只收实际轮数。离开对应上界时不投影该邻域，回到原界仍保留成长。
- 一／五／十轮确定性培养；原仙界NPC已实际经过的道统修习区间先在副本上结算，再报价与提交，避免吞掉已有年份。主动培养标记`cultivated`，战斗读取时按配置修为上限，不再被随机生成NPC的稀有度上限压回；`mentor`沿原字段抑制自主重复修习。报价不写原人物、时间或RNG。
- 机缘培养不得超过施教者同一传承的实际等级。专材培养不扣玩家机缘或MP，新增悟域仙砂、凝域煞晶、镇域妖髓、轮域魂砂四件专材，一轮一份；材料只在对应上界使用。全部材料目录现为65项。
- 成长只写原人物账本，先结清原元力恢复区间，再扩容；邻域培养不直接恢复余额。玩家战斗与NPC战斗共同读取同一能力投影，释放受禁人物后保留同一人物的培养成果。现有玩家式独修五光／五脏／五蕴、择路等没有由这一步批量赠送。

邻域机缘报价取九阶一层玩家本体邻域最低基础步价的1.5%，专材单价12。完整的全DLC／装备／折扣实际自修成本标定仍沿首轮待验收事项，不宣称已完成全组合证明。

## 立绘与动作

内置image_gen参考已采用的细线衣饰原稿，新绘人形机关、男炼尸、女炼尸三套全身立绘及同源头像；原稿、完整提示词在`design/controlled-351`，运行素材在`web/assets/pixel/controlled-351`。导出只裁分主体、最近邻缩放、48色与二值透明，沿原128×192立绘、96×96头像规格，不程序补画人体。三张原稿均检查双手、双足、连续身体和边距。

受禁NPC与活傀使用原人物身份立绘并增加受控标识；培养窗口、御傀与俘虏旧页面都接入。固定人物、未知形态与特殊宿身继续遵守原图像选择约束，不把异族或非人形机关画成人形。此次新绘覆盖人形机关与人族炼尸，其他机关形态未新增专属静态稿。

参战机关、炼尸、活傀使用已有对应攻击／受击／防御动作序列。新增每回合`ordinary_attacks`记录实际出手者及作用阶位，回放按真实记录筛选；能源耗尽、受控停手不再被队伍动画代为出手。仙阶攻击增加金色环效及仙阶标签，凡阶不显示；领域仍沿原邻域展开动画。所有效果只读战报，重播不付费、不消耗RNG。
