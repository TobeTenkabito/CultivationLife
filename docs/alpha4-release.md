## 本体与 DLC 边界

`cultivation_life/realm_appearance.py::resolve_realm_appearance` 是无随机数、无持久写入的通用选择函数：输入境界、分支、变体、已记录历史以及内容包提供的阶段表，返回静态与战斗身份。可使用稀疏阶段表，选择不高于当前境界的最近已绘档位。不会凭历史缺口猜测玩家的分支。

妖修桥接层读取当前实际血脉节点的 realm_index，复用普通 `evolve_monster` 完成突破后产生的权威节点；封印下界显示等级不改变肉身形象。既有变身、宿身、依附条件优先，不覆盖其身份。头像、详情、缩略和新生成战报使用同一选择结果；历史战报保留当时的身份快照。

所有妖修 PNG、图集、阶段表、战斗定义与 576 条注册声明均位于 `dlc/monster-bloodlines/assets/visual`。DLC manifest 的 `visual_registry` 声明装载入口，本体公共图录只合并已启用包且不允许覆盖本体身份、注册他包地址或逃逸素材目录。安装目录与冻结资源目录分别传入，支持 Windows EXE 外置 DLC 和 Android 内置发行包。渲染器依据已注册 combat_actors 与 energy_effect 读取动作及灵息效果，不硬编码八族名单。运行时不读取 design、提示词或制作脚本。

卸载／关闭妖修 DLC 后，其图录不公开、专属 HTTP 素材地址返回 404，缺少注册表的历史战报不加载可选图集。原有 DLC 关闭时的玩法资格处理保持不变。

## 验收与发行

采用用户允许的相关领域范围，不声称全仓回归：`verify_scoped_release.py --profile visual --focused-visual --monster-visuals` 覆盖八族、通用境界接口、插件归属、战斗／展示／存档上游、跨界既有保护，以及三项仓库门禁。浏览器逐套检查 143 种静态形象、139 种动作身份并通过真实进化按钮验证即时切换；播放不改存档和随机状态。

Windows 使用最终同一 EXE 在有／无 DLC 的隔离目录运行；Android 使用签名发布 APK 与独立测试 APK，在 Android 12 横竖屏验证八族高低境界、动作加载、原进化按钮和资源释放，另保留既有事件、NPC、邻域与四主题检查。最终证据绑定源码摘要与 EXE／APK 哈希，`package_scoped_release.py` 校验后输出 Windows、Android 和妖修 DLC 独立包。未做实体手机验收。

离线重导入口：各族 `scripts/prepare_monster_*_assets.py`；羽／猿静态重导会重新接回已采用动作；最终由 `prepare_monster_release_assets.py` 统一装配 DLC 图录，禁止把可选声明写回本体图录。
