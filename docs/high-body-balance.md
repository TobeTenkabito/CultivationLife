# 四道途高阶炼体首轮平衡（历史）

本文保留首轮数值和验收记录。用户随后要求缩小分差，当前配置与最新结果见[缩差平衡](high-body-close-balance.md)。复现本文旧数值需给下述模拟命令加`--config build/body-balance-accepted-config.json`，不再使用当前源码默认值。

2026-11-03，按用户要求将完整高阶炼体的综合强度调整为魔修＞仙修＞妖修≈鬼修。比较同层数、同独修重数、同六维／装备／元力与邻域配置，不要求所有阵容和每个成长阶段都按固定顺序获胜。培养价格、专材产地、十层解锁、五十层上限及原本源收益沿用原规则；本轮不升版、不打包，不读写用户游玩存档。

## 数值与定位

下表为零重→十重。百分数均为实际机制比例，行蕴按目标每种原始触发机制分别计算。

| 道途 | 本轮配置 | 作用 |
| --- | --- | --- |
| 魔·色 | 威能加成0→70%，侵夺加成35→80% | 提高争域能力，让暴击和追加施权有合法兑现机会；仍须支付原费用并通过对抗 |
| 魔·受／想 | 暴击20→70%，固定200%效果；额外施权免费率15→70% | 高压爆发与连续施权，真实暴击命中后才追加 |
| 魔·行／识 | 每种增幅3→16%；敌方每次额外施权回复态势与元力1.2→4% | 放大敌方原始机制暴露，缓解追加行动造成的资源差 |
| 仙·坤／震／坎 | 抗封禁0→30%；治疗增幅0→65%；额外行动15→50% | 保留综合恢复、普通出手与行动优势 |
| 仙·离／乾 | 侵蚀1.5→4%；静默5→18% | 降低群战叠加与整轮封锁的支配性，先后手规则保留 |
| 妖·玄肤／逆骨 | 仙级态势减伤4→15%；逐段闪避10→20% | 防御反应型，仍可克制多次主动施权 |
| 妖·烈脏 | 数值效能2.5→4.5%；控制反击成功率10→20% | 闪避后免费择一；数值治疗／修复／镇压不额外投控制骰，封锁与二值禁制须判成功再过原抵抗 |
| 妖·沸血／神魂 | 解控消耗45→35%可用容量；交换阈值40→50% | 保留解控与一次翻盘能力，同时提高反复解控成本 |
| 鬼·无相／御魂 | 回复增幅0→30%；每人阵亡回复3→6%态势与元力 | 保持既有回复与真实阵亡限制 |
| 鬼·照业／忘情 | 三段各40→65%；溢出／追加20→55% | 增强培养成长与目标集合联动，不凭空增加行动次数 |
| 鬼·因果 | 累计实际元力减少阈值50→15%；固定16%攻击强度 | 培养只降低阈值；无消耗全体攻击经照业仍是三段全体 |

配置入口为`content/doctrines.json`、两个道途DLC的`content/world.json`及`cultivation_life/ghost_body_content.py`。鬼修数值从原分散公式集中为同一纯数据表，正式投影和离线候选共用构建器；实际人物与NPC没有测试专用强度修正。

## 结算边界

新建且未显式给定基准的邻域采用`authority_reference=max(100,基础strength)`。同阶邻域的威能、侵夺、稳固等绝对数值一起升高时，效果按相对威能结算，避免原固定100基准让高阶每段直接触及100%上限。显式基准与已保存快照的具体数值保留；不重算已有战斗。

离上沿原维度对抗选择的有效攻击邻域侵蚀目标，同侧重叠邻域不逐个重复侵蚀。色蕴只将侵夺倍率接入原建域结算，静默后加成为0，不跳过展开、维持、覆盖和对抗。烈脏控制成功率是反应本身的数值门槛，失败照样消费本次免费施权，不改选第二种效果；沿原战斗RNG，战报记录目标、概率及成败。旧冻结描述符若未包含新控制通道，保持原显式反应语义，不改其数值。

轮首资格／暴击／静默、实际事件目标、因果路径防重、死亡凭据与可用容量仍按[通用因果规范](ghost-body-and-causal-events.md)执行。新增`incursion`和`retaliate_control`只属于原能力快照，人工登记[状态合同](world-transition-state-contract.json)，不新增个人养成字段、资源池、世界迁移或时钟；结构仍12，只接受12。

## 对抗方法

`python scripts/calibrate_high_body_balance.py --seeds 32 --seed-offset 512 --sizes 1 2 3 --output build/body-balance-accepted.json`可复现独立验证。六组无序组合，各自交换双方位置；完整50层、独修0／5／10重、单挑／二对二／三对三、争域／强攻／守势／恢复四类等配邻域、32个未用于选值的种子，共13824场。轮首先手轮换，双方同六维100、同仙级被动装备、同可用容量800或1600；四分之一种子从35%元力开始。普通伤害调用正式`exchange_damage`六维曲线，邻域和炼体使用正式`VoisinageBattle`账本，不复刻另一个战斗引擎。

得分为胜1、负0、平0.5，对三种对手等权平均，不能把该分数称作全游戏胜率。普通交锋六维与装备保持同配，用于隔离本轮机制；没有遍历全游戏的所有功法、装备、境界差、移动或混合阵容。相持48轮只记模拟平局，不截断真实战斗。

独立验证共13824场、67273轮，48轮上限平局0场。综合得分如下：

| 直接对抗 | 左方得分 |

妖鬼整体及满重强度接近，直接交手也接近五五开；不是把两者强行设为必定平局。零重仙修的整体稳定性略高于魔修，魔修随培养形成更强的侵夺、暴击与追加行动联动。30层未解锁完整后两法的阶段仍有自己的克制与成长空档，不按完整五法排序强行补发机制。

另以6912场等配压力对抗，将邻域三轴绝对值放大五倍、主动强度提高到20%，综合得分为魔67.97%、仙55.99%、妖36.88%、鬼39.16%；妖鬼直接对抗45.92%。在1152场满重“烈脏固定封禁邻域”专项中，综合为魔79.08%、仙58.33%、妖30.56%、鬼32.03%，妖鬼直接对抗48.96%。封禁模式保留克制价值，没有再用必成控制取代数值效果。原始结果分别在`build/body-balance-accepted.json`、`build/body-balance-accepted-power.json`与`build/body-balance-accepted-control.json`，后两组复现分别加`--seeds 16 --seed-offset 256 --effect-power .2 --authority-scale 5`，以及`--seeds 8 --seed-offset 320 --ranks 10 --monster-choice voisinage`，均保留`--sizes 1 2 3`。

## 回归入口

新增`tests/test_high_body_balance.py`核对候选构建器与正式人物投影一致、0–10重合法边界、等阶倍率、显式基准续战保留、色蕴受静默约束、重叠离上仅一次，以及烈脏控制成功／失败、免费额度、数值恢复不误投控制骰、旧冻结描述符和新通道存读档。固定独立种子的整体排序检查调用原战斗引擎。

`scripts/simulate_high_body_combat.py --seeds 8`继续检查16种有向组合（含镜像）的有限数值、可用容量、因果链、阵亡、JSON续战与逐轮名册反序一致性。培养页面真实点击验收另外核实色蕴威能／侵夺、烈脏效能／控制率、鬼修满重比例及固定因果强度，仍覆盖付费、过期恢复、缺材与布局；事件和百科页面沿原浏览器回归。

最终数值的因果检查：4608场、23884轮、6389次JSON续战核对、23884次名册反序核对，失败0，原始记录在`build/high-body-simulation.json`与`build/body-balance-final-causal.log`。这是结算一致性检查，普通输入是受控夹具，不与上面的正式伤害曲线平衡得分混算。

最终代码回归：领域376项、战斗与功法285项、跨界／身魂／事件边界270项，共931项全部通过；证据为`build/body-balance-final-domain.xml`、`build/body-balance-final-combat.xml`和`build/body-balance-final-boundary.xml`。跨界契约、模块依赖及文档三项门禁通过，没有新增禁止的world直写或依赖环。

最终浏览器验收：四套培养页、旧事件、四道途离体旧按钮边界、百科共七个脚本全部通过，日志为`build/body-balance-final-browser-*.log`。四套培养页继续覆盖桌面、手机、横屏与原主题，新增数值文字断言随真实付费或满重加载核验；截图沿各脚本原`build/*-browser/`目录。全部仅使用临时角色，未修改用户游玩存档。发行EXE与签名Android验收留给正式打包步骤，不以旧dist作为本轮成品。
