# 著经立道 · 自创功法与一代传承

本体3.1.0，DLC `official.authored-techniques` 1.0.0，Android版本码82。只支持存档结构10。本次仅改动领域、必要上游及成品验收，不做全仓回归。最终通过数量和成品哈希见发行清单；本文不代替验收证据。

## 玩法和价格

2026-10-31源码外观调整：创法入口使用紫墨书卷、金色书脊及DLC菱形角标，桌面侧栏、手机修行导航与常用／最近快捷入口保持同一标识。面板内定稿、添加效果、刻录与合参按钮沿用紫墨主题，并保留禁用和键盘焦点反馈；配色随四套文字主题及新版浅暗切换。仍由原加载资格控制入口，所有操作、点数、费用和存档规则保持；本次未升版或重新打包。

修行导航进入著经立道。所有普通已学功法都提供创法点，无须装备；每部收入为10×原初境界品阶²×等级²。已经计入的最高收入保留，升级仅补差额，卸下或重复学习不能重复领点。自创及继承功法不返点，防止自行创作后无限领点。

编撰时选择名称、境界、类型和属性，给机缘、气血、法力、战力分配整数点数。境界不超过已学普通功法的最高境界。每项数值按同境通用功法基准×投入点数÷(10×品阶²)生成；界面即时列出实际Lv.1数值和价格。定稿自动学会Lv.1；同一存档至多24部作品，书名不得与既有书籍重复。

每书至多4条效果，每条只有栏目、解锁等级、一个轮次条件和一个效果。条件为始终、某轮起、仅某轮；效果为普通六维、邻域杀伤／侵夺／稳固／维持消耗与最大战斗态势回复，均明确按百分比计。比如“Lv.2，作为辅修时，第3轮起，每轮回复5%最大战斗态势”。普通六维上限50%，回复上限10%；等级只决定何时解锁，不重复放大效果。

效果价格＝向上取整(数值×效果单价×(10－解锁等级)/9×条件系数)×品阶²；普通六维每个百分点2–3点、邻域4点、回复12点，条件系数为始终1、某轮起0.75、仅某轮0.5。属性和效果价格相加，服务端复算并扣点，不接受客户端报价。更晚解锁更便宜，需要升级后才能发挥。

本世作品的玉简仅在书架刻录，Lv.n玉简价格为向上取整(定稿总价/2)×2^(n－1)，1≤n≤8。使用原有同级玉简合参升级，最高Lv.9；继承玉简也沿原合并／升级入口。

## 继承和流通

开局页面可选一个已有存档作为前世，普通、快速和自定义开局共用该选择。新存档仅深拷贝该来源的own作品，绝不复制其inherited作品、人物、资源或点数；继承书架是冻结的定义，不自动学会。A创甲，B继承甲再创乙，C选择B时只继承乙。

本局创作不进入公共商品／任务／掉落池。前世作品仅经黑市、交易集会拍卖／场内私下交易及匿名交换会获得，受原地点、界面、入场、货币／材料、库存与忙碌守卫约束。首次获得学会Lv.1，后续得到玉简。高阶作品不能在低阶世界流通。普通商店、宗门研究池及自定义开局物品池不注册这些定义。玩家传授给已有同道是该NPC的学习记录，不产生玩家领取途径；自创玉简不允许寄拍回购。

交易会向真实在场NPC生成前世传承供货时记录其掌握等级；满足境界／灵根者沿人物原有身份学习，稳定等级1–9，不新增或克隆人物。重复供货不重掷、不重复叠加战力。人物功法等级及装备栏目均随本人保存；既有主修等级、宗门研习记录和已发生的传授事实保留。

## 权威入口与边界

Player.creation_insights归personal；GameState.authored_techniques归global，已登记[状态契约](world-transition-state-contract.json)。NPC technique_levels与technique_slots属于人物事实，通过关系引用访问，不能成为关系副本。纯查看和估价不消费点数或随机数；写入沿GameEngine命令锁，revision拒绝过期提交，原存档保存入口持久化。

效果编译成现有combat_semantics V3规则，由combat_loadout一次投影。玩家、NPC和试炼使用同一结算，栏目、等级、灵根、界面、禁用功法／辅修限制均有效；回复是最大态势百分比，不能复活退出战斗者。效果输入为有限白名单，不接受脚本或任意条件树。DLC关闭保留存档作品，关闭创法入口、流通和额外效果；既有基础功法数值不擦除。

本次没有迁移行为、空间实例或跨界例外。所有移动、资金及交易仍由原入口负责。Android缘界面用可收缩的图文布局和断行，修复立绘挤出文字问题；既有导航增加修行内的创法项，未另设堆叠工具条。
