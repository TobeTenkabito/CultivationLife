# 新手教程入口与阅读指南

维护基线：本体v3.3.1，2026-10-30。仅支持结构11，结构1–10拒绝加载、不迁移。文件名保留初次引入编号。

新手教程提供两条路线：新版界面导览帮助认识当前电脑／手机布局，修行实践则保留高亮真实控件的32步操作引导，详见[亲手问道](tutorial-1481.md)。两条路线都从原新手教程入口进入，不增加侧栏功能键。

进入人生后，可选“新版界面导览”。它按当前文字／新版界面、桌面侧栏／手机六分类底栏高亮真实入口，带玩家打开人物、行动分类、绘景、行囊、地图、诸天、设置与百科；手机实际输入搜索并打开结果。教程完成过的角色也能重新查看。窗口缩放或横竖屏切换时重新定位原控件。

界面导览只查看与切换页面，不提交游戏命令、不改变人生进度或领取奖励。进度只保留在当前页面，可暂停后继续；刷新或换人生后从头重看。它不消耗原修行实践步骤，完成后可回到原实践进度。

设置中的完整阅读指南与操作步骤分开维护。旧十课用于基础阅读，设置百科另有搜索、分类和按实际加载 DLC、当前角色进境显示的章节。阅读、搜索、切换章节不推进时间；特定教学实践采用明确说明的一次性确定收益。

符合条件的新手可在教学事件中接受或谢绝沈照尘的师缘，再选择宗门引荐。已有在世师父、宗门或高境界的角色按当前处境调整，不替换身份、不重复领取奖励。师父通过 NPC ID 关联真实人物，其后续成长、生死与位置由权威人物记录决定。

修行实践进度随结构11存档传递；FSWD1是传输封装，不提供旧结构兼容。维护代码为 `system/tutorial_walkthrough.py`、`system/tutorial_mentorship.py` 与 `web/tutorial*.js`，验收见[百科维护](handbook-1481.md)。本次双端发行范围与证据见[3.3.1说明](release-331.md)。
