# v1.48.0 新手教程

在初始页点「新手教程」，可决定下一个新角色是否开启引导。进入游戏后，同名按钮可随时打开说明，开关只改变当前角色的选择。旧角色默认关闭。暂时收起窗口不会关闭引导；关闭引导也不会清除已读章节或既有师承。

十课依次介绍：认识界面，灵根与机缘，资源获取，功法差异，成长与战斗，NPC 的一生，拜师，游戏目标，远行与上界，以及存档。可顺序阅读，也可用章节下拉框查阅。设置内另有完整的折叠指南，不必开启引导也能阅读。

「看看包裹」等演示仅打开相关窗口。它们不修炼、不交易、不扣资源，也不推进年月；从主界面再次打开教程即可接着阅读。真正的行动仍由玩家在各窗口自行决定。

## 师缘：山道授业

拜师一课提供一次可选的师缘。人间诸界尚未结丹、没有在世师父、且已处理眼前事件与困境的角色，可以遇到结丹后期的沈照尘。选择执弟子礼，便确定成为其弟子；选择谢绝，不损及声望。相遇、拜师均不消耗岁月或灵石。

师承建立后，在「关系」查看师父和日常往来。沈照尘会参与正常的世界生活，并非永不变化的教学人物；若相遇后继续长年闭关，其处境也可能改变。已有在世师父、修为已到结丹或身在上界的角色仍能阅读说明，但不会被替换师父。反复开启、关闭、翻页或刷新不会重新发放师缘。

教程进度和师缘随当前角色保存，也随存档码跨端迁移。六套主题、Windows 与 Android 使用相同内容。
