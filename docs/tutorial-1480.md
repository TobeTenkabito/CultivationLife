# 新手教程入口与阅读指南

维护基线：本体 v1.58.0，2026-10-04。文件名保留初次引入编号。

当前教程是直接高亮真实控件的 32 步操作引导，详见 [亲手问道](tutorial-1481.md)。初始页可决定新角色是否开启；游戏中可暂停或续接，已完成步骤与教学奖励随角色保存。

设置中的完整阅读指南与操作步骤分开维护。旧十课用于基础阅读，设置百科另有搜索、分类和按实际加载 DLC、当前角色进境显示的章节。阅读、搜索、切换章节不推进时间；特定教学实践采用明确说明的一次性确定收益。

符合条件的新手可在教学事件中接受或谢绝沈照尘的师缘，再选择宗门引荐。已有在世师父、宗门或高境界的角色按当前处境调整，不替换身份、不重复领取奖励。师父通过 NPC ID 关联真实人物，其后续成长、生死与位置由权威人物记录决定。

进度随受支持的结构 6／7／8 存档传递；FSWD1 是传输封装，不提供结构 1–5 的兼容。维护代码为 `system/tutorial_walkthrough.py`、`system/tutorial_mentorship.py` 与 `web/tutorial*.js`，验收见 [百科维护](handbook-1481.md)。
