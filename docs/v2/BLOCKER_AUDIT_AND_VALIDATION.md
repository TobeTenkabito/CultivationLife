# V1/V2 阻断项根因审计与校验基线

## 结论

原有的44个阻断项不是44个独立回归错误，而是功能矩阵中所有尚未达到`pass`的必需功能。经过各批领域迁移，最后5项已经在本批次清零：统一行动覆盖全部12种行动，剧情运行时覆盖363/363条事件，势力客卿/决议/招募闭环完成，影子适配器覆盖全部行动，独立V2 HTTP与正式前端接通。当前阻断数为0。迄今转为完整通过的功能包括：

- `presentation.settings_debug`：Schema 4 持久化界面设置；异界消息继续模拟但默认不投影，Debug 模式才显示全部世界。
- `relations.faction_invitation`：只有当前世界中存活的师父、道侣或道友可被引荐入宗；弟子、侍妾和无关系人物不能借此加入。
- `factions.rewards`：元婴及以上成员可固定年度奖励；每年结算贡献与收益，永久属性在退宗后仍保留。
- `cultivation.body`：炼体训练、圆满、分段概率、失败保留、保底和每层固有气血成长进入独立组件。
- `cultivation.divine_sense`：神识训练与手动升级进入独立组件，突破仅扣当前等级所需经验。
- `cultivation.transformations`：真灵素材直接/提纯/批量炼化、六维圆满度、容量和战斗空间编队闭环完成。
- `cultivation.realm_breakthrough`：概率突破、保底、传统三关、天劫五关和五轮天魔劫均进入可保存读取的统一试炼状态机。
- `world.realm_crossing`：下界飞升、邀请过滤、下界封印/返回、仙界与修罗界九重飞升全部复用九领域清理事务；事件内部发起的跨界由最后一个领域回执提交。
- `economy.spirit_plant_sale`：采收灵植成为带年份、品质和价值的实例资产，出售精确消费该实例并原子结算灵石。
- `economy.spirit_field`：瞬时开垦、播种、统一时钟生长、MP灌溉、造化灵液、采收与五艺经验形成闭环。
- `crafting.alchemy`：堆叠药材和实例灵植共用材料校验与消费路径，MP、随机结果、产物和经验原子提交。
- `economy.auction`：预告、开场、竞价、结拍和黑市阶段进入可保存状态机；竞价与寄拍复用统一托管账本，跨界取消立即退款，匿名身份、交涉和私下买卖均已接入。
- `crafting.artifacts`：四个精确材料实例的预览、品质抽取、锻造、图谱、出售、寄拍和战斗属性形成闭环。
- `formation.nine_palace`：九宫推演、预设、真实实例启阵、收阵、删除、镇地、修复和撤阵全部复用托管账本。
- `artifact.natal`：普通/炼器法宝认主、祭炼成长、等级槽位、唯一镶嵌、解绑返还及战斗/渡劫效果完成。
- `relations.lifecycle`：解除关系结束唯一关系边、重置规范好感；解除道侣时按配置增加心魔，人物投影直接读取规范寿命与生死状态。
- `relations.dao_friend`：结交门槛、切磋/论道、机缘、好感和年度冷却完成，并与引荐入宗共享同一好感档案。
- `relations.master_disciple`：同宗师徒请求、拜师帖决断、向师父索取、向弟子赠物/传功及对应限制完成。
- `relations.dao_companion`：在既有结侣与互动闭环上接通直接突破和持久化试炼的同步突破，且只允许同界、同境界、同主修功法的存活道侣参与。
- `inventory.item_use`：孕育丹药力进入家族权威组件，下一次有效孕育尝试消费；至此冻结清单内物品使用分支均有明确状态所有者。
- `relations.capture`：魔修生擒师父、道侣或好友复用统一剧情队列；两段压制共享持久化运行时，成败都会正确断开原关系，成功只创建一条规范俘虏边。
- `factions.succession`：玩家创建宗门后可指定在世同界继承者；永久飞升无条件退出下界宗门，安排后事者在重返下界时才有概率触发寻觅祖师并恢复控制。
- `factions.family`：家族外姓招募、年度修炼、寿命重排、控制者生命周期与跨界话语权已经闭环；玩家离界后自治继续但界面不泄露名册。
- `factions.npc_operations`：内容表 NPC 惰性实例化为规范人物，派遣、截杀和同宗师徒操作共享生死、境界、地点与成员关系。
- `factions.diplomacy`：种族/宗门表决持久化为类型化外交关系；附庸方向明确，调人会原子迁移同一个人物实体而非复制页面记录。
- `party.management`：最多两名队友以规范关系边保存；同界/生死限制、行动单位互动、飞升选择和V1的50%/25%队伍系数均进入统一战斗快照。
- `combat.automatic_resolution`：单挑、击杀、生擒和多人战斗统一读取规范人物；地形、队伍、启用阵法与法宝特质写入可追溯战报。
- `war.aggregate`：外交宣战创建持久战争实体；双方阵营、盟友、名册、士气、厌战、先锋战、会战、议和、解散/吞并和三权通缉均使用规范实体，并支持旧档导入。
- `demonic.prison`：监禁使用规范收押关系；服刑按统一时钟逐年结算，刑满、死亡与跨界均会收束，旧档服刑状态可以直接导入。
- `demonic.captives`：俘虏释放、拷打、炼尸、活傀与鬼修夺舍进入同一事务；战死鬼修可保留合格俘虏完成一次战后夺舍。
- `demonic.puppets_souls`：机关、炼尸、活傀及外来元神成为规范实体；培养、控制衰减、反噬、战斗贡献、吞噬、炼魂和飞升清理形成闭环。
- `relations.concubines`：侍妾炼尸结束侍妾关系并生成同一人物实体上的炼尸组件，侍妾始终不会被当作道侣。
- `economy.black_market`：机关傀儡与炼尸可按战力估价出售，活傀被明确拒收，交易与其他黑市资产一样原子结算。
- `ghost.reincarnation`：轮回使用类型化确认事件；修为、神识与未用往生按规则重置，轮回印记、魂蚀、既有魂伤及历史本源高水位持续保存并影响后续突破。
- `ghost.soul_ecology`：百鬼夜行按统一时钟预告、生成和结束；游魂为持久实体，拘魂为类型化关系，十魂槽位、魂压、修炼与战斗效果读取同一权威状态。

## 校验结果与边界

本轮建立 `tools/audit_v1_v2.py`，同时执行以下检查：

1. 从 V1 HTTP 分派源码重新提取公共操作，与冻结清单逐项比较；当前为 101/101，无新增、遗漏或重复。
2. AST 扫描 V2 包，禁止导入 V1 `engine`、`models`、`storage`；当前违规数为 0。
3. 校验矩阵覆盖、证据文件及具体测试节点。`pass` 不再能仅引用一个存在但无关的测试文件。
4. 影子命令适配器覆盖12种冻结行动；道修、魔修、妖修、鬼修的多种种子继续执行稳定的`rest`/`cultivate`同源对比场景，避免随机事件把后续命令误报为执行失败。
