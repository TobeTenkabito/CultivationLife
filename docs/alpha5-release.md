# alpha.5 · 鬼儒佛人物实装

本体 3.0.0-alpha.5，Android versionCode 78。存档仍仅支持结构 10。

鬼修、儒修、佛修各新增男女主角及男女通用 NPC 共 12 套形象，36 张像素头像／详情／缩略 PNG、108 个完整人物关键姿态，编排待机、施法、受击、防御、承击、战败和施域预备 84 组动画。属于关键帧编排与现有渲染器微动，不宣称逐帧手绘。佛修女性为有发在家修行者，使用世俗裙装而非尼姑造型。

独立归属：百鬼夜行 3.10.0、圣人之道 1.6.0、诸法无我 1.2.0；各包含自身注册表、静态图、动作图集与来源哈希。本体仅提供通用声明选择与加载，不内嵌三个可选包的图像。禁用或未安装不返回或提供相应资源。男女形象按实际性别和道途匹配；鬼修沿现有人族出身道途模型，不新建“鬼族”种族。宿身、附身、未知身份、变化形态保持回退，具名 NPC 静态图优先，不新增世界人物。

主角与 NPC 使用现有头像／详情、缘界面人物卡、宗门名册、事件及战报入口；战报按真实双方及随行成员加载可选清单，修复只按主角加载而遗漏 DLC 敌方的情况。法术表现不改伤害、时间、RNG 或任何持久字段；无跨界例外。动作缓存有上限，关闭回放释放位图。

原稿和提示词：本机 design/three-paths-alpha5-20261025；内置 image_gen 生成，最近邻导出并保留软透明。儒修女主承击姿态采用独立双足修正版，其余八帧原稿保持。

发行采用三道途人物与必要表现／战斗／持久化上游专项，不做全仓回归；运行三项仓库门禁、真实浏览器交互、Windows EXE 带／不带 DLC 以及签名 Android 12 模拟器横竖屏验收。实际结果以最终同版发行清单与 build 验收证据为准，不宣称实体手机验收。
