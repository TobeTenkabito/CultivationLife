# v3.6.0 瑶池西望

本体3.6.0，Android版本码99。仅支持存档结构12；结构1–11拒绝加载和导入，不迁移、不覆盖。继续使用山海图志、沧海夜色两个像素主题。

## DLC 本批内容

《瑶池西望：紫气东来》以 **1.0.0** 随包提供：瑶池专修与功德账本、主庙分庙及专项设施、六类地方争议、四司与属员、监察巡天、仙圃经营及三项仙会、三条仙府访古和七曜项目议政。补完三途交接、功德私人修缮、真实讲师清修讲席，以及四章紫气主线和四种原仙府结局。具体规则见[实施记录](yaochi-westward-implementation.md)与[1.0补完](westward-finale.md)。

所有新增功能沿原人物、建筑、库存、府库、工时与移动入口结算。仙界原有人口和原地点承载玩法；异地不能远程结算个人事务。

## 界面

DLC 专属入口、常用快捷入口、专属子页及操作按钮按所属扩展使用独立配色，仅统一 DLC 字样、按钮结构和禁用状态。瑶池西望为紫金，修罗为赤铜、佛修为檀金、鬼修为幽紫、归墟为海蓝、合纵连横为胭脂、妖族血脉为绯红、万灵争衡为苔绿、圣人为靛青、神机为铜棕、著经为墨梅、试境为星蓝。深浅两主题分别配色；禁用按钮保留灰淡虚线及原禁用状态。瑶池、天庭中的本体交易和政务沿用本体按钮，扩展子页单独标记。功能仍使用原导航和分页，不新增按钮堆叠。

## 发行验收

本次同版本重包采用 `scripts/verify_full_westward.py` 自动发现整个 `tests` 目录中的 pytest 用例，逐模块执行并核对发现数与实际执行数；任何失败阻止打包。每份测试和日志绑定最终源码哈希，保留逐模块证据。浏览器范围见 `scripts/westward_release_scope.py`，包含真实加载与点击、过期提交恢复、后续奖励与禁用状态、两种像素主题和多种尺寸。Windows 同一 EXE 分别有／无 DLC 验收；签名 Android 12 专用模拟器横竖屏实际操作与两主题检查。不声明实体手机验收。

同版本审计修复：瑶池专修、原委托、地方事务与本人公务双向检查个人占用，拒绝请求不扣款、不覆盖原任务；委托页按同一权威原因禁用接取。专修取消及退款也检查本人神游、试炼和诸天亲自任务状态，不能借恢复入口绕过普通地点规则。取消原专修后可正常接取新委托，DLC 停用后的合法交接仍保留。

最终测试记录、源码及产物哈希以 `dist/release-3.6.0*.json` 为准。验收仅使用隔离临时存档。Windows 请解压完整包以包含 DLC；Android 已内置十二个官方 DLC。

同时修复托管商队无货先聘护卫而长期耗尽资金、空库存挤占选货名额，以及诸天异象中交谈生成未准入人物导致保存失败的问题。商队地图补充本地情报与结算原因入口说明；真实亏损和风险仍保留。详见[经济托管复核](economy-trust-and-income.md)。
