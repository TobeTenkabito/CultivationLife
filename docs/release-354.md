# v3.5.4 简而有序

本体3.5.4，Android版本码97。仅支持结构12，结构1–11拒绝加载／导入，不迁移、不覆盖。DLC版本及原玩法保持。

## 适配与UI共用

`system/character/wiring.py`将16个重复适配收敛为6个具名工厂；工厂仅在装配时创建原签名闭包，实际调用不新增转发层。保持省略参数、显式None、关键字限制、调用时读取host和原回调异常传播，不改结算算法、准备／保存顺序或RNG。原独立依赖契约和兼容入口保留，不使用动态属性代理。

`web/ui-panels.js`在原有脚本中提供三个具名DOM工厂，15个面板直接引用；分别保留非空文字、非undefined文字与真值文字三种已有语义，以及class和id的区别。只创建原生脱离文档节点，使用textContent，保持按钮事件、禁用、旧页面拒绝及导航归属。没有新增网络请求、DOM框架、状态副本或游戏命令。

纳入前一轮旧组件清理：31处退役主题选择器、未挂入页面的旧容器／按钮、教程备用定位。当前主题仍为山海图志与沧海夜色，固定布局标识和存档结构不变。

扩展魔道回归时，在原适配代码上也复现了临时遭遇人物生擒后的读档错误：肉身快照将缺失的精修记录写成None。快照入口现在仅为缺失字段提供空字典，已有记录仍保留，不修补或覆盖用户存档；原读档校验不放宽。同时补齐旧傀儡测试夹具缺失的唯一ID，原战力断言保持。原失败证据保留在build/refactor354中，最终发行重新执行完整声明范围。

## 验证边界

沿body-ui发行范围增加架构、魔道、儒道和秘法领域测试，以及共用DOM契约与界面教程浏览器；保留师徒、NPC培养、Debug、高阶炼体、战斗、跨界、空间、211／212及存档回归，不宣称全仓测试。Windows同一最终EXE分别有／无DLC验收，签名Android12专用模拟器横竖屏实际操作并校验安装包、测试APK、签名和源码指纹，不宣称实体手机验收。

适配前后16个回调的执行字节码相同，另核对省略／None及绑定后替换原方法；微基准只评价对应回调，不推断全游戏帧率。DOM契约比较空值、零、false、中文、含标签文本及属性，记录原生分配微基准；真实面板仍由浏览器和成品验收。清理前后双主题三种尺寸的六组主界面截图逐像素一致。当前发行最终结果与产物哈希以dist同版清单为准。
