# 轮首机制计划与五蕴

2026-11-02开发源码，结构仍为12，只接受12，拒绝1–11，不迁移、不改写用户旧存档。本轮不升版、不打包。用户授权将轮首统一判定接入当前战斗，再实装魔修五蕴；后续明确把八部的玩家魔躯门槛降至10层。

## 通用结算

`system/combat/body_mechanisms.py`是中立规则模块，不读取人物、世界、内容或存档。`BodyMechanism`声明稳定编号、名称、优先级、依赖、轮首概率、有限输出与修炼等级。依赖必须存在且无环，每人至多32个机制，输出仅开放固定类型；每轮至多八份额外行动额度，禁止任意脚本或递归产生额度。内容提供方在战前读取原人物；五色神光沿已有资格数据适配，五蕴沿真实魔躯投影。

顺序为：

1. 读取参战状态，按原先后手、战力和稳定ID固定遍历顺序；生成双方全部原始触发记录。每种机制本轮仅判断一次，暴击、免费、抗封禁与乾古的概率结果均在这里取得。
2. 按依赖计算候选输出。受蕴成功时，想蕴登记一份须实际暴击后才能使用的额度，免费结果在轮首确定；坎道登记无需暴击条件的额度。行蕴读取目标的原始触发种类数，同一种只计一次，不合并敌我。
3. 按先后手落实静默。先成功者阻止敌方后手执行乾古，后手原始成功记录保留。被静默机制的实际输出清空；原始记录及行蕴的计数不重算。乾古静默敌方邻域及全部高阶炼体机制，包括五色神光和五蕴。
4. 沿原资源供给、展域费用、侵夺／庇护、连续支配与施权流程执行。通用执行器逐批消费已登记额度，基础批完成真实暴击后才能兑现相应条件额度。执行阶段不再重掷炼体概率，不再增加机制额度。
5. 每批实际施权完成后，统一计算敌方额外施权次数并兑现识蕴回复，然后继续剩余合法额度与普通交锋。取消、无目标或不能付费的行动不计；同次多目标仅计一次；免费施权计入，普通武器处决不计。付费施权已经发出、但被目标自身封禁抵抗时，仍为一次实际施权；特殊介入在付费前取消的动作不计。

普通行动与邻域行动仍分开；魔修未具备震合时，邻域治疗仍占普通出手。已死亡、镇压或逃离的人物不能通过识蕴复活。双方合格攻势沿原批次执行，不让人物列表顺序决定额外回血。每位特殊介入者仍每轮最多回应一次，额外行动不重置。

## 五蕴修持与初始数值

修罗DLC实际加载的魔修采用五蕴，沿原`asura_cultivation.body_level`培养至50层；10／20／30／40／50层依次解锁，初解锁0重，各自培养至10重。魔躯每层原有HP1200、MP800本源收益保留，不额外重平衡原六维。五蕴取代该道途本轮的神光投影，仙躯旧记录保留，不与五蕴同时叠加。

| 机制 | 零重效果 | 每重成长 |
| --- | --- | --- |
| 色蕴 | 免疫凡属性伤害，邻域威能加成0 | 威能加成增加3个百分点，十重30% |
| 受蕴 | 每轮10%概率使合法数值施权暴击，按200%计算 | 暴击概率增加3个百分点，十重40% |
| 想蕴 | 本轮实际暴击后一次额外施权，10%概率免除这次施权费 | 免费概率增加4个百分点，十重50% |
| 行蕴 | 目标每原始触发一种机制，既有削弱增幅2% | 每种增幅增加0.6个百分点，十重每种8% |
| 识蕴 | 每次敌方实际额外施权，回复最大态势1%与本场可用元力容量1% | 两项比例均增加0.2个百分点，十重3% |

这些是用户未指定数值部分的首版配置，位于`dlc/asura-manifestation/content/world.json`，加载时校验所有0–10重结果、依赖与费用。色蕴只增强邻域威能，不改普通六维；威能未显式定义的旧域沿实际效果强度应用。暴击共用本轮结果，一次多目标施权不多掷骰；杀伤、数值镇压、封禁进度与恢复可暴击，二值禁器／禁功和终结处决不翻倍，不借暴击绕过资格与上限。

行蕴倍率为`1+目标原始触发种类数×每种增幅`，只增强已经合法成立的邻域受压稳固损耗、连续支配侵蚀和主动态势削弱。杀伤带来的额外态势削弱不额外造成肉身伤害，仍遵守接收损耗上限；没有额外的邻域血条。被乾古静默时，战报仍显示候选增幅及实际0%。

想蕴仅免该份额度的主动施权费，不免展开、维持、覆盖或追加投入。免费结果在选取效果及费用校验前使用，剩余元力为0也可兑现已经合法维持邻域的免费额度。免费施权不消耗原语义系统中留给下一次付费施权的减耗次数。额外施权可以暴击，但本轮计划只登记一次想蕴额度，不继续派生。

识蕴新增明确的战斗内元力回复来源，直接回写原人物本场资源账本，封存容量不参与基数，不建立新资源池；回复至本场可用上限。态势回复走原非肉身恢复入口，不修复HP、不解除控制、不恢复永久魂基。

五蕴修炼使用原精魂与机缘：零升一重按色至识分别需要10／20／30／40／50精魂，以及原开脉基础机缘的1／2／3／4／5倍；下一重费用乘目标重数。沿原修罗地点、煞元转化、事件、劫战、拘禁、寄身、压制、旅行、归墟和诸天忙碌校验，不推进时间或消耗RNG。提交携带所见等级，过期重复请求拒绝且不扣费。

八部凝练、融合统一要求玩家魔躯至少10层；材料自身普通炼体至少60/100层的条件保持。八部路线身份、肉身唯一归属和实际融合战入口不变。

## NPC、快照与公开信息

NPC沿原`immortal_body_level`判定资格，魔修且DLC加载时投影五蕴，各蕴培养强度为独立肉身层数整除5、最高十重。没有新的NPC年度培养循环。真实材料肉身只投影自己的资格；三尸及各道途属性镜像复制玩家入战时的完整机制定义与等级。

能力定义随原劫战快照保存；轮首计划、静默、额度和实际消耗归当前战斗轮。续战从下一轮重新生成计划，沿保存的真实战斗RNG，不重新读取人物培养。战报保留原始触发、候选输出、静默来源、额度使用、暴击、费用及真实回复。既有光效仍仅展示神光解锁外观，本轮未新增五蕴动画。
