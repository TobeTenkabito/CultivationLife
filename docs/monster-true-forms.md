# 万妖归宗：本相铸域

本体 v2.7.0 / 万妖归宗 4.15.1，2026-10-09。内容目录为 `dlc/monster-bloodlines/content/monster_true_forms.json`，使用已有幽冥界邻域面板、培养报价、元力与战斗能力入口。蓝图确认、化境和至臻定型新增独立成就，见 [三级界面成就](upper-achievements-270.md)。

## 边界与培养

开启万妖归宗的妖修，在幽冥界达到九阶、确认返祖或自成血脉后，可以预览并铭定本相。实际进化流程在进入九阶前选择高阶路线，因此不新增“临时返祖”兼容特例。旧版自成血脉尚未确认祖谱时，先使用原有补刻祖血入口；其他未达有效高阶节点的旧存档不擅自换血。

八源分别为蛇、羽、猿、狐、龟甲、虫、水族、草木。本相为第三种可选冥域，九幽镇域与黄泉回生域保留。每场仍只采用一种邻域，每轮仍走原战斗内核的一次权能选择；原祖谱及族血规则只在原入口执行一次。

确认不加等级、不补元力、不花机缘；之后初成至至臻十三阶使用通用邻域报价。初成四层后永久铭定辅权能，化境起生效；化境四层后永久择定守中、固本或争衡，大成起生效；至臻正常付费修成时自动标记归真。两项权能、一项有限特征是上限，没有额外经验条。

返祖沿本源首项为主，自成血脉可以在本源两项间选择主辅。自成血脉快照中的威能、破防或身法标签允许争衡，防护、续航或神识等标签允许固本，守中始终可用；只授予有限选择权限，不复制祖谱触发规则。固本与争衡在稳固和侵夺间挪移 0.1 倍，三项总预算不超过 3 倍通用强度。隔绝明确针对支援，禁制明确针对功法，恢复不能回复元力。

## 状态与内容校验

唯一记录为 `Player.world_voisinages.nether.true_form`：版本、原始种属、祖谱身份和规则快照、确定性蓝图编号、主辅与调校锁、归真标记。培养等级和上阵继续使用同容器的 `levels` / `active`；不增加顶层存档字段。蓝图只显式确认一次，预览、加载与斗法无随机生成。

关闭 DLC 或离开幽冥界时保留状态并沉寂；重新开启恢复有效蓝图。未知版本、身份不符、非法快照或阶段记录保持原样并阻止执行，不自动覆盖。DLC 数据加载时验证八种属引用、权能、特征和有限强度预算；整个错误包由扩展加载器拒绝。

## 快速与自定义出生

仅创建角色时配置，普通低阶角色与旧档加载不补发。妖修按本源形成连续进化历史，每经过一个大境界对应一次合法随机族血觉醒，最高十二项。九阶以上默认承接返祖路线并补齐其已达进化的前置印记，不虚构自立祖谱；玩家仍需主动确认本相且正常培养。

鬼修按境界承接至多十道独立结契遗魂、合法持久魂性、正常魂压与已走过层级的往生，不复制地图 NPC、不赠送轮回印记。魔修十阶以上承接本命、支脉与神通，九阶初入仍保留肉身融合选择；魔脉按已达层级配置，明确自定义邻域优先。儒修配置浩然之气，佛修配置适度愿力与业力，不凭空建立信众产业。道修仍沿用仙脉、仙体和自定义仙域入口；神机维持显式选择并受 DLC 开关控制。
