# 龟甲属四境立绘与战斗动作

2026-10-24，按用户“仿照前面的流程一次性完成龟甲属”制作并接入19套形象、171个绘制姿态、126组有限关键帧动画。每套包含128×128头像、256×288详情立绘、128×144缩略小人，共57张静态PNG和19张战斗图集。本体3.0.0-alpha.3、DLC1 4.18.0、结构10保持；未打包或更新已安装的发行程序。

## 运行与导出

运行文件全部在 `dlc/monster-bloodlines/assets/visual/turtle/`。manifest记录节点与动作，registry登记77项资源并进入现有DLC白名单，provenance保留原稿路径与SHA256。游戏运行不读取被忽略的design目录，资源启停服从扩展加载资格。

静态图由原稿两个独立主体分离并最近邻等比缩小，保留多级透明。九姿态为待机、蓄势、发招、防御、承击、受击、失衡、伏低／跪撑、倒地；一套人物使用共同缩放比例、384×288逻辑画布和192,256落脚锚点。图集只存9个绘制姿态，时间序列复用索引；这是有限关键帧动画，不宣称逐帧重绘。低阶不套人形骨架；七套低阶各6组动作，十二套人形各7组，包括施域储备。施域图不会授予玩家原本没有的邻域能力。

战前身份和真实结算继续由现有入口生成。回放只呈现既有战报，护盾、法术和邻域复用现有表现层；不改胜负、HP/MP、时间、代价、移动、游戏RNG或持久字段。主界面和人物详情须开启“新版界面”；旧进程需要重启以加载新增Python代码与资源清单。

重导：`python -m scripts.prepare_monster_turtle_assets`，仅离线制作需要本机原稿。脚本校验来源及已有狐、蛇、羽、猿目录保持原字节。本批静态有效修订：金岩、潮汐、元婴潮海女、合体潮海女为v2，其余v1；动作有效修订：金岩v2，其余v1。提示词和修正记录分别位于两个本机设计目录的prompts.json。
