# v3.5.3 师门薪火

本体3.5.3，Android版本码96。继续使用结构12；结构1–11拒绝加载／导入，不迁移、不覆盖。发行仅使用隔离验收存档。

## 师门与同门

整合师徒两批功能：嫡传、亲传、真传、记名位次，有限同门、履约、不满、忠诚、晋位比试、传承精修、可撤销契约、原人物身外化身与真实叛师战。规则见[第一批](mentorship-stage1.md)、[第二批](mentorship-stage2.md)。同门实际请教／切磋各得1%阶段机缘，索物／求法仅转交实际宝物及已学功法；每人每项每固定周期一次。旧收徒、拘管、离门和跨界接口统一原师承与培养限制，见[对抗审计](mentorship-bug-audit.md)。

界面沿原像素人物和浅暗双配色，增加人物身份头部、位次标签、好感／忠诚／资历／额度概览，桌面双列名册、手机单列。晋位和争端分别折叠，同门交流按所选项目给出奖励或禁用原因；成功操作及过期页刷新后保留当前角色的选择与展开状态。页面偏好只存在当前浏览器内存，不写角色存档、无额外游戏请求。

本轮修复：延迟登记已有师承时，初始化的既有同门被错误视为晚入门；登记不再改变其相对入门先后。修复同门交互后菜单重置到请教、导致实际已完成的动作与当前禁用提示不对应的问题；切磋提示补全最低1点收益及耗材说明。重新检查实物单份归属、读档／晋位／重入防刷、过期提交、异界／实例／任务与记名限制。

新增师门UI无人物移动或状态副本；原 `joined` 字段仍表示入门时间，`peer_requests` 仍为原固定周期凭据，未增加持久字段。师父头像只读原人物。NPC培养及其他系统Debug沿原隔离工作台共用正式入口。
