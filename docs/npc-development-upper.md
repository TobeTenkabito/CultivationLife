# NPC高阶简化培养与傀儡供能

2026-11-04，承接[NPC培养首轮](npc-development.md)。用户要求高阶培养简化，并确认“傀儡普通出手耗自身储能、仙阶攻击另耗玩家元力；元力不足退回凡阶，储能不足停止出手”。仍为3.5.1源码、结构12，不打包、不迁移、不修改用户存档。

## 简化成长

独立培养窗口增加元力转化与傀儡充能；原修为、肉身、神识及传法入口保留。

- 普通人物高阶培养限定对应上界：道／仙界、魔／修罗界、妖／幽冥界、鬼／轮回界。真实地址、控制关系、成年、存活、事件、封印与任务限制仍由共同入口校验。
- 已在对应上界的八境圆满人物可培养至九境一层；九至十二境每实际轮确定提升一层，包括同界升大境界，十二境圆满停止。机缘培养不超过施教者实际修为；专材按当地上限。低界飞升／迁界关口不变，培养不移动人物。
- 按用户授权，NPC不执行玩家开脉、路线试炼及大境界渡劫流程，也不伪造玩家调用玩家命令。原NPC已登记的周期劫期不清除或延后。
- 元力转化每轮最多20%，五轮可从零转化完成；不足一重的剩余量仍为实际一轮，完成后不再收费。
- 普通肉身100层、主修九境以上且位于对应上界，可直接培养高阶肉身，每轮至多两层、最高50。普通炼体刚到100层的同一批量不会顺带取得高阶肉身，下一次明确报价后再培养。普通人物五光等战斗能力继续沿原真实肉身投影，不新增玩家式独修面板。
- 邻域专门培养仍未开放，原NPC邻域与道统成长保留。转道、化形、第二元婴及复生不属于本轮通用培养。

人物使用原`transcendence`。扩容前按原容量和旧速率结清已实际经过的时间，再设置新容量及下一段速率；扩容、转化和查看不回满元力。首次建立账本当前值为0。材料培养不额外扣玩家机缘、法力或元力。

## 傀儡培养与供能（第二阶段历史规则）

后续同日用户已调整供能规则；本节及末尾验证记录对应当时实现。当前实现以[傀儡能源与玩家供能](puppet-energy.md)为准，取消双重扣费，增加能源更换与供能开关。

机关、炼尸、活傀都接入同一服务，写原`Player.puppets`资产；活傀释放仍回写原来源人物，储能不转成人物元力。炼尸不复活来源人物；充能不修复完整度／耐久，不恢复控制，不救活毁坏资产。

材料共52个定义：原36个四道途材料全部开放，加四个上境转化材料，以及傀儡修为／肉身／神识／能源四类、每类三档的12个定义。傀儡不使用活人道途配方。凡／灵仍按原界层，上境傀儡专材可在四个第三级普通界面使用；低品不能代替高品，充能品阶按傀儡主修判定。原库存、坊市、黑市／交易及探宝渠道承载，凡／灵／上境基础单价1／4／12灵石。

| 项目 | 当前规则 |
| --- | --- |
| 储能 | 上限100，原资产`operating_energy`保存，无年度再生 |
| 每次普通出手 | 消耗5；攻击被金光挡住仍收，无合法出手机会不收 |
| 一次充能 | 原行囊能源晶一份，补至100；满额／缺料拒绝，不扣费 |
| 新造机关 | 装配已实扣能源组件，初始100储能 |
| 缺失储能的资产、新炼尸／活傀 | 视为未充能0，不靠加载、查看、等待或战斗补发 |
| 储能不足5 | 不进入下一场出战名单；本场耗尽后停止普通出手 |
| 九至十二境仙阶攻击 | 每次分别扣玩家10／20／30／40元力，同时扣自身5储能 |
| 玩家无法供能 | 未具备元力资格、失去战斗存续、供给受禁或余额不足时退回凡阶，不透支，不借被封存余额 |

傀儡仙阶攻击统一为玩家驱动，不借术法／装备标签免费取得仙阶伤害。此次傀儡仍为简化资产战斗：保留本体战力、形体完整度及高阶护体资格，不作为普通人物自行展开邻域或消耗／恢复来源人物元力。普通NPC自身战斗能力不受该资产规则影响。

储能与元力分别记账。各傀儡在真正预付攻击时逐笔扣同场玩家余额，不复制储量；正常玩家沿`ApertureResourceBinding`保留封存余额、回写原仙窍，显式旧MP能力沿原账本。调息、五蕴／五光回复、战场供给及战报重播不补傀儡储能。暂停快照保存剩余储能，加载不得增加。

## 数值与验证

高阶修为引用原`immortal_breakthrough_cost`，转化引用原`conversion.COSTS`，使用首轮1.5%系数，无额外法力费用。全DLC／装备／正常折扣组合的实际自修成本校准仍是首轮待验收事项，不能把积累点／经验基线说成已证明的真实兑换率。

`tests/test_npc_development_upper.py`覆盖四道途高阶成长、转化不回满、旧容量结时、异界拒绝、三类傀儡专材、充能原子拒绝、多傀儡共用余额、降阶／停手、暂停续战及真实战斗存读档。`tests/browser_npc_development.py`增加手机端高阶升境、转化、充能、过期拒绝和高阶肉身实际点击，截图`build/npc-development-upper-mobile.png`。同时执行合同、模块、文档及跨界／事件／战斗回归；本轮没有Windows EXE或签名Android重新发行。

2026-11-04验证结果：16组领域／战斗／跨界／发行回归合并373项通过；最后补充炼尸不继承离体来源魂态的回归后，NPC培养、拘禁、待修复审计、玩家战斗和邻域六组共141项通过（与前者重叠，不能相加作为独立用例数）。三项工程检查无问题；独立窗口桌面／手机／横屏及上境充能实操、`browser_release_2135.py`、`browser_events_212.py`均通过。尸傀／机关使用原5%毁坏阈值，供能接入没有套用普通人物12%退场阈值；缺储能不会自动带入战场。
