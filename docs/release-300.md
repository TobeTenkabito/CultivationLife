# 3.0.0 正式版

本体版本3.0.0，Android版本3.0.0-android.80。存档仅支持结构10，alpha系列的结构10存档可沿原入口读取；结构1–9不转换、不映射。Windows本体与可选DLC仍分离；Android携带十个官方包并沿用原开关和正式签名。

本版汇总alpha阶段的主页地图视图、建筑阶段像素图、玩家与NPC立绘、妖修分境外观、鬼儒佛及修罗人物动作、战斗与邻域回放。最新增量包括连续施法特效、30款透明轮廓内景、20款控制组件、雷劫与飞升各三款动画。白线增强、流动钟面、五层95株彼岸花海及道途资格见[特效说明](spell-domain-effects.md)。人物与DLC具体范围仍见[alpha.4](alpha4-release.md)、[alpha.5](alpha5-release.md)、[alpha.6](alpha6-release.md)及[修罗人物](asura-character-visuals.md)。

## 正式版验收要求

按用户此次明确要求，使用 `python scripts/verify_scoped_release.py --profile visual --shards 6 --workers 2 --balance-tests` 运行全部 `tests/**/test_*.py`，不使用focused选项。三个开发门禁、旧事件真实加载提交、原四主题与新增表现浏览器检查须通过。全仓模块列表、逐分片XML、运行日志和最终源码摘要登记于 `build/scoped-300.json`。

本次先以两个分片并发，避免与Android构建和模拟器争用内存；原生验收完成后保留正在执行的分片，启动剩余两个待运行分片，提升到四个并发。调度交接记录为 `build/release-300-scheduler-handoff.json`，全部六个分片仍采用原模块划分。

Windows同一EXE在有／无DLC的隔离安装目录验收；Android构建签名release和对应测试APK，在专用Android12模拟器验证横竖屏原生操作、实际安装包哈希、签名、元数据和Lint。通过后由发行脚本复核源码与产物证据，生成Windows ZIP、独立EXE、Android APK/ZIP及同版发行清单。模拟器验收不代表实体手机验收。

正式版不改世界移动、资源或事件结算，不新增Player／GameState持久字段，不新增跨界例外。实际结果和下载文件以 `dist/release-3.0.0*.json` 为准；此文档本身不是完成凭据。

## 版本边界测试修正

首次全仓进程已载入alpha阶段的存档断言，把3.0.0-beta.1、rc.1及正式版本身当作未来版本，因此记录了三项预期与正式版规则不符的失败。修正测试后，整个存档导入模块21项复测通过，仍检查未来版本、非法版本、损坏数据和原档保护；产品代码无需因此修改。最终聚合报告以该模块完整复测替代其旧18项记录，原分片XML和日志保留，并在发行清单的 `regression_reconciliation` 中登记来源、哈希和计数。

普通战斗浏览器验收的DLC禁用夹具同步清空服务器与内容注册表的加载报告，使人物素材目录和新增邻域目录处于一致的禁用状态；仍严格断言无DLC私有素材请求，并检查域式目录不包含DLC所有者。

## 最终验收结果

2026-10-25：247个测试模块共6508项通过，0失败、0错误、0跳过；存档模块21项复测已计入6508项，不重复计数。23项浏览器流程及跨界契约、模块依赖、文档三项检查通过，包含六条妖修素材线的DLC禁用回退检查。

同一Windows EXE在有／无DLC两种隔离安装中通过；签名Android 12模拟器横竖屏原生验收通过，安装APK哈希与发行构建一致，Lint无问题。产品源码摘要在回归、浏览器、EXE和APK构建证据间一致；未进行实体手机验收。
