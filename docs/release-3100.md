# 3.10.0 功法斗法与秘术贯通

本体3.10.0，Android 3.10.0-android.104。存档仅支持结构12；结构1—11拒绝加载与导入，不迁移或覆盖。DLC版本独立管理，两套像素主题和各DLC配色沿用各自定义。

## 功法与传承

- 4258部固定功法的专属条款正式参与玩家与NPC战斗，卡片可展开完整说明。修炼、辅助、炼体、神识、变化功法也有相应战斗用途，仍须符合原装备和身体条件。
- 3888部通用功法重写独立书名并检查重复；传承ID、等级、数量和原获取渠道保留，同名相似字样不代替同一传承的升级条件。
- 新生成仙界道统沿固定种子生成效果，32个主题提供不同的触发与兑现组合。合练真传继承本门主修机制，在同类预算、费用与冷却上优于普通同级功法。修罗、幽冥、轮回本体功法分别体现受击反攻、分期兑现与奇偶节奏；合练仍使用既有仙界入口。
- 已生成且冻结的道统配方不重抽，已开始的战斗沿原快照继续。固定书仅同步目录说明与机制，保留已有等级和配置。

## 七部斗法与资源结算

玩家须先把功法成功装备进原战斗功法栏，再加入最多七部的斗法配置。NPC按实际境界、灵根与当前身体等条件选书，元婴起至少三部、化神至少五部、炼虚起七部；合法候选不足时不强塞越阶或不可用功法。已见人物保留原名单，后续改变走培养等正式系统。

费用采用混合机制：低阶功法固定扣费，同阶按开战容量比例扣费，越阶按比例加固定值；这不授予越阶装备资格。玩家和NPC逐人检查真实法力或元力，余额不足不发动，连续战斗与读档不回满。Lv.1—9最多减费16%，退款只来自实际支付，分包、延期和多人支援共用原预算。

《太元归墟剑》保留原升级入口：Lv.1—9同敌剑意由8%升至16%，实际破持后的强化档由12%升至24%，两档不叠加。Lv.1在元婴扣4%法力，化神至大乘使用固定55.68点；伤害随本人的普通交锋成长，每战最多三次。

战斗界面采用选定的C版式，独立机制区域展示触发、支付与结果，配合原回合、动画和邻域回放。回放不重复结算。修复有限护持、跨战力支援预算、延迟效果、退款及NPC首次配书等边界，补强劫战期间换装检查。

## 功法—秘术

新增62门固定功法关联秘术。学会并配置在指定主修、辅修或战斗栏后，在原秘术目录查看实际投入和收益；自创功法暂不声明此类秘术。

- 新增元婴水系辅修《高天寒芒》：五行各一件至少五阶闲置阵材激活“五色凝冰”，冲击化神基础概率增加5个百分点；失败不重置，仍须功法在指定栏位且符合适用境界。
- 新增筑基辅修《天元术》：“知天”消耗当前大境界基础机缘的25%，永久提高神识一级、保留已有经验，每个实际大境界一次；跨界、换装与跌境不刷新次数。
- 其他秘术提供大小境界突破、炼体突破、神识减耗、渡劫属性、心魔消解和神识经验。另有3门炼体积累、4门灵魔妖阴气经验、5门百艺经验秘术，复用原成长入口与倍率。
- 持续效果激活一次即可，换下、资格不符或封印时暂停，恢复条件后重新生效；已得一次性成果永久保留。炼体只补当前层，仍走原突破；气经验不补法力，百艺经验不赠成品。
- 重复请求、过期报价、已占用材料、保存失败和突破后的境界限制均由服务器复验。Debug／Agent同步支持正式激活动作与报价，不能绕过支付或次数。

## 百科与验收

游戏百科同步七部配置、机制预算、混合费用、NPC余额、道统差异、合练、62门秘术及跨界／突破后的适用条件。阅读百科不推进时间或发奖。

Windows建议下载完整Windows压缩包，解压后运行`launcher.exe`；压缩包携带十二个官方DLC及文档。单独EXE只提供本体程序，扩展仍从旁边的`dlc`／`mods`目录加载。Android可直接安装签名APK，或下载附带文档的Android压缩包；APK已内置十二个官方DLC。同包名、同签名覆盖安装保留原文件，存档兼容范围仍以结构12为准。

发行验收由 `scripts/verify_technique_release.py`、最终Windows EXE有／无DLC验收及签名Android 12横竖屏原生验收共同完成；最终数量、源码指纹、包哈希和设备范围以同版GitHub Release所附 `release-3.10.0*.json` 为准。Android包含arm64-v8a与x86_64，模拟器验收不等同于ARM实机验收。
