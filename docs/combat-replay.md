# 普通战斗回放

本体 v3.0.0-alpha.2，结构10。“启用新版界面”开启时，所有具有普通交锋事实的玩家战斗可播放 CG，包括切磋、截杀、猎妖、剧情、机械／试境和劫关。魔修使用魔修立绘，其它未专绘道途暂用同性道修示意；NPC 优先使用真实人物／缓存人物记录的性别和道途，缺少性别的无名剧情对手用稳定哈希选择示意，不消耗游戏随机。宿身采用战前身份快照。旧战报缺少普通事实不补造历史。

## 多人阵容

每方至多显示三人，不改变实际参战人数、战斗力或结算。标准战斗在结算前读取原 `player_units` 与目标原成员，排除零战力／零完整度单位后按原名单顺序取前三人；完整人数仍在原战报名单，画面名录保留显示人数／总人数。视觉 schema 2 只保存两方至多六条有界身份描述、性别、类型、名称、素材 ID 与战前有效战力权重，不保存 NPC 副本、个人血条或新战斗实体。旧 schema 1 保留原单人回放，不追造历史参战者。

原人物和原炼尸／活傀 `source_npc_id` 的性别优先于临时代理字段；机关和妖兽素材无性别，不为了去重借用人形。男女同行修士与活傀共用素材；普通人形道途使用同性道修／同行候选，魔修仍只使用同性魔修，炼尸按男女使用自己的仪甲素材，机关仅使用人形机关，禽／兽／昆只在对应分类取图。缺失原始性别时才使用稳定占位；不能从名字推断有证据的性别。

战斗负责生成**合法且按偏好排序**的候选集，去重与复用统一调用 `cultivation_life.visual_selection.select_assets`，不在战斗分支内另写去重策略。通用接口见[视觉系统](visual-assets.md#通用素材选择)。本次选择范围跨双方、限本场；候选未耗尽不复用，耗尽后仅在原合法集合内均衡复用，不改变性别、类型或 DLC 资格来凑不同人物。

**排除的是邻域阶段，不是整场混合战斗。** 纯邻域轮不播 CG；同轮或后续发生普通交锋时仍播放普通部分。邻域计算、结算和后台 NPC 战斗均不接动画，也不因查看战报再执行一次。

## 事实与时序

`PlayerCombatSystem.resolve` 在实际普通路径记录每轮 `ordinary_exchange.opening/before/after`：普通阶段起点、实际普通扣减前、扣减后双方态势；`actors.player/enemy` 标记该阶段双方的普通行动权。混合路径从既有权威能力账本读取普通损耗，不把邻域伤害混入攻击。劫关 `system/combat/trials.run_batch` 同样只记录真正发生的普通阶段。轮末原有 `player_combat_state/enemy_combat_state` 是恢复、邻域尾部效果及快速判定后的权威值，作为检查点直接同步，不虚构攻击。仅增加只读采样，不改变公式、分配、资源、时间或随机调用。

`engine_combat_runtime._record_player_combat` 将 `combat_visuals.report_visuals` 的有限视觉描述放入原 `last_combat_report.visual`：主角、对手模板、真实本命物品 ID／炼器形制。它不是新人物记录。字段仍属于原 session 战报，保持结构10，无 Player／GameState 新字段。失效的旧报告不猜测初值或伪造回合。

`web/combat-replay.js` 依真实轮数，每个普通阶段按先手排列具有普通行动权的一方或双方进攻，每方在场人物按名单顺序各表现一次。整方该轮损耗按战前权重分配到有限动画接触点，多段动作再在这些接触点内分摊；累加结果严格等于原普通阶段扣减，不制造额外结算。命中对象轮换只是表现，不宣称内核已有逐人伤害。零损耗用护体应对。原内核普通伤害同时结算，视觉先后不是抢先击杀、取消后手或新增反击规则。至多读取原报告最近72轮，每轮最多六个动画段，纯邻域轮不会变成攻击次数。双方条形仍为真实合计态势，不是人物 HP，真实完整阵容仍列在原战报中。

招式由战报散列派生独立表现序列，同一战报重播相同；不消耗 Python 或游戏 RNG。道修现有详细龙波与御宝效果共用详细施法姿态，不回接旧 Q 版旋转／瞬斩人体；魔修有御宝、魔影、近搏，低矮妖兽暂不选尚未适配高度的近搏。NPC 道修／魔修使用各自专属攻击模板。御宝使用战斗记录的本命形制，重播时不从当前背包选武器。不存在／已禁用的 DLC 映射不请求专属图片。

猎杀名单保留四个等权入口，妖狼、妖猿用兽类，灵鹫用禽类，刀螳用昆类。只调整原妖蟒／毒蛟的显示名称与形态对应，不改抽取数量、强度、阈值、掉落或经济公式。

## 战场绘景

单人对局与多人对局使用两套独立绘景，均按原报告 `natural_terrain` 的开阔／狭窄／险要精确选取。一对一的开阔露台保留用户指定的原图及原绘制方式，SHA256 为 `87e129336dc44e789fbab6a975d59f729ccd27d5d27d5e100668cdfb55ac7a1c`；单人狭窄与险要另绘低视角、上部远景／下部交锋区两张，不从多人图裁切。

多人三张另绘宽落脚面，后排仍落在实际地面。窄屏最近邻等比覆盖并将地平线限制在可落脚构图内，不拉伸人体；单人继续原近景构图。现用六图及尺寸、源哈希与本体归属在运行 manifest 的 `battlefields.single/group`。五张新原稿与提示词在工作区 `design/combat-terrain-study-20261022/`，运行只读取机械提升后的本体文件。

禁空、禁神识、大阵只从原 `artificial_conditions` 添加独立的低透明禁线／雾纹／地面阵纹，不烙入自然背景，不新增条件或更改其结算。未知地形回退原露台，不根据所在世界或名字猜造地理。一场只解码所选的一张背景，不同时加载六图，不读取当前地点覆盖历史战报，也不把这些通用氛围图变成新地图或建筑资产。

## 战败动作

最终普通交锋分出胜负后，在最后接触之后插入败方在场人物的战败动作，胜者留场，败者保持倒地终点。四主角、三妖兽使用选定的七组动作；十二NPC用各自现有受击短引导接各自完整倒地图及局部余势，未借主角身体替换NPC。新增五套同行／炼尸／机关也使用各自受击短引导与各自完整倒地图，男炼尸只用脚部重绘后的独立倒地图，不恢复清空的旧错误格。NPC及随行单位过渡是有限关键图动画，不冒称补绘了连续倒地全过程。合计败势不是个体死亡事实，不伪造额外死亡或损坏。女魔修沿用用户指定的临时第二张及原第一／第三张，已知腿部问题没有被重画或宣称修好。

2026-10-22 收尾修正：先手顺序、原普通攻击段及态势接触点不重排。若最后一段恰为败方出招，额外的 `finisher` 只复用胜方本场已获普通行动权的一个攻击模板，作为表现收势；它不进入 `rounds/events`、不新增扣条、回合、RNG 或结算。败方先受击，再于胜方最后接触后0.2秒进入倒地，胜方继续原收招而非突然切回待机。表现收势期间两方态势保持原最终值。整场没有胜方普通行动事实时不伪造胜方攻击或普通击倒；未决、存活目标及纯邻域终局仍沿原排除规则。

倒地仅表示此次交锋失利，不把非致死切磋、负伤撤离或被擒改成死亡，也不把态势条强行清零。未决／僵持、仅存活即过关的胜利不虚构敌方倒地；最终结果若来自后续纯邻域阶段，也不补普通战败CG。原胜负、击杀、生擒、逃脱、掉落与剧情后果不变。

## 资源合同

运行素材仅位于 `web/assets/pixel/combat/`，不加载 design、GIF、原稿、网络 CDN 或外部依赖。`scripts/prepare_combat_assets.py` 机械提升已采用图集：逐帧裁透明边、原像素去重、保留锚点及独立接触点，并提升战败素材。战败格独立登记384×288、朝向和脚锚，不按待机格截断倒地图；小屏约束倒地横向边界。源文件与成品 SHA256 在 manifest 中；重导不是运行或打包步骤。这些普通道修、魔修及遭遇妖兽是本体素材，不冒充 DLC 专属物种。

生成原稿的画幅不等于人体比例。人形正常动作沿用176像素站姿基准，蹲姿不按包围盒拉成176；妖兽各保留物种尺度。补绘倒地图此前曾独立按横向画幅注册，存在人物突然变大的问题；现在以 `scripts/combat_asset_scale.json` 登记逐角色／逐完整关键姿态的审阅头部尺度（不含发髻、飘发、翎羽），在导出时统一作最近邻等比校准。尺度为人工审阅的近似参考，不是自动人体测量或解剖修复。每张关键姿态的局部补帧固定使用同一校准，受击短引导保持正常动作尺度；锚点和地面不变，不逐帧用外接矩形自适应，运行也不按姿态动态拉伸。24套均须显式登记，新角色缺少校准则禁止导出；清单及每帧校准记录带哈希，可追溯并继续精调。有效原稿和待修女魔修的原始结构不修改。

新增同行的符纹凝灵、炼尸的煞气符带、机关的枢纹冲击与各自护面共享接触时钟，蓄势／发招／碰撞／消散分离；半透明能量合成后 alpha 不超过180，弹道在目标接触处逐段消散，不穿透。每帧粒子按固定公式计算，不消耗游戏随机、不累积粒子实体或保存特效图。

仅当前对阵所需图集解码，每播放器最多36张、96MiB硬预算，另有少量有限画布。机械提升将人物局部微动按10Hz保留取样，姿态／脚锚转换点和端点原时刻保留，时间轴和20fps特效不变；本轮仅对需要匹配正常人体尺度的倒地图作上述离线等比校准，不修改有效原稿。新随行单位跨动作合并去重，整个人物库不预解码。单人场仍保持较低按需用量；六人测试与保守最重六套全部动作上界见测试证据。只保留一份有界清单与一场既有战报，不保存 GIF、逐帧图像或回放日志。不存在无限历史、localStorage 回放或每年扫描。

关闭／Escape／返回开局／切换报告／关闭新版立即取消 RAF、断开 ResizeObserver、清空图像引用并把画布置零。异步准备有代次校验，旧加载不能覆盖新报告；销毁幂等。后台暂停时钟，结束停止循环，20fps 有限绘制。减弱动态默认静止，玩家可主动回放；播放、暂停和重播不调用行动 API，不写存档或推进年份。
