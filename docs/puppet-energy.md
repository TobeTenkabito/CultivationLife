# 傀儡能源与玩家供能

2026-11-04，按用户最新要求替代[NPC高阶培养](npc-development-upper.md)第二阶段的“每次同时扣储能和元力”规则。源码仍为3.5.1、结构12；不迁移存档。本轮未重新发行安装包。

> 同日后续阶差、承载限制与九阶仙级边界以[NPC培养第三阶段](npc-development-stage3.md)为准；下表记录上一阶段的等耗规则。

## 每次出手结算

一次出手只支付一种资源。傀儡能源耐久上限100，自供一次扣5，不自动恢复；剩余不足5时不扣残余耐久。机关、炼尸、活傀统一执行，控制、身魂、战场限制及原毁坏判定保持。

| 条件（按顺序判断） | 结果与支付 |
| --- | --- |
| 低阶傀儡，能源耐久至少5 | 凡阶攻击，扣自身5耐久 |
| 九至十二境傀儡，仙级能源耐久至少5 | 仙阶攻击，扣自身5耐久，不扣玩家 |
| 高阶傀儡能源品阶／耐久不足，玩家供能开启且有足够可用元力 | 仙阶攻击，按傀儡九至十二境分别扣玩家10／20／30／40元力，能源耐久不变 |
| 无法支付仙阶攻击，但自身耐久至少5 | 降为凡阶攻击，扣自身5耐久 |
| 自身耐久不足，供能开启且玩家可用MP至少5 | 凡阶攻击，扣玩家5 MP，能源耐久不变 |
| 上述均不可用 | 停止出手，不扣任何资源 |

低阶傀儡不会因安装仙级能源获得仙阶攻击。未具备元力资格、余额不足、失去战斗存续或供给受禁的玩家不能垫付仙阶攻击。供能关闭时，无论自动／手动战斗都禁止垫付MP和元力；仍可使用自身能源攻击或降阶。攻击被护体阻挡仍属实际出手，支付费用；被控制而无法出手不支付。

战斗设置与手动预案共用`Player.combat_plan.puppet_supply`，默认开启；自动预案也保留此开关。事件／试炼进行中不能更改冻结的预案。多只傀儡逐笔检查同场玩家原余额，不预复制预算、不透支、不使用封存余额；战斗中的垫付不会给傀儡充值。普通剧情的MP损耗缩放不能免除已发生的供能付款。

## 更换能源

独立培养窗口显示已装能源、凡／仙品阶、剩余耐久、供能状态，并提供更换选择。可安装行囊中的三档傀儡能源晶或原机关能源组件；上境能源晶及九阶以上能源组件属于仙级，其余属于凡级。允许获取和携带，安装仍受当前普通界面品阶限制；未知界面和空间不按人界兜底。高阶傀儡可安装凡级能源，但只能自供凡阶攻击。

安装行囊能源实扣一件，新件耐久100。卸下仍有耐久的能源保留在该傀儡的备用能源列表，换回时恢复其原剩余值，不能靠切换回满；耗尽的能源不进入备用列表。同品行囊能源在当前耐久已满时拒绝消耗，不同品可正常替换。目标死亡、忙碌、不可接触、材料不足、界面不符或过期提交均拒绝且不扣费。更换不修复傀儡本体、不恢复控制，不推进年龄或RNG。

`operating_energy`就是当前安装能源的耐久，`energy_source_id`是其目录来源；`energy_spares`仅保存卸下原件的唯一ID、来源和实际耐久，随原傀儡资产归属，不复制到来源人物或其他物品堆叠。已有真实装配组件可只读确认能源品阶；没有来源记录的既有有限储能仅作凡级，不按傀儡境界推断仙级，不补发耐久。

## 责任入口与验证

- `system/puppet_energy.py`：原库存与备用原件的替换、界面限制、品阶识别。
- `system/npc_development/service.py`：统一目标资格与更换入口；旧`charge`调用适配安装标准能源晶。
- `system/combat/puppet_supply.py`：每次出手选择并扣除唯一资源来源；战斗适配器提交原资产耐久，玩家MP和元力仍通过原战斗结算入口回写。
- `tests/test_puppet_energy_supply.py`：结算组合、多傀儡余额、供能封禁、暂停快照、原件交换、原子拒绝、真实战斗与存读档。`tests/browser_npc_development.py`通过真实页面点击更换／换回能源、关闭／开启供能及重载，并检查过期提交与非法开关值。
