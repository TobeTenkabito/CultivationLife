# 身魂、第二元婴与转道（v3.2.0）

本体功能，不依赖鬼修或妖修 DLC。存档结构为 11；结构 1–10 明确拒绝加载，不自动转换，不改写原文件。

## 能量与神游

人物详情展示体魄、神魂两条能量：上限分别为 `100 + 炼体等级×20`、`100 + 神识等级×25`。新人物初始化满值，调息每年恢复上限的20%。炼体、神识每行动单位消耗对应上限的10%；战斗损伤按损失比例消耗体魄，神游期间改耗神魂。肉身已毁无法调息恢复体魄。

体魄归零：元婴以下爆体死亡；元婴及以上进入神游，炼体等级和进度归零。神魂归零每次枯竭只结算一次等概率后果：永久修为停滞、邪魂夺舍危机、跌落一个小境界。夺舍危机须在详情中抗争，成功率为 `35% + 神识等级×2.5%`，最高90%；失败进入统一死亡结算。恢复到正值后再次归零会产生新后果。停滞保留终身。永久修为损伤同时更新可恢复的压制／封印记录，解除秘法或返界不能恢复已损失的修为；原返程凭证继续保留。

元婴期自动解锁「秘法 → 已获秘法 → 元婴离体」，无需研习或灵石，主动离体消耗10神魂；各道途均需达到元婴期，鬼修也不再提前开放此主动秘法。与第二元婴、转道秘法一同复用原秘法目录及详情样式，不再单列身魂秘法栏目；未解锁项目在潜在秘法中显示条件。人物详情保留归还原肉身、离舍归魂与身魂能量。新开局仍为普通状态。神游战力为普通的35%，机缘效率增加25%，天劫、雷劫伤害增加75%。离体时固定记录原境界一个时间单位对应的年数，改变境界、读档不会重置期限；超过期限非鬼修消散，鬼修不受限。主动离体的肉身留在原世界、地点和空间实例；必须正常移动回来才能归体。肉身被毁后只能夺舍或转鬼修续命。

NPC 使用同一普通／神游状态；战斗摧毁元婴以上NPC的肉身可使其离体，其战力和离体期限也按本体规则处理。第二元婴由同化维持，不受自由NPC离体期限约束。

## 第二元婴

秘法页花费12000灵石研习，需元婴期。学会后桌面侧栏出现“婴”，手机使用现有修行导航。任意道途可选择元婴及以上的真实活俘虏，每次炼化消耗15神魂并经过一个真实年，累计三年完成；中断保留进度，取消不退款。

只允许一个第二元婴。提取后沿用原俘虏的唯一NPC记录及修为、功法等级，退出俘虏列表，以第二元婴拘禁身份保存。独立战斗单位可配置六类功法和三件普通装备；装备从背包实际移出，卸下、散去或替死时原样归还一次。本命和组合炼器不转交。

同化间隔在提取时固定为本尊一个时间单位。费用 `10 + max(0, 元婴境界序号−3)×5` 神魂；序号以凡人为0、元婴为4，因此元婴实际15点、化神20点，之后每高一境再加5点。自动同化默认开启，也可手动提前支付。控制力独立于战斗完整度，范围0–100，提取初值100。每次同化恢复20控制力和20完整度；欠费或关闭自动同化时每期降低2控制力；扣除后控制力不低于50时无反噬，低于50时概率为 `(50−控制力)×0.7%`，最高35%。反噬者先被消耗，不能同时替本尊承接。同化期限、自动设置及世界年幂等锚点均持久保存。

第二元婴保留原NPC的生理年龄和寿命，炼虚以下寿尽消散，炼虚起不受寿元限制。`age_year`记录原NPC年龄已结算到的世界年；普通世界、独立空间、跨界沿同一时钟结算，不因同化或读档重置。结构11中此前缺少控制力与年龄锚点的第二元婴，分别明确采用100与载入时的世界年，保持原NPC既有年龄，不追造历史；后续保存保留这两个值。界面只读投影剩余寿元，不推进时钟。

### 存活结算（2026-10-27修订）

所有玩家致命结果进入引擎 `_die`。各阶段资格仅允许继续判定，不是无条件免死：

1. 寿元不足直接死亡；寄身时使用宿主生理年龄。剧情、天劫、雷劫、飞升劫、裂缝护持失败及显式`special`原因直接走相同终结出口；剧情失败不再由旧凤凰涅槃分支直接免死。
2. 本尊未达到元婴直接死亡，不进入神游，也不检查第二元婴。压制／封印按已凝结元婴的真实修为判断。
3. 普通肉身致命伤尝试本魂离体：已经神游、神魂能量耗尽或本魂受拘，不能再次脱出；宿身离体仍要求原本魂达到元婴且寿元未尽。成功则肉身毁去、炼体清零，进入有期限的神游，不消耗第二元婴。
4. 神游失败，才检查是否持有仍存活、寿元未尽且完整度大于0的原第二元婴；不存在有效第二元婴即死亡。存在后检查独立控制力，低于50死亡，达到50才可承接本魂。
5. 承接成功只消耗一次第二元婴，返还其托管装备；本尊采用其境界、层数与剩余寿命，炼体清零并进入新的无身神游。不能为寿尽本尊续寿，也不能用已过期元婴承接。

夺舍失败、邪魂侵夺、魂蚀消散、神游超时、元神反噬由调用者显式使用`survival_stage='spirit_failed'`，完成寿元与元婴资格检查后跳过已失败的神游尝试，进入第二元婴资格检查。特殊死亡优先于该参数。终结后不再生成战陨夺舍复活选项；旧选项加载时移除并保留后续事件，旧提交拒绝且不复活。神游存续后的期限、神魂及魂蚀规则继续适用。

战斗完整度只在战斗单位贡献中折算一次，界面战力展示同一折算结果；失败夺舍的日志按最终存活状态记录，不能出现已续命仍显示魂飞魄散。

## 夺舍与转道

夺舍使用原俘虏处置入口，只允许存活、神游且目标境界不高于本尊；沿用现有夺舍概率和次数。继承原NPC修为、炼体、神识等级、寿命及生理年龄，世界年保持单调；主修功法保留原等级，动态功法沿原世界定义解析。寄身时不能再次夺舍或转道，先离舍。夺舍后的宿身为普通状态。已毁肉身不能炼体或炼体突破，普通、空间、归墟入口在扣费和耗时前拒绝；修为永久停滞同时阻止涅槃和外王升境，拒绝不消耗资源或次数。

秘法页各花800灵石研习转道秘法，最低练气期；转换还须掌握至少一门目标道途功法。道、儒、佛消耗灵气，魔消耗魔气，鬼消耗阴气；需求为当前境界序号×2级，最低一级。足额保留修为，短缺按实际气等级／需求比例折算累计修为层数，预览结果后提交。不能转为妖修，不因转换移动世界或重新生成NPC。

## 权威归属与验证

新字段按[状态契约](world-transition-state-contract.json)人工分类。原肉身地址固定；第二元婴为随身个人魂体，明确例外于普通俘虏永久离界退出规则，沿[跨界规范](world-transition-development.md)唯一执行入口携带原NPC，不复制名册、资源或装备；转界取消未完成炼化。

规则、指令、持久化测试见 [test_soul_lifecycle.py](../tests/test_soul_lifecycle.py) 与 [test_survival_settlement.py](../tests/test_survival_settlement.py)。发行前须通过改动领域与上游测试、真实浏览器操作、最终 Windows EXE 和签名 Android 12 原生验收；完成情况以同版本 `dist` 发行证据为准。本次存活结算修订为源码修复，现有3.2.0发行包不代表本修订的验收或交付。
