# 第三阶段架构与发行验证

维护基线：2026-10-19，本体 v2.16.3，存档结构 10。

## 职责边界

`GameEngine` 不再继承上界机构、佛门、家族、儒道、侍妾、鬼道、妖族血脉、本命法宝或魔道 Mixin。原 119 个方法在原领域模块中成为普通函数，保留真实模块全局变量及配置钩子的归属；机构命令与王庭血战分别使用命令契约和只含战力、战斗的窄契约。新增玩法转发均为静态声明，不动态拷贝 Mixin 函数、重绑定函数全局变量或提供任意属性代理，也不增设第二套状态；既有 `serialized_commands` 的命令锁与失败缓存清理保持。

`system/character/dependencies.py` 声明各职责所需的冻结契约，`wiring.py` 是唯一获知调用方能力的装配层。引擎保存聚合契约，业务函数只接收对应小组。妖族进化校验与傀儡预览分别只有规则查询或读档能力，不持有保存、响应或整引擎；年度和状态准备沿原入口调用。旧 Mixin 仅适配既有独立调用方，不再提供引擎的隐式能力。

每个回调有明确参数、关键字约束及返回值。资源、引擎方法与配置在实际调用时解析；省略的可选参数继续省略，显式传入的 `None` 仍向下传递。类方法保留子类规则覆盖；静态方法仍是静态方法。儒道静态费用函数显式接收原目标回调，保留旧静态钩子的行为。

跨界请求、计划和结果移入 `world_transition_schema.py`，依赖契约无需为了引用数据类型导入转场算法。`world_transition_system.py` 继续导出相同类型对象，并保留唯一规划和提交入口；转场回调补齐参数及返回类型。入口转发增加静态调用位置，不新增路线、许可或实际通行。

## 保持的行为

架构主体调整调用关系。准备、费用、随机数、年度、死亡、中断、历史、发奖、保存与展示的原顺序保持；既有视图中的补全和成就评估仍属于第二阶段明确的视图准备，不提前到读档或重复发奖。人物、原库存、组织账本和实例继续使用原权威状态，不复制实体模拟迁移。

没有新增持久字段或存档迁移；结构 1–9 仍拒绝。大模块的业务分支和专用活动时钟继续保留，不能用合并时钟或跳过结算来减少代码量。三阶段之前尚未发行的源码修复随本次打包，具体规则边界保留在[跨界审计](world-transition-audit.md)与[人物拘禁契约](npc-custody.md)。

全仓验收还在改造前归档中复现了勘察拘禁的保存冲突：拘禁已移除自由空间名册，诸天引用校验却仍要求原人物在场。校验现在按原受控名册归属要求其不在自由名册，继续保留原勘察引用；同场释放恢复原普通居民的权威容器，暂停、续行、真实死亡与奖励算法不变。测试同时拒绝把受控人物伪造回空间名册。旧测试的跨界驻地、实例真实世界、真仙战力阈值和失败后请求缓存夹具同步当前既有规则。

## 验证与发行

- `tests/test_architecture_stage3.py` 验证独立契约、旧接口、描述符、子类分派、资源替换、可选参数及纯类型导入；从改造前源码捕获的 281 种原回调调用形式另验证位置参数、关键字参数及省略行为。模块检查还拒绝恢复玩法继承和未声明能力。
- 改造前源码归档及 119 个算法体的语法树摘要位于本次构建证据目录。对照只归一接收者名称和明确的静态回调参数，不忽略业务语句。
- `tools/replay_architecture.py` 运行生命周期、时间、五系统及三组流程的原有完整状态回放，共 413 个检查点。跨发行版对照在导入运行时之前，显式将两侧发行身份设为 2.16.2；仅统一版本身份，不删除响应、存档、RNG、历史或成就字段。
- `python scripts/verify_scoped_release.py --profile architecture --shards 6 --workers 3` 执行全仓测试、三项契约检查与七组真实页面验收；测试阶段限并发，各浏览器流程串行运行。
- 最终源码重新构建 Windows EXE 与正式签名 Android 12 APK，验证有／无 DLC 的同一 EXE；Android 使用专用测试模拟器，运行上界、佛儒、本命、修罗、地区、组织和既有修复七阶段横竖屏实际点击。原生证据同时绑定 APK、测试 APK、版本、签名和源码。

正式清单仅在全部要求通过后由 `scripts/package_scoped_release.py` 生成；实际产物、测试数量、设备与哈希以 `dist/release-2.16.3*.json` 为准。测试使用隔离存档，受保护的原存档与设置以改造前后哈希核验。未进行的实体设备或更高系统验收不计为通过。

本轮全仓验收发现一条 v2.7.2 的旧商品数量断言，改造前归档也能复现：v2.15.1 已新增 138 种普通符箓，原 1666 件应为 1804 件。仅更正该断言常量，整个 109 项模块重新执行并全部通过，品阶与战斗资格检查保留。最终覆盖报告按原测试身份保留未改用例的实际通过记录，并用该模块的新执行记录替换其全部旧记录；校验测试集合无遗漏、无重复，其他测试及共享夹具字节不变，运行时代码指纹一致。原始首轮日志和 XML 均保留，不将分批复验表述为一次全仓全绿。

原生旧验收脚本在秘法目录中直接定位详情按钮，现补上真实卡片点击，并检查下界解除按钮可见且禁用。只更新测试 APK，游戏 APK 字节保持不变；发行仅接受使用更新后测试 APK 完成的全部 14 组日志，旧失败记录保留。
