# 宗门任务、薪俸与财政危机

本次按用户限定，仅玩家当前加入且同界的宗门启用新增结算。退宗、死亡、飞升及其他离界后立即停止；其他宗门仍沿原经营规则。返回或重新加入只结算当前真实年，不补算离开期间的薪俸、任务、捐献或危机。原地区补算中的历史年份也不套用玩家当前宗籍。

暂停招新的政策保留在原宗门，但只有满足上述当前宗籍与同界条件时才约束原招募入口；离开后原宗门恢复旧招募规则，不继续运行本次新增治理判定。

## 任务与贡献

宗门页面内设任务、发布、兑换与捐献、薪俸、治理、记录六个栏目。旧 `faction + duty` 随机事件退出选择；已打开的旧差事在原加载校正入口退出，保留已得后续奖励。旧页面提交会重新核验当前事件编号。

最低发布境界默认炼气，掌门或控制者可调整。每项普通材料任务消耗 `10 + 数量` 影响力，数量1–100；只允许本界普通市场材料，排除独有材料、丹药、功法和特殊装备。每人最多3项待办，任务栏最多30项待办、保留最近30项已结束记录。玩家每行动单位最多发布3项、完成1项；NPC最多完成3项。不能自发自领，也不能重复完成。

玩家交付真实行囊物品；NPC花自己的已领薪俸从原当地市场购买实物，市场资金、手续费、库存与成交额都按原交易入口登记。玩家发布的任务直接收到原物；NPC发布的征集为门内公用资材，交付至原府库。交付贡献为材料基础价格折值除10向上取整。普通材料征集无随机生成库存，府库满额则拒绝交付。

NPC贡献复用 `intrigue_state.factions.sect:ID.member_contribution`，玩家沿原 `faction_contribution`。年度履职增加 `2 + 境界序号` 宗门影响力，完成任务增加3，影响力最高1000。捐献每100真实灵石获得5贡献与1影响力，不可能经捐献兑换循环增钱。

贡献直接兑换每点10灵石，普通实物按府库现价折算。每行动单位兑换上限为 `max(100, 本人最低年薪×2)` 灵石折值；本单位尚未使用额度时也可单领一件更高价物资，此后本单位无法再领。沿原 `diplomacy_unit` 保存已用额度，读档、切页、宗籍来回变化不刷新旧宗额度。原延时审批申领保留审批、预留与单次数量限制，实际领取与新兑换共用额度，避免旧入口绕过限额。

## 薪俸与危机

最低年薪为 `5×(境界序号+1)²×界面层级`；凡人也有最低档。原宗门经营收入入库后，按实际境界、层数由高到低支付，随后办理原养护和可选采购。实付薪俸抵扣原聚合日常劳务预算，保留原研习津贴份额，避免同一劳务二次收费。只有能覆盖全员最低薪俸并保留三年养护预算时才额外发放，最高加发50%。个人收到原行囊；NPC使用 `economy_v2.accounts.person:ID` 的唯一个人账户，初值0，仅真实转账增减，不复制府库。

逐人记最低额、实付额及年份；未付最低薪俸只作本年财政缺口，不自动重复扣成债务。任一人未领足最低档时，不满增加 `2 + 10×欠薪人数比例 + 2×累计罢免次数`，正常发足年度不满降低5。富余NPC在欠薪或不满达到30时，保留三年最低薪俸，仅捐献多余部分的10%，单次最多1000灵石。

不满40触发争薪冲突，70触发高阶修士出走，95且连续三次欠薪触发山门解散。各阶段首次提升立即触发，同阶段最多五年一次；事件通过原待处理事件链展示，不覆盖原奖励。出走和解散沿原人物迁出入口及原宗门解散入口，不虚构死亡、不复制人物。事件确认不再次施加财政结果。

有实际部署或研究行程的门人不在行程中强行出走、被开除。财政解散时原战略战役先按本宗撤回入口下令原路归返，盟宗保留原命令；普通旧战役将本宗出阵者登记离场。人物只变更宗籍，物理地址、返程时间与原军需不复制、不瞬移。

决策者在欠薪且不满至少20时可以罢免掌门并任命合法继任者，立即降低25不满，每年度危机限一次；每次罢免永久增加以后欠薪的2点不满。掌门、决策者或控制者可暂停招新；掌门或控制者可开除普通弟子，不能开除实际控制者、掌门或在押者，开除增加5不满。停止招新同时挡住自动招募、扩招候选、旧入宗事件及关系引荐。

## 战争与地点

战争动员只能绑定本宗参与的同界实际活动战役。NPC完成玩家发布的动员后，本方下一场会战战力增加2%，最多10%；原会战开场领取增益，战斗编号改变即失效，不形成永久加成。离界或不再在籍时不启用留存动员收益。

玩家完成NPC动员需要沿原地图抵达战役地点，随机迎战敌方实际出阵名册中相差至多三个小境界的修士；在途、离场、拘禁、异界或无可战对手时不能提交。不新建NPC、不远程伤害山门中的人物，也不直接修改玩家世界或位置。战斗沿原战斗与非剧情存活结算入口，失败不给贡献。发布、物资交付、兑换、捐献和治理均须亲赴山门；任务战斗在战场办理。

## 状态与验证

任务、发布门槛、招新政策、影响力、逐人薪俸、危机记录和修订号归原宗门 `task_board`，不是随行组织；NPC个人现金归原人物ID，物资归原固定府库或玩家。任务保存发布时世界、地点、宗籍时间，宗门迁址、发布人离宗或战役结束后不可领取旧任务。无新增 Player/GameState 顶层字段，嵌套归属登记在字段合同。
