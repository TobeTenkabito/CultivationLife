# 经济消费端重平衡：结构 10 当前规则

本轮补齐居民消费、组织供养、生产投入、产业养护及战争后勤。所有收支复用原钱包，所有商品复用原市场、府库、产业仓库和战争托管；折值只用于展示与预算。黑市继续承担玩家寻找大部分材料的保底职责，沿用原流通范围、搜索、溢价、批量购买和独立供给规则。

## 一、商品用途、品阶与供给

完整逐商品表见 [商品供给审计](economy-supply-catalog.md)，由 [离线校准工具](../tools/report_economy_rebalance.py) 生成。表格遍历目录仅发生在离线审计，年度经济不照此逐商品结算。

| 类别 | 用途 | 居民基础年需求率 | 常规供给 |
|---|---|---:|---|
| medical | 疗伤、恢复与战地医疗 | 0.100 | 初始存量、消耗同品阶原料加工、原玩法 |
| training | 修炼与突破丹药 | 0.080 | 同品阶原料加工、原炼丹玩法 |
| material | 日常修补、矿材、药材及加工材料 | 0.080 | 明确自然原料采掘／种植；加工品扣原料 |
| arms | 法器、装备及低频补损 | 0.008 | 同品阶原料加工、原炼器玩法 |
| energy | 阵材、能源及能源组件 | 0.060 | 同品阶原料加工、原玩法 |
| general | 其余普通消耗品 | 0.020 | 有原料则加工；否则仅实际存量及原玩法 |

品阶沿用权威商品目录，普通索引最多覆盖 0–13 阶；境界统计为 0–12。每个用途品阶选两件稳定代表品，材料组优先保留一件自然原料和一件加工品。受限特殊来源不加入普通流通；进口库存不获得本地产能。居民需求为代表品初始目标库存 × 上表年率 × 实际经过年数 × 人口系数；人口系数为 `min(3,发展潜力^0.15)`，再乘配置年消费率与 0.08 的比值。

原料来源必须区分成品：铁衣符、玉露丹药和傀儡外壳不能因名称含“铁／玉”被当作矿产；未刻制符玉可作为自然矿材，符纸和朱砂按加工品。具体矿区也复用此来源判断，不再“开采铁衣符”。军需读取旧记录时只计算投影，只有真实会战或动员入口更新名册分组；已离开原供给界面的成员退出部署。

加工采用用途组的可替换实物投入，而非逐件重建炼丹炼器配方：每件扣同阶自然原料 `ceil(成品参照价×0.45/原料参照价)`，至少一件。无适用原料不自动生产。加工劳务为参照产值的 12%；采掘／种植劳务为实际净销售收入的 70%，均进入原界背景账户。具体玩家产业仍沿用自身权威配方。背景部门内部劳动不产生额外账户或重复工资。

经销商只用已有现金购买真实订单，库存最多补至当时目标的 1.5 倍；不按发展指数增加库存或重置收购资金。组织每次最多完成四批，按同地存续组织分配销售容量，避免结算次序让后结算者失去全部订单。扩建提高劳动能力，不保证销售。发展潜力不再直接发行灵石；只有实际终端消费收据的 2% 上限、且背景资金低于初始市场资金目标时，才允许显式记录有限发行。

## 三、战争范围、动员与后勤口径

实际战争名册仍由原战力与战争状态入口生成，保留原人数上限；军需不按全宗人口，也不按单场 1–3 个对手计算。指挥者可在原军事导航选择半数／全员动员，默认全员指“既有战争名册全员”。半数取原名册前 `ceil(人数/2)`，同一范围同时用于战力、军需及劳动占用。每次会战复核死亡、逃离、拘禁、邻域压制和科研占用；玩家实际参战时计入其境界。

| 支出 | 口径 |
|---|---|
| 开战准备 | NPC 主动宣战参考至少三场储备；现金与适用府库军需可计入，贫困防守仍允许 |
| 一次动员 | 一场参考需求的 10%，仅支付已有战争托管现金 |
| 驻军 | 每真实年一场参考需求的 0.1%，保留小数；资金不足记录最近缺口，不复利、不发币 |
| 会战 | 实际部署境界组消耗下表实物及能源；不因仅发生小规模战斗重新定义整个名册 |
| 补给 | 目标四场物理储备，预算按实际缺货报价，保留四场能源现金；不是按显示折值判断充足 |
| 常规／跨界当地采购 | 会战参考需求的 20%／跨界攻方 10%，受已有钱货限制 |

运输、前线地址、原组织出资、贡献返还沿用既有真实路线。运输损耗永久销毁；劫粮仅取得实际被夺实物的 60%。战争中暂停组织新产业投资。不能把战争 UI 的物资折值当作新现金或经济产出。

## 四、军需份额及替代

| 军需 | 每部署成员每场基础件数 | 品阶与替代 |
|---|---:|---|
| 医疗 | `0.040×W` | 同阶或高一阶医疗；同用途丹药可替代 |
| 物资／修补材料 | `0.064×W`，含 0.060 常规和 0.004 修补 | 同阶或高一阶材料，不整场报废整把法器 |
| 阵材能源 | `0.030×W` | 同阶或高一阶能源组件 |
| 灵石能源 | `max(40×世界层级,ceil(Σ人数×W×12×世界层级))` | 实际战争现金支付，不用贵重货品折值代替 |

高阶需求先分配，每件实物最多覆盖一次需求；低阶不得顶替高阶，高一阶按一件覆盖一件，不因价格涨跌改变可支撑场数。每组最多四个候选。小数需求先整件预付，后续使用余额；不可每场把不足一件向上取整重复扣货。欠供取各军需目的覆盖率的最低值并计入能源覆盖，战力系数为覆盖率 ≥1／≥0.75／≥0.5／≥0.25／其余时的 1／0.95／0.8／0.55／0.25，士气按实际缺供下降。

固定六人名册、初始十万府库的四场后勤样本用于检查成本尺度。消耗物资当前折值、实际资金拨付、未消耗库存必须分别报告；该样本不是完整战争胜负或全部境界的收益证明。较高境界通过权重及相应商品价格共同提高费用，不额外指数放大；夺取产业、税权和既有战争收益仍走原入口。

## 五、自动经营优先级、止损与欠费

优先顺序：已欠及当期仓储养护 → 保留养护资金 → 完成已付款批次 → 按限价销售 → 有资金、有原料且预期盈利时新采购投产。基本养护不会被可选扩建或新投产抢占。

| 规则 | 当前初值／计算 |
|---|---|
| 年仓储养护 | `max(1,ceil(实际库存当前价×0.002))`，只遍历产业实际库存 |
| 自动经营储备 | 配置保留资金与三年仓储养护取大；组织产业另加三年 65% 基本养护 |
| 默认保留灵石 | 100，可在原产业页面设置 0–10¹² |
| 默认单次支出上限 | 100000，可设置 0–10¹²；为每次自动投产／进货上限，不是年度无限授权 |
| 自动止损 | 预计净售款至少为实际工料成本的 1.05 倍；库存、限价、限额、现金任一不足即暂停 |
| 委托经营 | 自动支出限额按可支配资金的 10% 规划，并继续执行资金储备 |
| 欠费 | 线性累计到既有限额，不收复利；暂停采购、新投产，已付批次和库存保留，可售库存回款 |

本人产业只动用原产业周转金，不擅自扣玩家行囊；组织产业直接使用原府库。玩家手动付费投产保留自主选择，自动盈利门槛不强加到明确手动订单。

## 六、聚合边界与性能验收

年度消费不遍历全部 NPC 与全部商品，更不逐人买卖；名册仅一次汇总为 13 个境界组。用途品阶索引在市场首次建立／目录变化时构建，常态消费最多 `6×14×2=168` 个代表品采购请求。每组织最多四批成功生产，会战物理场数检查固定 24 次二分。NPC 出生死亡、战斗和剧情仍走原年度流程，本轮没有宣称整个游戏对经过年数是常数复杂度。

168 指居民代表品采购请求；若代表品需要加工，每种至多另发生一批真实原料采购。既有竞争治理只处理实际交易／仓储产生的观察记录，产业只处理持有库存及在制订单；这些真实资产结算不被伪装成免费的虚拟篮子。常规委托、事件及战利品报酬由本界背景资金实付，通缉赔偿从原势力府库实付；项目托管及拍卖退款沿用原实有托管余额，不能重复向背景账户索取。

允许：稳定人数和类别下线性累计件数，小数保留九位；未消费的整数缺口当期配给；跨多年观察按当前真实库存、现金和报价一次兑现，不虚构过去各年的市场交易。恒定需求、可供库存足够且无价格变化时，合并与分年消费件数一致，整石账单的取整差每笔不足一灵石。动态价格、稀缺、出生死亡、战争等路径不保证批量结算与逐年结果相等，也不回写虚构历史。生产原料与用途组是宏观可替换投入，玩家具体配方保持独立。完整商品表只用于离线审查。

| 验收项 | 阈值／方式 |
|---|---|
| 资金与实物 | 扣加必须对应实际钱包／库存；不为负，重复结算幂等；总现金差仅允许显式发行 |
| 稳定需求 | 百年合并与 100 次一年测试件数相同；需求小数误差控制到 10⁻⁹ |
| 单市场篮子 | 1／100／500／1000 年，暖机九次中位数 ≤50ms，1000 年 ≤一年中位数三倍，代表品请求 ≤168 |
| 真实百年动作 | 三种子真实休息、年度 NPC 和存读档，中位数 ≤5 秒；只关闭无关弹窗中断完成整段 |
| 长期稳定 | 三种子固定名册 200／1000／5000 年；资金守恒、库存非负、读档一致、基本养护不普遍停付 |
| 有界状态 | 总账 80 条、市场／组织历史各 12 条；篮子缓存 64 个且不持久化；订单份额每年重置；样本经济 JSON ≤256KiB |

使用 [校准工具](../tools/report_economy_rebalance.py) 输出 `build/economy-rebalance/report.json`，将纯经济压力与真实行动测量分别记录，勿将固定名册模拟当作完整五千年人物模拟。长期样本逐年调用既有经济与组织年度入口，冻结名册来隔离钱货循环；直接跳过数百年仅按当前库存兑现，并不等价于每年销售、支付养护和再生产。性能阈值适用于验收机器和该固定样本，不是任意规模存档的响应保证。

真仙及以上（境界 9–12）行动单位统一 100 年，所有境界最长单位不超过 100 年；外交单位、真实经过年份、战争会战与驻军年费分别计数。已有结构 10 存档首次采用新消费政策仅建立当前年基线，不追扣过去消费；结构 1–9 继续不兼容、不转换。新字段归属见 [状态合同](world-transition-state-contract.json)，原跨界流程、黑市保底和免费基础修炼继续适用。

## 百年行动算法优化（2026-10-09）

4.170ms 是单市场消费篮子的耗时，完整百年行动需另测。首轮剖析中，商队路线与选货占剖析累计耗时约 64%；每个商品、每个装载量都重复推导相同的护卫标准及路线风险，是主要冗余。剖析器会增加耗时，改善幅度以下面的非剖析对照为准。

| 优化 | 等价性与计算量 |
|---|---|
