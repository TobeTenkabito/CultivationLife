# v3.3.0「诸天开拓」发行

2026-10-30。本体3.3.0，Android版本码88，存档结构与最低可读结构均为11。结构1–10拒绝加载，不转换或覆盖；本次不修改用户游玩存档。DLC版本保持各自已登记版本。

## 本版内容

三层普通界面共17组同层双界、34个方向，完整规则见[诸天开拓](heavens-outposts.md)。入口为“诸天 → 诸界 → 跨界开拓”：原总部批准文书与当地军令，原门人沿实际道路和固定通道派驻，使用原钱货建成驻地，再经营、扩张、出征、迫使当地原宗门／家族归附，循路归返结清。各目的界许可、人员任务、仓储和账本分别校验；同双界的宗门、家族共享同一实际年的单人通道。

同时纳入[要求承诺与凤仪亭](npc-promises.md)、[貂蝉皮肤](diaochan-skin.md)及[导航延迟构建与按需素材](navigation-performance-280.md)。身魂、其他通行方式与已有战争规则继续使用原权威入口，不授予远程移动或免费输送权限。

发行回归补修普通年度的死亡／身魂中断边界：个人年龄已经推进后，原身魂结算即使终止个人行动，仍沿原地区入口完成已发生的世界年、NPC年和诸天年度；保留原死亡结果，不再执行个人奖励或成长。原身魂随机与死亡顺序不变，空间年度沿原隔离规则。由 `test_heavens_autonomy.py` 的寿尽／事件中断及身魂、存活、地区与时间上游回归验证。

旧托管护持同样保留已发生年度的原费用：先按唯一年度游标实付该年，再终止并退回未耗预算；死亡当年即使达到末年工期也不取得维护收益。`test_heavens_upkeep.py` 验证死亡首年、最终年和重复回调。经济目录采用测试改按当前结构11核对，不放开旧结构载入；旧主题测试补齐现有独立配色与侧栏偏好字段。
