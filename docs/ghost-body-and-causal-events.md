# 鬼躯五法与通用炼体因果结算

2026-11-03开发源码，结构仍为12；拒绝1–11，不迁移、不折算、不修改用户游玩存档。本轮没有升版或打包。本文取代旧文档中“全部动态事实在轮首预掷、最多八份反应、派生行动不能再触发其它机制”的限制。

## 结算阶段

轮首只固定机制资格、依赖、受蕴暴击、坎道、抵抗封禁、神魂交换及乾古静默顺序。所有原始记录先生成，再静默，行蕴仍读取目标静默前的原始机制种类，不因静默清零或因一次机制多次响应重复计数。事件型机制的原始记录表示本轮具备响应资格，不表示提前发生阵亡或消耗。

实际攻击逐段确认合法目标并锁定ID集合，再判定闪避、数值与阵亡；想蕴免费在额度实际创建时判定。所有随机沿调用者的原战斗RNG，不在预览、打开培养页或读档时投骰。相同快照和RNG重放一致。原特殊介入仍每人每轮一次，原普通伤害仍先预分配再同时结算，不能因逐段处理改变基础普通攻防的先后手。

每个派生分支携带不可变的`(战斗单位ID, 机制ID)`路径。不同机制可联动，不同人物的同名机制分别计算，同轮独立根事件与照业兄弟段也分别计算；路径中已有的同人同机制不能直接或间接重入。`A→B→A`在第二个A处停止；没有按伤害来源“一刀切”禁用所有派生机制。队列迭代执行，子事件在下一兄弟攻击段前结清，不使用递归调用栈，不丢弃第九次合法反应。内容声明的直接额外行动数仍受原八份内容校验限制，实际跨机制反应不再共用八份截断。

受蕴在真实合法数值行动上应用时进入路径；该次暴击触发想蕴，想蕴追加的同一分支不能再次进入同人的受蕴或想蕴。另一根暴击可再次兑现想蕴。逆骨实际成功进入路径，再进入同人的烈脏；敌人的逆骨与烈脏可以继续响应，但不能绕回同一人的相同机制。识蕴响应一次实际额外行动，照业三段仍只计一次；即使首段已击杀全部目标，已发出动作仍计一次，阵亡者不靠识蕴复活。伤害、阵亡与御魂子事件先于下一兄弟段结清；想蕴和烈脏产生的施权额度仍进入原执行器的下一行动批次，不打断已付费的同时攻势。无相的回复增强走原态势／稳固恢复入口，不改变元力回复、物理HP或永久魂基。

## 鬼躯培养

鬼修道途DLC实际启用时，从独立“鬼躯”入口培养，手机归原“修行”分类。本人在轮回界九阶且普通炼体100层后，可修高阶鬼躯50层，每十层依次解锁无相、照业、御魂、忘情、因果，各自0–10重。层数复用原`Player.immortal_body.level`唯一高阶炼体坐标，独立等级写入`ghost_training`，不创建第二份层数或资源池；此道途投影取代五色神光，不叠加。

鬼躯层数修炼实扣原机缘和轮回界原普通筑域材料实例（优先较低品质），每层材料数为目标层数。五法独修改用下表各自专材，从原行囊真实扣除，不能用筑域石、其它五法材料、稀有或动态材料替代；机缘为原开脉基础机缘乘目标数，五法额外分别乘1–5。普通炼体、缺材、满级、过期提交、事件、劫战、拘禁、寄身、已毁肉身、修为压制、旅行、归墟及诸天亲自任务都在扣费前校验。修持不耗时间、不投随机。层数增加沿原鬼修魂基本源高水位入口结算，保持当前HP／MP比例，机制独修不直接增六维。

## 攻击与目标

`VoisinageEffect.target_mode`明确`all`或`single`，默认保留现有邻域覆盖范围内的全目标语义。单体照业每段从当前实际合法覆盖目标中随机选择；自疗不随机敌人，盟友治疗只在原可支援目标中取值。原邻域覆盖、可触及和实际受控资格仍适用，不凭随机选靶扩大范围。因果明确全体，故照业必定将其拆成三段全体攻击，每段重新取得当时仍在场、未逃离且未死亡的合法敌人；濒危或被制伏不等于死亡，杀伤仍按原目标与诛杀／擒拿目的结算。

照业只收费、计行动一次。数值效果乘继承比例，二值禁制与无威能的二值控制以继承比例判成功，不能变成三份满强度控制。终结处决沿原第二轮支配和实际武器资格执行，不拆分、不由鬼躯凭空授予处决。实际维持的邻域才能触发逆骨；每一攻击段独立判闪避，已支付费用不退。

忘情比较连续攻击段锁定的**精确战斗ID集合**，忽略集合顺序，不将“全体”当作永远相同的标签。第一次只登记历史。不同集合时，以本段实际态势伤害之和乘比例向本段集合之外的合法敌人溢出；相同集合则对原目标追加各自实际伤害乘比例的一段。受免疫、闪避或防护而无实际伤害时不制造伤害。历史锁定后不因阵亡反向删成员。`{A,B,C}→{A,B}`不一致，但第二段已覆盖所有剩余敌人，没有其余目标，因此不溢出。照业`A,B,B`依次登记、溢出、追加，忘情派生段不反过来污染自己的攻击历史。若忘情先由普通攻击触发，其邻域性质的派生攻击可以再触发照业，但不能再回到同人的忘情。

## 元力与阵亡边界

所有战斗内实际扣费、神魂交换导致的真实减少、沸血支付及旧MP链路同步扣减都走同一`_energy`入口。因果以该单位本场可用容量为分母，封存容量不参与；回复不冲减已累计消耗。跨过多个阈值逐次发出，余量保留；同一笔扣减不会被后续同步再记一次，单纯容量或展示归一化不计消耗。静默或本机制因果链内跨过阈值时仍消费该阈值，不储备成解除静默后的延迟攻击。

御魂只认真实杀伤或明确合法诛杀造成态势／身体归零的角色；镇压即使令态势归零，也不是阵亡，失去行动资格、逃离、离场同样不算。耐久劫战会重凝、原本不视为真实阵亡的虚影不发凭据，普通一次性劫相不因此免除真实本场阵亡。死亡ID在原`UnitState.death_observed`防重，双方真实阵亡都可响应，已死亡／被制伏的持有者不能靠御魂复活。只回复本场态势与原可用元力，不恢复物理HP、永久魂基，不生成魂材或复活人物。继承比例、劫战资源和顺序修复见[对抗审计](high-body-bug-audit.md)。

因果余量、忘情上次目标和阵亡防重随原劫战单位快照保存；切批次、JSON读写或续战不重置。路径和待办队列仅归当前结算，快照只在队列清空后的轮边界生成。异常的非有限余量、非法目标历史及阵亡标志拒绝加载。战报记录三段、目标集合、比较结果、实际伤害、元力阈值／余量、阵亡回复、静默及因果路径。
