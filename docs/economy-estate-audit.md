# 产业经济审计（2026-10-13）

范围为经济模块及其组织府库、商队货单、军需、年度时钟、产权交接、市场和产业页面的调用链，并运行全仓回归。源码修改不代表发行包已经更新；本轮不修改用户存档，也不转换结构1–9。

## 缺料后出现交易金额

正式 `fleet_action` 开工在仓库缺料且未授权自动补料时拒绝，保存文件不变。随后沿真实 `advance` 推进时间，产业的在制、库存、累计生产及销售收入仍为零。世界时间同时推进居民、宗门、商队的真实经营，因此全市场成交额可能增加。该金额不是玩家产业的收入，也不是玩家钱包变动。

市场页面将“累计成交”明确标为“全市场累计成交”，说明参与者。产业卡显示经营状态、缺料提示及养护组成，收入来自真实出售库存，支出包括采购、劳务与养护。已存成品可以在新批次缺料时售出；已付批次可以在停产或欠费后完工。这两种行为保留唯一实物，不能仅凭缺料提示判断为虚构收入。

## 确认的缺陷与修改

| 缺陷 | 修改与边界 |
|---|---|
| 空仓每年只收1灵石，扩大设施及在制品没有计费 | 设施年费为产权基准价的0.2%向上取整，再加库存及已付款在制成品当下价值的0.2%仓储费向上取整。产权基准价复用 `10000×界层×等级²`，丹坊和器坊乘2；不随短期产权报价漂移。一级人界空仓药田、矿区、猎场、商铺年费20，丹坊和器坊40；二、三级界面按2、3倍计。停产仍需场地维护，资金只来自原产业周转金／组织府库，不自动扣玩家行囊 |
| 收回委托保留启用、采购和销售开关，下一年仍经营 | 收回委托同时暂停三个自动开关，保留原配方、库存、限额与已付批次。可在原所在地重新配置持续经营 |
| 战争接管仅关闭持续经营，旧掌柜下一年重新启用 | 接管同时撤销旧委托及自动采购／销售；原地点、原批次、库存、矿藏、欠费与唯一府库归属继续使用原交接入口 |
| 委托在同一结算调用两次自动出货，绕过单次额度 | 掌柜结算只执行一次自动销售；未卖完的货仍在原仓库，当前付费批次不取消 |
| 商铺只检查现金与限价，没有自动止损 | 核对采购后同地真实卖价与养护估计，预计收益不足5%就不自动进货；仍可手动采购及销售已有库存 |
| 自动生产／规划忽略整个周期养护及已有原料价值 | 掌柜规划和自动开工使用共享估价。已有原料按当前完整重置采购价估算，养护按生产周期计；实际付款仍只扣缺口原料和劳务，不再次购买已有原料。手动批次仍允许明确承担风险 |
| 补缴欠费未登记组织已付成本，后续销售被当作额外利润再收费 | 实付补欠先进入原组织 `estate_cost_credit`，再增加产业支出；未付欠费不提前抵扣。后续销售先收回这些已付成本，再按真实净利润结算经营服务 |

年度维护和三年储备使用同一只读计算入口；不新增持久字段、不重算已结算流水、不增加迁移、远程操作或玩家移动例外。原结构10数据从下次实际结算采用费用计算，只处理原 `last_year` 之后尚未结算的区间。费用随实际经过年份线性累加，重复同年结算不再扣费，既有欠费上限保持。

新增固定维护使部分低阶小批次原本的微薄毛利变成亏损。自动经营应暂停这种批次，扩仓不保证盈利；玩家仍可选择合适配方和批量或手动囤货。此数值是当前基准，不是所有产业必然盈余的承诺。

## 开局传送阵位置

全仓回归另发现原地图“无相邻阵点”断言失败，修改前提交 `45299e2` 也复现“镜湖—无棣原”冲突。用户随后明确要求一并修复开局阵点，因此保留原断言并调整七界初始配置，共消除28条相邻阵点道路。原道路、地点与门槛保持，默认出生地仍有阵；已登记的旧阵址、所有者、停用记录及付费设施保留，不能以新开局目录搬走或补发旧存档设施。详细位置规则及数量见[开局阵点复核](maps-2131.md)。
