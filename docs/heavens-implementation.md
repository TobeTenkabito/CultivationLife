当前发行 v2.1.1：情报已细分为五级，同界及下界自然消息为 lv5、上一层 lv2、上两层 lv1；商盟一至五星分别对应 lv1 至 lv5。妖界与地狱界均按第二层级处理。以下 v2.1.0 记录为历史验收，当前行为以[跨界审计](world-transition-audit.md)为准。

## v2.1.0 新增覆盖与消息规则

本轮在原十一地方案之外增加十一异象案、十一战地案；每案两条互斥分支。目录按「诸界／异象／战局」分离，每页仅展开一份档案或一项处理方案。异象新增的是普通地图现场事件，原镜律和因果遗址仍是独立空间。战地新增的是实际救护与庇护工事，原岚疆有限军队战役保持独立；未将这些事件宣称为全界征服或通用军队 AI。

- 所有新案复用真实地图、共享任务、实际年份、托管及回执。异象疏导结案恢复 30% 法力一次；封存保留有限普通参悟余量。救护在现场完成时对至多三名实际存活、自由且负伤的人物各减轻一级伤势；无患者不能启动，人员变化按续行规则处理，不生成或复活人物。庇护在返程复核后留下有限当地调息余量。
- 自然视野：同级与下界 lv3；上一层 lv2；上两层 lv1。仙界能了解灵界、人界的明确记录；人界无法从自然消息中读取仙界地点、势力和战果。已有亲历档案不因下界被抹去。详情查询和行动预览也执行可知范围校验。
- 战讯只依据实际战争日志；无战事不编造交锋。lv2 只保留界面及交战传闻，lv1 仅为灵气异动。跨界商盟可用原有付费情报委托转讯：1–2 星获得 lv2，3–5 星获得 lv3，最多保存 32 份带取得年龄的历史记录，后续战争变化不会自动改写旧报告。实物、人员、逆灵通道仍使用原商路限制。
- 系统势力宣战只允许双方存在同层级世界；旧关系补建战争同样受限。玩家明确发起的外交／家族／势力决议走豁免路径。现有同级的人魔岚疆案例不受影响；灵界物资援助不等同于灵界对人界宣战。
- 设置独立承接发现、通知和机会暂停三个偏好；诸天主导航只保留五个玩法页。主题保留四套，前端缓存和机器偏好兼容被移除的两套旧值。

入口为 **诸天 → 战局 → 岚疆界门 → 地方**。“地方”用档案选择器分别打开 **地方秩序／议约文书／救护与去留**，每次只显示一页。地方页以地点关系图、真实职责名单和通行规则为主，议约页展示文书条款，救护页展示现场伤员与撤离路线。协议和救护选择器每次只呈现一项操作，援助页也改为单项意向选择；战局每个详情页最多两个玩法操作按钮，操作按钮和选择器至少 44px 高，桌面和手机沿用六主题色板。

1. **实际地方控制**：新增可选 `campaign.settlement`，不修改共享地图或旧政治归属。来方原士卒真实驻守岚疆、两端界门可用且当地有补给，原阵师履职、无可用守方时，形成军事占领；双方均在场则争持。有效附约下由原天剑守备负责当地秩序、血狱原驻军护路。每年额外从原九万专项支付 100 灵石行政护路费，保留原返乡预算；不存在自动税收、无限资源、反抗军刷新或新的替代人物。
2. **控制落在普通玩法**：普通地图远行和公共传送抵达岚疆时提供实际驻军查验反馈。确有原驻军且补给有效时，非来方玩家的普通探索、寻宝暂停；出发前与长行动的每个行动单位边界重新核对。中途形成的管制在已经开展的完整单位结算后生效，避免一年的新军事中断换取整个旧单位收益。修行、调息和普通道路离境保持开放。驻军死亡、重伤、受控、离开、升境超载或补给中断时立即解除限制，不等 UI 刷新，不限制相邻地点。
3. **独立议约委任**：原阵师、原天剑守备离开驻地之前，由各自现任合法主体另授 `local_settlement` 文书，明确批准者、代表、世界、地点和期限。军事施工批准本身不是议和权，玩家仅提案和见证。双方原代表必须实际同处岚疆且自由、委任仍有效，才能经过两年亲自任务签署。没有代表、没有权限或玩家掌权时不代签；任意一方继任、授权到期会终止未获续任的地方保障，并保留安全撤回。
4. **三种有限协议**：当地停战停止本案双方交战并启动原路撤回；修复后撤军还须原关联阵眼实际恢复；限期附约只约束岚疆的原守备，期限三十年，保留双方实际职责与经费，不征税、不征发玩家、不处分全宗或全界。每案只签一次，不刷新期限。附约驻军失能、守备离去、供给保障失效、发生个人袭击或到期即结束保障。期满、失效与签约都不传送人物，仍沿原道路、单人容量撤离。
5. **结局与真实恢复**：记录守住并拆毁界门、占领后耗尽撤回、停战、限期附约结束、修复后撤军等分支；只有原编制实际返乡或失去部署资格且账目结清后才记内部终局。占领消失后，没有真实守方在场就记录驻防中断；重新出现可用原守备才是重新驻防。前端仅在现场展示已知地方状态与离场结果，签署文书保留玩家亲历条款，不显示远方预算、履约计时或即时撤回进度。
6. **战后个人路径**：普通修行继续沿用本体。可在岚疆花两年救护一位实际在场的原伤员，减轻一重伤势，每人本案一次，不生成金币、物资或新 NPC。对自己通过详细战斗实际擒获的原人物，可花两年办理释放，复用原拘禁服务移交同一权威对象并启动原许可返乡；不冒用敌方监狱，也不释放不受自己控制的人。撤往无棣原使用玩家当前境界、原地图道路和实际工时，事件可暂停，续办重新核对道路，取消不会返还已耗年数。
7. **旧档与扩展恢复**：R2 原存档可不带新字段，查询和读档不补写。下一实际外界年度才登记地方账目；已经远行的旧人物不会凭空补发携行委任，因此旧案仍可通过交锋、救护、撤离收束，但不能伪造当地签约资格。关闭生成不清除已有任务；界面关闭时原人物和撤离进度保留，恢复后继续原路。所有新增字段严格校验，人物引用进入原清理保护；协议、救护与撤离沿用原命令回执、最终年暂停、零补时续办及单存档原子提交。

代码分为纯条款／校验、地方规则、个人动作、普通地图与资源的只读规则接入、引擎服务适配及前端展示。未增设年度循环、伤害模型、宗门政治解析器或全界控制状态。

### 第二轮玩法与实现

入口为 **诸天 → 战局 → 岚疆界门**，只在收到实际预警后出现在目录。详情分为 **军情／界门／交锋／援助** 四个独立子页；军情保存亲历报告，界门只显示本人在岚疆已经查勘的目标端，交锋只列本地已见人物，援助单独办理申请与领取。远方预算、未知批准者、运输队列和精确工时不进入前端。

5. **维护、中断与撤离**：稳定运行每年实际消耗一份目标端补给；驻守失能、界面关闭或供给不足导致稳定性逐年下降。尚有供给且原阵师恢复履职时，可花四个实际年消耗唯一预备阵材修复。批准变更／到期、经费只余返乡预算、阵师失能或界门崩解后停止输送。未到达运输原位卸回；已在界人员持独立 `evacuation:human:demon:lanjiang` 返回许可，单人容量、每人八年，再沿实际来源道路返乡。拘禁期间暂停，释放后继续原人物行程；死亡不复活。

### 第一轮玩法与实现

入口为 **诸天 → 战局 → 岚疆边情**。目录只展示一条边情；详情在问讯前显示“问讯”，登记后分为“情报／现场”。已同意返程或收到结清回讯时收起不再适用的劝返操作。其他诸界、异象和民用行程仍为独立页面。

2. 接收方是已有的 **血狱魔宗**，而非新造宗门。下一次普通外界 NPC 年度才检查来源证据、现有决策者、真实可用门人、道路、专项预算。已有政治记录的 `controller_id` 优先；没有记录时依据本体门人领导序列。玩家掌权时不替玩家签发命令，也不读取 DLC 性格或政策来生成意图。此次权限只准一人调查阵眼，不准施工、征兵、军事输送或处分全界。
3. 从原宗门选择未被其他战争、关系或独立空间占用的三至四阶真实门人。移交**同一个人物对象**到 `world_npcs`，保留 `faction_id`，不新生或复制；其后仅由原世界人物年度成长，回到原界后仍保留同一权威名册。宗门成员查询仍识别其原归属。普通交往、旧战争征兵、民用行程均读取部署占用。
4. 集结使用原宗门实际驻地到魔界赤髓城的地图道路和真实行程；默认固定输入为 **55 年**，不免费搬到来源端。独立登记 `recon:demon:human:lanjiang` 的单人有限路线：**魔界赤髓城 ↔ 人界岚疆草原，各 8 年**，真实境界上限五阶，无军队／货运容量。抵达时再次检查位置、受控状态、世界开关与真实修为，伪装不算压制。

6. 此次调查拥有随该唯一实例登记的血狱魔宗**初始专项储备 18000 灵石**，是新增本体案例资产，不冒充原 DLC 内政库，也不从玩家背包扣取。普通行军／勘察每年消耗 100，批准前预核整个往返；已耗、未耗和退回原专项均持久记账。默认自然往返 140 年，其中实际支出 13800、退回 4200；回讯不收费。此处初始储备仅生成一次，不会通过重访、取消或关闭生成刷新，也不给玩家平空报酬。
7. 批准期限 **200 个诸天实际年**；批准者变更、死亡或被取代会令已有先遣转入实际撤回，返回不依赖新的进攻许可。受控、实际位置不符、路线关闭时暂停且不扣行军费；真实释放并恢复位置后续行。死亡结清余款，不复活；正常成长／迁界超过该有限路线承载时结束部署并保留人物真实修为和位置，不伪造降境或传送。

只有唯一普通外界 NPC 年度推进先遣；独立空间冻结、不补算，同年度回调去重。期限仍依据诸天实际日历。关闭新生成保留已批准的调查与返程。问讯尚未送出时可取消且不会派遣，送出后取消个人任务不等于撤销另一方的授权。所有亲自行动沿用原唯一任务、短活动单位余量、最后一年事件暂停／零补时续办、命令回执和单存档原子提交。

运行状态置于可选 `runtime.frontier`，定义修订 1；旧档不自动增加实例。具名授权保存批准人、来源、对象、目的、路线、容量及起讫时间。内部阶段、精确行程、未获知人物身份和预算不进入前端；“情报”只保存亲历或真实回讯，历史报告不冒充实时敌情。定义、纯校验、调度、引擎公共适配、前端分别位于 `frontier_definitions.py`、`frontier_schema.py`、`frontier.py`、`composition/heavens_frontier.py` 与 `web/heavens-frontier.js`，不新增伤害引擎或复制年度循环。

## 进入玩法

六主题侧栏都有“诸天”入口。新建角色默认允许发现联系，旧档迁移仍只增加空容器，不自动开启；在“偏好”中勾选“允许发现新的诸天联系”。通常默认打开“见闻”，身处异象时默认打开对应详情。满足未受控、未封印、未压制的九阶以上修为后，到本界联系地点体察；经“诸界”目录选择联系即可查阅详情，异界动作会说明须在当地参与。查阅、导航和切换页签不会移动角色或生成实例。生成关闭后不产生新对象，已建立的联系、期限和托管继续处理。

主导航为“见闻／诸界／异象／行程／战局”，偏好另设入口。每次仅渲染当前页面，切换并非滚动定位同一长页；设置、全部历史、四界操作和两个异象的全部机关不会一起显示。

### 四界有限托管护持

从“行程 → 护持”选择一处联系；“诸界 → 对应联系 → 参悟”也可跳往护持详情。目录只列四界状态，详情才显示预算、供能进度、截止余年、已安装阵材及部署／终止操作；“进行中”仅提供活动设施数量与跳转入口。身处镜律或遗址时仍可主动选择联系查看托管，默认异象入口不变。

- 仙界法则天海、修罗界寂灭海、幽冥界界树天冠、轮回界因果天城全部可用。本人须在当地，具有未封印、未压制的九阶修为，未受控、没有待处理独占事件或亲自任务，已取得该联系 E3 合法抄录并完成当期体察。

- 完成后沿用原维护事实：本周期本地余韵延续 **600 年**，可登记第二次参悟；共享原收益总上限，不另发机缘、项目补助或材料，也不延长另一端的客观窗口。跨周期清空本期效果，旧设施记录保留；今后周期仍可亲自维护。
- 可在任意地点终止尚未完成的托管；窗口到期或本人死亡自动结清。**只退未耗灵石**，已安装阵材、实付法力、已耗经费和当期名额不退；部署预览明确说明该设施与亲自维护的取消差异。关闭新生成不撤销已授权设施。
- `echo.upkeep` 为可选持久字段，保存设施状态、部署周期、工期、进度、唯一安装阵材、累计托管账目和已处理年度；读取旧档不自动创建。实际阵材从背包移入设施记录，不能在其他库存、货运或任务中同时存在。严格验证窗口、当期维护效果、真实世界来源及资金守恒，提交失败沿用原工作副本回滚，重复命令不重复扣费。

### 居民先行发现镜律场域

玩家无需先打开镜律入口。穆陵沙漠原有自由的四至五阶居民，在普通年度的百年窗口中可自行发现镜纹、启程并进入同一镜律场域；不为发现新造居民，不赋予外地居民尚未取得的本地目击。

- 发现只创建有限场域事实和原人物行程：玩家世界与地点不变、访问次数保持零、市场与背包不变，预留的两件阵材仍由各自机关持有。玩家未接触时，异象不进入已知目录，NPC 姓名与进度、机关状态、痕迹及容量不经诸天视图泄露，也不广播远方纪要。

- **NPC 先发现的镜阵，在玩家首次亲自入场之前不绑定玩家法力容量。** 容量与实付、收集、储量都为零；NPC 继续采取被动观察，不凭空创造 NPC 法力账本或替玩家施术。玩家首次实际入场时，用本人当时法力上限的 25% 固定容量，之后升境、装备变化、重访、读档或重复提交均不重算；旧镜律存档保持已有容量。
- 居民先行入场仍耗两个真实外界年。玩家尚未进入时，该空间年度冻结，居民不会在外界年月中额外研究或衰老；进入同一空间后才继续八年研究与一年退出。场域建立后即使关闭新生成、居民改道或真实死亡，已成立的场域与预留物权仍保留，玩家日后可亲自调查，不补造替身。
- `mirror.player_known` 与 `mirror.capacity_pending` 均为可选持久字段。等待首次入场的状态须有自主居民来源、零法力账目、零机关操作／痕迹及零玩家访问；首次入场固定容量并移除待定标记。拒绝不可能的知情、供给和访问状态，保存失败回滚创建／揭示／固定容量的整个工作副本。存档结构仍为 9，诸天子协议仍为 1。

### 双异象同勘与自主择路

镜律入口由玩家实际踏勘或当面遇到探访者后，“异象 → 镜律场域”提供独立“入口／同勘”子页；进入后为“机关／同勘”。行程页以一张进行中卡片链接到对应异象，同勘内容不会混入三处机关操作。六主题共用导航，机关选择器与外层页签各有独立的无障碍面板引用。

- **两座异象分别一次、同时仅一项、同一人物仅参与一次。** 沿用原权威人物名册、四至五阶自由居民和既有职责检查。手动邀约要求交情至少 20，实际在对应入口办理；镜律在穆陵沙漠，因果遗址在无棣原。取消仍保留本次记录和已耗时间，不刷新人物或名额。
- 自主探访继续使用原已持久化的每百年窗口与 25% 有限试抽，不消费旧 RNG。已有行程不会改选；空候选、失败窗口、查询及重载均不重抽。选中真实居民后，在尚有名额的可用路线中优先选择本人当前所在入口；没有本地入口时使用同一独立摘要稳定选择。因果遗址可沿旧路独立发现；镜律尚未建立时，只有实际位于穆陵沙漠的居民可把它作为候选。镜律已建立后，其他合格居民也可选择稳定入口。整个成功窗口只筛选一次候选名册，不分别为两个目标全量扫描。
- 一份行程结束后，后续实际百年窗口可以由另一位居民选择另一座异象。仍最多保存两份勘察；旧自主记录的来源窗口不因新窗口被处理而失效。同一窗口不能生成两份自主行程，同一人物也不能先后被复制到两座场域。
- 镜律同勘为 **2 个外界年赴约＋8 个本场域年观察整理＋1 个本场域年退出**。第 2 个研究年获得本人的观察事实，第 8 年形成完整笔记，再沿稳定入口返回穆陵沙漠。原人物实际切换世界与空间成员引用；年龄、陨落、受控暂停继续服从已有年度系统。玩家离场或进入另一异象时，镜律内部冻结，外界年月不追补。
- 镜律居民采取被动观察与整理：不替玩家试探、不开机关、不隔断、不强攻、不领取预留阵材，也不虚构施术法力；镜储、守护快照、痕迹和机关状态不会因同勘自动变化。居民有笔记并不等于玩家已经取得笔记。
- 邀约者仍须实际会面交换；自主来访者还要求实际接触和交情至少 20，商请结束也遵守相同条件。未遇到的自主行程隐藏姓名、进度与远方纪要。交换后，**随后启动的镜律低耗破解由 4 年缩短为 2 年**；仍先亲自试探，照常实付法力并进入镜储账目，三处机关原有唯一所得不重置。镜律笔记不缩短因果遗址读取，遗址笔记也不替代镜律研究。
- 以可选 `runtime.mirror.survey` 保存同一套居民事实，原镜律存档缺省保持不变，不补造人物或自动邀约。坏档校验覆盖场域建立时间、年度进度、知识来源、单人占用、唯一空间归属及零托管等候任务；提交与实际抵达沿用工作副本、单次持久化和回执去重。存档结构仍为 9、诸天子协议仍为 1。

### NPC 自主发现与探访

普通世界年度现在可以在没有玩家邀约、玩家尚未进入遗址时，安排一位原有人界居民自主探访因果遗址。它仍是一条有限和平路线，不代表任意异象、任意商贸或军事行动的通用 AI。

- 启用诸天生成且内容可用时，自登记日历经过首个百年起，每个百年窗口在第一次实际普通 NPC 年度结束后最多检查一次，初值 **25%**。失败或没有候选也保存已检查窗口；关闭生成、独立空间年度、玩家在 NPC 阶段之前死亡／遇事件均不执行。离开空间后最多检查当前窗口，不补跑错过的世纪。
- 候选为原有自由的四至五阶人界居民，沿用名册、关系、队伍、战事、受控与其他行程占用检查；自主出行不要求已与玩家有交情。目的明确限定为求证旧路、观察与合法抄录，不取芯、不夺取玩家预留阵材。没有候选则不生成人物。每座遗址与玩家邀约共用唯一勘察名额；死亡、结束和读档后不补充替身或重新抽取。
- 独立的带版本 SHA-256 抽样使用世界种子和保存的百年窗口；不消耗旧世界随机流或玩家诸天感知随机计数。仅窗口到期且抽中时筛选候选，其他年度不全量扫描居民。
- 自主决策发生在原普通 NPC 年龄、成长、生死处理之后。决策当年不同时计为出发年；其后真实经过 **2 个外界年**寻访，进入同一个已持久化的遗址。后台建场只登记有限机关与稳定入口，不移动玩家、不刷新市场、不增加玩家访问次数。
- 未实际接触时，遗址与行程保留在客观状态中，但不列入玩家已知记录，不显示人物 ID、行程进度、阵芯和痕迹，不向玩家纪要广播远方发现或死亡。玩家亲自进入遗址，或在普通年度于无棣原实际遇到尚在当地的探访者后，才记录接触；事件、死亡或受控期间不自动完成会面。
- 进入后继续沿用下述 **2 年观察＋6 年抄录＋1 年退出**与空间冻结。自主探访者不受玩家远程召回；交换笔记或商请提前返程，要求实际会面且交情至少 **20**。可从“同勘”详情的“前往交往页交流”进入原有人际交往界面，直接选中本人，真实改善关系后再回来协商。导航不写档，不另建好感或人物副本。
- 自主寻访期间若真实离开原出发位置、离开人界或修为不再符合资格，本人结束旧计划并解除占用，保留实际所在；不强制拖回、不永久占住已飞升人物。拘禁但仍在原位置时保留暂停，获释后才继续。玩家主动邀约仍保留原有暂停与撤销规则。
- 新增可选 `runtime.survey_discovery_window`、`ruins.player_known` 及 `survey.autonomous / introduced`，严格校验窗口、出发时间、知情来源和原有唯一人物／材料约束。旧邀约存档缺省仍按已知且受邀处理，不改变旧任务工期或所得。

### 遗址同勘

入口为“异象 → 因果遗址 → 同勘”。首次亲自进入再退出后，可以在无棣原邀约；入口介绍和同勘分别渲染。场内同勘与调查、阵芯、痕迹分开；“行程 → 进行中”仅提供恢复详情的快捷入口。

- 每座遗址终身仅一份勘察约定，引用原有 `world_npcs` 居民，要求人界四至五阶、交情至少 20、自由且没有势力、关系、队伍、战事或其他行程职责。不创造同伴或替身；自主探访另按上节规则处理，并共用这一份名额。
- 赴约耗 **2 个普通外界年**，原普通 NPC 年度负责年龄、成长与生死；完成后同一个人物进入已有遗址场景，使用公共 NPC 跨界资源迁移，并登记唯一空间成员 ID。本人不取阵芯或预留阵材，也不新设金钱、法力或副本奖励。

- 本人观察与抄录事实独立保存，不自动授予玩家。完成抄录后，在遗址内或退出后的无棣原与本人实际会面，才能一次交换笔记，使玩家下一项亲自读取从 **6 年缩短为 3 年**；原本须先观察的条件保留，阵材仍只由玩家完成读取后领取一次。已有六年读取任务不会被追溯重写。
- 未入场可撤销后续邀约，人物仍在原位置；入场后需当面提出结束，再耗一个空间年退出。保留实际观察进度，不伪造完整抄本。原位置变化、被俘或职责冲突暂停，恢复真实条件后续行；人物陨落终止，不复活或替换。完成后解除占用，可按通常规则继续交往。
- `runtime.ruins.survey` 可选字段保存同一人物 ID、出发位置、阶段、有限进度、实际年数、去重年号与本人知识。旧档不补造此字段；严格校验经历与知识对应、唯一空间成员和权威人物引用。可与外界民用行程并存，但各自仅由所属时钟推进。

### 镜律场域

在人界**穆陵沙漠 `human / muling_desert`**，从侧栏“诸天”进入。首轮机关面向未封印、未压制的四至八阶本体修士，实际入场仍须满足本体界面规则；不得以封印上界资源绕过法力来源限制。进入和退出不额外推进时间，复用原跨界计划清理队伍与坊市状态；入口始终保存为同一地点，事件、劫战或拘禁须先处理。存在亲自任务时，先完成或取消才能退出。

场域挂接现有独立空间，机关事实保存在 `runtime.mirror`，并校验 `spatial_state` 中唯一的空间引用。外界人物、机构工资、政治和交易时钟不随场内研究推进；实际寿元、身体年龄、劫难、魂蚀和本人养成仍走原年度链。短活动继续累计精确行动余量，完整单位只进入独立空间允许的本人收尾。场内普通修炼采用正常倍率，不套用六倍秘境加成。地图提供返回诸天面板的入口，不开放随机探索战利品或普通裂缝绕行。

| 镜律行动 | 实际成本 | 持久结果 |
| --- | --- | --- |
| 低耗试探 | 2 年，开始时实付法力上限的 5% | 查明收集规律；本次施术也计入镜储 |

三处机关共用有限镜储：只收集上述登记施术及本场机关战斗**实际扣除法力的 25%**。累计收集上限锁定为玩家首次亲自进入时法力上限的 **25%**；不随升境、调息、重访或重新查阅增长。气血、封存仙灵力、普通修炼与其他战斗消耗均不计入。隔断只影响指定联系，不倒扣此前已经收集的法力。

守护为机关对象，不创建可重复击杀的修士。每处首次强攻时，从现有镜储实际划拨供给并保存快照，额外强度最多 **15%**，之后不追溯增强该处机关；当次交战收集的法力可供之后尚未遭遇的机关使用。固定初值基础强度为 **2200**，遭遇使用共用机械单位、战斗预案与击退目标，持久损伤经现有战斗适配体现。预览明确告知强攻可能负伤或死亡，不因机关胜利发放修士击杀、杀戮炼化或普通修炼奖励。

实例建立时预留两件本体人界四阶普通阵材，第一、第二处机关各持有一个唯一实例；第三处保存一份镜律规律记录。破解和强攻共用同一份所得，重访不补货；材料领取后可沿原阵材玩法使用，记录不重复发机缘。施工／施术保留最近 32 条本地痕迹，仅记录该场动作与时间，不生成全知敌人情报或自动追兵。取消、死亡与存盘失败分别保留真实消耗或回滚整次未提交操作；响应丢失重试复用同一回执。

这是 M2 的第一个独立异象闭环，现已与因果遗址共同开放；两个异象已支持上述有限居民自主发现与同勘，尚未实现 NPC 主动破阵取物或跨界军事后果。

### 镜律修补与守约

入口为“异象 → 镜律场域 → 守约”。这是原守护机关的本地修补许可，独立于居民同勘；不新增有身份的守护 NPC，不替任何势力签订条约。入场并完成低耗试探后可操作；离开后可查阅已知约定，解除须实际重返场内。机关、守约与同勘分别渲染。

- 新增 `mirror_repair`：三处机关都尚未被解开、隔断或强攻时，投入一件真实闲置的**人界四阶普通阵材**，实际修补 **3 年**，**不额外施法或收费**。这为法力不足但愿意保留核心的修士提供另一种选择。阵材安装即消耗；只在明确提交时建立内容修订 1 的可选 `mirror.pact` 快照，已有实例的机关定义与镜储容量不重写。
- 完成后只打开第三处的**同一份规律记录**。前两处材料核心继续由场域持有，不能破解、隔断或强攻；不复制第三份材料、不增加机缘、不重新充能或扩大镜储。玩家也可不立约，继续原有三种机关解法。
- 每处场域只接受一次修补。期间占用原唯一亲自任务，支持实际事件暂停与续做；最后一年出现待处理事件时，暂不发放记录，处理后零补时续办。取消、死亡或离开原场域导致失败时保留已安装阵材与工时，不取得记录、不再受理第二次修补，但原探索方式仍可使用。关闭新生成不撤销已建立场域的选择。
- 履约后约定跨退出、重访、重载及最近四项任务历史截断持久存在。新增 `mirror_release` 为场内明确的零年解除动作，预览说明永久后果：已有规律记录保留，修补投入不退，前两处核心**此后仅能通过真实强攻取物**，不再开放低耗破解或材料隔断；守护供给、遭遇快照、伤势和已取得物品不重置，不生成额外追杀或远程知情。
- 修补不增加施法收集，也不消去试探的实付记录；解约后的交锋完全复用原真实战斗与有限镜储供给。最终最多仍为原两件阵材及一份记录，保留核心的约定不能与和平取物同时成立。
- 严格检查修补实际工期、结清／解除顺序、任务对应、唯一阵材、守约期间的核心保留及解约后真实胜利；损坏状态拒绝覆盖，预览纯读，命令重试与保存失败沿用同一原子提交。存档结构 9／子协议 1 不变，旧档读取不自动创建约定。

### 四界联系的共同时间规则

诸天年度入口仅位于 `GameEngine._advance_world_year` 的既有普通／独立空间年度返回之后，包括返回 false 和死亡。原年度顺序不变，不使用语义事件订阅，不重复魂蚀。已处理序号独立于身体年龄，同一序号重放不重复处理。

每项联系首次生成时分别固定 T0；旧碑记录为 T0−4000、T0−2000，每周期 2000 年，原窗口前 1200 年可用。刷新面板不重写年代。维护只延续本地余韵，最迟至当期 1800 年。下周期保留 E2／E3、校订履约事实、项目账目和人物身份，清空当期应用与维护预算，须重新完成 E1。

四名合作人物均保存于现有权威人物容器，按各界道途初始化本体九阶能力，以 NPC ID 引用并保存本地 `location_id`。原普通年度负责成长；合作核验生存、拘禁、地点、队伍、势力、独立空间和旧战争名册。人物离开或死亡不重建，已取得证据仍保留。四界被引用的人物记录均受名册清理保护。合法抄录不等于人物已跨界迁移，也不开放军事运输。

个人发现每实际 100 年检查一次，以真实境界概率和独立 SHA-256 计数随机流求值；没有符合条件的已实现内容时记录检查窗口，不消费旧 RNG。只尝试当前所在界面与地点的未登记联系，已拥有其他界面档案不阻止本地发现。默认只通知；“完整修行单位结束时停下”为额外主动设置。旅行、短活动、归墟和独立空间不在诸天通知中间强制停下。

短活动每段锁定当时单位年数，以约分后的分数累积 `unit_credit`，只有完整单位进入公共收尾。20＋30＋20 年在九阶留下 7/10 单位；升境后不会追溯改算旧余量。年度系统、魂蚀和机构实际年数照常运行，零完整单位不发工资、不推进单位市场、不发普通修炼奖励。单条耗时命令最多执行 100 个实际年，任务暂停后由新命令续做。

## 存档、接口与恢复

8→9 的纯迁移仍只加入 `{}`，支持 6→7→8→9。旧档第一次启用建立子协议 1 的日历、随机计数、短活动余量及有限容器。每项联系首次生成保存定义、地点、人物设定、证据及后续任务成本快照，后续内容修订不追溯重写已有实例。已有 M1 的 `sea_echo`、任务目标缺省和回执继续有效，读取不补写；其他三界按需存入可选 `runtime.contacts`。旧程序会按严格字段契约拒绝扩展后的诸天数据，不能用旧构建回存扩展档。

本阶段最多四项本地联系、两处异象、两项征兆，合计八个已实现对象及四名新增合作人物，同时一项亲自任务、一项外界民用行程、一项异象勘察、一项参悟登记，另至多四份有限托管护持记录及一份镜律修补约定；征兆、异象与四界研究共用亲自任务限制和最近四项任务窗口。另保留三条通知、128 条纪要和 128 份命令回执。已获取证据、项目账目与人物引用独立保留。解码和保存校验版本、字段、数值、容量、周期、人物引用、校订托管、个人访学许可与返程资金、NPC 回访进度与项目资金、镜律供给守恒、空间引用、阵材与阵芯唯一归属、阵眼部件一致性、证据取得／送出时间及征兆百年窗口来源，损坏时拒绝覆盖原文件。旧档不自动创建征兆、异象实例或预留奖励，`runtime.omens` 为可选字段。

| 正式引擎入口 | POST 路由后缀 | 用途 |
| --- | --- | --- |
| `heavens_view` | `heavens-view` | known / opportunities / tasks / history，纯投影 |
| `heavens_preview` | `heavens-preview` | 纯报价与当前修订 |
| `heavens_command` | `heavens-command` | 连续 `command_seq`、`expected_revision`、动作、对象、有限选项 |

动作包括 `configure`、`dismiss`、`observe`、`check_history`、`exchange`、`attune`、`maintain`、`correspond`、`resume`、`cancel`。NPC 回访有 `mission_start`、`mission_wait`、`mission_recall`，目标为原联系 ID、选项为空；个人访学另有 `visit_depart`、`visit_study`、`visit_return`，目标均为出发联系 ID、选项为空，不能自行指定落点或费用。关注设置通过 `configure.options.watch` 修改，暂停选项为 `pause_on_opportunity`。四个研究目标 ID 见上表；继续／取消任务使用返回的任务 ID，交流与校订要求权威 `person_id`，维护要求唯一 `material_id`。不接受自报收益、期限、费用或任意状态补丁。视图可指定 `target_id`，默认选择当前世界；`records` 列出所有已登记联系，`sites` 仅公开四界地点，不提前揭示证据或生成人物。

镜律动作：`mirror_enter`、`mirror_leave`、`mirror_probe`、`mirror_decipher`、`mirror_isolate`、`mirror_assault`，以及 `mirror_repair`、`mirror_release`，目标固定 `mirror_field`。破解／隔断／强攻要求 `chamber: "0" / "1" / "2"`，隔断另要求真实 `material_id`；修补只接受 `material_id`，解除选项为空。未取得的材料定义、未发生的守护快照不会经诸天投影提前泄露。Debug、HTTP 和六主题面板使用同一能力，例如 `heavens preview mirror_decipher '{"chamber":"0"}' mirror_field`。

护持动作：`upkeep_start`、`upkeep_cancel`，目标为四界联系 ID。部署要求真实 `material_id`，终止选项为空；`upkeeps` 提供目录、`upkeep` 提供单项预算与可行动作，查询和报价不写档。

同勘动作：`survey_start`、`survey_recall`、`survey_share`、`survey_wait`，目标为 `causal_ruins` 或 `mirror_field`；开始要求真实 `person_id`，其余选项为空。等候一年接公共年度与精确行动单位结算，不发额外修炼机缘。

遗址动作：`ruins_enter`、`ruins_leave`、`ruins_observe`、`ruins_verify`、`ruins_read`、`ruins_take`、`ruins_replace`、`ruins_erase`、`ruins_contact`、`ruins_return`，目标固定 `causal_ruins`；仅替换要求真实 `material_id`，其余选项为空。关联端地点只在接触调查完成后投影，查询不扫描痕迹、不生成实体、不补发所得。新增定义可选，已有 M0／M1／四界／镜律存档不需要补写新字段。

整个准备态深拷贝后执行，费用、NPC、旧随机流、新随机流、任务、日历及回执同段原子保存；成功后才发布请求缓存，失败失效缓存并保留原档。相同序号和规范化参数先读取原回执，再检查当前资格，因此窗口结束、人物死亡或内容开关变化不会让重试再扣费。不同参数复用同序号拒绝，过期回执不重新执行。普通修炼沿用原 API 提交语义。

面板、HTTP 与 Debug 使用同一正式能力。受控状态与独立空间仍可读取、设置和清理托管，耗时参与由领域资格阻止。Debug 示例：`heavens preview observe '{}' sea_echo`；命令序号与修订须取诸天视图，不能使用调试会话修订。诸天查询对准备态纯读，原加载流程仍可能执行旧系统补全。
