# 3.11.0 分身、风岚与霜剑

本体3.11.0，Android版本码105（3.11.0-android.105）。存档继续仅支持结构12；结构1—11拒绝加载与导入，不迁移或覆盖。各DLC版本、配色独立保留。

- 功法秘术增至107门。六道途各可突破大境界均有对应支持；概率加成绑定功法指定境界，不随玩家升级变成通用加成。补齐佛、儒配套功法，沿原市场和升级入口取得。
- 新增分身资产类别，复用NPC培养、能源与损伤结算。分身有独立战斗力，不占队友名额，不计入本体及组队汇总战力；合格九阶以上分身可参加高阶劫战，敌方镜像不因分身而增强。
- 分身立绘与战斗形象采用半透明、青蓝偏色和轻度虚化。战场每侧最多显示12人，共24人；自动分列、缩放，兼容攻击回位、邻域和窄屏。超限人数保留在完整战报，实际结算不受视觉名额影响。
- 新增元婴风灵根《临岚天魔功》与天魔乱舞：战斗栏激活后一次取得两具元婴初层分身，最多培养至八阶圆满，不重复补发。这两具分身不能进入要求九阶的高阶劫战。
- 新增大乘水灵根《十万寒霜剑阵》：Lv.7在九境及仙力转化后升为仙阶，功法仍以Lv.9为上限，机制可沿用至角色第十二境。万籁霜天由凡阶雷劫减伤7个百分点替换为仙阶劫战六属性各增加4%，不叠加。
- 两部功法具备真实付费战斗机制和专属风岚／冰剑特效。秘术报价、重复领取、换装、跨界、培养上限、升级与续战均由原权威入口校验；百科及详细规则同步更新。
- 修复归墟专属功法作为秘术前置时导致归墟DLC加载失败的问题；专属功法的原获取渠道保持不变。

两门新增秘术各消耗原书起始境界基础机缘25%。天魔乱舞分身初始能源为0，沿现有御傀能源晶或玩家垫付规则驱动；已获分身不会因卸装而撤销，毁坏或永久飞升遗失不会重新领取。详情见[风岚与霜剑](wind-frost-techniques.md)、[分身体系](clone-support.md)及[秘术完整清单](technique-secret-catalog.md)。

发行采用完整发现的全仓回归、开发合同／依赖／文档检查、真实浏览器操作、同一Windows EXE有／无DLC验收，以及签名Android 12横竖屏原生验收。最终测试数量、源码指纹、设备范围和包哈希以Release附带验收清单为准。Android包含arm64-v8a、x86_64；模拟器验收不等同于ARM实机验收。

Windows、Android及随附DLC统一发布于[GitHub Release v3.11.0](https://github.com/TobeTenkabito/CultivationLife/releases/tag/v3.11.0)。上传后核对远程大小与SHA-256，清理本地临时安装包，保留源码、存档和验收记录。
