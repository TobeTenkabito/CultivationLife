# 瑶池西望：紫气东来 DLC 策划案

版本：V0.5 完整DLC讨论稿，2026-11-07。[完整玩法扩展](yaochi-gameplay-expansion.md)新增八条长期玩法线与共同主线，覆盖此前的一庙、两职司和少量服务首版范围；[功德功勋细案](yaochi-merit-design.md)继续作为经济基础。本文保留修持与单庙助修的数值原型，扩展后的总收益须重新测算。2026-11-08按用户要求开始实施，已实现与待实现范围见[实施记录](yaochi-westward-implementation.md)，本文不代表全部已交付。

## 1. 核心方案

高阶道修沿原真仙、金仙、太乙、大罗成长。散仙保留自由修行，地仙以本地护民换取持续助修，玄仙以正式履职获得定向修炼支持。瑶池新增三个直接服务原仙痕、仙躯、五色神光的修持项目；天庭新增职司、功德待遇兑现、有限属员调度，以及有具体结果的拨款政务。

不增加第二套境界、万能修为货币或通用社交积分。新增的地仙香火只归土地庙，用于本地助修。现有机缘、仙痕、仙躯等级、神光等级、功德、功勋、材料仍各用原账本。

用户已明确：仙界有凡人和低阶修士，地仙在仙界本地接受供奉，无需回人界；DLC需同时扩展天庭功能。三途不是境界高低。原修炼、师门、交易和天庭本体功能保留。

## 2. 为什么这些内容有实际需求

### 2.1 源码中的三条资源链

| 现有行为 | 实际所得 | 仍需另外解决的事项 |
| --- | --- | --- |
| 普通修炼 | 机缘；每次正向机缘入账15%概率增加一枚仙痕 | 高效率只增加机缘金额，不同比增加仙痕 |
| 师父／同门请教 | 按原机缘基数给机缘，当前师门实现不触发普通仙痕掉落 | 师门可缓解机缘需求，开脉与仙域的仙痕仍需另取 |
| 瑶池工作 | 原瑶池功勋与瑶池经验；该行动的普通机缘配置为0 | 能筹集材料，却不同时完成机缘、仙痕积累 |
| 普通仙躯淬炼 | 消耗药材，随机提升原仙躯等级，失败增加保底 | 失败消耗、重购药材的成本 |
| 五色神光培养 | 消耗指定材料，确定提升原神光等级 | 高重材料总量较大，已有瑶池兑换渠道 |

道友普通论道只有基础6–13机缘乘效率；师门与道门已提供更实用的指导。瑶池不再以重复这些入口的“社交中心”为核心，不把一场宴会中的好感增长当作主要奖励。

### 2.2 可核对的成本

当前配置中五光零重至十重所需材料，按原瑶池单价折算：

| 神光 | 全十重材料的功勋标价 |
| --- | ---: |
| 坤元缃光 | 8,800 |
| 震合缥光 | 79,200 |
| 坎道玄光 | 330,000 |
| 离上朱光 | 1,100,000 |
| 乾古素光 | 759,000 |
| 合计 | 2,277,000 |

计算为各光基础配方乘1至10之和55，再乘当前材料单价。它证明已有长期消耗，不证明所有玩家库存不足。瑶池经验会提升工作收益，不能用固定初始工资把标价简单换算成终身耗时。

参考真仙一层：二十七脉预算计入失败保底约2383301机缘、1681.5仙痕；原校准配置普通修炼年均106.987机缘。师门真传请教一次可得72000机缘，但不会随之获得一批仙痕。定向补仙痕因此有明确使用场景，而非宣称人人缺仙痕。

## 3. 瑶池：三个能够立即用在原养成上的项目

三途均能亲至瑶池申请。沿现有瑶池功勋支付；只允许一个亲自修持项目进行，使用真实时间，不能同时工作、闭关和修业。以下是首轮测试数值。

记U为当前境界行动单位，当前源码四个仙境均为100年；Y为原瑶池一次完整工作所报功勋，包含境界、层数与瑶池经验倍率，供时间成本比较使用。新服务不按个人瑶池经验抬价；报价锁定工时与培养目标。两币价格及付款规则见[扩展细案](yaochi-merit-design.md)。

### 3.1 澄心池·凝炼仙痕

- 费用：固定400功勋，或按同价承兑规则支付10可用功德；这是V0.4对浮动收费的修正。
- 工时：U；期间不获得普通修炼机缘、不完成瑶池工作，也不增加工作经验。
- 产出：3×0.15×U仙痕，当前为45枚，确定产生在原个人仙痕账本。
- 语义：本人入池参悟凝炼所得，功勋购买修持服务；不是从机构库房复制仙痕。
- 进度：按实际在场修持年份累计，小数余量持久保留，累计满一枚才结算；已产生部分不可重复领取。费用按服务进度消耗，取消退未使用部分，不退已过时间。

普通修炼200年期望30仙痕并获得机缘。以真仙一层、瑶池经验从零开始且期间配置不变为例：先工作100年获得400功勋，工作后经验100、未跨经验等级，此时入池报价仍为400，再入池100年可得45仙痕，但舍弃这200年的普通修炼机缘。这是有明确代价的专修：适合已有师门机缘、眼前缺仙痕的人，不适合机缘也短缺的人。更高境界或瑶池经验可以缩短筹集费用的时间；服务本身仍需100年，不能用余额买掉工期。

地仙香火不叠加到入池项目；任职资助只能支付实际费用，不能把45枚复制成两份。不能在读档、查看或等待时结算修持。

### 3.2 玉液池·辅助淬体

- 使用玩家当前已选仙躯功法，提交原下一层完整药材。
- 每次另付原配方按瑶池价格折算价值的10%功勋，向上取整；亲自修持0.1U，当前10年。
- 在原功法加成、原失败保底基础上，本次成功率增加15个百分点，最高100%。
- 成功只提升原仙躯一级；失败照常消耗本次药材，并增加同一个原失败保底。
- 不能越过仙灵力转化、普通炼体、已学功法、仙躯上限、神游或压制限制；原来可以即时普通淬体的玩家仍可选原入口。

实际价值是用功勋和时间降低药材失败损耗。以玉髓混元仙身经、无既有失败保底为例：

| 目标层 | 原首次成功率 | 普通达到该层的期望药材价值 | 辅助模式药材＋服务费期望值 | 辅助模式期望时间 |
| --- | ---: | ---: | ---: | ---: |
| 20 | 62.2% | 约371功勋 | 约336功勋 | 约12.7年 |
| 40 | 38.2% | 约1099功勋 | 约933功勋 | 约17.7年 |
| 50 | 26.2% | 约1768功勋 | 约1429功勋 | 约21.6年 |

计算包含每失败一次增加5个百分点保底，沿当前药材每包数量换算，表中这些配方的10%费用均无需额外舍入。未计整包购买余料、旅行和筹集功勋时间。材料富余、时间宝贵的玩家可能仍选择原即时入口，不宣称新模式总是最优。

### 3.3 五光坛·精炼神光

- 选择已经解锁的一道神光，只加工当前下一重。
- 每种材料按原配方的70%收取，分别向上取整；工时U，不另收功勋。
- 完成后沿原神光培养入口提升一重，不增加新神光、不改原战斗效果、不免除仙躯解锁门槛。
- 这是新增的耗时精炼配方，与原全额材料即时培养并存。节省来自精炼工艺降低耗材，不是假设瑶池凭空补发另外30%材料。
- 开始时托管材料并绑定等级；中断保留进度，主动取消退未耗材料，失效目标不得再重复晋级。期间不能从另一个入口提升同一目标。

例如离上朱光九升十，原需三昧真火400份，即200000功勋标价；精炼需280份，即140000标价，加100年。节约120份、标价60000功勋。面板同时展示“节省材料”和“额外时间”，并显示当前一次瑶池工作Y供比较。若玩家100年已经能赚到超过节省价值，原入口可能更合适。

### 3.4 仙会的位置

首版保留瑶池仙会作为这些项目的阶段性展示与剧情入口，不另做一套强制签到奖励。会中使用原人物、真实修业成果与原功勋业务，不发虚构社交货币，不把普通道门注解改成只有仙会可得。

## 4. 三途如何区别

### 4.1 散仙：自由使用本体与瑶池服务

不受地方香火或正式岗位约束；继续普通闭关、师门请教、探索、组织经营和公开委托，也能使用上述三个瑶池项目。首版不强造“散仙专属积分”和额外访道系统。

优势是无需立庙投入和履职，可随时更换地点、安排养成；机会成本是没有地仙的本地助修和玄仙的内部供养安排。以后如果自由不足以形成有效选择，应先比较全周期收益，不能仅用多一层领取按钮补偿。

### 4.2 地仙：把现有城市和普通修炼连接起来

基础助修以一座主庙为单位，绑定仙界同地点一座已有凡人或混居城市。V0.5完整范围扩展为一主最多三分，地点、设施与经营见[完整玩法扩展](yaochi-gameplay-expansion.md)；分庙不能重复叠加本人的助修倍率。原建筑系统已经区分mortal/mixed/cultivator，无需制造第二份人口或居民NPC。用原城市ID、等级、状态表示供奉承载，新增“香火信任／愿力”只记录本庙信仰，不冒充已有城市人口统计。

取得城市使用许可或完成当地奉建剧情后，沿普通建筑工程入口新增土地庙子类型。土地庙不使用佛修寺庙的信众或状态，也不要求安装佛修DLC。

首轮建庙报价：同界原九阶结构／导灵／蓄灵矿材120／60／30件，工费为同阶原材料基价×4000，进入原营造账户；属于拟新增配方，约为现有一级城建设规格的十分之一。采用原即时营造语义，不另虚构施工年数。土地许可、原城市所有权与土地庙所有权分开，立庙不占有整座城市。

核心循环为“完成一段护民事务 → 在庙修炼，消耗有限香火 → 再次履行职责”：

- 护民每轮按U实际工时预算，结果关联原城市状态、明确地方事件或合法修缮／赈济。物资另列并实际扣除，不能重复发放原城市一次性逸事奖励。
- 成功履约为本庙建立最多4U年份的助修额度，按实际修炼年数消耗；不按点击次数刷新。
- 香火成熟、城市与庙宇完好时，普通修炼机缘增加50%，原仙痕年度判定概率由15%变为22.5%。仍只判定一次，不额外生成第二次普通奖励。
- 初建信任较低时加成按比例下降；建议信任50时加成25%，100时加成50%。完成护民提高信任，明确失约或地方问题损害信任；建立与变化数值需在事件中说明。
- 香火有容量上限，多庙不能重复叠加本人助修；在庙内选择普通修炼才消耗和享受加持。离庙仍保留地仙身份与个人成长，停止加持；在辖地内巡境可以处理事务，不自动享有庙内修炼效果。
- 额度最迟在该次护民开始后5U失效，长期离开后可重新履约；不以往返、换身份、换境界或读档续期。到期只结束额外助修，不剥夺既有修为。

成熟状态、一次护民100年＋四次在庙修炼400年，在不计随机事件和额外物资情况下，获得相当于600年普通修炼的机缘与期望仙痕，用时500年，即长期普通修炼产出提高20%。初始25%加成时只达到500年普通修炼产出，还未收回建庙成本。该数值让经营香火有成长过程，不把50%局部加成错误宣称为50%整体收益。

师门请教、丹药、天庭报酬、瑶池修业均不乘香火加成。不能宣称地仙总效率高于所有其他配置，因为师门及其他既有收益仍须独立计入。

### 4.3 玄仙：按当前缺口选择仙禄

玄仙以实际岗位和任职契约确立，不因存档默认存在九品字段就自动承担新职责。原实际职位、七曜身份与政治权益先做对应，不能清空重练。新职责从接受岗位后开始，不追罚过去。

基础验证先接巡境与瑶池往来两类工作；V0.5完整内容将岗位明确为巡天署、司土署、天工署、御史台四类，瑶池驻署归天工往来工作，详见[完整玩法扩展](yaochi-gameplay-expansion.md)。瑶池作为独立合作机构，驻署官员属于天庭编制，不由此宣布整个瑶池是天庭下属。

每份正式差事显示地点、总预计时间、风险、必要物资和功德报酬。V0.4取消“直接发完整机缘／仙痕／材料，再额外发功德”的设计：先完成真实差事、取得功德，再按当前需要支付待遇费用。

功德资历沿原考核，可用功德负责消费。首轮标准差事按不含瑶池经验的本境本层原工作标价折算，公开委托为B/40，正式职司为1.2B/40；真仙一层100年分别10与12功德。短任务按实际劳动同比计算，未满一点的余量共同保存，不因拆单多发。

花功德可以取得指导、购买瑶池修持服务或指定资材、申请个人修缮与运输；这些用途共享原40功勋对1功德的报价边界。正式职位和七曜席位不出售，原合法俸禄保留，差旅本金不作为个人奖励。

日常护民已换得一整轮香火助修的工作不再领取完整公务奖励；存在独立额外工作才另记工时和报酬。主管可分得原任务最多10%功德，执行者取得其余，总额不增加，不复制亲自修炼奖励。

任务需先落实经费、服务容量和真正的目标。首版驻署标准差事在所属驻地完成，外勤另展示真实旅行成本。原天庭财政不足以无限兑现新增待遇，因此配套有真实来源及上限的公共服务采购预算；详细账本、出处、资助、退款与完整例子见[功德与功勋扩展细案](yaochi-merit-design.md)。

## 5. 天庭新增的四项实功能

### 5.1 职司任职、考课与调任

官品继续走原一至九品考核；岗位另外记录具体职责、驻地、授权范围和正在处理的任务。九至八品亲自办差；七品起可申请有空缺的主管岗位。这个门槛是拟议值，官品达标不自动创造一个职位。

考课直接检查已接受差事的完成、延期、交接和失败原因。请假冻结未接受的新差事，不凭空完成已有承诺；辞职先交接公物和任务。原七曜选举不被岗位晋升替代。

### 5.2 主管派遣真实属员

首版主管最多安排两名被正式划入本司、自由且无其他占用的原NPC，只执行同界已有任务模板。人员沿原任务占用、旅行和资源入口行动；不能同时同行、被培养和出差。

NPC完成公事的成果归原项目；报酬在事先登记的执行者与主管之间分配，主管履行实际审核与验收责任时最多取得原总功德10%，不增加总额。玩家不会因点派遣就得到一份亲自修炼的机缘或仙痕。主管同时得到真实履职记录，并能借属员完成修庙采购、核查和运输等工作。

### 5.3 地仙登记与地方援助

地仙可以在天庭登记神位和主庙地址，登记只承认地方身份，不自动入编，不额外收取一套香火税。未登记地仙仍能修行，登记者可走明确救援和争议处理流程。

首版只实现两类具体援助：对同一原土地庙／城市的受损修缮资助，以及原材料采购运输。申请时给出费用与责任，批复后实际付款、采购、运输、修复才生效；庙宇不随天庭调任迁移。玄仙可经办，地仙可申请，散仙可承接公开运输或护卫。

### 5.4 七曜议政决定实际用途

在原表决、权威、府库和决议槽位之内新增两类可审议项目：地方修缮预算、瑶池专修采购预算。通过只是预留原账户资金和服务容量，不立即提升任何人的修为。

项目展示明确受益人、地点、交付内容和期限。七曜可以选择给哪一处庙修缮、为哪些合资格人员采购几次原价修持服务；主管负责执行。不得让玩家对自己无限拨款，不得绕过原表决，也不因新项目重复结算原赈济令的同一笔资金。

新增有限资助以真实采购支付，不能凭官阶直接无成本打折；瑶池获得服务对价，个人支付不足部分，费用与名额只登记一次。

## 6. 瑶池、天庭与三途的完整实例

一名真仙已从师父处取得机缘，但准备开脉时仙痕不足：

- 散仙可直接普通修炼，或完成原瑶池工作筹集功勋，再入澄心池定向凝痕。比较界面显示舍弃的机缘与增加的仙痕。
- 地仙可继续完成护民并在原庙修炼，长期同时提高两种产出；若眼前急缺，也能亲赴瑶池，但离庙期间没有香火助修。
- 玄仙可完成正式差事取得功德，再支付10可用功德申请澄心池；资历不因消费减少。天庭须落实承兑预算并向瑶池实际支付服务费用。

之后该人物达到仙躯40层，打算培养离上朱光：先用原瑶池功勋兑换三昧真火，再比较即时全价培养与五光坛耗时精炼。玄仙差事所得功德可用于支付部分材料采购，地仙靠修炼优势节省的时间可用于原瑶池工作，散仙可以自由使用已积累材料直接培养。

若地仙在外时庙宇实际受损，可申请天庭修缮；主管派遣真实属员核查／采购，七曜决定是否投入有限预算。工程回写原建筑后恢复助修条件。整个过程分别影响已有成长、实际库存、原建筑和具体人员，不另立一个脱离本体的“仙界生活分”。

## 7. 身份转换与退出

三途主身份互斥。地仙登记不算入编；正式转为玄仙前交接主庙责任并停用香火助修。玄仙辞职转散仙需交还公物、处理已接任务；不清空已经合法获得的个人修为、功德或物品。

辞职、弃庙、换身份不能刷新未完成项目、报价、已领报酬或师门周期。庙宇、材料托管、岗位、历史人物和任务各留在原所属系统。允许无惩罚地拒绝尚未接受的新职责；已经接受的失败后果须事前展示，不能随机剥夺修为。

关闭DLC保留新记录，停止专属项目及新职责的新增结算；原本体成长、机构政治和合法资产照常存在。重新启用不追发关闭期间供养，也不追罚新职责。专修托管应提供明确取消／恢复路径，不能因关闭就吞掉玩家材料。

## 9. 基础实现顺序与验收

以下三阶段用于验证原修持、账本和职司基础，不代表完整DLC的发行范围。V0.5的八条玩法线、共同主线和内容下限以[完整玩法扩展](yaochi-gameplay-expansion.md)为准。

### 第一阶段：瑶池三个项目

先交付三种可实际使用的修持模式及全额即时入口对照。检查机缘富余／仙痕不足、材料富余／时间紧张、功勋不足、已有保底、未解锁神光、重载／中断／取消、不同项目重复提交。

产出必须进入原成长：仙痕可开脉，玉液池提升的仙躯触发原神光解锁，五光坛提升的神光在真实战斗中读取原等级。没有这些结果，不算完成。

### 第二阶段：三途与地仙

地仙接入原仙界城市和土地庙，验证建设费用、护民真实工时、有限助修、离庙停止、受损／修复、转身份以及同一城市不重复产生满额香火。明确它不要求建一套城市人口模拟。

### 第三阶段：天庭实功能

先验证两类工作、功德账本与待遇兑现、主管两名属员、两类拨款项目、调任与交接。低官品、主管、七曜分别执行真实操作；验证不能越权、虚领、重复调度和复制财政。

### 数值验收

1. 普通修炼样本与师门高机缘样本分别比较，不能只用一个裸装新仙作为全部结论。
2. 澄心池必须用完整“筹功勋＋入池”耗时比较；显示实际牺牲的机缘，不称无代价加速。
3. 玉液池用当前功法和失败保底计算期望，并加入旅行／筹功勋时间；允许部分配置普通淬体更优。
4. 五光坛逐重检查向上取整，比较当时真实Y，不用永不变化的初始工资计算长期收益。
5. 地仙的20%只指成熟、无额外损失的普通修炼周期；总回报必须计入建庙、护民物资、损毁、旅行和全部本体收益。
6. 天庭先验证初始及长期真实财政足以兑现所发布的材料任务；不能靠测试无限府库宣称闭环成立。工作报酬按总时间统计，不靠免除外勤行程做平衡。
7. 在相同总年份下至少存在三种合理选择：自由活动多的散仙、本地长期修炼的地仙、按缺口选择报酬并经营职权的玄仙。任何一路在所有场景都占优，应调整首轮参数。

执行仓库三项门禁及相关领域测试；涉及事件加载、提交和按钮则追加既定2.1.2真实浏览器验收；涉及跨界公共入口则追加跨界三组回归。发行需最终源码对应的Windows EXE和签名Android证据。
