# 修罗王庭收尾开发：第一轮地方经营

2026-11-12，基于本体3.8.0／修罗1.5.0源码继续开发。本轮不另行发行；第二轮完成剩余设计后统一更新版本、全仓及原生验收并打包。存档仍为结构12，不迁移旧结构，不改用户原存档。

## 原系统衔接

本体新增 `institution_operations`，提供公署设施实付、原人物培养、原市场分期供货和已实现盈余分配；原 `building_management` 接受有限城市任职授权，继续使用同一城市经营年份、原经营账户和建筑工料。所有专属资格、方针比例、设施和间隔在修罗DLC配置及 `asura_governorship.development`，本体不导入该适配。没有新增NPC自主规划逻辑。

总督仅可在原任职城市、普通界面、有效任期及完好公署经办。城池依然归原背景城市，不因为外任变成私产。原城市营造市舶会馆、当年市集经营和赈济均实付；一级城市仍只有原来的一个城市设施位。原地方经营账户没有现金时不发钱，首次须任职后经过真实年份，离城百年也只核当年一笔。经营账共用本体原入口，不重复领取。

## 两项府署设施

军需署与演武院占原public_office的两个专项设施位。原市场有货且公款足额才营造，即时工程沿原建筑模式，不虚构施工工时；已付材料保存为规格凭据，不另存一份可用库存。府署损毁停效，重建报价包含原两项设施全部工料。

军需署将地方供货从一期四件扩大到三期、每期八件。只针对原址市场实际缺少的九阶结构、导灵、蓄灵矿材；总量不得超过签约时真实缺口，市场先将三期全部货款实转原分期托管。每十年交一期，最后交货日须严格早于卸任日。供货人使用原行囊实物，货入原市场；交易手续费照原报价，净货款九成付原供货人，一成是本府经办收入。经办费率由DLC提供并在原合同固化，本体不硬编码修罗比例。原扣物入口返回失败时拒绝交货，不向市场添货或发钱。实际货款与总督待遇在界面及账目分开。府署每五十年签一份，取消、换人和读档不重置；取消或撤权只退未交付货款，已付货不回滚。供货人应自行评估货物成本，此项并非无成本收益。

演武院每二十年可培养原名册中的一名属员一轮修为、炼体或神识。购买原当地NPC专材，使用本体培养报价与回写入口；人物不移动、不复制，不能绕过原突破、修为、道途、身体、神识与材料限制。在途、驻军、项目占用、拘禁、身故或异地人物不能同时演武；可先培养空闲属员再登记原驻军。没有增加军队人数或战力乘数。

## 方针、待遇与考绩

休养地方把新增净盈余5%付在任待遇，95%留府；奉贡王庭把50%实缴王庭、10%付待遇、40%留府；供养边军把40%交本府驻守原军、5%付待遇。原军在外、无人、原人物死亡或失去现场资格时，相应金额留府；不能仅凭尚未刷新的驻守名册拨款。只有刚完成的经营净盈余、供货经办费参与分配，拨款、捐款和未交货预付款均不能分钱。

在任满五十年、至少三笔真实市集或交货且有收入，可核实绩取得原功勋5、累计功勋5及王庭观感1。后续间隔五十年，必须有上次审核后的新实绩；新签未交货合同不能充数。真实经营成果接入原续任争议的履约资格。经营账、签约周期与设施在交接后保留。

界面复用建筑详情的原总督府页，增加一个折叠经营区；三项收支摘要、方针、原合同进度及分类选择框共用一个办理按钮。保留修罗赤色，两个像素主题与其他DLC配色独立。

新版本体搭配没有经营配置的旧修罗DLC时，隐藏新功能；若已有本轮原合同，则保留交接并退回未履行款。前任的经营履历保留为机构历史，但新任考绩从接任时的累计基线重新计数。
