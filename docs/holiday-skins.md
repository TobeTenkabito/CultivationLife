# v3.2.1 节日时装与攻击特效

## 圣诞绘制关键帧补充（2026-10-29，源码）

男女「霜夜礼赞」共用新绘的16张雪花特效关键帧：聚雪蓄势、冰晶飞行、六角冰冠命中绽放、碎雪飘落消散，各阶段4张。原圣诞人物、服装、解锁资格与施法姿态保持原定义；动画只增加视觉细节，不授予冻结或额外伤害。

`web/christmas-effects.js` 在原 `SpellEffects.draw` 中识别战报角色的 `holiday_effect=christmas`，按既有接触时钟采样并交叉淡化。双向飞行沿原护面裁剪；仅圣诞参战角色加载对应图集，继续使用原解码预算、透明度限制与关闭清理。图集不可用时回退旧雪花表现，万圣节男女的糖果／蝙蝠特效保持原配方。无游戏随机数、独立计时器、人物或持久字段变动；不改变时间、代价、世界归属或移动方式。

内置 image_gen 原稿与提示词位于 `design/christmas-effects-20261029/`；运行图为 `web/assets/pixel/holiday/christmas-keyframes.png`，来源与裁切信息见同目录 `christmas-effects-provenance.json`。使用 `python -m scripts.prepare_christmas_effects` 机械裁切、等比排图，原节日导出脚本会继续调用；不程序绘制雪花或修改人体。末帧碎冰面积较小，组件裁切仅为此导出显式使用500像素阈值，其他导出默认阈值不变。

`tests/test_holiday_skins.py` 检查16帧互异、透明留边、末帧消散与原皮肤完整性；`tests/browser_holiday_skins.py` 真实换装与战斗覆盖男女圣诞、男女万圣，检查新雪图实际解码、双向／倒拖一致、缺图回退、手机横竖屏、关闭释放及回放不写档。动画录屏位于 `build/holiday-ui/christmas-female.webm` 与 `christmas-male.webm`。本次沿用3.2.3与结构11，不更新既有发行包。

## 原节日版本

万圣节「幽夜绮宴」和圣诞节「霜夜礼赞」各有男女版本，全道途、本体默认解锁，无境界、日期或 DLC 门槛。圣诞男装为红黑礼装、银饰与长披风，女装为红色短裙和毛边短靴；万圣节采用紫黑橙配色、南瓜与蝙蝠饰件。

个人详情 → 立绘旁「衣橱」小按钮 → 形貌衣橱弹窗中切换，复用 `Player.character_skins`、原选择命令与保存入口。四套共12张头像／全身／缩略图、40个绘制姿态、28组沿既有时序组合的动作，不宣称逐帧独立绘制。宿身、附身、变化仍按原规则限制；NPC不自动穿用。时装只改变外观，不授予化形、修为或战力，也不自动替换成长外观。

圣诞攻击为大型旋转六角冰晶、螺旋雪流、双重霜环与命中雪屑；万圣节女装攻击为南瓜彗星、彩色糖果飞流与烟花爆散；男装改为会振翅的蝠群、紫色螺旋尾迹与命中散群。`web/holiday-effects.js` 依据战报已冻结的角色素材声明 `holiday_effect` 选择配方，在原 `SpellEffects.draw` 入口替换普通攻击表现。蓄势、飞行和爆散均由原出手／接触时钟直接采样；双向投射使用原护面裁剪。每接触点至多36个粒子与有界轨迹，无独立计时器、游戏随机数或持续实体；关闭、后台暂停与减弱动态沿原回放。换装不改历史战报的身份，不改变伤害、领域、命中、剧情或奖励。

原稿由内置 image_gen 绘制，工作区来源为 `design/holiday-skins-20261027`。最终圣诞男稿v3为4列3行，其余3列4行；万圣节女稿v2补全抬手姿态鞋底。有效源、完整提示词与哈希见 `web/assets/pixel/holiday/provenance.json`，离线导出为 `python -m scripts.prepare_holiday_assets`。运行素材、清单及特效均随双端离线打包，不依赖 design 或生成缓存。

本版一并交付此前源码中的存活结算修订、第二元婴每期−2控制力与动态反噬、仅玩家当前在籍同界宗门有效的任务及财政结算。存档结构保持11，结构1–10仍拒绝，不迁移。没有新增 Player/GameState 字段、移动、世界归属、时间／代价或跨界例外。
