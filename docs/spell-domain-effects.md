# 施法、道途邻域与渡劫演绎

2026-10-25 源码更新。本轮不更改本体或 DLC 版本号，不重新打包已有发行成品。能力、伤害、邻域支配与渡劫结果仍由原结算入口决定。

## 普通施法

`web/spell-effects.js` 替换普通回放中的单个龙形、符印、魔影图片投射分支。表现包括地面蓄势环、收束微光、多股光流、尾迹、命中光晕、扩散环和碎光。道修用龙波／剑流／御宝阵，魔修用法焰与魔影，鬼、儒、佛、妖及随行机关／炼尸分别取自身能量语言。真实本命宝物可以作为御宝光阵的内核，缺少本命宝物不再显示默认符印。爪击等近战仍使用近身轨迹。

所有粒子由既有接触时钟与有界公式直接采样，拖动／重播不会积累实体或消耗游戏 RNG。投射保留目标护面裁剪；合成 alpha 上限180、96MiB解码预算及关闭清理沿用原播放器。邻域杀伤和修复施权同步使用多层轨迹与碎光，控制组件仍按真实支配目标显示。

`GET /api/domain-styles?id=存档ID` 只读原存档的 `player.path`；`POST /api/ui-preferences` 提交 `game_id`，后端重新读取真实道途，拒绝跨道途／未加载扩展的轮廓和意象。没有当前存档时只开放13款通用样式。界面不采信客户端道途字符串。

本机偏好仍共用，未新增 Player／GameState 字段。切换道途或停用扩展不会抹掉保存的搭配；编辑器及新战报投影将不可用项回退烟霞。历史战报保持原快照，已停用扩展的未知图形在绘制时回退通用样式。NPC从自己道途允许的组件及既有淡色库抽取，不改变结算随机流。编辑器可读取当前 DLC 主角静态立绘作预览，不以道修冒充。

## 渡劫

新劫云原稿由内置 imagegen 生成，机械最近邻导出768×432像素背景 `web/assets/pixel/effects/tribulation-storm.png`。提示词、原稿与哈希记录在工作区 `design/spell-domains-20261025/`；运行来源记录见 `web/assets/pixel/effects/provenance.json`。游戏不依赖 design 目录。

`web/tribulation-effects.js` 绘制缓转劫云、细雨、地面阵环、分岔雷击、分段护体、冲击波及余光。人物沿用当前合法立绘。待选事件只展现聚云；点击原事件选项并完成真实结算后才播放雷击及后续，气血／死亡信息来自返回状态，不能凭动画推定成功或晋阶。动画总长4秒，支持暂停、重播、收起、后台暂停和减弱动态；不增加选项、不自动提交、不改奖励与时间。
