# 斗法资源与混合费用

2026-11-13，根据用户对HP／MP比例损耗的反馈及后续指定的混合机制调整。复用原战斗、法力、元力与人物结算入口，不新增资源池、装备入口或越阶资格。

## 功法费用

设本书品阶为G，本人实际境界序号为R，开战时本资源的合法容量为C，同阶费率为p，本书固定报价为F：

| 条件 | Lv.1实际费用 |
| --- | --- |
| G小于R | F |
| G等于R | C乘p |
| G大于R | C乘p加F |

1阶对应练气、4阶对应元婴、5阶对应化神，依原目录延续至12阶大罗。封存境界、伪装、装备战力不代替实际境界。此公式不放宽功法的灵根、境界、肉身、转化或世界资格。Lv.1—9将总费用乘以1至0.84；不能只对越阶费用的一部分减费。

普通法力的F采用原品阶初层本征法力基准（无装备、灵根和永久加成）乘p，编译为固定目录的`mana_cost`。例如太元归墟剑4阶、费率4%，基准1392点，F为55.68；元婴按4%容量付款，化神及以上按55.68付款，越阶为两者相加，Lv.9再减16%。

元力功法（含种子道统）的固定报价使用原元力单位：上界对应品阶初层的1000乘以（1加3乘以品阶超出9的部分）作为价格基准，下界仿仙灵力使用原60点单位，再乘本书费率。没有合法可用元力时不能用普通MP代付。此基准是报价，不创建、补满或改写仙窍余额。

投影在原书上冻结`cost_model`中的品阶、实际境界及固定报价。玩家与NPC、V1/V2道统与V3固定书共用费用计算器；继续战斗不重读境界或刷新价格。原书升级后下一场使用新等级。未带此投影的已开始旧战斗沿冻结配方核验原收据，不重新计价。

既有普通爆发使用同样的三档比较；预算不足则不发动，不能付部分费用获得完整爆发。七部专属效果仍分别按自身收据付款，退款来自本书实付；每笔退款同时受已付比例、单笔容量上限和整战容量上限约束，多次触发不能突破单笔上限。

## 普通出手与HP

普通出手费用按原境界、层数及炼体的标准法力基准计算，保留灵根耗费修正，并乘以对抗强度系数：对手与本人原始战力比的平方根，上限为1。与同阶或强敌交锋仍需正常投入；对付弱敌不因自身最大MP较大而强制按满容量消耗。增加装备、丹药或永久MP上限不会提高这一普通出手价格。原高阶邻域等独立主动能力的专属费用不受普通出手折扣减免。

普通交锋取消最低3.5%／4.5%态势损耗的保底，仅保留原攻防曲线与单轮上限。弱者的有效伤害可以低于旧保底；攻防属性、防护资格、护盾和特殊效果继续结算。

战后肉身损失按原境界、层数及炼体的标准HP基准折算，至多使用实际HP上限作为基准。增加装备或永久HP上限不再同时抬高相同攻击的扣血额。战斗态势仍负责胜负与败退，HP负责实际肉身损伤；明确处决、致命追杀、身魂和特殊比例效果沿原规则。结算保留小额损耗精度，不再因四位比例舍入把高容量角色的实际付款放大或抹去。

## 验证入口

`tests/test_combat_resource_costs.py`覆盖三档费用、升级总价、玩家与NPC投影、道统元力、余额不足、重复退款、恶意付款快照和旧冻结战斗。实际引擎对照化神与练气、同阶对战及增加10万HP／MP后的损耗，确认低阶固定费用与普通出手不因池子变大而涨价；同阶、越阶功法按用户指定保留比例部分。
