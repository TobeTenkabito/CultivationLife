# v3.6.1 仙途与建筑布局

本体 3.6.1，Android 版本码 100；瑶池西望 DLC 数据包仍为 1.0.0。仅支持结构 12，不迁移结构 1–11。保留山海图志、沧海夜色两套像素主题和各 DLC 独立配色。

## 功能归属

- 左侧新增「仙途」，合并仙籍与专修；右侧新增「仙府」，合并访古与紫气主线。手机沿原「修行／诸界」导航分类，复用原按钮。
- 土地庙接入地图与场景的原建筑条目：当地城市奉建主庙、营建分庙；原土地庙办理庙务、专项设施、地方争议与庙域管理。
- 瑶池原药田通过当地建筑区域办理仙圃经营；承办前仍为同一原产业，不生成新地块或改变产权。受损私产的功德修缮位于对应建筑。
- 瑶池保留委托、资材、仙会、天庭往来及账簿；天庭职司、属员、监察巡天与项目议政仍归天庭。
- 补充土地庙完好与遗址立绘，修正其被识别成普通产业的问题；佛寺按原等级与毁坏状态选图。场景、建筑详情和庙务页衔接见[寺庙立绘](temple-art-361.md)。

没有独立「建筑」侧栏按钮。建筑事务窗只能从当地实际建筑打开，返回原地图；跨地或切换存档后关闭失效上下文。建庙后衔接同址新建的原土地庙，保持原工程结算。

## 边界与验收

界面只读取原公共投影；动作仍经原 `yaochi-action`、建筑、事件提交入口验证地点、资格、原报价、忙碌和工时。未新增持久状态、移动、远程权限或豁免。新面板沿现有按需渲染，关闭期间仅保留最新响应。

发行证据见 `dist/release-3.6.1*.json`：开发门禁、受影响领域回归、真实浏览器点击、最终 Windows EXE 与签名 Android 原生横竖屏验收。测试使用隔离存档，不改用户存档。
