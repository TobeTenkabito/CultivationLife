# alpha.6 主页地图与劫象表现

本体 **v3.0.0-alpha.6**，Android 版本码79，存档仍为结构10。此次属于本体表现更新，现有 DLC 版本和资源归属保持。

## 布局与地图

修复鬼修旧往生／轮回栏的不可收缩按钮组挤压文字问题。新版侧栏中的突破栏按容器竖排，地图采用独立有界高度；事件卡从窄侧栏移到主状态栏下方的整行区域。NPC图、文字、选项和渡劫画布各自约束尺寸，切回旧版恢复原事件位置及原按钮。手机仍使用原绘景抽屉，不额外叠加导航入口。

主页绘景新增山河、势力、时令、商旅、营造五种视图。势力读取原公开影响力与驻地，时令读取已公布拍卖、交换、夜行和战役，商旅只读取原当地可见商队及其游戏年份进度；未知资料不补造，不泄漏货物、异界库存或隐藏情报。营造按原建筑等级、类型、状态选图，远处不提供进入或经营权限。

选点显示真实路径、耗时、门槛、风险及续程，点击前往与旧地图共用 `requestMapTravel` 和原 `/map-travel` 入口。移动主体是原玩家，地址是当前界面／实例内原地点到所选地点，时间和成本由原旅行系统逐年结算；此更新不新增跨界路线或传送权限。事件、拘禁、受控、死亡和忙碌状态仍阻止移动，必死路线仍先显示原确认框，旧页面不自动重发命令。

## 镜像与渡劫

原天魔、心魔、三尸目标由责任入口登记白名单视觉标记。战报保存玩家当时的素材ID与变体，镜像继承同一人物动作、境界形象和DLC资格；只在离屏画布变色及叠加光纹，不修改原图片、不创建人物副本、不改变战斗结算或游戏RNG。反噬元神和普通同名NPC不会因名字被换成玩家镜像。三尸分别使用青、赤、金色调；心魔绯紫，天魔暗紫。旧战报没有标记时保持原展示。

渡劫事件使用单个576×324画布和既有当前人物图。选择前显示劫云酝酿；只有正式选择成功返回后才显示落雷／收束及实际气血变化。三千年雷劫、飞升劫关、天劫、传统突破与已登记镜像劫象按明确事件编号选取，不按任意正文关键词猜测。动画最多4秒、20fps，后台暂停、关闭／切回旧版释放，减弱动态默认静止；重播与暂停不提交选择、不推进年份、不影响恢复道具或后续事件。

## 建筑图

`web/assets/pixel/buildings/` 包含46张96×96像素图：城池、洞府、通用工坊、寺院各三级与遗址，另有药田、矿区、猎场、丹坊、器坊、商铺仓库各五级。受损在当前级别图上降饱和显示；摧毁使用遗址。寺院只随原已启用佛修建筑投影出现，关闭DLC不产生建筑。景色保留原地图自然绘景，不伪造建筑等级。

原稿由内置image_gen生成，提示词与源图保存在 `design/alpha6-map-events-20261025/`，离线提取入口 `scripts/prepare_home_buildings.py`；运行与打包不依赖design。运行manifest登记源哈希、裁切与成品哈希。

## 验收

原生验收发现并修复镜像出手时误取普通NPC的 `attack` 动作问题：镜像与本体使用同一套具名施法动作，邻域施法也遵循这一选择。浏览器与原生验收均逐段采样完整镜像回放，覆盖敌方攻击、防御、受击及倒地，避免静态预览漏检。

`python scripts/verify_scoped_release.py --profile visual --focused-visual --home-scenes` 执行相关领域与上游测试、三个开发门禁、旧版与新版浏览器验收，不宣称全仓回归。新增 `tests/test_home_scenes.py`、`tests/browser_home_scenes.py` 验证只读镜像、文件完整性、四宽度、五视图、真实旅行和连续雷劫选择。发布脚本还要求同版最终代码的有／无DLC Windows EXE、签名Android12横竖屏原生点击及来源证据。实际完成情况以同版dist发行清单为准，不宣称实体手机验收。
