# 妖躯五蜕

2026-11-02开发源码。用户授权实装玄肤、逆骨、烈脏、沸血、神魂，接入通用轮首判定、战斗文本与独立培养材料。结构仍为12，只接受12，不迁移1–11；本轮不升版、不打包。

## 培养与归属

开启万妖归宗、在幽冥界达到九阶的妖修，从独立“妖躯”入口打开五蜕培养页。普通炼体须满100层，妖躯上限50层，每10层依次解锁一蜕，各自从零重独立修炼至十重。桌面侧栏显示“妖躯”，手机位于现有“修行”分类；妖躯培养不放在邻域面板内。现有境界不自动赠送妖躯；新出生的明确高阶炼体配置写入新角色原妖躯，不在加载时补发。

唯一培养记录为`Player.immortal_body.monster`，包含`level`、`training`与`reaction`。仙躯旧记录保留沉寂，妖躯与五色神光不叠加。每层本源上限沿仙躯基准增加HP5000、MP4000，当前HP／MP同量成长，不补满既有损伤。妖躯每层消耗目标层数件天妖玄玉，以及原开脉基础机缘乘目标层数。修成层数不会单独授予仙级攻击来源。

独修每次消耗对应材料与机缘：材料数量及原开脉基础机缘的倍数均乘目标重数。修炼与查看不推进时间，培养本身不消耗RNG。事件、劫战、拘禁、寄身、修为压制、行程、归墟、诸天亲自任务及肉身毁去均在扣费前拒绝；提交核对所见等级。全部材料和机缘足额才整笔实扣原行囊与原机缘，不另存材料余额。烈脏选择须已解锁，入战后冻结，不能中途改写快照。

| 五蜕 | 初解锁 | 培养成长 | 零至一重材料／基础机缘倍数 |
| --- | --- | --- | --- |
| 玄肤，10层 | 免疫凡伤；仙级攻击的态势削减减免5% | 每重增加2.5个百分点，十重30% | 天妖玄玉×4／1倍 |
| 逆骨，20层 | 自身邻域实际存在时，对敌方每次主动施权有10%闪避概率 | 每重增加3个百分点，十重40% | 逆纹龙骨×6／2倍 |
| 烈脏，30层 | 实际闪避后，一次免费自疗，恢复肉身与态势，基础比例12% | 每重效能增加0.4个百分点，并依下表开放功能 | 百窍灵髓×8／3倍 |
| 沸血，40层 | 消耗本场可用元力容量15%，解除自身当前支配 | 每重减少1个百分点，十重5% | 赤祖血晶×10／4倍 |
| 神魂，50层 | 每场一次，轮首元力比例严格低于40%且低于对手时交换百分比 | 阈值每重增加2个百分点，十重60% | 归元魂珀×12／5倍 |

未指定的初始数值属于本轮首版配置，位于DLC `world.json`，培养页显示实际值和报价。

## 轮首与实际兑现

通用`BodyRound`先冻结双方原始资格、依赖及轮首概率，再按原先后手落实乾古静默。逐段目标、闪避与实际阵亡沿[通用因果事件规范](ghost-body-and-causal-events.md)在发生时结算。神魂采用原普通先手投影，供本轮普通交锋复用，不重复投先手骰；NPC与劫战沿各自原有先手尺度。行蕴继续读取静默前的原始触发种类，五蜕每种至多计一次，不按闪避次数重复计数。

神魂的比例条件、候选对手和双方比例在轮首固定。静默裁决后才兑现交换，按双方各自实际可用容量写回原本场账本，封存容量不参与；容量为0或不可触及的目标不参与。群战优先既定攻击目标，随后按原稳定顺序选择；每轮每人最多参与一次交换，只有实际施术者消耗本场唯一次数。被静默或配对已占用时不消耗次数，轮中才跌破阈值留待下一轮。`UnitState.exchange_used`沿原劫战快照保存，切批次与读档不重置。

支付原展开、维持及覆盖费用并完成本轮对抗后，沸血足额扣款，移除自身当前支配及其直接产生的退路限制，重新核验普通与邻域行动。敌方邻域仍存在，不重跑本轮对抗，也不清除独立术式禁制、已造成的损耗或已经支付的费用。下一轮重新对抗，仍被支配时可以再次足额支付；元力不足不部分扣款。

玄肤保留原凡／仙资格门槛。仙级普通攻击与邻域数值杀伤、镇压、持续侵蚀中，态势削减单独减伤；封禁进度、控制资格、战意和肉身伤害不借此削减。原普通物理损伤与态势损伤分开回写主战，不能让态势减伤顺便变成HP减伤。终结处决仍走原明确资格，不由数值减伤制造免死。

逆骨对每段真实作用于自己的敌方主动施权判闪避，沿原战斗RNG，不为尚不存在的行动预耗骰子。己方必须有真实已支付并仍存在的邻域；凡躯、缺费未展域、破域或被静默时均不凭空获得闪避。仅避开针对自己的敌方主动施权，不改变领域对抗、轮首静默或持续侵蚀。对方在实际施权后被闪避，原费用不退；被闪避的目标不产生实际暴击命中，想蕴不能据此虚增兑现。

## 烈脏每次择一

烈脏自身提供有限的反应能力，不要求原邻域事先具备治疗。依培养等级依次开放：

| 烈脏等级 | 新功能 |
| --- | --- |
| 0 | 治疗自身肉身与态势 |
| 2 | 稳定自身心神 |
| 3 | 修复自身邻域稳固 |
| 4 | 数值镇压施术者 |
| 5 | 封锁施术者传讯与支援，积累封禁进度 |
| 6 | 禁制功法 |
| 7 | 禁制法宝 |
| 8 | 隔绝支援 |
| 9 | 截断供给 |
| 10 | 封禁邻域 |

可在培养页选择“自动择一”或固定功能。自动按真实可执行状态优先恢复肉身／态势、心神和稳固，再镇压或封锁；固定功能无合法目标时不执行，不自动换成另一功能。每次实际闪避成功只启用一份轮首已登记的免费额外额度，执行一项，不同时附加治疗与控制。

反应不占基础邻域行动或普通出手，只免该次施权费，不免领域维持。烈脏行动本身仍可被闪避或特殊介入，也可以触发另一人物的逆骨、烈脏或识蕴。统一按“角色ID＋机制ID”的因果路径拒绝同一分支重入，不再写死反应来源禁用或每轮八次截断；不同原攻击与照业兄弟段可分别响应。

有限战斗例外：用户明确要求闪避后施权。责任入口为`body_effects._reaction_effect`及原效果执行器：即便普通出手受支配封禁，仍可消耗已登记烈脏反应；敌对功能仅针对刚刚实际攻击自己的同一原施术者，并复用可触及、存活、特殊介入与抗封禁校验，无需另获对该施术者的支配关系。不影响普通邻域施权范围，不授予终结处决、免费普通攻击、外界目标或新人物。测试覆盖受支配时自疗／反击、固定选项、无领域、取消、静默与反击不递归。

实际烈脏施权计作一次额外邻域行动，可触发敌方识蕴回复；取消、无目标或额度未启用不计，多功能候选不重复计。乾古可以静默全部五蜕，原始预判保留而实际输出停用。

## 材料、立绘与可见性

五种专属材料仅在幽冥界九至十二阶原货架登记，沿原坊市、黑市、拍卖与可达产地商盟取得。基础单价按表中顺序为50万、65万、80万、100万、120万灵石，实际交易仍按渠道报价。其它十界、特殊空间和归墟不新增天然产出，真实已得材料可随身携带、按原权限实物转售。

五幅图使用内置image_gen直接参考现用`design/inventory-icons-v2-20261020/source/special_materials.png`，沿用透明底、深色描边、左上高光及分块明暗。运行32×32行囊图标与128×128同源像素立绘、提示词与来源哈希归`dlc/monster-bloodlines/assets/visual/body-materials/`，复用原可选素材目录和DLC访问校验；关闭包后不新增物品、产出或素材访问。机械导出及校验为`python scripts/prepare_wuyun_material_assets.py --family monster-body --check`。

NPC沿自己的`immortal_body_level`投影，培养强度取层数整除5、最高十重，不按境界补满，不新增年度培养。属性镜像复制完整机制、数值与烈脏选择，锁入入战快照；真正俘虏肉身读取自己的资格。寄身仅读原宿主，高阶本源收益和五蜕不借本魂记录。原肉身毁去时清除原妖躯培养，寄身宿体毁去不抹本魂妖躯。

战斗文本与结构化战报记录原始触发、静默、每次闪避概率和结果、实际反应功能、费用、减伤前后数值、解除支配和神魂交换前后比例；本轮未新增五蜕人物动画。
