# 3.13.0 遗境舆图与阵前追逐

从主界面「探幽寻宝」进入遗境，可以在舆图上按八个方位探路、寻找修士，也可以提前选好交战地点。

- 神识越强，探查范围越广，可辨认附近人数、前路征兆、暗阵和争斗余波。高品遗境需要更强的神识。进入前已生成的副本沿用原有事件与奖励。
- 遭到追杀时可以沿岔路逃遁。境界、实力与追杀意愿决定追赶速度。玩家可以从阵法栏选择九宫阵，把真实阵材布在脚下，引敌回阵，再从「启阵迎敌」进入正式战斗。战报、阵法经验和耐久都按实际参战的阵法结算。
- 用行囊中的独立阵材布设另一座地阵时，原本启用的随身阵可继续随身使用。原地收阵或探境结束时，阵材按原归属归还。
- 副本封藏新增当地已有的突破丹、装备及十种专用丹药。灵界和真魔界的护雷丹可减轻下一次雷劫伤害；仙界道修可用对应品阶的丹药凝聚仙痕。行囊描述列明适用境界、道途与药效。
- 此次发行也收录自上版以来的副本境界匹配、外界队伍入境、威名与凶名事件、物品插画及游戏文案修订。

Windows 本体 v3.13.0，Android 版本码 107（3.13.0-android.107）。存档结构为 12。安装包、验收清单及 SHA-256 见[本次发行](https://github.com/TobeTenkabito/CultivationLife/releases/tag/v3.13.0)。
