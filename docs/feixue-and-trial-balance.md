# 沸血调息与劫战平衡

本页保存沸血平衡时的测量。后续[八部承压修复与差异化权能](asura-eightfold-differentiation.md)已改变原本命权能；下列实际目录通过率为修复前基线，不应当作新版通过率。新八部逐路线结果见该页。等配炼体测试不含八部语义权能，结论范围仍以原口径为准。

2026-11-03。用户要求改善妖修本体、排查妖魔特定关口，并提出“解除支配后下一回合无法行动”。本轮把该代价接入正式战斗，配套调整原数值；复用原轮首机制、实际行动入口和战斗快照，没有新增世界移动、资源池或逐年逻辑。不读取或改写用户游玩存档，结构仍12，拒绝1–11；未升版、未打包。

## 沸血的回合边界

第N回合完成领域对抗后，足额实扣沸血费用，解除本轮支配及其直接退路限制，第N回合重新核验并允许原本合法的行动。第N＋1回合调息，禁止普通出手、领域基础／追加／反击施权、事件派生攻击及再次沸血；第N＋2回合恢复资格。实际静默、缺费未解除支配时，不产生调息。不会通过每轮沸血把下一轮继续锁为调息。

已展开领域在调息回合仍维持、覆盖并支付原费用，不能重新展开或换域。免伤、闪避、神魂交换等被动仍结算，闪避不创建烈脏主动反击；领域原对抗与维持产生的被动压力沿原规则。调息不清除控制、不豁免伤害、不退款。轮首仍冻结机制原始资格及静默次序，“行”读取的原始触发种类不因行动取消而抹去。

同一`UnitState.release_recovery_round`保存下一轮编号，统一在普通、领域及因果事件行动入口检查。NPC与属性镜像不例外，完整复制沸血数值与该标志。调息跨JSON保存和战斗批次延续；已入战且没有新标志的结构12快照保持原冻结行为，新战斗采用新规则，不扫描重建旧快照。

培养页说明费用、当回合可行动及下一轮限制；战斗文本记录预告调息的回合、实际调息、解除支配与支付数值。结构化战报提供当前调息单位，未增加动画或新的操作按钮。

## 调整前的原因

妖修原两种本体领域的侵夺偏低，黄泉回生尤其偏守。群战覆盖两敌还会分摊领域力量；即便玩家领域练至十三阶，镜像每回合沸血解除支配，也会让已经建立的领域杀伤失去合法受制目标。末劫仍有两个完整普通战力敌人，普通交锋持续一对二，故基础目录在原准备组与满练组均出现0通过。只提高伤害不能解决未获合法施权目标的问题。

魔修第二关原为1.8倍普通六维压力，玩家与心魔领域上限都为八阶，准备优势较少。恢复型邻域受到轻伤便每轮施疗，占用普通出手；五蕴的回复、暴击治疗与镜像叠加，可形成很长的恢复战。原八部阶段准备通过率仅14.45%，五种路线为0。这里需要调整原领域／敌人压力与自动施疗选择，不跳过击杀判定。

## 独立对抗与突破复测

同配验证沿原正式六维伤害曲线：完整50层，独修0／5／10重，单挑／二对二／三对三，四种等配领域，六组组合互换位置，种子512–543，共13824场。结果魔56.55%、仙51.70%、妖45.30%、鬼46.46%，最高与最低差11.25个百分点，妖鬼差1.16个百分点；没有触及48轮诊断上限的平局。共77983轮，证据为`build/recovery-independent-body.json`。这是受控综合得分，不等同于所有玩家的实际胜率。

另以真实两种本体领域，与仙魔鬼各两种参考领域做768场等六维／等元力的双向对照，妖修得分20.70%→39.58%，证据为`build/catalog-pvp-baseline.json`与`build/catalog-pvp-final.json`。该小目录只用于核对本体领域确实改善，未遍历仙修25道统、魔修八部和全部魂相，不能替代全目录排名或上面的等配炼体比较。

突破沿[基线报告](upper-breakthrough-rates.md)的正式人物准备、装备、完整炼体镜像、法力与原元力账本。准备组九／十／十一阶分别20／35／50层、五重，领域4／8／12；满练组50层、十重、领域4／8／13。两个内容种子930211／930212，最终战斗种子8000–8031，每个目录项每准备组64场；未把有工作量预算的未决当作通过或死亡。
