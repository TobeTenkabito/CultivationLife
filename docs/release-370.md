# v3.7.0 机构经营与瑶池西望1.1

本体3.7.0，Android版本码101，瑶池西望1.1.0。仍仅支持结构12，不迁移结构1–11；原结构12存档按新增可选账本继续使用。保留两套像素主题和各DLC独立配色。

## 本体与DLC归属

本体新增机构需求提案、有限预算、原人物驻任与委派、年度执行、暂停请示、追加与交接、履约凭据、竞标评估和分期合同结算。宗门与家族首先使用原府库补缺和原址修缮；关闭DLC也能使用。玩家管理机构默认不自动花钱，须明确指定原执行人与单项预算。

瑶池西望在这一框架上增加驻庙三类服务、七曜施政安排和原天官提案、机构仙圃竞租、三期实货合同、散仙独立补缺、三类获奖待遇和仙府后续经营。人物、库存、财政、建筑、时间与身份仍沿原系统，详见[分层设计与规则](institution-ai-and-westward-110.md)。

界面嵌入原宗门、家族、土地庙、仙圃、天庭、仙籍与仙府页面，不增加侧栏按钮。经营摘要可展开，预算、人员、履约进度和交接记录同页显示；契约说明到期年份与实货不足原因。

## 验收范围

新增对抗用例覆盖重复年度、重复提交、无效资金、原人物重复占用和离场、原机构失效、超期退款、停用恢复、实货与资金守恒及存档篡改拒绝。真实浏览器点击覆盖本体委派、长期供货、读档、过期页面恢复和桌面／手机横竖布局。

回归修复包括：其他地区年度结算误清驻任、原人物拘管资格遗漏、无效方针参数、天庭当前年度报价的时钟适配，以及未开讲席时收益预览读取空项目。讲席实际结算同时覆盖普通十年和获奖八年，验证总机缘一致、凭据一次消耗且不附送仙痕。

最终发行证据以`dist/release-3.7.0*.json`为准：运行发行脚本列出的受影响领域回归、跨界三门禁、既有与新增浏览器用例、Windows EXE有／无DLC，以及签名Android12模拟器横竖屏原生验收。不将此选择性回归称为全仓测试或实体手机验收。
