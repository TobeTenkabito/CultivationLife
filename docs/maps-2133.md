# 地图中心平移与触屏手势（v2.13.3）

修改前阅读[跨界开发规范](world-transition-development.md)与[当前跨界审计](world-transition-audit.md)。本次只调整地图相机输入、视野和响应式显示，十一界[独立地貌素材](maps-2132.md)、地点、岛屿、道路及旅行结算全部保留，无持久字段或年度结算改动。

## 操作

Web 鼠标中键拖动平移中心，左键拖动保留自由转动，滚轮围绕指针缩放；平面模式同样支持中键平移和滚轮缩放。安卓和触屏浏览器单指平移，双指捏合缩放；立体模式双指移动、扭转用于转动，平面模式双指移动仍平移。轻触选点，拖动和多指操作不误选地点。

视野中心使用当前页面相机的 panX / panY，绘制不再逐帧把地点重新居中。缩放改变投影而不扩大 SVG；固定大小的响应式视口没有横竖滚动条。“定位当前”直接将当前位置投影到视口中心；复位恢复中心、缩放与角度。选点、影响力筛选和重新渲染保留视野，同一角色的不同界面及平面/立体模式分别保存相机；切换人生清理相机。

手势使用 Pointer Events 与真实指针捕获，支持鼠标中键从地点标记开始平移、指针移出视口、双指结束后继续单指、取消手势和关闭面板。ResizeObserver 只在尺寸改变时重绘，输入合并到 requestAnimationFrame；关闭窗口取消待绘制和观察器。地图外仍可滚动面板；查看、拖动、转动、缩放、定位都不写档、不移动玩家、不耗时。

## 专项验收

按用户要求只运行改动相关测试与三项开发门禁，不做全仓回归。覆盖相机平移、指针缩放、完整手势与只读存档，十一界四主题桌面及触屏浏览器，两种地图投影、实际地点选择、事件旧交互和相关布局检查。Windows 新 EXE 核对相机/输入模块并验证有无 DLC；签名 Android12 模拟器横竖屏各14组，覆盖十一界与人界四主题，真实注入单指平移、双指捏合/转动和选点，核实中心移动而非仅角度变化。安装哈希、源码输入、签名、版本与最终验收一致后打包。未进行物理手机验收。
