## 独立素材

大陆以最初完整陆地为基底外扩12%，在外围进行剪切与侵蚀。大陆岸线分别描绘半岛、深入陆地的海湾、河口、海峡及三块大小不等的分离陆片，宏观轮廓来自逐界绘制的地理结构，局部追加细小岩岬与侵蚀凹口。海湾避开玉台、斗场、轮池等标志性建筑与景观，完整保留其台地。每一陆块分别投影断崖，不以墙面连接分离陆片。

web/assets/maps 下十一份 SVG 分别绘制，tools/build_map_artwork.py 保存各界独立岸线、景观布局与绘图源。共享的仅是树木、山峰等笔刷及投影方法，去除颜色后大陆轮廓、水系、山系与标志景观仍不同。web/map-artwork-data.js 记录素材地址与各自岸线供断崖投影，不是玩法地图。

素材投影于世界地面，断崖来自该界自己的岸线；部分远方大陆使用本界素材展示。不创建可进入的新地点或NPC。地点、真实道路和势力色环覆盖在素材上，素材没有按钮或点击权限。新增地点继续复用既有稳定布局；新增界面可在素材登记表添加独立 SVG，没有素材或加载失败时使用通用地貌回退，不把未知界面当人界。

SVG为本地静态图片，首次展示按需加载并缓存，兼容离线 Windows 与 Android12 WebView，无外部URL、WebGL、图片脚本或动画。相机和素材缓存不读取游戏随机数，不参与时间结算。

## 自由拖动

web/map-camera.js 使用连续轨迹球旋转矩阵，指针在可视地图区域中移动决定方向与转量；无固定俯仰、偏航或翻转范围。不同窗口和缩放以实际可视区域归一化，支持经过侧面与背面。可从空白或地点标记处拖动；移动超过阈值才成为旋转，小点击仍选点，旋转结束不误选地点。鼠标与触屏共用 Pointer Events；地图以外仍可滚动面板。

矩阵仅存于当前地图窗口相机，角色切换清理；转动、缩放、复位和定位不写档、不移动或耗时。绘制依输入合并至一帧，关闭窗口取消待绘制帧。现有旋转按钮、复位、定位、平面模式、图层导航与旅行入口保留。

## 本次验收

按用户要求不做全仓回归。地图内容、独立素材、相机、旧交互及发行凭据领域测试，三项开发门禁；十一界四主题桌面与移动浏览器真实拖动/选点，以及地点经营、地图目录和事件旧交互回归。Windows 新 EXE 核对全部素材并在有/无DLC环境操作；签名 Android12原生横竖屏各覆盖十一界，另在人界覆盖四主题，共28组，验证真实触屏拖动、素材加载、选点、复位、只读存档和实际旅行。

scripts/package_map_release.py 为2.13.2登记专项范围，要求最终源码、真实测试XML、浏览器报告、同一EXE、APK签名与输入清单、实际安装哈希及两方向原生凭据一致。历史验收不计作新版通过。物理手机未验收，包包含arm64-v8a和x86_64。
