# 百项功法与法宝传承

玩家与 NPC 共用下表。修成所列功法至九级可领悟对应特质；列有法宝时，也可从该法宝参悟。同一特质可记录两个来源，效果只结算一次。

普通交锋中的出伤和受创按真实战损分别计算。多人战中，六维修正和本方战意按持有者参战战力占比分摊。文中的短效减益指来自敌方、可驱散、含当轮最多剩两轮的普通交锋减益。

配气属于同一特质类型，按等级覆盖、同级保留。配气在赤砂手、断雁剑意等招式定色之后结算，物理份额保留。
