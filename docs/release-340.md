# v3.4.0「百炼仙锋」

2026-11-02。本体3.4.0，Android版本码92。沿用正式包名、签名与结构11；结构1–10拒绝加载，不迁移、不覆盖，不修改现有用户游玩存档。

## 内容

首次发行[本命三铸与独立仙器培养](immortal-artifacts.md)。同一绑定期间实际付费温养至少37次后，三铸神魔铁×1将非仙伤害本命进阶为仙。仙器页在四个三级普通界面开放，按实际加载的道途DLC显示仙器、魔器、妖器、魂器、佛器或儒器。

仙器从五品培养至一品，依次消耗三铸神魔铁、阴阳和泉钢、原初太一银、先天元合金各三件；品阶不直接增加战斗力。首材散布十一界，后三材只在三级界面。普通装备、原炼器和本命共用各自权威记录，叠放装备仅分离其中一件；解绑、读档、附物和寄拍保留该件属性与品阶。

培养页采用材料架、器物品阶印、五阶进度、下阶所需与库存对照。桌面四列材料、手机两列，短横屏保留可触及的关闭与操作区；兼容四套文字主题及新版浅暗配色。四种新材料沿用原材料图集的像素描边与光影，运行图标与立绘离线打包，百科同步说明规则。

## 发行验收

入口：`python scripts/verify_scoped_release.py --profile immortal --shards 2 --workers 2`。执行本命、仙器、材料、战斗资格、炼器、拍卖、物品条件、成就、附物、持久化、跨界／空间／2.1.1／2.1.2及发行相关上游，运行三项工程检查、素材哈希与真实浏览器培养、材料、导航和事件恢复。为相关领域回归，不宣称全仓回归。

最终Windows EXE在有／无DLC的隔离目录，使用`verify_release_exe.py --immortal`验证实际温养、升仙、四次培养、精确耗材、旧页面拒绝恢复和重载。最终签名Android12在专用模拟器，以`immortal`原生阶段运行横竖屏，覆盖四套文字主题及新版浅暗配色，真实触摸上述操作和离线素材，核对战力、年龄、RNG及只读页面不写档。不是实体手机验收。

`verify_android_scoped.py emulator-5580 --immortal`核对已安装APK及原生测试APK哈希、签名与原生日志；`package_scoped_release.py`核验源码、回归、EXE和APK证据后生成发行物。具体测试数量、通过状态与最终产物哈希以`dist/release-3.4.0.json`和`dist/release-3.4.0-android.92.json`为准，旧版日志不代替本次验收。
