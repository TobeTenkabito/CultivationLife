# 邻域效果与主战资格

> 维护基线：本体 v1.57.0 开发源码，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名保留历史编号以维持链接；历史采样不是本轮实测。

通用的条件、计数、限时状态及普通／邻域联动规则见 [战斗语义 V3](combat-semantics.md)。
该层只开放语义与结算接口，不定义具体 DLC buff。

本次扩展保留邻域前置阶段与普通六维交锋。`combat/contracts.py` 定义有限的数据语义，
`combat/voisinages.py` 管理覆盖、资源与轮次，`combat/effects.py` 选择和执行主动效果。
这些模块不读取人物存档、物品目录、道统目录或 DLC。

## 主战槽位

NPC 独立保存 `main_technique_id`、`main_technique_level`、`combat_artifact_id`。
`treasure_item_id` 仍然是重宝，与主战法宝没有推定或复制关系。
旧存档缺失槽位时为空；已实际掌握道统功法的 NPC 可将其记入空的主修槽位，
不因为修为较高而在战斗时临时生成仙器。功法和法宝的随机分配不在本次范围内。

`combat_loadout.project_loadout` 在战前读取实际槽位与定义。功法须已修习且适用于当前世界；
物品的 `force_tier` 或 `immortal_attack` 标签、功法的 `force_tier` 或既有仙法标记
决定仙级作用资格。任一可用主战手段达到仙级，本场便可选择它攻击仙级目标。
不按攻击次数建立仙器储能，不在逐轮循环里访问物品目录。

人物的普通攻击资格与邻域庇护严格区分。仙器不会让同伴继承仙级攻击，也不自动解除支配。
器物隔离禁用该器物提供的资格和特殊介入；功法禁制禁用其资格及主动术式调用，
不追溯移除已经计入基础面板的长期属性。人物仍可使用另一个合法主战来源。

玩家沿用现有已配置功法和物品规则，装备型 Item 在持有时有效，锻造器物仍须配置在装备栏。
物品定义只描述能力，不证明归属。玄黄仙甲提供有限的镇压／禁制抵抗；天河剑胎提供仙级攻击。
NPC 把它们放在重宝栏时不获得对应主战能力；放在主战法宝栏时才提供能力。
主战法宝击杀掉落与重宝各自转移并清除记录，不新增逐击状态。

## 被动护体金光

金光来自炼体，不依赖资源性质、仙灵力转换进度或当前余额，也不按受击扣仙灵力。
玩家保留真仙之躯二十层门槛；NPC 检查独立炼体坐标是否达到真仙后期（当前映射为仙躯十五层起）。
旧 `ward_cost` 字段兼容读取，但不再解释为金光的受击资源消耗。
凡级作用无法突破金光；仙级作用获得对抗资格后，由对应伤害或效果继续结算。

## 每轮主动效果

1. 同步明确的资源供给，支付展开、维持、覆盖和追加投入费用。
2. 逐目标比较侵夺与庇护。支配立即封禁普通退路、神识与身法。
3. 同一施术者连续支配时侵蚀战意、战斗态势，无须另付主动效果费；不直接造成肉身伤害。
4. 每个有效邻域从自身声明的能力中，按目的、对象状态与预算选择一个主动效果。
5. 检查明确的抵抗、脱困、临时庇护、破域介入，重新确认执行资格。
6. 只为仍可执行的效果付费；互相突破的合法攻势同时保留。先结算敌对作用，再结算恢复，
   已死亡、逃离或被镇压的单位不会被恢复效果复活或解除控制。
7. 有资格的单位继续普通交锋；轮末及时解除失去邻域支持的封禁。已造成的损耗保留。

自 v1.52.1 起，邻域效果与普通行动独立计数。邻域杀伤或恢复不会占用普通出手；
未受支配的角色仍可参与普通交锋。借连续支配机会使用普通武器或功法处决时，
才会占用该角色本轮普通行动，下一轮重新获得行动资格。玩家与 NPC 使用相同规则。

每个邻域最多八种效果，每个施术者每轮选择一种；每位具备特殊介入能力的参战者每轮最多回应一次。
没有对应能力时不扫描候选回应者。效果不会递归触发其他效果。

`effects` 中每项声明 `kind/cost/power/target/defense/tier`，禁制和隔离另声明 `restriction`。
`defense: ward` 检查目标防护资格，`bypass` 表示该效果明确绕过该防护；普通身法不重新推翻支配。
旧定义没有 `effects` 时转换为原有单一能力，不修改其数值。

| 效果 | 语义 |
| --- | --- |
| strike | 实际杀伤；非诛杀目的限制伤害，不把切磋自动变成死亡 |
| suppress | 侵蚀战斗态势或完成镇压，不据此制造肉身伤害 |
| seal | 封锁传讯、支援与退路，并按权能收束至镇压 |
| restrict / isolate | 显式禁用功法、器物、供给、支援、传讯、邻域或普通行动 |
| restore_body | 修复气血与战斗态势，受上限约束，真实回写玩家 HP 与 NPC 伤势 |
| restore_spirit | 稳定战意、缓解支配遗留的态势损失，不解除当前支配 |
| restore_field | 修复受压导致的稳固损耗，用于后续轮次的庇护比较 |

没有恢复仙灵力的效果。`ResourceSupply` 仍仅表示明确的外部供给，供给链被隔离或失去来源时停止。

## 两轮终局

真实修为更高、目标自身无邻域且没有同伴邻域庇护时，第一轮只建立支配。
连续第二轮可以通过实际可用的普通主战手段或邻域杀伤完成诛杀；普通主战手段仍须能作用于目标防护。
若只有封锁／镇压能力，无法借“诛杀目的”生成不存在的杀伤。
擒获、击退依实际可用手段制伏。终局前仍允许明确的特殊介入，不重掷普通追击或身法概率。
多目标按各自的连续支配资格判定，不因其中一人符合条件而终结整支队伍。

## NPC 与迁移

后台 NPC 使用相同邻域内核、金光资格、主战来源及资源账本。普通交锋仍使用简化伤害曲线，
将战意和神识／身法劣势转换为有限系数，不模拟一套完整玩家回合。
后台目的支持诛杀、擒获、击退、制伏；下界灵域使用与玩家遭遇相同的仿仙灵力子账本。
伤势恢复与资源消耗均回写真实人物，不新增年度恢复或背包扫描。

旧道统目录按独立稳定流补充效果列表，记录 `effects_schema`；不重抽名称、维度、功法或未来等级。
只展示玩家当前已揭示等级的能力。灵域维度与权能缩放保持原值，效果成本沿用仿仙灵力尺度。

洛天衡首次交锋已按明确剧情接入锁仙灯；其余阵器剧情及独立炼体、神识对普通六维的全面接入仍暂缓。

## 剧情中的定轮封域

`VoisinageSeal` 仅声明目标、起始轮和战报文案。轮首在维持消耗、覆盖与效果之前封停该角色的邻域，
释放依赖该邻域的控制，保留已产生的伤势、战意与态势损失。只改本次战斗快照，不修改保存的邻域能力。
通用内核不识别角色名、事件 ID 或锁仙灯物品，不扫描 NPC 世界列表。

`EVT_MA_LIANG_005` 自带局部太虚灵域定义与有限的 60 点仿仙灵力，前两轮维持消耗分别为 8、4。
洛天衡的真实修为独立标记为真仙，普通战斗投入仍沿用这场剧情的编队数值。
盟军由剧情明确获得灯辉抵抗终结的临时能力：它不会取消封禁、压制和消耗，避免凡修在第二轮必死。
第三轮 `enemy-0` 被封域，剩余仙力仍能支持普通仙家攻击，不会因封域被清空。
普通装备最多提供八个响应，剧情最多附加八个；合并后最多十六个，仍然每名角色每轮只响应一次。

剧情敌方强度可显式填写 `target_power`，否则兼容旧剧情的检查数值。推荐值不是胜负门槛，
这次仅主动攻炉路线进入逐轮战斗；护持灯阵的法体、元神路线继续使用原先的固定属性判定。
数值依据见 [洛天衡灵域战校准](luo-spirit-calibration.md)。
