# v3.5.2 同道共进

2026-11-04。本体3.5.2，Android版本码95。仅支持存档结构12，结构1–11拒绝加载／导入，不迁移、不覆盖。只使用隔离验收存档。

## 独立培养窗口

沿同道导航打开「培养」，旧有弟子、后代、道侣、神识禁制与傀儡培养入口统一结算。修为、普通／高阶肉身、神识、元力转化、传授功法、研修功法、邻域与肉身精修分别选择；每次1／5／10轮，按实际完成轮数扣款。报价、选对象、看立绘、失败和过期提交均不推进时间、不改变RNG。

四道途有独立专材，培养专材共81种（含傀儡能源）。新增四种高阶肉身精修材料与十二种分品阶功法研修材料；获取沿现有坊市、交易与探宝，不要求只能灌注玩家机缘。材料培养每实际轮一份，普通／灵品／上境培养材料基础价1／4／12，不另收机缘和MP；能源另按品阶标价。机缘培养按原成长坐标参考值的1.5%，既有丹药减免最高35%。这是主动培养的平衡口径，不把不同资源与被动免费成长伪称同一种货币。材料与界面分级仍由服务端校验，高阶四途分别在仙界、修罗界、幽冥界、轮回界使用；傀儡高阶在第三级普通界面使用。

高阶修为每轮一层，高阶肉身每轮最多两层，元力转化每轮20%。结算旧的独立元力恢复区间后扩容，不借培养补满原人物元力。不代替人物迁界，不修改世界与实际地点；离线、未成年、任务占用、失控、毁坏、未探明身份、忙碌／劫战状态仍拒绝。

## 高阶分项

四系肉身精修共20项：基础五色神光、修罗五蕴、妖躯五变、鬼躯五法。每轮一重、最高十重，按真实肉身层数解锁。保留原NPC随肉身成长的天生造诣，显式精修可提前提升已解锁项，不降低其他能力；实际战斗直接读取原有四个机制投影。DLC未开启时只显示基础体系，已存精修不会替关闭的体系授予权能。机缘施教受玩家当前实际肉身及已掌握等级限制。

精修记录属于原肉身，受禁人物仍写唯一原NPC；肉身毁坏时清空，夺舍沿原宿身接管。傀儡不冒充独立人物修炼五法或邻域：机关／炼尸／活傀继续通过修为、淬体、凝识与能源提高出战能力，活傀主修仍沿原传法配置。

人物已掌握功法可每轮研修一重、最高九重，写回原NPC功法等级和已装备栏目；机缘施教不能超过教师对该功法的掌握。邻域可选择本界传承，培养后启用，也能切换已学传承。须先完成元力转化；仙界本源确定后不覆盖，其他道统最多四阶；既有专属传承不转写成通用传承。邻域成长仍受境界上限约束，培养和切换都不填充元力。

## 傀儡能源与表现

能源一至十二阶，九阶起为仙级。仙级能源不能装入八阶及以下的凡阶傀儡。同阶每出手消耗5耐久；低一／二阶消耗20／60，低三阶及以上无法驱动；高一／二／更多阶消耗2／1／0.5。耐久不足时不拆成两份付款：合格自身能源优先，供能开启才允许玩家垫付，普通攻击5 MP，高阶仙级攻击按境界10／20／30／40元力。没有仙级能源且禁止垫付时，仅在凡级能源能驱动的情况下退回凡级攻击，否则停手。

战斗设置的傀儡供能开关同时作用于自动／手动预案。更换能源消费一份真实库存，卸下件保留原耐久与唯一编号，装回不刷新耐久、不修复傀儡身体。沿原战斗单位和资源提交入口结算，不复制玩家或NPC资源池。

沿原细线低饱和风格，补齐七种机关形态全身像／头像：天人、龙、夜叉、灵木、蛇、乐伎、鸟；另有63个手绘关键姿态、35段有限姿态动画。原人形机关、男女炼尸与活傀动作继续使用，受禁人物保留原身份。造型不把未知物种、宿身或未公开身份伪装成普通人。动作按真实已付款出手记录播放，耗尽停手，不伪造额外攻击。原稿／提示词见design/controlled-352，运行来源及哈希在web/assets/pixel/controlled-352/provenance.json；生成使用内置image_gen，导出只裁切、限色与等比最近邻缩放，运行不依赖design。
