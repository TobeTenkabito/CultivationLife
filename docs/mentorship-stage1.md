# 师门第一批：身份、名册与日常履约

第一批实现四级身份、有限同门、晋位比试、忠诚与不满、日常福利义务，以及旧入口和 Debug 的统一校验。欺师灭祖、夺位、夺舍契约及身外化身属于第二批，第一批不会触发这些结果。

## 身份与人口

嫡传一位、亲传三位、真传 `4 + 真实境界索引 // 2` 位，记名不限。封印不缩减真实名额；名额减少只禁止新任命，不追溯逐人。初次收录优先真传，否则记名。出师、离门、死亡解除活动名额，历史保留。一个人物只能有一位活动师父，禁止循环师承。

待处理拜师帖最多八份，与在籍弟子数量分开；随机拜师事件与直接收徒使用一致口径。玩家正式出师要求非记名身份，且累计履约三次或境界达到师父当前境界。玩家可准予自己的弟子出师。

名册只保存原人物 ID，不复制培养值、地点或物资。玩家正式拜师成功后才为该师父建立一次小规模同门（至多两人），不递归生成他们的师门或家属，不按满额补人。浏览、失败拜师、读档均不补人。已有结构12师徒在首次实际师门事务时登记，读取仅投影；结构1–11仍拒绝加载。

## 权利与代价

2026-11-07发行回归补齐：成功向师父请教后沿原人物入口增加1点好感，并调用原天机线索回调、保存原RNG进度；同地同界、位次和额度限制均先验证，失败或重复请求不生成线索。不新增远程请教权限或情报来源。

记名没有定期福利及义务，不能通过旧请教、索物、功法、交流、同行入口取得师门权利；仍可办理晋位、离门。玩家主动赠物、传功与培养记名属于自愿行为，继续使用原 NPC 培养入口。真传、亲传、嫡传依次提高指导额度与职责要求，不删除低位弟子已有培养。

赐物转移师父实际未领取的随身宝物；传法只教其真实已学功法。指导是有周期额度的服务，不建立第二库存。弟子贡物只能取其原赠物托管或实际随身宝物；不会根据人数自动印钱。玩家履约消耗明确显示的修行机缘，积累履约资历并减少不满，不产生可反复兑回的货币。

忠诚与好感独立，培养收益按实际成功结算，每个固定周期最多增加12点；同一功法重新装备不增加忠诚。领取贡物降低忠诚，记名拒绝征收。低忠诚记名在日常周期可离门。叛乱暂不结算。

自愿呈交心得每周期一次，消耗该次面板显示的机缘，师父好感增加10、不满减少10；记名不做这件事也没有处罚。主动与师父或同门争执会被记录为师门不满，每次5点、每周期累计最多15点；不凭空制造未发生的谗言。第二批再接入同门结盟、主动挑拨和叛师事件。

周期在首次登记时固定，为当时玩家行动单位的五倍；晋位、换界、读档不重置。每个周期最多一次履约、贡物和晋位申请。履约要求随身份增加；记名始终免除。失约提高不满，60预警，100且曾获预警后才逐出。远离师父、跨界、特殊空间隔离或玩家被困时暂停未完成义务的倒计时，不补罚旧年。主动离门不会清除原周期、资历和不满。

## 晋位与空间

晋位逐级、好感与资历双门槛；满额时指定在位同门，非致命单人切磋胜利才交换位次。战斗使用原完整战斗结算与动作报告，真实HP/MP照常结算，不改培养、不发击杀奖励；比试不携队友、傀儡、第二元婴。失败消耗申请次数。玩家任命自己的弟子同样校验名额，降位不清除培养或履约记录。

晋位门槛分别为好感20/45/75、履约资历0/2/5；师门不满达到60须先处理。战场法令及原有装备、法阵规则仍然生效，师门比试不签发仙庭授权。高位弟子增加师门服务额度；特殊培养维度、夺舍和身外化身在第二批扩展。

面授、任命、履约、贡物和比试均需同一真实界面、实例、地点，检查人物自由状态、任务占用和玩家忙碌状态。历史关系可保留，但不可从异地结算资源。特殊空间仅允许实际同处一实例同一地点的人物交互，无跨界移动例外。

## 持久化与验证

### 师兄师姐交流（2026-11-05）

在「人际关系 → 师徒 → 师门名册」的同门卡片展开交流菜单，可请教修行、切磋论道、索要物品和索要功法。入门时间不晚于玩家者为师兄／师姐（首次初始化的既有同门与玩家同年登记，算先入门）；晚入门者显示师弟／师妹。师门辈次不按嫡传等位次决定，男女同门均可办理。

3.5.3修复延迟补登记：既有同门的相对入门年份使用玩家原入门年，不因晚初始化变成师弟妹。页面重排为身份概览与原像素人物卡；成功操作及过期页恢复保留当前角色的交流选择与展开状态，切换角色清空这些内存偏好。

- 双方必须仍在同一在世师父门下且非记名弟子。同门本人须同界、同实例、同实际地点、自由且无任务占用；玩家忙碌、归墟亲自副本、监禁、试境等限制复用原师门接触入口。不要求师父同时在场，不移动任何人物。
- 每位师兄／师姐每项事务每个玩家固定师门周期一次，独立于师父指导额度。领取后换位、读档、暂时跨界、离门重拜不刷新；周期沿原时间入口推进。请求被资格校验拒绝不消耗额度、物品、机缘或RNG。
- 请教和切磋需同门好感至少0，各得当前阶段所需机缘的1%（至少1点）。切磋无论胜败均有领悟，沿晋位比试的真实非致命单人战斗结算和动作回放；不携队友、傀儡、第二元婴，不换位、不发击杀奖励，HP／MP及战斗耗材照常扣除。
- 索物需好感20，转移对方实际未领取的随身宝物，同时清空原持有ID并登记已领取，不能后来重复取得战利品。求法需好感30，仅教其真实已学、玩家尚未学过且满足原传法适配条件的功法。师父与同门共用物品／功法结算；没有宝物或可教功法时显示具体原因，不为请求临时生成奖励。

可选持久凭据 `peer_requests` 归玩家当前师承记录，以原同门ID和行动存最近使用周期，无人物／物资副本；结构12已有存档缺少该凭据时按未使用读取，不做结构迁移。普通操作和Debug的 `mentorship action peer_consult|peer_spar|peer_item|peer_technique <npc_id>` 使用同一命令、资格与修订保护。

专项验证：`tests/test_mentorship_peers.py` 覆盖四项真实命令、实物守恒、实际切磋与动作立绘、各项冷却独立、读档／重新收录防刷、只读投影、跨界／空间隔离、任务占用、记名限制、严格凭据验证及隔离Debug；`tests/browser_mentorship_peers.py` 覆盖真实菜单四项点击、拒绝过期页并刷新、禁用原因、1440／390宽度和战斗动作回放。结果记录在 `build/mentorship-peers-tests.log`、`build/mentorship-peers-browser.log`。

验收结果：23项新增专项、91项既有师徒与对抗测试、309项跨界／空间符箓／2.1.1／2.1.2／Debug能力／玩家战斗回归通过；新交流、旧师门与旧事件三组浏览器通过。跨界合同、依赖、文档检查及页面JS语法检查通过；本轮保持3.5.2、结构12，未打包或改动用户存档。其余记录为 `build/mentorship-peers-existing.log`、`build/mentorship-peers-regression.log`、`build/mentorship-peers-old-browser.log`、`build/mentorship-peers-events.log`。

`GameState.mentorship_state` 是全局关系历史容器；学生记录保存身份、忠诚、不满、资历及周期凭据，人物、战力、地址仍归原实体。展示不写入。年度入口只结算当前实际玩家时钟，地区历史回放不得处罚或发放玩家权益。普通UI和Debug都调用 `mentorship_action`，服务器检查页面版本。

出师或主动离门时，原关系的赠物托管、突破药效等附属记录移入该关系唯一的 `former_relation`，不复制人物事实；若重新收录，再移回原人物的当前关系。物品离开师父或弟子的随身宝物栏时同时清空原持有ID和标记，防止后来战利品再次领取。普通地区和独立空间各自的真实年度入口推进同一周期凭据，归墟被困与空间隔离不会在返回后追罚。

界面位于既有「人际关系 → 师徒 → 师门名册」，同门与弟子沿用原像素立绘。独立NPC培养窗口显示位次与忠诚；既有培养、赠物、传法成功后统一记忠诚。Debug通过「功能调试 · 全部系统」的 `mentorship action` 操作，`game inspect /mentorship` 只读检查；不另设可绕过名额、地点、材料或忙碌状态的入口。

验收覆盖全部拜师入口、只读名册、名额、单师/循环、跨界/实例/任务限制、旧入口、实物守恒、忠诚防刷、固定周期、非致命晋位、存取档及浏览器操作。
