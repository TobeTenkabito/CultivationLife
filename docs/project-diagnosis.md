## 后续修复：生存、拘禁与名册分离

已完成上述俘虏状态问题的修复，当前源码结构为 **8**。生擒、议和人质、俘虏来源侍妾和新活傀保留同一 NPC 身份；退出自由名册不再记为死亡，释放不能复活真正死亡者。另补齐受控人物的组队／互动限制、后代重入防护、临时跨界随行，以及真实处决、夺舍、活傀失控等转换。现有捕获概率、费用及俘虏／侍妾养成时序保留。转换规则和旧档限制见 [人物拘禁契约](npc-custody.md)。

本次新增 32 个状态回归用例，并修订此前将活傀当作死亡的旧断言。实际验证：

- 浏览器烟雾通过，包含受控人物仍存活、无“已故”标签、无普通道侣互动按钮的新增断言。
- 显式依赖 **324 个模块、1,800 条边，0 循环、0 边界违规**；Ruff F821／F822／F823、`node --check web/app.js`、49 份 Markdown 一致性及 `git diff --check` 通过。

证据：`build/custody-tests.log`、`custody-part-*.xml`、`custody-final-focused.log`、`custody-browser.log`、`custody-dependencies.json`。旧活傀缺失原 NPC ID 时仍保留专用记录，不按姓名猜测身份。本次未修改本体发行标识、未打包或执行设备验收，未操作玩家实际存档。
