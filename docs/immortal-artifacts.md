# 本命三铸与仙器培养

2026-11-01实装，2026-11-02纳入v3.4.0「百炼仙锋」。沿用结构11，不迁移结构1–10，不改写用户游玩存档。本命与仙器是两个独立入口，共用原物品、炼器实例或丹田本命记录；发行范围见[3.4.0说明](release-340.md)。

## 本命三铸

同一绑定期间记录实际灵石温养次数。单次计一次，一键温养按实际扣费次数累计；被动年份、经验和等级不计。超过36次，即至少37次后，消耗三铸神魔铁一件，将非仙伤害本命进阶为仙。原数值、祭炼等级、经验及镶槽不重置，已有仙级伤害不重复收费。原无上限温养继续沿旧入口和价格。

结构11缺少计数时，只核对当前绑定后的明确温养历史回执，不以旧等级或未知历史补数。解除本命仍散去温养并处罚本源，原器物的仙级伤害与品阶保留，镶材仅归还一次。

## 独立仙器页

电脑左侧新增“仙器”，手机在现有“修行”分类。仙界、修罗界、幽冥界、轮回界开放，独立空间和归墟会话不套用外界资格。对应道途DLC实际加载时，魔修显示“魔器”、妖修“妖器”、鬼修“魂器”、佛修“佛器”、儒修“儒器”；关闭时回到仙器，品阶保留。神机榜保持原入口。

只列实际持有且伤害类型为仙的装备，包括普通随身装备、原炼器实例和丹田本命。商品品阶、基础战力、祭炼等级、伤害类型、仙器品阶分别处理，初始五品，最高一品；品阶不参与战力或仙级资格公式。
