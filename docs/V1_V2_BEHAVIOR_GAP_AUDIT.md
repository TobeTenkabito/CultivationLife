# V1 → V2 行为迁移复核

基准提交：`83641711ef1e8f8d5f74dc0ad973d6a07c36932f`

本表核对的是“玩家可观察行为及其完整信息流”，不是只核对 HTTP
路由或按钮是否存在。每项按以下链路检查：

`V1 规则 → V2 权威状态 → 时间/命令处理 → 领域事件 → 存档 → V1 前端投影`

状态说明：

- **完整**：现有实现及回归测试覆盖整条链路。
- **本轮修复**：复核时发现断链，已补实现与测试。
- **部分**：主流程存在，但仍有可观察的 V1 行为尚未迁移。
- **缺失**：没有对应运行逻辑，不能以界面入口存在视为完成。

## 后续阻断项

以下项目不能以“按钮能点”判定完成，必须继续补实现与场景测试：

1. 将本轮已经跑通的“创建/快速开局”影子对照扩展到普通开局六条道路、修炼与突破序列。
2. 按 V1 的 552 条行为测试建立语义交叉表；当前 V2 只有 173 条测试方法，不能用 HTTP 入口覆盖率替代行为覆盖率。
3. 瞬时经济、炼器、阵法、关系、内政操作的完整生平纪事投影。
4. 拍卖、坊市、跨界、势力、家族、关系、DLC 各选一条完整命令序列做 V1/V2 影子对照；比较最终状态和可见消息类别，而不是内部随机调用次数。
5. 100、500、1000 年行动的固定性能预算与事件日志体积上限。

只有上述阻断项完成并通过影子对照，才能把“全部迁移完成”作为发布结论。
