# 修罗、幽冥与轮回上境

> 维护基线：本体 v1.58.0，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名编号仅用于保持链接。

修罗、幽冥、轮回界沿用本体普通进阶，开放至第十二阶九层。本体普通路线机缘积到当前关口即封顶，玩家手动突破；修罗显圣已加载且魔修达到修罗境时改用无上限储量、魔脉与专属劫战，不走此处普通路线。三至四层、六至七层沿用普通三关，大境界沿用原有五关天劫，魔修沿用天魔战斗劫。周期雷劫继续生效。仙界的仙脉、仙躯、人五衰、天五衰和斩三尸不用于这三个世界。

血脉进化仅在妖修 DLC 实际加载后启用。幽冥上境妖修保留原有一层起的血脉进化入口，不能改点普通突破绕过进化；禁用 DLC 后按九层本体路线修炼。鬼修魂蚀、往生、轮回印记等继续由鬼修 DLC 控制，关闭即回到本体普通规则。DLC 开关需要重启才能改变实际加载内容。

三界各新增四个品阶的主修、战斗、炼体和神识功法，共 48 部；均使用当地气源，不要求仙灵力转化，不直接赋予邻域。每阶新增主辅两用材与淬炼材，共 24 种；阵材用静态内容矩阵补齐十四种性质。材料随当前境界在坊市出现，功法仍需按气等级与玉简规则修炼。常规炼体功法只支持原有百层炼体，不冒充仙躯功法。

NPC 使用原有年度概率成长，只扩展品阶表，不增加逐项扫描或新的常驻养成字段。受支持存档中的普通上境路线补全时按关口处理机缘；修罗显圣的无上限路线及其封印储量不截断。普通路线恢复手动突破状态，缺失周期雷劫计时则从读取时开始计时；不会自动补领修为。

百科新增“补灵根与炼虚”和“三界上境”。本体普通化神九层冲击炼虚需要金木水火土齐备；灵界紫阙玉书、真魔界魔阙天书、妖界／幻冥界妖阙天书、地狱界冥阙魂书可在相应坊市寻找，化神起在对应世界参悟。已有属性不重复消耗书卷，补属性不改变原灵根品质。妖修 DLC 进化按血脉条件单独处理。

验证入口：`tests/test_upper_world_progression.py`、`scripts/verify_upper_world_ui.py`、Android release instrumentation 的 `upper` 阶段。常规完整回归与六主题既有功能验收仍是打包前置条件。
