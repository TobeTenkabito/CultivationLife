# 种族战争首期实现

本轮按[三层战争策划](racial-war-design.md)交付同界的首期可玩实现，纳入 v2.14.0，存档结构保持 10。跨界开发边界继续遵循[开发规范](world-transition-development.md)和[审计记录](world-transition-audit.md)。下文首期与增量验收保留原采样口径，发行最终证据以 v2.14.0 清单为准。

## 当前玩法

- 灵界、真魔界的族议宣战建立政治战争；种族不再直接生成军队。现有宗门／家族独立战役保留原规则。
- 本界支持组织分别批准参战，玩家实际有权控制的组织由玩家批准，其余由原组织决策。承诺最多每边六家；军需上限为批准时原库现金的两成，调拨仍扣原府库。
- 首期固定两个真实组织目标，分别以一对宗门／家族开战，后续可接收多个已承诺的闲置组织，形成多对一、多对多联军。组织代表推举 NPC 统帅；玩家作为承诺组织的决策者可竞任，真实代表逐人去重投票，任期一百年。失权、死亡或任期届满重新校验。
- 原地图道路决定部署时间，优先选择最快成员及慢十年以内的先锋，其余留守。人物、军需、劳动占用和返乡各有唯一事实。部众未抵达不得提供战力；玩家不会被自动编入军队。
- 每十个真实年推进一次会战，仍用原战斗、阵势、物资消耗与伤亡入口。旧外交行动单位不重复推进。宗门有权者只能下令本部进攻、固守或撤回；有效统帅可调整本方联军方针。固守不会冻结敌军。
- 一场战役结束只产生一个目标结果，不直接结束父战争。首期两个目标各占五十分，胜败与相持可追溯原战役；回执重复提交不重复计分，更不发灵石或重复扣伤亡。
- 族议可提议总停战，对方按既有战果与厌战接受或拒绝。动员三十年未形成有效计划会安全收束；正式战局的期限为实际最晚抵达后再给一百二十年，不跳过长途。停战后部众沿原行程返乡，原剩余军需只退一次。首期总约不新增割地、吞并或赔款玩法。

## 闲置预备队与多宗战役

用户明确约束：**调度仅限整宗闲置，战役中的组织不能转进其他战役。** 后端统一检查主战宗、联军宗和原名册占用，行军、交战、待结算、撤军均不闲置；即使还有留守修士也不能另派。旧独立战役不能再召入正在战略战役中的组织，避免另一入口抢占同一宗。已经结算的目标不重开、不重复计分；原战役完全归返结清后，尚有批准额度的组织可以支援另一场仍在交战的战役。单宗提前退出只撤回本宗，盟军继续；该宗原军资仍待战役整体结清，期间不释放调度占用。

统帅在「战争 → 战役」选择目标战役及闲置预备队；页面显示实际本次经费和军需行程，提交核验当前权限、修订号、唯一命令及报价。两侧联军按原组织分卡显示人数、行军与归返。玩家担任统帅时保留手动调度；NPC 统帅每十个真实年最多调遣一家，使用同一资格、道路、名册和资金入口。动员初期优先已有组织，在终身十二家限额内尝试补足每方两家有实际人力的主战组织和一家有资金的预备队，不为已有主战组织补发资金，不因进入交战每年增生组织。

每场战役每边最多六宗、四十八人，单次增援最多十二名先锋；新增宗门不增加每轮交锋次数。实际交锋先选择在场组织再选择该组织出阵修士，避免追加在名册尾部的援军永远无法上阵。本组织固守只限制本宗主动出击，统帅方针仍适用于本方全军。

增援本轮仅携带实扣的灵石，经费不超过原承诺剩余额度、原府库现款与当前战场三场军需参照值中的最小值。在途款封存在唯一附属军需托管；抵达后交付原前线账户，沿既有军需入口在当地买实际商品，不遥取山门实物。援军不会冻结原战场或重置交锋日期；中途停战按已走路程返乡，未交付款只退款一次。已经交付的原款按原贡献比例清算，不算新经营收入。所有运输、占用和待结清记录保留原战役内，父层不持现金、人物或物资副本。

## 轻量名录与容量

种族宗门预设继续仅是名录。战争需要组织时才选择实际安全地图，排除玩家当前地、玩家宗门／家族驻地和个人产业地；复用普通招募生成六名原人物，登记真实驻地。当地市场扣除有限周转金出资，写唯一来源凭证，组织不凭空获得库存或经营收入。

本轮采用可验证的硬界限：动态组织（包括旧 NPC 新创组织）一生至多十二家，随机日常创立仍保留同时八家的原限制；灭亡也不释放终身名额，不重抽死者。达到上限保留名录，不能满足动员时按期安全退出。**尚未实现分块冷存储、组织休眠与激活工作集轮换**，十二家硬限额是这一步的明确性能边界，并非已完成策划中的冷存储。后续应替换为事务化、跨平台可导出的分块存储，不把全部原始字典塞进 JSON 冒充节约内存。

父战争最多同时两案、每案两场组织战役，完结保留最近二十案；进行中日志八十条，完结案压成最近六条摘要，命令回执六十四条及不回退的序号高水位。超过历史窗仅移除已归返、已退款的旧战役与零余额托管，不影响原人物、资产或仍有义务的战局。

## 兼容、界面与边界

新种族关系用明确世界的键，旧裸约保留并显示待确认，不从玩家当前界面推断原约。原族战停止直接交战，由有族议资格者表决结清：已定胜负执行原胜方条款，未定胜负沿原白和与退款入口退出；不复制为新战局，也不把旧分数兑换新奖励。没有实际战局的旧战争关系，确认本界归属并通过议事后可收束。只能采用一次，不覆盖已有本界条约。

战争页复用原“经营 → 战争”：态势图、分阶段进度、组织战役卡、议事和分层战报。每次只画选中的战争与子页；手机使用单独坐标布局。后端按本界白名单返回概览，原 NPC 全册、路线与府库余款不下发给父层页面。过期修订号、命令重放、撤销权限和跨界下令均拒绝并由原前端恢复页面。

本轮不支持任意跨界出征、不开放其他世界的自动族战、总和约产权条款、个人主动加入日历战役、援助承诺与多目标权重。相关扩展停用时不补生人族，已有案不再发起专属进攻，撤回与原账清理继续。原独立战役的玩家参战入口保持原义。

## v2.14.0 审计与发行

- 预设宗门仅在缺失时初始化支持种族，读档保留实际政治支持；原组织改换支持、灭亡或失去权限时，旧统帅授权即时失效，动员计划也重新验证当前阵营。
- 组织代表必须仍在原成员册、同界、自由且不在独立空间；已离册的历史代表不再参与推举与停战投票。
- 行军每年检查原拘禁和实例归属，被关押者失去本次出征资格，不将原囚犯移动到战场；释放也不自动恢复旧部署。
- 军费退款只分配给原实际出资组织，整数舍入余款不会流向零出资盟宗；原本金退回不算经营收入。
- 剩余军需由实际承运部众原路带回，所有相关运输完成后才按登记归返地址交付。原仓容量不足、组织已迁离或仍有原款待结时，保留原实物和托管；历史清理不得吞掉资产。
- 满仓导致的未入库实物由原年度军需入口重试，独立于父战争历史；只有原运输全部归返、原组织仍在原地点且有容量时才接收，不再次退款、不转化为收入。无货可收或仍满仓时不刷府库记录和修订号。
- 联军卡按实际存活、自由人数投影，阵亡或关押部众不再显示为可用援军。
- 全仓页面复验发现手机商盟阵法委托的六维数值框被三列布局压窄，改为按实际宽度换列；四主题、三种宽度通过真实小数输入、边界校验与发布委托。
- 遗留浏览器脚本改用现行四主题、实际分页导航和设置入口；地图先真实打开再核对延迟渲染结果，等待新档加载完成后操作。保留越权拒绝、异步失联重试、过期恢复、几何布局及实际资源结算断言。
