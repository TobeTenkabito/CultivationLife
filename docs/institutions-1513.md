# 机构势力与人物归属

> 维护基线：本体 v1.58.0，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名编号仅用于保持链接。

天庭和瑶池归入新增的“机构”类型，与宗门、家族、种族分别处理。天庭仍驻玉京仙都，瑶池仍使用原驻地，两者原有事务入口不变。

机构不接受拜入山门，不占用玩家的宗门归属，也不参加宗门招募、弟子治理和宗门外交。机构人员仍有自己的修为、年龄、关系与日常成长；天官和执事保留原职衔。

地图将两处标为“机构驻地”，故人笺增加“机构人物”分类，可以直接与同界的天官、瑶池执事交往。此分类遵循既有跨界限制。六种主题共用这一入口。

## 旧存档

读取旧存档时自动修正势力类型，不重新生成人物，不清空瑶池功勋、货物锁定、天庭功德、七曜职位、选举和政策。

旧版若曾将玩家登记为两处的宗门成员，原加入时间、贡献和奖励偏好将保留在机构往来记录中，并释放宗门归属。对应机构界面显示原贡献；已获得的永久加成不回收。

新开局的天庭席位以真正的宗门为宗门代表来源，天庭和瑶池的官员仍可参与机构事务。旧存档已经产生的席位和选举记录保持原样，避免迁移改写正在进行的政治进程。

## 存储与扩展

增加通用 `institution` 类型和独立的玩家机构往来记录。机构暂时沿用现有势力容器存储，以兼容旧存档；宗门专属入口和自动流程根据类型过滤。后续新增机构可在内容定义中声明类型，无须将其伪装成宗门。
