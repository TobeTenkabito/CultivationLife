# 织田信长与安倍晴明皮肤

2026-10-28 源码增补，沿用本体 v3.2.3 与结构 11；本次没有生成新发行包。

两套均为男性主角、全道途、无境界限制。织田信长绑定原成就「天下布武」；安倍晴明绑定新增本体成就「百鬼夜行」，不是 DLC 的「今夜百鬼行」。完成后由现有全局功业录授予个人 `character_skins.unlocked`，现有和新存档均可在立绘旁衣柜选用；原宿身、附身及变身限制继续生效，不修改实际道途、战力或资源。

## 百鬼夜行计数

同一存档内，玩家在击杀结算时是鬼修，累计实际击杀100名非鬼修修士。直接战斗及本人处死俘虏复用 `_apply_cultivator_kill`；胜利未杀、逃生元婴、俘获、灵兽、凡人、未知道途、鬼修、商盟代杀及 NPC 自行死亡不计。原人物身份优先于临时战斗描述，不根据受害者姓名或事后玩家道途倒推。

`achievement_kills.record` 将事实写入原个人 `milestones.ghost_non_ghost_kills` 与最多100条 `SYS_GHOST_CULTIVATOR_KILL` 历史；有原人物编号时去重。存读档、跨界、转道保留已有进度；离开鬼修期间的击杀不追加，重新转回后可继续。新存档进度从零，不合并多个存档；已取得皮肤沿全局成就保留。旧日志没有可靠击杀时身份时不追认。不新增人物、资源池、时钟或顶层持久字段。

## 美术与动作

内置 image_gen 原创绘制，历史人物元素独立组合，不使用现成游戏立绘作输入。信长采用黑漆甲、绛红披风与军扇；晴明按用户反馈调整为月白、浅玉、烟紫狩衣，细柳月纹、乌帽与折扇，强调轻盈风雅。每套含完整立绘、头像、缩略图、10个关键姿态与7组动作。倒地、跪地、持扇姿势经单独检查，透明原画只机械裁切打包，不程序重画人体。

原稿与提示词：`design/historical-skins-20261028/`；导出命令：`python -m scripts.prepare_historical_skins`；运行素材与来源记录：`web/assets/pixel/historical/`。特效沿现有接触时钟，仅为两位角色配置各自三色调色板；原水浪、节日与枪击分支保持原处理。

## 专属施法差分与特效（2026-10-29）

按用户追加要求，通用施法已替换为两个专属动作。信长「烈扇军令」：提扇、蓄势、展扇、挥令、跟进、收扇，配赤金扇阵、三重焰刃、扇形爆散与余烬。晴明「月华引符」：开扇结印、胸前引符、扬扇、送扇、回腕、合扇，配月轮法阵、折纸鹤式神、符光爆散与碎光；保留原风雅造型。

内置 image_gen 新绘每人6张施法差分、每套12张特效关键帧。人物新增差分与原待机机械拼成独立 `*-casting.png`，每套仍为7组动作，专属动作使用原4秒时长和2.1秒唯一接触点。六个关键姿态加待机采样为81帧，不宣称81张独立绘制。不同颜色／多枚焰刃／纸鹤仅为视觉表现，不增加攻击、队友、伤害或玩法能力。

`historical-effects.js` 将12张特效按蓄势、飞行、命中、消散四段、各3帧采样及交叉淡化。动作发射点来自绘制扇尖；双方反向镜像，投射沿原目标护面裁剪。只有当前参战皮肤才加载其图集，每张1536×864；继续遵守原96MiB解码预算、alpha上限及关闭清理。特效图加载失败时回退原通用施法，下次打开可重新加载；缺失人体动作仍沿原资源错误处理，不能凭空替换角色。

新增来源：`design/historical-effects-20261029/`；导出脚本：`scripts/prepare_historical_effects.py`，由皮肤导出脚本继续调用；记录为 `effects-provenance.json`。只机械裁切原透明图、等比缩放与排图，不程序重画人体、焰刃或纸鹤。不新增持久状态、随机数、时钟或结算入口；版本与已有发行包仍不变。

六张施法差分分别登记扇尖锚点，让蓄势光随提扇、扬扇和送扇移动；通用角色继续使用原固定发射点。真实回放录屏保存为 `build/historical-skins-ui/nobunaga-male.webm` 与 `seimei-male.webm`，仅为只读播放预览。
