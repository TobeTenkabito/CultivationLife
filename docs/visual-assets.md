## 呈现范围

- 主界面以批准的“山河常在”样稿为依据：电脑端所在地绘景与原常用行动并排，地域可直接点选浏览，当地建筑直达原事件；不叠人物。手机与 Android 横竖屏将绘景收进左侧默认关闭的抽屉，首屏行动不下移。电脑事件放在右侧行动区，保留顶部状态和绘景中心；手机仍用原事件入口。
- 头像与人物详情采用同一身份匹配：普通人族道修或魔修、明确男女。魔修男女使用已采用基础差分中的正面站姿与同源头像，按真实道途匹配，不按所在界面推断。详情立绘位于姓名／境界右侧，属性通栏。宿身、附身、变化形态及未覆盖身份不套普通人物；缺图回退文字。
- 立绘只额外显示真实本命法宝，不根据背包或镶材改变衣装；不编造装备栏。独立本命页采用真实物品／炼器形制，保留原无限槽位和镶嵌按钮。
- 新行囊为桌面分类／网格／详情三栏，手机网格与详情窗；分类、搜索、排序不写档。同名炼器实例按原唯一物品ID区分。普通随身装备沿原规则生效，只有原神机提供装备／卸下操作。
- 十一界绘景用于主页，不替换原3D／平面节点地图、路线及势力界面。地理标注采用新锚点，不沿用旧3D坐标。绘景使用最近邻像素采样，只有全幅适配与0.5／1／2倍有限档位，不提供无级放大；文字独立显示且避让工具栏。地域下拉保留全部公开地点。浏览远方不移动、不推进时间；行程与势力按钮进入原节点地图及原行程、危险确认、耗时和事件限制。
- 绘图中的屋顶是固定地理概念，不是可摧毁实体；实时建筑、遗址及产权以原详情为准。未知界面、失落空间及裂缝不默认为人界。

## 通用素材选择

2026-10-22 用户明确“先将已采用素材接入游戏”。`web/npc-art.js` 在可选像素外观开启时，给宗门门人名册、缘页故人笺、师徒／道侣／道友／好恶／侍妾名册增加头像；故人笺详情与有明确人物参与的事件展示静态立绘，点击打开只读人物卡。宗门成员复用同一通用身份匹配与人物卡，玩家“你”这一行复用主角身份选择器与同源头像，点击打开现有人物详情及立绘，不套NPC图；切换外观同步刷新宗门名册。关闭外观恢复文字；加载失败保留原文字与按钮。

固定人物按真实 NPC ID、种族、道途与当前模板性别核对，不按所在界面猜身份。43位采用原稿与像素哈希冻结，巫行云保留；望舒旧稿停用，新观星学者稿待审阅，不进入运行包，也不套通用头像。灵曦圣祖、霜天女帝、月蚀姬依用户确认采用女性美术，catalog登记差异，程序性别与玩法未修改。16套通用素材只用于公开身份完整的成年人族道修／魔修男女，以稳定ID散列选定，同一人在事件、名册、重载后保持一致；有限通用池允许多人共用，不声称每人独有面容。

事件只认原 `pending_event.runtime.npc_id`、`runtime.members[].npc_id`，以及已核对的顾长庚破界图事件显式参与映射；人物必须同时存在于服务器已公开的人物列表。无明确参与编号的普通叙事不根据文字猜人，不增加后端人物、遭遇或事件。多人切换只切图片，人物卡与图签位于原事件选项容器之外，原事件提交、交往资格与忙碌限制不变。名册可以显示服务器已有的异界／陨落记录，图片不提供新去向，不刷新远程情报。未覆盖身份、未成年通用人物、未知身份、宿身／附身／变化形态均回退文字。

离线提升入口 `python scripts/prepare_npc_social_assets.py --fixed design/fixed-npc-portraits-20261022 --generic design/npc-social-portraits-20261022`，先核对采用记录和源图哈希，再逐字节复制成品。运行、打包和测试仅需已提交的web素材，不依赖design。本轮不增加持久字段、时间／RNG调用或素材分配存档，不改战斗图集、版本与发行包。

专项检查：`python -m pytest tests/test_npc_social_assets.py tests/test_npc_contacts.py -q` 与 `python tests/browser_npc_art.py`，覆盖真实加载、事件领奖、交往提交、身份稳定、公开范围、手机布局、缺图回退及浏览不写档；事件回归另跑 `tests/test_release_212.py` 与 `tests/browser_events_212.py`。

`cultivation_life.visual_selection.select_assets(candidate_pools, used_assets=())` 是独立纯选择器，不依赖战斗、性别、DLC、文件路径、存档或 RNG。每个候选集由调用领域先按合法性筛选、按偏好排序；通用层不猜测这些资格，也不会从集合外补图。

逐个请求先选首个未使用 ID；合法集合耗尽后选其中使用次数最少的 ID，并按候选顺序打破平局。同一池的重复 ID 不增加权重。`used_assets` 表示已上场／已展示的保留项，输入不会被修改；空集合返回 `None` 交由调用者回退文字或缺图状态。每次调用使用独立选择范围，不把上一场人物或上一页结果保留为全局占用。

战斗只是该接口的一个调用者：战前身份适配器提供两方至多六个候选集后一次性选取，随后固定在原 session 战报。未来物品、立绘或其他视觉场景可复用相同策略，自行提供自己的合法候选和已使用 ID，不必引入战斗判断。通用测试见 `tests/test_visual_selection.py`。

## DLC 分离

`cultivation_life/visual_assets.py` 按实际扩展加载报告过滤清单，不以角色所在界推断 DLC。十一界地理属本体，关闭妖修／鬼修／修罗玩法不删除相应地图。

DLC 独占素材应放 `dlc/<package>/assets/visual/`，清单登记 `requires`，经 `/extension-assets/<package-id>/...` 校验读取。关闭／移除 DLC 后清单不包含它，直接请求也返回404；路径不能逃出该包 `assets` 目录。共享本体素材不因 DLC 引用变为独占。

归墟物品虽在本体定义表中，宝池的 `exclusive_source` 仍是专属来源的权威声明，不能只按 JSON 所在目录认定素材归属。当前440个映射按归墟资格过滤，其中325幅独占图稿位于归墟 DLC，真正共用的本体图形留在本体。归墟资源包版本为2.7.1，不改变副本、宝池和已获物品规则。

关闭扩展后不加载专属图稿，已获物品不删除；图标回退本体中性类型。未专绘的其他 DLC 物品也用中性图形，不根据名字擅自认定所有权。实际关闭、移除与启用均由原加载报告控制。

## 状态与性能

2026-10-22 邻域外观组件与编辑器：设置新增“邻域编辑器”，轮廓、内部意象、自由颜色、六款已采用控制与质感分别选择，实时预览、显式保存／取消。`voisinage_appearance` 是可选的本机 UI 偏好，严格校验完整组件集合与质感范围20–100；沿原 `/api/ui-preferences` 原子保存，失败不改原值，不增加 Player／GameState 字段。此偏好由本机各存档共用，不授予邻域或改变能力。

按用户纠正，NPC 配色不绑定身份或主题。`web/voisinage-appearance.js` 为每次遭遇从淡色库独立抽样，快照内保持一致，允许跨遭遇同色；使用浏览器独立随机源，不消耗游戏 RNG。目前用于编辑器和独立对照预览，正式战报尚未接入；后续接入必须将选色随对应战报保存，不能在回放时重新抽色。主角配色由内置取色器与 HEX 输入框指定，与轮廓／主题独立，不限制在 NPC 淡色库内。保存六位 #RRGGBB（规范为小写），保留完整 RGB 明暗与饱和度；亮边与控制核心由选色提亮。原机器偏好的预设色仍可读取，打开编辑器时转换成对应色值，显式保存后写入新色值；无效色值阻止保存，服务端独立校验。

`web/voisinage-fields.js`、`voisinage-controls.js` 为程序绘制组件，`voisinage-preview.js` 与 `voisinage-editor.js` 按需加载人物原图集并绘制预览，运行不引用 design。材质320×180，人物及线纹960×540，最高20fps；关闭、后台停止，减弱动态默认暂停。六款控制已采用；十三种场域组件在本轮源码中供编辑器预览，不等于正式战斗动画接入。验证为 `tests/test_ui_preferences.py`、`tests/test_voisinage_appearance.py`、`tests/browser_voisinage_editor.py`，截图与结果在 `build/voisinage-editor/`；本轮不升版打包。

外观复用机器偏好 `pixel_art`，与主题和减弱动态保存在独立 `data/ui_preferences.json`，不新增 `Player`／`GameState` 字段，不迁移结构1–9。浏览器缓存只供首绘，服务器偏好为权威。版本按 `alpha.N` → `beta.N` → `rc.N` → 正式版比较，兼容2.x结构10存档码并拒绝未来版本；Windows数字版本3.0.0.0，显示版本为完整预发布名。

新背包移动原按钮节点，切回归还，不重写业务处理器。地图与建筑沿原目录和行程入口。清单仅开启新版时获取一次，图片按需加载，有界缓存，不做重试轮询、游戏 RNG、年度扫描或时间结算。普通战报播放时最多20fps，结束或关闭后无动画帧循环；后台暂停，切回旧界面立即销毁播放器。
