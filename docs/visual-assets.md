# 可选像素界面与素材

本体 v3.0.0-alpha.1，存档结构仍为10。设置和外观窗口的“启用新版界面”默认关闭；关闭保留四套文字主题、原背包与旧节点地图，开启后采用批准的 C「山海图志」。本轮不接入战斗动画。

## 呈现范围

- 主界面以批准的“山河常在”样稿为依据：电脑端所在地绘景与原常用行动并排，地域可直接点选浏览，当地建筑直达原事件；不叠人物。手机与 Android 横竖屏将绘景收进左侧默认关闭的抽屉，首屏行动不下移。电脑事件放在右侧行动区，保留顶部状态和绘景中心；手机仍用原事件入口。
- 头像与人物详情采用同一身份匹配：普通人族道修、明确男女。详情立绘位于姓名／境界右侧，属性通栏。宿身、附身、变化形态及未覆盖身份不套普通人物；缺图回退文字。
- 立绘只额外显示真实本命法宝，不根据背包或镶材改变衣装；不编造装备栏。独立本命页采用真实物品／炼器形制，保留原无限槽位和镶嵌按钮。
- 新行囊为桌面分类／网格／详情三栏，手机网格与详情窗；分类、搜索、排序不写档。同名炼器实例按原唯一物品ID区分。普通随身装备沿原规则生效，只有原神机提供装备／卸下操作。
- 十一界绘景用于主页，不替换原3D／平面节点地图、路线及势力界面。地理标注采用新锚点，不沿用旧3D坐标。绘景使用最近邻像素采样，只有全幅适配与0.5／1／2倍有限档位，不提供无级放大；文字独立显示且避让工具栏。地域下拉保留全部公开地点。浏览远方不移动、不推进时间；行程与势力按钮进入原节点地图及原行程、危险确认、耗时和事件限制。
- 绘图中的屋顶是固定地理概念，不是可摧毁实体；实时建筑、遗址及产权以原详情为准。未知界面、失落空间及裂缝不默认为人界。

## 素材合同

运行素材随源码、Windows 内容与 Android 离线资源打包，不依赖被忽略的 design 原稿、网络服务或 CDN。

| 内容 | 运行位置与规范 |
| --- | --- |
| 人物 | `web/assets/pixel/v1/`，男女各图集与头像；384×384 RGBA，16个96×96姿态，脚锚(48,84)，静态站姿；二值透明、最近邻整数倍 |
| 物品 | 共807幅32×32 RGBA图标：本体目录 `web/assets/pixel/v2/icons/` 为482幅，归墟扩展独立管理325幅；1165个精确映射，加形制、灵植和材料定义映射 |
| 地理 | `web/assets/pixel/v2/maps/`，十一界768×576逻辑像素；标注坐标为百分比 |
| 清单 | `content/visual_assets.json`，稳定语义ID、尺寸、SHA256、归属与地点锚点；不复制玩法数值、路线或状态 |

人物规范化登记在v1的 `provenance.json`，重导入口 `scripts/prepare_pixel_assets.py`；物品和十一界机械提升入口 `scripts/prepare_visual_release.py`，仅有原稿时使用，不是启动／打包步骤。按钮采用随源码许可的 Lucide 子集。

## DLC 分离

`cultivation_life/visual_assets.py` 按实际扩展加载报告过滤清单，不以角色所在界推断 DLC。十一界地理属本体，关闭妖修／鬼修／修罗玩法不删除相应地图。

DLC 独占素材应放 `dlc/<package>/assets/visual/`，清单登记 `requires`，经 `/extension-assets/<package-id>/...` 校验读取。关闭／移除 DLC 后清单不包含它，直接请求也返回404；路径不能逃出该包 `assets` 目录。共享本体素材不因 DLC 引用变为独占。

归墟物品虽在本体定义表中，宝池的 `exclusive_source` 仍是专属来源的权威声明，不能只按 JSON 所在目录认定素材归属。当前440个映射按归墟资格过滤，其中325幅独占图稿位于归墟 DLC，真正共用的本体图形留在本体。归墟资源包版本为2.7.1，不改变副本、宝池和已获物品规则。

关闭扩展后不加载专属图稿，已获物品不删除；图标回退本体中性类型。未专绘的其他 DLC 物品也用中性图形，不根据名字擅自认定所有权。实际关闭、移除与启用均由原加载报告控制。

## 状态与性能

外观复用机器偏好 `pixel_art`，与主题和减弱动态保存在独立 `data/ui_preferences.json`，不新增 `Player`／`GameState` 字段，不迁移结构1–9。浏览器缓存只供首绘，服务器偏好为权威。版本按 `alpha.N` → `beta.N` → `rc.N` → 正式版比较，兼容2.x结构10存档码并拒绝未来版本；Windows数字版本3.0.0.0，显示版本为完整预发布名。

新背包移动原按钮节点，切回归还，不重写业务处理器。地图与建筑沿原目录和行程入口。清单仅开启新版时获取一次，图片按需加载，有界缓存，不做帧循环、重试轮询、游戏 RNG、年度扫描或时间结算。

- 最终源码对应 Windows EXE 有／无 DLC 与签名 Android 12 横竖屏原生点击，门禁不借用其他版本证据。实际完成情况以 dist 同版清单为准；源码或浏览器模拟不等同原生验收。
