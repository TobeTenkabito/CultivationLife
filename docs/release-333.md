# v3.3.3 性能与界面发行

2026-11-01。本体3.3.3，Android版本码91。沿用正式包名和签名，仅接受结构11；结构1–10拒绝加载，不迁移、不覆盖。本次没有新增皮肤、玩法或持久字段，不修改用户游玩存档。

## 纳入内容

包含3.3.2之后四批已完成的优化，具体实现、原始测量和限制见[项目诊断](project-diagnosis.md)：

- HTTP游戏响应在原准备和保存后生成不可变JSON字节；商队商品目录按实际经营需要加载，组织订单保持完整目录。
- 市场篮子仅在同一次结算内复用配方；内容引用查询及存档摘要减少重复计算，摘要每次仍校验完整文件内容。
- 模型解码与视图快照采用保持独立memo、共享引用和环语义的纯数据复制，扩展类型保留原回退。
- 八类经过审阅的目录、机器偏好、已提交摘要和账户读取可在长行动期间独立返回；游戏GET、写入、Debug及资格判断仍沿原事务。Windows文件读取与原子替换使用统一短锁。
- 著经立道入口、导航和操作按钮采用墨紫书卷与金色书脊样式，覆盖新版浅暗主题及原有主题。

不承诺所有操作同步提速：长行动中的独立读取降低排队，但模拟、完整游戏读取及写入仍可能等待原事务；并发读取也会占用CPU与I/O。原年度、RNG、资格、资源、保存和失败回滚顺序保持。

发行预检修复此前已记录的两项检查问题：Debug能力表补齐四个原有接口的类型参数、闭合创法Schema与原规则调用，保持DLC及修订号检查，不开放任意载荷转发；逐出模板NPC测试改为读取原释放入口使用的notable名册，继续验证重复整理、亲疏及唯一归属。人物迁移及生命周期规则没有变化。

## 发行验收

使用`python scripts/verify_scoped_release.py --profile performance --shards 2 --workers 2`，覆盖四批优化、存读档、事务、经济、身魂、Debug、著经界面、教程和必要跨界上游，不执行全仓回归。包括三个工程检查、真实事件恢复、四组优化浏览器专项、著经操作及原教程四种布局实践。

Windows以最终EXE在有／无DLC隔离目录运行教程、百科及真实创法、刻录、升级、继承或禁用拒绝。签名Android12模拟器以同一最终APK执行教程及著经原生阶段的横竖屏验收，包含真实触摸、输入法、保存和重载。没有实体手机验收声明。

入口为`verify_release_exe.py --tutorial --performance`、`verify_android_scoped.py emulator-5580 --tutorial --performance`与`package_scoped_release.py`。最终测试数量、状态、源码和产物哈希以`dist/release-3.3.3.json`及`dist/release-3.3.3-android.91.json`为准；旧版性能报告只说明优化来源，不代替本次最终代码及成品验收。
