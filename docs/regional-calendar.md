# 地区历法与远行续程

本体 v2.16.0，结构 10。原始游玩存档不参与测试或补丁修写。

## 权威状态与时钟

`GameState.world_simulation` 保存十一界的结算年、商盟年度标记、独立随机状态、人物年度标记及最近十六次同步区间。首次真实年度推进从该年的上一年采用；原结构 10 存档不会倒算采用之前的历史，不复活已经死亡的人物或重建已经灭亡的宗门。

当前界面每年结算。未被任务依赖的其他界面，经济、人物寿数、事故、招新、截杀、归墟和 NPC 刑期一起冻结。首次需要时按历史年份逐年调用原经营、真实采购与招新资格、寿元和死亡入口；不能只推进风险而留下零府库。资金仍来自原市场经营与账户转移，库存、组织、NPC 均保持唯一实体。

地区视图只投射结算年份，不改玩家界面、地点、年龄或背包。`world_simulation` 为全局字段；`map_journey` 为行程会话字段，人工登记在跨界合同中。

## 跨界与远程行为

跨界移动先同步出入两端，再走原移动入口。跨界商队、维护、战争与远征、远程委托继续使用原任务状态和原结算标记；相关地区先追平当前年，之后才处理物资与人物变更。发布远程委托、新建商路和诸天任务也建立这一边界，预览不推进时钟。人物年度标记避免原 NPC 飞升后在目的地再加一岁。

这一版采用保守依赖：人界与 NPC 可自动飞升的目的界面联动，已有跨界商盟路线的端点联动；家族、亲近人物、已建立的上界机构和诸天研究联系可能保持远方地区运行。故**不保证任何时候只计算一个界面**。连接越密、任务越多，可冻结范围越小；独立地区返界仍可能需要等待补算。新开跨界研究任务目前先同步全部正常界面，避免新联系改写已结算的过去。

普通外界年度中，已启用诸天自主发现或仍有同勘任务时，人界原居民社会也保持运行，保证先结算其年龄、生死与经营，再筛选探访者；不能从冻结的人物历史中直接派出一名未衰老的居民。

本地外交随机事件若选中冻结地区，先补算该地区再检查现存宗门；NPC 新势力的排挤检查同理。领地仍使用原行动期末费用入口，只结算已追平地区；冻结期间的费用跨度留到该地区下次期末结算，不凭空重演行动单位。原区域 RNG 保留，未模拟事件不靠随机补钱代替。

遗址／镜律同勘保留原双时钟例外：赴约阶段仅由普通外界年度推进，内部研究仅由玩家所在的同一空间年度推进；通用远程年历不把空间年算作赴约年。责任入口为 `engine/composition/heavens_missions.py`，针对性验收见 `tests/test_heavens_survey.py::test_outbound_cancellation_after_location_change` 及镜律同勘测试。普通商队、远征与外部托运不采用这一空间玩法例外。

同勘原居民退出空间时，由 `engine/composition/heavens_survey.py` 先追平人界，再迁移同一个人物，避免将其空间经历再次计入人界的旧年份。`test_returned_original_resident_is_not_aged_by_destination_catchup` 验证真实往返后，零耗时离场不再额外增龄。

外层串行命令拥有工作状态和原子存档提交，补算每年不再复制全游戏；原有需要写时复制的命令仍只复制一次。失败命令清掉请求内未提交缓存，重新加载最后落盘状态。地区时钟与业务收据一起写入同一存档；重复同步同一年不再次扣款、发货、招人或执行死亡。

## 远行与其他修复

地图路线保存起点、终点、路线、总年数与已走年数。通知在末年出现也先处理事件，随后零年完成抵达，不重复耗时。继续前往同一目的地仅计算余程；改选目的地重新计算，发生跨界、死亡或所在地址变化使旧路线失效。归墟公告保留，历史补算不弹出已经过时的通知。列表和地图详情沿原按钮显示续程。

纳妾提议筛选与提交均排除已有师徒、道侣、道友、侍妾、控制和后代关系。化神破界 `EVT_SPIRIT_CROSSING_003` 使用 `combat_ratio >= 1.3`，其他路线和法阵资格不变。

## 验收与复现

`tests/test_regional_calendar.py` 覆盖真实逐年对照、未到访宗门收入与招新、死亡、故障回滚、状态校验和无逐年整存档复制；`tests/test_regional_integration.py` 覆盖完整远征、商队、战争、委托、重载与不同哈希种子的新进程。`tests/test_travel_relationship_2160.py` 及 `tests/browser_regional_calendar.py` 使用真实通知提交与续行。

运行 `python tools/benchmark_regional_calendar.py --years 100 --repeats 3` 生成 `build/regional-calendar-performance/report.json`。对照使用相同初始状态与生产年度入口，比较全界持续结算和冻结后补算。比较包含全部实际人物、物资、财政及 RNG；只规范化无关界面历史的写入顺序、跨区域归墟宝物目录顺序，忽略全局限长流水缓存和同步诊断次数，不忽略账面余额或库存。全局任务均沿原日历，不替换战斗胜负。

发行入口 `python scripts/verify_scoped_release.py --profile regional`，之后使用既有 Windows EXE 和签名 Android 原生验收、`package_scoped_release.py`。最终数值与执行范围以匹配最终输入摘要的发行清单为准；未进行实体手机测试。

v2.16.0 最终源码的三轮百年集成对照：全界持续结算中位数 40.11 秒，冻结方案离界推进 23.94 秒、重入测试上界补算 10.81 秒；三轮完整状态比较、重复同步和重载均通过。这是本机合成夹具的测量，已等待本次其他验收进程退出后单独运行，不代表所有存档或设备的耗时。该场景七个关联下界保持运行，四个上界冻结；并未以停止远程任务取得提速。返界计时仅包括进入的仙界；全状态比较前另行同步其他冻结地区，这部分校验准备不计入单次返界时间。样本中五个灵界宗门各新增 19–20 名门人，死亡仍真实结算；远征原有 120 份物资按源地、目标、在途、消耗和损失守恒，委托完成。

旧回归中的两项预期随本版时序调整：玩家个人死亡／事件不能跳过已经流逝的一年远程结算；玩家在裂缝中也不能冻结外界已派出的承运人。对应测试继续检查未接触情报不公开、原材料唯一归属和真实费用。旧拍卖用例改为选择合法场次档位，资金守恒断言不变。
