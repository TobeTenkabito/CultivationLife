# 修罗王庭

> 维护基线：本体 v1.58.0，2026-10-04。存档结构 8，支持 6→7→8；文中“旧档补全”仅适用于允许加载的结构。文件名编号仅用于保持链接。

王庭爵位、常规政务和血战属于本体。派系平衡与王权贡赋需要修罗 DLC。到修罗界第九阶后，在万战魔城登记效力；不占宗门身份。

## 爵位与换位

效命者是无固定席位的廷臣，以上依次为战将、封侯、战公、摄政辅臣、修罗王，五个席位分别保存真实 NPC 或玩家的身份。初始七位人物可在其他人物界面交往，其修为、伤势、生死和离界状态与王庭共用。

功勋受封沿用累计功绩、境界、恩宠门槛，最后一级需累计三千功绩、第十一阶、恩宠一百；受封时原任降至玩家原席位。也可绕过功勋要求，挑战唯一的上一级爵位。血战由实际战斗系统结算，使用功法、魔域、阵法、傀儡和同行者，排除对方本人充当玩家队友。失去战意或被镇压视为认负，败者负伤且保留性命。胜负未分时不换位。

主动血战间隔两个本界政历单位。初次加入、换位和已经分出胜负的血战后有八单位保护。NPC 每四单位评估一次下级争位机会：挑战者为紧邻下一级的持爵者；玩家为战将时，从未占席的廷臣中选最强者。评估包含修为战力、装备增益、伤势、随行战力、元力储备、护体与魔域；至少具备约十五个百分点优势才有机会发战书，忠诚高则更谨慎。

全局战书间隔至少十二单位，同一人间隔至少二十四单位，且每次合格评估只有四分之一机会发起。战书显示在王庭和纪事，不占用事件；须在发出后的第四单位结束前回王庭应战或让位，超过期限按让位处理。事件、劫战和囚禁期间不新发战书。人物死亡、离界或失去对应身份后战书失效。

退出王庭会放弃爵位；重新登记从效命者开始，功勋保留。已有战书必须先应战或让位，不能退出规避。失去王位后立即失去内政权限。

## 王权与内政

修罗王可直接施行政令，不再消耗请奏功勋。每次更替间隔四单位，支出府库十二万灵石。征战、养域、赐禄、通商、休养、战赋、招贤七令同一时刻仅一道生效，玩家在位时不会自动覆盖；NPC 在位恢复定期议政。

府库总管、掌军使、养域使由在世廷臣担任，爵位与官职分开，一人只能任一官职。各人三类才干固定，随修为适度提升，不因刷新变化。任命花费六万府库灵石，每人每单位官俸三万，每单位只能调整一职。

| 官职 | 实际效果 |
| --- | --- |
| 府库总管 | 单位府库收入增加才干值 × 0.2% |
| 掌军使 | 新接委托功勋增加才干值 × 0.2% |
| 养域使 | 本体邻域的机缘与灵石培养费用减少才干值 × 0.1% |

万战互市每级增加一成府库收入，血战武院每级增加一成新委托功勋，养域坛每级额外减免三个百分点本体邻域费用。三类营建上限三级，一次一项，工期四单位，逐级支出四十／八十／一百二十万府库灵石。培养总折扣最高六成。

开仓安抚消耗二十四万、民心增加十五；征收战赋增加三十万、民心减少十五，需民心至少四十；犒赏群臣消耗二十万，使在世廷臣忠诚增加十二。三项决策共享四单位冷却。

府库基础收入六十万／单位，乘以官职、建筑、民心和当前政策系数，随后支付官俸与玩家俸禄。民心五十时无额外修正，零至一百对应收入倍率 0.75 至 1.25。所有结算只随本界实际时间发生；读取界面不发俸禄、不掷挑战、不刷新才干。

## 存档与发行

旧档保留功勋、累计功绩、在位爵位与已有人物记录，补入缺少的廷臣，已死人物不会复活。旧档摄政辅臣保持四阶，修罗王是新增第五阶。王庭账簿继续存入 `upper_institutions.asura.court`，当前随结构 7 保存，支持结构 6 迁移；这里的字段补全不代表支持结构 1–5。

本体包含全部王庭玩法，八个官方 DLC 可选加载。Windows 与 Android 共用规则，六主题保留独立布局与五页签。当前发行版本见根 README；发行包及验收范围见当前发行清单。

## DLC 派系与贡赋

政令按政治、外交、军事显示，没有对应内容的分类保留空位。DLC 开启后有血裔诸族、征伐军府、万战城盟三派，影响力总额 100，单派 5–70，初始忠诚 60。当前政令每个政历单位使受益派影响力增加 1.5、忠诚增加 1，其他派忠诚减少 0.4。影响力达到 48 或忠诚低于 20 持续四单位，会在既有保护期、战书冷却和人物资格允许时，由实际廷臣代表发起王位血战。复用原战斗与换位流程，不按随机数字直接剥夺王位。

在位王可花十万府库灵石定向扶植、调停、削权，间隔四单位。王权贡赋包括本界普通物品、炼器材料和阵材，以及要求同界自由修士贡献自身修行积累或押献弱者。对应人物扣除真实积累；俘虏通过既有拘禁契约移入持有者名册，保留 NPC ID 与生存状态。灵石每次一百万，其他资材每次一份。同一贡赋间隔四单位，每次降低对应派系忠诚六点；人物献贡还降低好感五点。资源白名单不包含其他 DLC 及独立空间专属产物。

Agent 使用 `upper institution faction_decree restrain:blood_clans`、`upper institution royal_tribute material:spirit_stone`；人物与其他资材 ID 从 `game view /upper_institution/court` 读取。关闭 DLC 后隐藏并拒绝这些操作，保存的派系状态保留。
