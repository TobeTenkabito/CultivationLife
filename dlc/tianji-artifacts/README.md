# 神机百变：巧夺天工

当前扩展版本 **2.2.0**，本体维护基线 v1.57.0 开发源码，2026-10-04。存档结构 8 支持 6→7→8；版本与默认启用状态见 [manifest.json](manifest.json)。

提供十一界神机榜、情报揭示、动态材料、仿制和重铸。自炼器物可动态入榜；神机原始榜值与后续培养增益分开记录。能力采用有限规则定义，不执行内容脚本。

实现位于 `cultivation_life/system/tianji/`，按六组具名依赖连接引擎，旧 `tianji_system.py` 保留独立消费者接口和静态辅助。引擎不再继承神机 Mixin。跨界、情报、持有登记与战斗投影仍应使用同一来源，不能因展示重复生成词条。

扩展开关在重启后生效，以实际加载状态为准；新规则须通过内容校验、相关系统测试及 [依赖检查](../../tools/check_module_dependencies.py)。
