# 妖修血脉 DLC V4.8.0

V4.8.0 新增结丹血丹快速开局：启用 DLC 时直接生成本源血脉，并配置妖丹、炼体功法与同境资粮；关闭后由本体兼容模板接管。V4.7.2 的血脉入口专属朱砂配色继续保留。

本内容包在本体通用扩展接口上提供妖修专属玩法：

- 蛇、禽、猿、狐、龟甲、虫、水族、草木精怪八大本源谱系；
- 200 个不可逆进化节点，八族均拥有从凡人境延伸至大罗境的完整生命路线；
- 常规进化保证每次突破都有稳定后继，特殊分支再由妖气、环境适应与血脉印记解锁；
- 妖界、幻冥界与幽冥界共四十一处地图，十八个政治种族与九座宗门；
- 十二部妖族功法、二十三类妖族物品及三界通用事件；
- 高阶妖功的炼体层数门槛；
- 妖修三倍寿命和 1.5 倍炼体修炼速度。

V2 为妖界与幻冥界各新增八处地域，两界共计二十四处可探索地点。寒域、火域、月华、荒漠、幻境、虫巢、界树和深海等生态会直接积累对应的环境适应，参与后续进化判定；九尾远祖、玄武遗脉、群心律核、鲲属异血与界树祖液等机缘印记则解锁特殊进化。

V3 开放幽冥界与祖庭体系。八个基础族群在大乘圆满后均可选择两类高阶生命道路：持对应祖血印记并将妖气修至二十级，可进入“真灵返祖”支系；也可拒绝祖先定义，进入无前置门槛的“自成血脉”支系。两条路线都完整覆盖真仙、金仙、太乙与大罗四阶，并保证每一阶都有不会卡死存档的稳定后继。

V4 将自成血脉细化为立祖、固谱、衍法、定祖四阶段。选择自成路线时先进入独立编辑器：系统只从固定立祖根基、白名单特殊进化、封顶渡劫里程碑和明确剧情记录结算功业点，年龄、财富、声望、当前境界、适应与印记均不能刷点。规则由时点、轮次、条件、敌我整体目标、效果和固定档位组成，不接受脚本；频率越高成本越高，条件越苛刻成本越低。编辑器会在每次修改后实时显示完整自然语言描述、当前费用、剩余血脉点数与不合法原因。已经确认的名称和规则不可重置，后续阶段只能追加；未用功业点会保留。V3 已进入自成路线的存档提供一次“补刻祖血”，槽位按当前阶段开放。

V4.1 在扩展加载阶段完整校验时点、轮次计划、条件、目标、效果、档位、槽位与功业定义；非法组合会让该 DLC 拒绝加载并在扩展状态中报告原因。玩家立祖后同时写入稳定的 `monster_custom_lineage_id`。后代可从父母已定型的自创祖血中继承一条，沿用相同 ID 与规则副本，不重新支付功业点，也不进行复杂混血计算。

V4.1.1 将独立血脉特质由 9 种扩充至 17 种。八大本源谱系各自在筑基层次解锁一种永久种族特质：蛇属蟠身锁域、羽属罡羽破界、猿属反震战筋、狐属梦瞳摄魄、龟甲属应击灵甲、虫属万象复眼、水族潮脉回环、草木精怪地脉扎根。种族特质与进化节点原有特质合并生效，后续进化不会丢失；其注册表及战斗钩子仍与变化术完全分离。

V4.2 为八个本源族群分别增加 16 项独立随机觉醒血脉库，共 128 项。DLC 启用时，每次成功完成大境界进化都会从当前本源族群尚未拥有的条目中随机取得一项，并作为永久本体特质保存；不会跨族抽取或重复抽取。当前从凡境修至大罗最多经历 12 次大境界进化，因此每族抵达幽冥界后仍有余量，达到现有境界上限时也至少保留 4 项未觉醒特质。族群库采用可校验的数据配置，缺族、跨族引用、重复项或数量不足会阻止 DLC 加载。

V4.3 将后续大境界觉醒升级为有限复合族血生成器。每项特质从五个结算时点、五种轮次计划、十八种条件与四十个固定效果档位中受约束组合，允许境界关系、先手、态势、法力、战意、地形、禁制、神识压制和本轮伤害共同参与判定。规则获得时固化并保存，不会进战后重随机；旧存档的固定池特质仍按原效果兼容。生成阶段执行语义时序检查、单项强度预算、整套叠加限制，战斗阶段再执行总增减伤、属性和恢复封顶。完整验收口径见 `BLOODLINE_RULES.md`。

V4.4 新增妖修专属八幕原创剧情链“祖山现世”。合体期妖修会遇见重现世间的百族祖山：八大族群为争夺第一祖名而冲突，祖火却在胜者献祭中不断衰弱。玩家可追查祖壁、联合年轻妖修、阻止百族围山，并揭开无相妖祖借最强血脉反复夺舍的真相。终局可取得祖火灯或万兽骨印。事件、奖励物品与两场专属战斗场景均封装在 DLC 内，关闭 DLC 后不会进入本体事件池。

V4.6 为“无名祖城”原创长篇剧情补充“百族立碑”成就；V4.5 的“返祖现象”“物种起源”“光耀门楣”三项成长成就继续保留。妖界与幻冥界货池同时补入五卷妖阙骨书，供不依赖血脉直升规则的通用五行补根流程使用；内容仍随 DLC 独立启停。

V4.7 为妖界新增虎啸天崖、蟠龙泽、赤蚁王丘、月泉古林，为幻冥界新增倒悬天林、兽魂灯城、空月裂谷、蜃骨原；八处地域均加入既有连通图并随本 DLC 独立启停，幽冥界暂不扩展。

V4.7.1 为妖界补入本体 v1.16.0 的界面雷劫基础威力上限；高阶妖修下界时同样受妖界法则约束，但角色自身累计雷威不会被改写。

幽冥界新增龙源祖海、元凤涅槃原、初梦祖庭、万虫星巢、玄武负界与无祖新生荒六处地域，并与三处本体幽冥地图组成完整路网；太初真灵殿、自脉万祖阁与界树根庭分别承载返祖、自创和共生道路。妖界与幻冥界的大乘妖修都能通过血脉进化飞升幽冥界；飞升后可选择逆行妖界或幻冥界，真灵道果临时封印至大乘九层，返回幽冥界时完整恢复。

妖修与道侣诞生后代时，后代会继承本源族群与基础形态，并有概率继承父母已经取得的血脉印记，也可继承父方或母方的一条自创祖血。其凡俗寿命同样执行妖修三倍规则。妖界与幻冥界现在也分别出售筑基至大乘各境界的境界内突破丹药，这些丹药只辅助小境界冲关，不替代不可逆的血脉进化；妖界、幻冥界与幽冥界另有各自的孕育丹药，内容随 DLC 一同启停。

妖界与幻冥界从凡人境起即可执行寻幽探宝，并各自提供法器、功法、丹药三类本界奖励。妖修依靠血脉本体完成生命形态变化，因此变化术对妖修完全禁用；旧存档即使残留变化术配置，也不会再获得对应战斗加成。

关闭或移除本 DLC 后，既有存档中的血脉、环境适应、机缘印记与进化进度会原样冻结，不会丢失；妖修仍可按本体规则正常突破，并在每次成功突破大境界后从 16 项较弱的本体通用特质中随机获得一项未拥有特质。重新启用后，血脉体系继续演算，已取得的本体通用特质则冻结且不与血脉效果叠加。

内容数据仍全部位于 `dlc/monster-bloodlines`；本体只提供通用扩展加载、跨界、存档迁移和有限规则解释接口。关闭 DLC 后，V4 的幽冥地图、祖庭、返祖、自成血脉与自创规则都会冻结。
