# 百鬼夜行:轮回往生

《浮生问道》鬼修大型系统 DLC，版本 1.0.0。

启用后，鬼修不再因寿元耗尽而坐化，而会在每个完整游戏时间单位结束时承受魂蚀。魂蚀永久削减角色自身的 Intrinsic HP/MP，并同步降低魂魄对功法、物品、宗门与本命法宝等 External HP/MP 加成的承载率；任一本体魂基低于 1 时立即魂飞魄散。

抵达大境界最终瓶颈后，鬼修可以放弃当前修为、回到练气一层并留下该境界的轮回印记。高境界印记会覆盖此前走过的低境界道路，每枚有效印记为对应大小境界突破增加 5 个百分点，最终可以达到 100%。历史最高修为单独保存，重复走过旧境界不会再次获得 Intrinsic 成长。

每次成功推进一个修为层级都会获得 1 点往生，包括轮回后重复走过的层级。消耗 2 点往生可令当前魂蚀率降低 0.02 个百分点，但不会修复已经失去的魂基；再次轮回时，未使用的往生全部散失。

关闭 DLC 后，魂蚀、轮回印记、往生与历史最高修为数据都会冻结而不删除；鬼修恢复本体常规寿元、属性和突破规则。再次启用后从冻结状态继续。
