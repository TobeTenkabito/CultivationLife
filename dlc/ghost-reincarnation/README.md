# 百鬼夜行:轮回往生

《浮生问道》鬼修大型系统 DLC，版本 3.0.0。

V3 第二阶段完整加入百鬼夜行、拘魂与三魂七魄、魂性、魂压、主动附灵、败亡受制和夺舍。百鬼夜行提前两个游戏时间单位预告并标记地图，活动中的魂魄沿用 NPC 身份数据；拘魂后仍永久保留其姓名、性格、境界、战力、魂性、魂压与原始身份。十个魂位功能固定，数值使用带硬上限的饱和曲线，魂压只提高未来魂蚀率增长。左侧“魂魄”在随机及剧情事件中保持可操作，允许即时换魂。

主动附灵保留自由移动和离器能力，以降低修炼效率换取更慢的魂蚀增长。败给合适 NPC 的鬼修可能进入受制状态，随主人移动并作为附庸自动参战；此时只能等待、有限修炼、反抗或夺舍主人，失败会进入正常 Game Over，绝不发放轮回印记。

本体 v1.3.0 提供 `GhostCore + OptionalHostBody` 夺舍模型，入口位于既有俘虏界面。默认每局只可成功夺舍一次，不可夺舍更高境或非人形目标；高级鬼功可增加一次或忽略限制。寄身后当前姓名显示为“宿主（原鬼修）”，宿主灵根、修为、炼体与寿元生效，而本魂的魂蚀、往生、轮回印记、最高水位及十魂全部冻结。宿主死亡、寿尽或主动离舍会毁去肉身并恢复冻结前的本魂，已用次数不返还，原 NPC 不复活。

启用后，鬼修不再因寿元耗尽而坐化，而会在每个完整游戏时间单位结束时承受魂蚀。普通行动、旅行、服刑与灵田等全部耗时来源共享同一条持久化计时进度，只累计实际经过年份；未满当前境界 `time_unit` 不会向上取整结算。魂蚀永久削减角色自身的 Intrinsic HP/MP，并同步降低魂魄对功法、物品、宗门与本命法宝等 External HP/MP 加成的承载率；任一本体魂基低于 1 时立即魂飞魄散。

抵达大境界最终瓶颈后，鬼修可以放弃当前修为、回到练气一层并留下该境界的轮回印记。高境界印记会覆盖此前走过的低境界道路，每枚有效印记为对应大小境界突破增加 5 个百分点；轮回经验本身不封顶，可以累计显示到 10000% 及更高，但所有突破的最终有效概率统一封顶 98%。历史最高修为单独保存，重复走过旧境界不会再次获得 Intrinsic 成长。

每次成功推进一个修为层级都会获得 1 点往生，包括轮回后重复走过的层级。消耗 2 点往生可令当前魂蚀率降低 0.02 个百分点，但不会修复已经失去的魂基；V2 支持一次尽数消耗所有可用往生。再次轮回时，未使用的往生全部散失。

V2 已完成魂基与外物承载明细、全境界轮回印记册、执行前精确预览、一键尽数往生、永久本源成长接口，以及再世为魂、十世归途、残灯不灭、往生有数四项 DLC 成就。鬼修突破丹在界面、物品接口和概率层全部禁用。所有新增展示和里程碑均复用既有存档对象，不建立第二套角色存档。

关闭 DLC 后，魂蚀、轮回印记、往生与历史最高修为数据都会冻结而不删除；鬼修恢复本体常规寿元、属性和突破规则。再次启用后从冻结状态继续，并只对关闭期间合法获得的新历史高度、炼体和永久本源成长进行一次性补记，不追溯结算魂蚀。
