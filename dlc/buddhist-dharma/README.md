# 诸法无我：众生为镜 v1.0.0

面向本体 v1.42.0 的独立佛修玩法包，无其他 DLC 依赖。新旧佛修存档开启后均可从侧栏「佛 / 弘法」进入。Windows A 风格优先适配。

## 弘法与香火

选择任意已学功法主持三场法会：开坛、论法、结会，每场消耗当前境界的一个行动间隔。功法等级为主要评价依据，品阶只有小幅加成。每场出现普通事件，进度、已选事件及随机状态随存档保存；重开界面不会重抽事件。遇到天劫等其他事件时，处理后可继续剩余时间。切磋失败不会导致玩家死亡。

当前境界、有效威名、此地信众及寺庙影响到场人数。原始因果与煞气提高问难概率、辩论难度、切磋对手强度，并压低最终评价。成果分大成、成功、平稳与失利四档。未结束的法会限制其他主动行动，也可在事件间隙提前散会并按失利结算。

地方宗门与家族分别决定许可。自身所属势力、联盟或依附关系可豁免；其余势力可分别付费获准。未缴纳仍能开坛，但各势力可能压低成果、驱散部分信众或清理至寺庙保底，甚至发布地方通缉；此类通缉不受威名庇护保护。

信众和寺庙按界面、地图分别保存。寺庙0–3级，年衰减率分别10%、7%、5%、3%，保底信众分别0、20、80、200。一级界面升建费用分别1500、6000、24000灵石；每升一个界面等级费用乘20。三级寺庙每年贡献少量业力。离开的界面仍衰减信众，但不向玩家输送个人收益。

## 业力和加持

业力范围为 −100 至 +100，与原始因果、煞气独立。日常有效因果与煞气为0，有效威名为原始威名＋原始因果＋原始煞气；原始资源仍保存，用于法会风险与净化。

正业力最多启用三项本界加持：坊市/黑市购买八折、商盟新委托耗时八折并向上取整、本命法宝手动温养八折、按境界领取年度灵石、年度净化因果、年度净化煞气。拍卖和卖出价格不打折。加持消耗业力，信众以递减收益降低开支，最低保留原开支20%；不额外惩罚多项选择。业力耗尽会清空选择，恢复后需重新启用。

每年依次结算信众衰减/寺庙保底、本界信众与三级寺庙业力、加持开支、施舍、因果/煞气净化、边界与庇护宽限。信众收益采用对数曲线，单年信众业力最多4点；异界加持暂停。

负业力不额外削减六维，反而线性增强玩家六维，−100时为+20%，不会给同队修士额外加成。业力低于−25禁止继续弘法；跌破时获得五个行动单位宽限，之后取消仅针对「威名过高」的新追杀庇护。恢复至−25即可重新获得庇护，不清除既有通缉、恩怨、战争或剧情后果。

## 双路线

人界飞升时，灵气经验不少于阴气经验则选择灵界，否则选择地狱界。随后可从灵界飞升仙界，或从地狱界飞升轮回界；不增加地狱界开局。保留人界偷渡机会、化神门槛，以及大乘九层圆满机缘和九重渡劫判定。全程保持佛修，实际迁移交由本体统一跨界系统处理。

## 存档与实现

全部玩法记录位于 `GameState.buddhist_state`。关闭 DLC 时不推进该容器、不消费加持，也不追补关闭期间的年份。法会已经生成的待决事件在重新开启后原样恢复。通用地图与轮回界承载能力属于本体，DLC 只提供玩法配置、事件和开放路线。

可调参数位于 `content/buddhist_way.json`，事件在 `content/buddhist_events.json`；加载时校验数值、寺庙等级、加持及事件引用。费用、资源投影、六维修正和追杀来源通过本体公共接口接入，既有道统没有散落的佛修分支。未加入策划案留白的第二套佛修系统。
