# 《明争暗斗：合纵连横》

维护基线：本体 v2.11.0，扩展 1.4.0；仅支持存档结构10，结构1–9不转换。

既有性格、执政倾向、修为顺位授职、议席、客卿、招徒和监狱继续保留。新增地方影响：山门固定100、阵保底40、据点保底50；新地须沿己方边界，名额满时先移除对方影响；受限地图禁止新扩张，已有驻地保留。

地图选点办理投放、政策、据点、比试和袭扰，多数表决后生效。设施支付原府库及当地资材，巡守维护按真实年份结算；缺钱收缩，富裕积极争取边界。地区采办帮助原真实生产，地方商路收益来自原运营账户已收费用。

战争可指定退出某地或捣毁据点，后者只需5分；移除山门强制同界安全撤离，解散清除所有影响。宗门、家族和种族同界迁址属于本体，产业、库房及阵留原地，玩家自行旅行。

关扩展冻结地方记录，原府库现金仍由本体经济维护，不重置余额。玩家规则见游戏百科；状态、例外、数值与性能见[地方开发说明](../../docs/territory-development.md)。
