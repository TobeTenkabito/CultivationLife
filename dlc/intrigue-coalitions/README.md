# 《明争暗斗：合纵连横》

小型势力内政 DLC，版本 1.1.1。

启用后为宗门、家族与种族势力加入 NPC 性格、一主偶次性格、四类长期执政倾向、职位、控制权与决策权分离、一人一票重大决议、客卿/供奉/卿族、客卿防御战争义务，以及宗门和家族的实体监狱。

V1.1.0 新增宗门内政决议“扩招徒弟”：可按天灵根、弟子境界、修炼路线、同境战力档位及性别筛选散修。决议通过后生成最多五名候选，玩家可从中任意录取；筛选过严时可能招不满或无人符合。候选人的战力门槛按其自身境界与层数的合理基准计算，修为筛选自动排除已达到宗门决策权门槛的境界。

V1.1.1 允许掌握宗门控制权的玩家从世界人物、人物关系或道友页直接邀请高好感人物及道友担任客卿长老；道友身份本身即具备受邀资格，仍会依据好感和性格决定是否接受。

所有运行状态保存在存档的独立 `intrigue_state` 字段中。关闭 DLC 时该字段原样冻结，本体的原有宗门、家族、种族与抽象监狱逻辑继续工作。
