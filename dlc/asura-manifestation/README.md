# 修罗显圣：无法无天

> 源码维护基线：本体 v1.58.0，2026-10-04；存档结构 8 支持 6→7→8，结构 1–5 不再加载。扩展版本以同目录 manifest.json 为准；旧档字段补全不扩大本体兼容范围。

本体保留修罗界地图、普通魔域、元神炼化名录，以及妖修种属选择。魔修第九至十二阶统一称修罗、非天、罗睺、摩诃。种属身份独立于万妖归宗的血脉增益。

当前扩展版本 v1.2.0，适用本体 v1.58.0。DLC 实际加载且魔修在修罗界达到修罗境后，左侧「煞元、魔躯、魔脉、八部、魔域、神通」分别打开独立系统；扩展入口采用煞元色与菱形标记。基础流程如下：

1. 从「煞元」依次完成引煞入府、洗炼魔元、煞元凝旋、贯通魔窍、煞元归一五个事件。
2. 在「御傀」中将已炼化元神提纯为精魂；原名录条目消耗，每阶元神产出10精魂。
3. 凡躯炼体100层后，从「魔躯」以机缘锻炼修罗之躯至20层；在「八部」凝练肉身。凝练俘虏或傀儡须其自身普通炼体至少60/100层（与玩家修罗之躯分开判定），消耗 `30 + 炼体层数` 精魂。
4. 选择凝练肉身发动融合战。禁止双方逃跑，无战斗轮数上限，战斗现场可保存、读档、继续。镇压或击杀所有肉身后继承其100%炼体战力，不继承原装备、功法或邻域战力。本命永久唯一。

| 本命 | 自动匹配条件 | 培养部位 |
|---|---|---|
| 天 | 一具道修或佛修肉身，或天人像傀儡 | 天相 |
| 龙 | 一具水族妖身、龙形血脉／龙类真灵肉身，或龙形傀儡 | 龙躯 |
| 夜叉 | 一具魔修肉身，或夜叉形傀儡 | 夜叉战躯 |
| 乾达婆 | 一具草木精怪肉身，或灵木形傀儡 | 香音身 |
| 摩睺罗 | 一具蛇属妖身或蛇形傀儡；龙形血脉优先归龙部 | 巨蟒身 |
| 紧那罗 | 一具狐属或猿属妖身，或乐伎形傀儡 | 合鸣身 |
| 迦楼罗 | 一具羽属妖身、鸟类真灵肉身，或鸟形傀儡 | 双翼 |
| 阿修罗 | 任意两具合格肉身，允许机关傀儡 | 三头六臂 |

这些是游戏适配条件，不是宗教文献中的入道规范。乾达婆与紧那罗采用天界乐神意象，龙部采用水神意象，夜叉采用护卫意象；狐、猿、草木以及道途限制用于映射现有角色数据。文化参考：[奈良国立博物馆乾达婆藏品说明](https://emuseum.nich.go.jp/detail?content_base_id=100247&content_part_id=2&content_pict_id=0&langId=en&webView=)、[大都会博物馆乾达婆](https://www.metmuseum.org/art/collection/search/38142)、[鲁宾博物馆龙众图谱](https://rubinmuseum.org/collection/c2003-10-1/)、[紧那罗王经与音乐研究](https://edizionicafoscari.unive.it/media/pdf/books/978-88-6969-528-5/978-88-6969-528-5-ch-09.pdf)。

八部本体和分支各最高9级。本体5级且达到非天境后可选择唯一分支。每部3个分支在开局时以独立种子流生成，旧存档首次启用时补齐，同种子结果相同，不消耗世界事件随机数。分支规则按路线偏好抽取；神通无路线偏好，每次获取消耗100精魂。洗练一次重掷全部未锁定属性，可锁定已有属性；成本为100精魂乘以2的锁定条数次方，不随历史洗练次数增加。全锁定或精魂不足时拒绝洗练。槽位随本体等级为1、1、2、2、3、4、4、5、6。本体2、4、7级及分支1、4、7级解锁条件效果。

魔域使用通用 V3 战斗语义，具备真实条件与战斗阶段判定，同时支持魔域效果和普通交锋效果。威能滋养与培养境界分开记账；培养境界沿用初成、化境、大成、至臻，共13级。

修罗境起机缘储量无上限，封印下界保留储量；炼体每次消耗目标层数 × 6000机缘，四境首层冲关费用为18000／90000／120000／150000，每层增加基础费用的12%。关闭DLC恢复普通上境规则。

魔脉沿用仙脉每层3条、每境27条以及相同成功率、失败保底和本源增益；仙痕成本改用精魂。

| 大境界劫战 | 心魔 | 域外天魔 |
|---|---|---|
| 修罗→非天 | 自身战力100%，无魔域 | 无 |
| 非天→罗睺 | 自身战力100%，有魔域 | 自身战力80%，无魔域 |
| 罗睺→摩诃 | 自身战力150%，有魔域 | 自身战力100%，有魔域 |

劫相同时入场，复制引劫时的六项战斗属性。有魔域者复制玩家实际魔域、条件规则与资源预算，仅培养境界限制为 `min(玩家实际等级, 8)`（化境四层）；不会把较弱魔域提高到上限。劫战双方禁止逃跑，须击杀全部劫相，不以固定轮数判胜。一次请求最多结算24轮，未结束则保存现场继续。

上述成本和最低炼体层数属于本版初始平衡参数，可继续调校；不改变永久本命、分支唯一、全额继承和复制上限规则。


六个修罗系统独立打开、关闭与返回。魔脉采用仙脉式排版，采用三头六臂透视轮廓线稿，左右手、神态与饰品区分明确的魔身图，27 个节点标出实际已开、下一脉与未开状态；六主题分别适配明暗配色。傀儡打造移至本体「造傀」工坊，御傀保留管理与培养。


补齐27条魔脉的费用、概率、失败保底和破境操作；修炼分为五页，八部条件移至百科。凝身要求材料自身普通炼体60/100层，玩家修罗之躯20层是另一个独立门槛。煞元使用赭红配色并显示真实储量。

符合外形的正式机关傀儡现可作为七部的单具材料，双具仍可融合阿修罗；外形与材料炼体成果都会保留到凝身名录。
