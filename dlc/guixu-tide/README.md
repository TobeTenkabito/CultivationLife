# 归墟之潮：九死一生

当前扩展版本 **2.7.1**，配套可选像素界面的本体版本为 v3.0.0-alpha.1。仅支持存档结构10，结构1—9不转换。版本与默认启用状态见[manifest.json](manifest.json)。

2.7.1 仅增补归墟专属图标资源，不改变副本与宝池规则。素材按宝池的 `exclusive_source` 归属管理；关闭扩展后保留已有物品，但不显示、加载专属图标，使用本体中性图标回退。运行资源位于本扩展的 `assets/visual/`，不混入本体素材目录。

十一界各有两座周期副本，共22座，每座四个常规层及一个秘层、60条独立有限宝池，共1320条。新副本的入口全部位于无境界门槛地图；每座仍按自己的入场上限、周期和副本天数执行。原副本位置与历史不变，新副本不复制任何旧会话、NPC或已消耗宝物。

探索、争夺、组队、交涉、闭门被困及苦修脱困复用原归墟入口。状态保存在原 GameState.guixu_state，以副本ID分开；关闭扩展安全结束当前会话并保留周期与宝池。本体地图、已获通用奖品保留。

完整边界见[归墟规格](../../docs/归墟之潮_九死一生_DLC策划案_V0.2.md)。
