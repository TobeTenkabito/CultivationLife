# 归墟之潮：九死一生

当前扩展版本 **2.6.0**，本体维护基线 v1.57.0 开发源码，2026-10-04。存档结构 8 支持 6→7→8；版本与默认启用状态见 [manifest.json](manifest.json)。

提供十一界周期副本、逐层探索、有限宝池、NPC 争夺与组队、交涉、闭门被困及苦修脱困。每座五层、六十条宝池条目。当前配置与完整边界见 [归墟规格](../../docs/归墟之潮_九死一生_DLC策划案_V0.2.md)。

状态保存在 `GameState.guixu_state`；关闭扩展会安全结束玩家当前会话并保留周期资料。本体地图及通用奖品定义不移除。算法位于 `cultivation_life/system/guixu/`，引擎使用显式依赖，旧 `guixu_system.py` 保留兼容入口。

扩展开关在重启后生效，以实际加载状态为准；新规则须通过内容校验、相关系统测试及 [依赖检查](../../tools/check_module_dependencies.py)。
