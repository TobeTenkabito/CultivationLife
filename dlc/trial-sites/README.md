# 万象试境

版本 **1.0.0**，ID `official.trial-sites`。独立 DLC，无其他扩展依赖。本体 v2.12.0 提供运行时与存档入口，内容包声明启用；未加载本包时不开放玩法、地图标记或右侧试境按钮。

十一普通界面各有一处由种子绑定的遗迹：人界与魔界 7 层；灵界、真魔界、妖界、幻冥界、地狱界 14 层；仙界、修罗界、幽冥界、轮回界 22 层。同境界的后一层基础强度递增，层序沿既有策划；独立空间没有试境入口。

桌面右侧的紫色“象／试境”按钮直接打开本界可视化试境面板。移动端在“诸界 → 试境”，复用同一按钮，可星标到常用。层图、五处机关进度、人物资源条、守关强度与遗藏卡片提供主要展示；事件正文保留判断所需事实，未知状态不会通过图标或接口泄露答案。

异地“前往试境所在地”调用原地图旅行，照常支付时间与风险；到达后点击“开始探索”。每层五事件及守关交锋、领奖、暂停、续行不推进世界时间，选择与战斗保留真实资源成本。NPC 不参与，自主年度结算不会调用本玩法。

奖励、机关、层记录与守关有限元力由种子生成后固定保存。已通过层不重复发放奖励。关闭 DLC 后保留记录，只摘除可安全暂停的会话，保留其他已获得的后续事件，不退款、不修复或刷新副本；既有受控或封逃结果不能借关闭 DLC 解除。开关保存后按现有扩展管理规则重启生效，重新启用可继续原局势。

只支持结构 10，不转换或覆盖结构 1–9。详细流程、资源与协议见[实现说明](../../docs/trial-sites.md)，层序与设计见[策划案](../../docs/万象试境_副本策划案_V0.1.md)。
