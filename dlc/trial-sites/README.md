# 万象试境：问道无涯

版本 **1.1.0**，ID official.trial-sites。独立 DLC，无其他扩展依赖。本体 v2.13.0 提供可选执行器与原物品、功法、战斗接口；层名、守关者、入口、修仙异闻和遗宝词库由本包提供。关闭或移除包后不开放玩法、地图标记和紫色快捷按钮。

十一普通界面各有一个入口，按原世界层级开放7／14／22层。层图展示具名景物，境界序列仅为内部强度依据。每层五段因缘影响守关者及遗藏，之后交锋并领取一次奖励；异地前往照常旅行，探索、交锋、领奖和暂停不耗世界时间。

新层以独立种子生成随机功法、法宝、宝物或丹药，名称、品相与属性首次入层即绑定。旧层保存的奖励不重抽。奖励进入原行囊、已悟功法及法宝记录；既有使用、配置和本命化权限继续适用，已获得遗泽不因关闭扩展而删除。

关闭时只摘除可安全暂停的会话，保存原层进度、遗宝和有限元力，不退款、不回血、不刷新奖励。已受控或封逃不能利用开关解除。试境没有年度或NPC结算入口。

仅支持结构10，详见[实现说明](../../docs/trial-sites.md)。
