# 圣人之道：内圣外王

当前扩展版本 **1.6.0**，本体维护基线 v2.14.3，2026-10-17。仅支持存档结构 10，结构 1–9 不转换；版本与默认启用状态见 [manifest.json](manifest.json)。

提供儒修教化、学说、门人、经典、内圣外王，以及人界结丹和灵界炼虚的专属剧情。普通物品与功法定义归本体，专属配置和事件由本包提供。

配置入口为 `content/sage_way.json`，规则位于 `cultivation_life/system/sage_system.py`。当前 `SageSystemMixin` 仍是引擎直接基类之一；后续拆分应先界定年度收益、门人更新与操作提交的边界，不能只移动文件并改变结算顺序。

扩展开关在重启后生效，以实际加载状态为准；新规则须通过内容校验、相关系统测试及 [依赖检查](../../tools/check_module_dependencies.py)。

## 1.5.0 · 游学上界

仙界、修罗界、幽冥界、轮回界分别提供本地学说，可加入、立说、传道、授业、解惑与论辩。首次到访时惰性建立，不重建已有学说；影响力、成员和退说冷静期留在各自界面，离界席位沿原规则冻结。每界仍最多五家学说。

九至十二阶经典按真实原初品阶积累浩然，重复同级不可再刷。上界沿用浩然被动、固化战力、经世灵石与机缘收益；外王强行升境保持练气至大乘的原有范围，上界升境遵守本体修持与劫关。人界、灵界专属剧情触发范围不变。详见 [上界 DLC 边界](../../docs/upper-teachings.md)。
