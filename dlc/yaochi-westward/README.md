# 瑶池西望：紫气东来

DLC 版本 **1.0.0**，配套本体 **3.6.0**。八条玩法与四章共同主线已贯通。仅结构12，沿山海图志、沧海夜色两套像素主题的原瑶池及天庭入口。

已接入澄心池、玉液池、五光坛、按目标备料、原功德资历与可用权益分账。需要道修真仙以上亲临瑶池，修持使用原世界年度与事件中断结算；功德承兑使用有限公共服务采购预算与真实资金托管。普通仙躯、五色神光和瑶池兑换仍沿原入口。

停用扩展后停止新预约和履约，已付项目保留，可返回瑶池退出并按实际未用工时退回原币种及未结算材料。换页、换境、读档不刷新报价、进度或采用权益。

地仙庙域页可在仙界原凡人／混居城市奉建一座主庙，使用原营造工料与损毁重建。三项日常护民经10年勘查、方案选择与100／150年总履约换取有限本地助修，普通机缘和仙痕仍只结算一次；离庙、停用或损毁暂停，不刷新截止年。

现在可沿原地图相邻道路扩为一主三分，各庙独立香火、共用本人单项履约。每庙两席，从护境阵台、济用坊、传习堂中择二；实付工料、现场施工，接入原镇地阵修复、遗址重建和本地人物培养。先交付原业务，再实际履行百年公共事务取得香火。两套主题提供庙务、专项设施和庙域名录分页。

六类地方争议采用原址来报、5年调查、两案取舍、实际执行与复核交付。分别影响原药田批次、市场实物库存、普通道路行程、庙产使用权、原镇地阵和遗址；未许诺可拒绝，固定500年期不因换页或读档刷新。争议沿地仙页已有导航，结案改变地方结果与信任，不重复发放助修额度或两币。

天庭增加四司任职、请假与交接、主管资格、两名原NPC属员及实际公务。巡天巡检、司土公共城市复建、天工实货调拨、御史原案卷核账各有实际对象；公务使用原府库、原市场、原人物和原道路。属员按原地区年度办理，本人实际复核后分配原总功德，返程交接才释放占用。

三类监察以原货单、逾期交接及任命关系取证，加入申辩、独立天官复核、真实补交／回避／暂停经办资格和一次申诉。巡天增加现行通缉人物的实际交锋，以及原伤者救治、同界道路转运与当面交接；原人物、府库、药品、伤势和资源只结算一次。详见[监察与巡天](../../docs/court-justice.md)。

瑶池增加250年原仙圃承办、实际生产销售、定向供货与原人物合作；同境论法、护阵演武和资材会办均使用原养成、战斗、阵法及实物结算。每500年一届，实际筹备、一次报名与有限实款奖金，详见[仙圃与仙会](../../docs/yaochi-fair-garden.md)。

三条仙府原址调查、独研／合作解禁、取藏／保全静室及真实返程已接入。天庭四类项目议案使用原七曜表决、府库实款、市场实货、NPC培养与建筑结算，履约后原回执移交诸司。详见[访古与议政](../../docs/westward-ventures.md)。

四章紫气主线提供守土济民、公共修持、瑶池承办、同道共修四种原仙府结局；散仙、地仙与玄仙沿原职位和庙域交接。私人功德可实付原修缮，清修讲席占用真实讲师并按十年工时结算。规则见[1.0补完](../../docs/westward-finale.md)。详细规则、当前限制与验收记录见[实施记录](../../docs/yaochi-westward-implementation.md)。
