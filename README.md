# 浮生问道

**当前本体版本：v1.3.0。** 本体采用语义化版本号，唯一代码来源为 `cultivation_life/version.py`；存档 schema、内容 schema 以及各 DLC/MOD 的版本继续独立管理。

各界现已拥有独立地域地图。跨域移动按最短路线、距离与角色境界消耗游戏时间，途中复用统一世界时钟；坊市货单与寻幽探宝奖励按当前地域分流，高危地图还具有阻挡或致死性的境界限制。

功法现具有固定的先天“源”（灵源、魔源、妖源、阴源及其加权组合），各界分别配置四类气浓度。当前修炼环境倍率为 `E(q) = 0.25 + 1.5q/(q+1)`；多源功法按源权重求倍率的加权平均。倍率只在主修吐纳或炼体进度结算时动态相乘，不改写功法原始数值，也不改变战斗力或已经获得的修为。普通开局可在选择道统后选择人界或该道统的本界，魔修可直接从魔界开始，鬼修可直接从地狱界开始。

角色还会分别积累灵气、魔气、妖气与阴气经验，累计经验达到 `25 × 等级²` 时提升对应气等级。获得正机缘时，主修与辅修按各自源权重吸收气经验，再乘当前地图的独立获取效率；战斗槽和炼体槽不会重复提供这份经验。所有功法均具有可组合的战斗气等级门槛，支持 `且 / 或 / 非` 与六种等级比较；门槛未满足时不能装入战斗槽，已装备功法若因上限条件失效也不再提供战斗力。

一个数据驱动的修仙人生模拟游戏纵向切片。主页提供正统结丹至真仙七档，以及魔修魔丹、鬼修结丹快速开局；炼虚、合体、大乘从灵界出生并自动补齐五行灵根。凡人与修士均可在取得炼体功法后另修最高一百层肉身，积累圆满后手动冲层；炼体里程碑会提高常规破境概率并削减雷劫、天劫伤害。踏入仙途后可进入按世界与境界隔离的坊市、加入或自创宗门、建立修仙家族、组建 NPC 队伍，也可猎妖、切磋或灭杀世界人物与同门。修士小队只按概率出现，一个行动单位只抽取一次主动遭遇；多人目标会先显示人数、修为和全队战力，再由玩家决定是否交手，切磋永不致命。普通偶遇修士先进入有界 FIFO 缓存，只有再次相逢、进入天榜、形成重要关系或成为通缉目标时才晋升为持续演算的世界人物。游戏现已包含师徒与道侣互动事件、血脉后代、同法同境联合突破、动态上界天榜、种族及宗门外交投票，以及从沧海宫、天裂古台、青冥洞天延伸到裂界魔潮、天墟岛、蚀天祖藤和真仙洛天衡下界的高阶主线。魔界与真魔界另有十二个专属日常事件，以及血河古鲸、尸月封瘟、裂谷界兽、黑日曜烬、坠星遗胎和渊极界柱六条完整剧情链；地狱界另有基础通用内容与忘川失名舟剧情链。大乘修士可在对应上界与下界间往返，进入下界时修为受法则压制，返还后恢复真实道果。练气以外的阶段突破及所有大境界突破均需手动冲关。杀伐会积累威名及势力敌对，并可能引发通缉、追杀、处决或牢狱玩法。炼虚后另有三千年周期雷劫与跨境界五重天劫。

初始化界面的“功业录”提供跨存档成就系统，分别展示剧情、修炼以及本体/DLC 来源。新建首个角色时会在 `data/saves/global_metadata.json` 建立全局元数据；解锁时间与角色名记录在此文件，不会写入或绑定某个角色存档。成就解锁提示可在游戏内设置中关闭，不影响后台解锁与记录。

本体 v1.2.0 新增“修好睦邻”年度行动与十三项本体成就，调整妖修击杀异道修士的因果/煞气结算；补灵根典籍恢复为金阙残书、紫阙玉书与魔阙，并为妖界、幻冥界、地狱界补齐严格限定本界的五行典籍。v1.1.0 开放的鬼修基础路线继续保留：鬼修可在人界或地狱界开局，自带低阶引阴与听魂法门；在人界达到化神初期后会前往地狱界。地狱界拥有完整通用系统、一至八阶本地功法与严格隔离的商品池、三座宗门、十四个专属事件及“忘川失名舟”剧情链。大乘鬼修可下界人界并复原返回，轮回界仍为后续高阶路线预留。

## 快速开始

推荐直接双击项目根目录的 `launcher.exe`。启动器会自动运行本地游戏服务并打开浏览器；如果服务已经运行，再次双击只会打开现有游戏页面。存档仍写入项目下的 `data/saves/`。

也可以使用 Python 命令启动：

```powershell
python -m cultivation_life.server
```

然后浏览器打开 <http://127.0.0.1:8000>。

## DLC 与 MOD

启动时会自动扫描程序同目录下的 `dlc/` 与 `mods/`。每个扩展必须拥有独立子目录、`manifest.json` 和 `content/`；本体总是先独立完成加载，随后依次叠加 DLC 与 MOD。扩展被禁用、依赖缺失或内容校验失败时会被隔离跳过，不影响已经验证通过的本体内容。初始主界面右上角提供独立的 DLC/MOD 开关，选择写入 `data/extension_preferences.json` 并在下次启动、内容加载前生效，不会修改扩展包自身清单；游戏内右侧“拓”面板仍可查看本次启动的加载及错误状态。具体格式见两个目录中的说明文件。

官方可选包 `dlc/monster-bloodlines/` 已推进至 V4.5：蛇、禽、猿、狐、龟甲、虫、水族、草木精怪八条本源谱系拥有共 200 个不可逆进化节点、17 种固有血脉特质，以及每族 16 个随机觉醒槽位，并新增返祖、立祖与十二血脉特质三项 DLC 成就。新觉醒由有限复合规则生成器从战斗时点、轮次、境界关系、先手、态势、法力、战意、地形、禁制、神识压制、本轮伤害和固定效果档位中受约束组合；规则获得后永久固化，经过语义时序、强度预算、叠加限制和运行时封顶四层校验，旧存档固定特质保持兼容。修至当前大罗上限最多取得 12 项，每族仍至少余 4 项。八族会在筑基层次分别解锁一种不会随后续进化丢失的种族特质。大乘圆满后从妖界或幻冥界飞升幽冥界，并在“真灵返祖”与“自成血脉”之间选择高阶生命道路；幽冥界可选择下界妖界或幻冥界，返程完整复原封存道果。自成路线包含立祖、固谱、衍法、定祖四阶段，可用白名单功业点在有限规则编辑器中配置轮次战斗规则；编辑器实时生成完整描述并显示费用、余点与非法原因，全部有限规则配置也会在 DLC 加载时预检。V3旧档提供一次补刻，立祖后的稳定血脉 ID 与定型规则可由后代从父母一方直接继承。DLC 同时提供妖界、幻冥界、幽冥界共三十三处地图、十八个政治种族、九座宗门、妖族功法、物品、事件和完整探宝/坊市池。妖修基础寿命为同境普通修士的三倍，炼体修炼速度提高 50%，高阶妖功还会检查炼体层数。妖修本体进化与变化术互斥，不能配置变身功法、炼化变身素材或获得变身战斗加成。生物谱系与外交使用的政治种族彼此独立；卸载或关闭 DLC 后本体仍能读取已有妖修存档，血脉、进化及 V4 内容会冻结，但妖修可恢复使用本体的普通突破流程，并在每次成功突破大境界后从 16 项本体通用特质中随机获得一项未拥有特质。这些通用特质的数值上限为 4%，弱于血脉特质，且重新启用 DLC 后会冻结，不与血脉叠加。

官方大型系统包 `dlc/ghost-reincarnation/` 已完成《百鬼夜行:轮回往生》V3.0.0。第二阶段加入提前两个时间单位预告的百鬼夜行、真实魂魄 NPC、十个固定三魂七魄槽、魂性与魂压、主动附灵、败亡受制以及完整夺舍闭环。本体 v1.3.0 以 `GhostCore + OptionalHostBody` 分层保存本魂与肉身：默认一生成功夺舍一次，高级鬼功可增加或取消限制；夺舍期间魂蚀、往生、轮回印记、最高水位与十魂全部冻结，宿主按自身灵根、境界、寿元和道途修炼，离体或肉身死亡后原魂精确恢复。V1/V2 的共享魂蚀时钟、Intrinsic/External 承载、轮回册、往生与最终有效突破率 98% 硬上限继续完整保留。DLC 关闭时专属状态冻结且不删除，旧档仍位于根目录 `data/saves/` 并通过缺省字段就地兼容。

## 当前范围

魔修使用独立境界名称：聚煞、铸魔、魔丹、魔婴、化魔、炼魔、真魔、魔尊。潜心修炼收益仅为正常值的一成，主要通过击杀修士或妖兽获得机缘，并可无视因果、煞气原有的修炼负面效果。魔修不能服用突破丹叠加自身突破率，改以吞噬炼尸或活傀、炼化外来元神累积冲关加成。

神识等级决定傀儡容量，每三个神识等级增加一个傀儡栏位；神识锻炼速度已大幅提高。大小境界突破会免费提升一级并完整保留当前经验，手动突破才按下一等级的经验差额扣除经验。玩家可生擒修士，也可对师父、道侣或道友发动两阶段背叛生擒事件；随机杀戮与生擒会排除这些关系人物、弟子及当前宗门同道，宗门名册则提供明确的“截杀”入口供玩家主动越过保护。在“俘虏与傀儡”窗口可释放、拷打、炼尸或种下活傀标记。炼尸继承八成战力且不会反叛，活傀继承完整战力、可换功法并消耗 MP 加固控制，但控制度会随成长下降。所有流派均可用二十五枚灵石和一柄青锋灵剑合成机关傀儡。机关与炼尸分别把自身战力的四成、六成直接计入玩家本体战力和剧情门槛；活傀以八成战力作为队伍成员参与实际战斗。炼尸与活傀还会逐年贡献少量机缘。

吞噬会立即释放一部分突破潜力，并在识海中留下具有强度与炼化进度的外来元神；剩余潜力可消耗机缘和 MP 主动炼化，也可选择不消耗两者的“闭关炼化”，以正常炼化时间的 120% 一次处理全部未净元神。闭关期间年龄、寿元、NPC 世界演化、控制衰减和元神反噬均逐年正常结算。未炼化元神越多、越强，年度反噬及死亡风险越高，已炼化元神则收纳在默认折叠的归档中；主界面的功法配置与已悟功法也默认折叠。魔界与人界同属下界，NPC 最高只会达到化神或化魔；魔界现有血狱魔宗与阴尸殿两个初始宗门。真魔界开放天魔宫、万魂渊与黑日神殿，拥有合体修士巫迟烟、曾砺川、多位大乘或魔尊人物，以及独立于灵界的二十族与动态天榜。除跨界飞升的人族外，始魔、天魔、血魔、魂魔、梦魇、虚魔等十九个真魔原生种族不会再与灵界族群混用；旧存档载入时会保留原有培养与外交数据，并自动迁移真魔界居民的旧族属。魔修 AI 的主动斗法与截杀倾向高于其他流派，但不会主动攻击同宗成员。化魔初期可由人界飞升魔界；身处魔界达到化魔一层即可尝试飞升真魔界，魔气等级要求同步降为 8 级，未达要求强行飞升会陨落。所有傀儡都会在跨界时遗失，飞升后威名清零。

魔修在真魔界达到炼魔后寿元无尽，并同样每三千年承受三道雷劫，但实际劫力伤害提高 20%。炼魔以后的大境界突破不再走普通五重天劫，而是至少连续迎战五轮域外天魔；每次胜利均可获得机缘，也都可能引出任意一道曾被吞噬的元神以其生前一半战力反噬。元神战结束后仍可能继续引发下一次反噬，因此天魔劫没有固定的理论战斗上限。

战争现以“战争领袖 + 参战盟友”的双方阵营为单位。同盟不会在宣战时自动入场：玩家取得战争指挥权后可选择具体盟友发送参战邀请；AI 只有本方战争分数低于 -25 时才会求援，盟友仍可能拒绝，冷却后可再次邀请。战争面板只显示玩家当前界面的战争，并列出双方总战力、前三位高阶修士战力、盟友与参战名册。纯 AI 战争会综合总战力和高阶战力后加入有限胜负波动；高阶修士战败时更倾向逃离，低阶修士则更容易阵亡。玩家可以参加先锋战取得士气修正，也可以直接推进首场会战。胜方可把处死、赔款、附庸、外交变更、解散或合并等和谈条款施加给敌方任一参战势力，对非战争领袖施压需要额外战争分数；强制解散还要求胜方总战力至少达到目标的 1.35 倍，合并要求 2.5 倍。玩家主导战争战败时，AI 会按实际战争分数生成不同强度、必要时包含多项内容的和约要求，而不再固定只要求处死首恶。

各界地图会不定期发布拍卖会预告，并留下两个有时间消耗的操作节点供玩家赶往会场；受地域境界禁制阻挡时无法入场。玩家入席时可在狻猊使者、百花仙子、青龙公子与朱雀公主之间选择匿名身份，竞价记录只显示该身份。拍卖开启后，寄拍、竞价、推进轮次及与到场 NPC 交涉都不消耗年龄。交谈会获得较高好感并开启该 NPC 的私下交易，从对方手中买入物品也会提高好感。寄拍须先支付额定价 5% 的占位费，起拍及后续竞价限制在额定价 25% 至五倍之间；成交后另收最终拍定价 30% 的服务费。玩家竞价时会冻结灵石，被 NPC 反超后自动退还。NPC 拍品、私下交易与散场黑市都严格读取玩家当前所在界面的货物表，不会跨界生成或成交；同界高阶珍品仍会按境界权重显著压低。黑市可用普通字符串或正则表达式检索本界货物并以 2.8 倍基准价补缺，也能出手普通物品、机关傀儡与炼尸，但不能出售活傀。

灵田最多可开垦八顷，面板以八块方格田地显示荒地、空田和在田作物；每次扩地消耗递增的灵石与年月。播种不消耗时间，作物随统一年度时钟自然生长，也可由玩家自行输入 MP 数量催熟；催熟年数同时受投入比例、角色大境界和御灵等级影响，大乘法力不会再与练气法力只产生相同的一年效果。采收年份按当前数量级向下取整，例如 201 年记作 200 年、2,001 年记作 2,000 年；各品种可拥有十年、百年、三千年或其他具体最佳药龄，过熟时品质和价值可能下降。坊市会固定保留一个灵植种子货位，并可按基准价值收购成株；散场黑市收购灵植的价格通常更高。行囊新增“灵植与种子”分类，角色栏新增可存档的炼丹、炼器、阵法、制符与御灵五类百艺经验；灵田经营和傀儡培养已经接入对应经验来源。

丹炉允许任意搭配行囊中的药材并选择目标丹药，炼制成功率综合丹药品阶、炼丹等级、药材数量与具体年份品质计算，成功或失败都会积累炼丹经验并消耗所投药材与 MP。特殊灵植也已进入同一套具体年份系统：枯荣藤须先吸收岁华灵露或太虚灵泉才能接受 MP 催熟，万年以上可炼成枯荣天剑；枯荣天剑除大乘快速开局外不再从坊市或固定 NPC 掉落。持有万年以上雷音竹会使最终战斗力提高 1%（不按数量叠加），使用五千年以上渡劫花则使下一次三千年雷劫伤害降低 10%。两种造化灵液也可增强其他灵植的一次催熟效果。

大乘或魔尊返回对应下界后，飞升入口会完全隐藏，且后端拒绝任何绕过界面的重复飞升请求；此时只保留重返原上界的操作，避免误触破坏境界、机缘和 HP/MP 状态。战争面板的操作按钮固定在单行内，空间不足时改为横向滚动。

玩家推荐战力、NPC 世界平均战力与动态战斗事件现已统一使用同一套内容基准，不再保留旧版本的低战力 NPC 底模。基准直接由当前战斗公式与内容表重建：角色满 HP/MP、当前层修炼圆满；纳入所在世界路线正常可购的战斗功法；同阶常规战斗装备按初期一轮、中期两轮、后期三轮积累；一次性剧情战力奖励按初期未完成、中期完成一半、后期完成计算。无限重复刷取同名装备、傀儡、队友及宗门加成不进入有限基线。练气一至十三层为 100–280；其余七境的初期/中期/后期依次为：筑基 600/1,000/1,150，结丹 2,500/6,100/8,800，元婴 20,500/42,500/64,500，化神 125,000/170,000/190,000，炼虚 705,000/1,070,000/1,400,000，合体 4,800,000/7,200,000/9,000,000，大乘 33,000,000/49,000,000/63,000,000。沧海宫、天裂古台、青冥洞天、裂界魔潮、天墟岛、蚀天祖藤及洛天衡下界等固定剧情的战力门槛也按新基准保持原有相对难度整体重标；最高风险的独斗与贪婪路线可以高于同境后期标准。

六档快速开局的默认功法、法宝与既有剧情战利品也按这套基准重新组合，不再沿用旧标准的低配行囊。结丹至大乘初期的实际开局战力依次为约 2,691、19,711、129,510、731,260、4,887,325、32,565,400，分别处在各自初期推荐线的 96%–108% 区间。已经随快速开局授予的低阶剧情宝物会同步写入相应完成标记，避免之后重复领取。

全界围杀的威名门槛对普通修士为严格超过 400、对魔修为严格超过 1000。宗门、家族、种族与全界势力的追杀令采用同一套终止规则：势力覆灭时触发对应的陨落事件；玩家组队战力不低于敌方势力，或玩家境界不低于敌方最高境界时，对方改派代表议和。玩家可索取巨额赔偿、勒令可解散的势力解散、要求向本人或本宗臣服，或索取重宝与最强者作为人质。全界包围网被议和压服后会在当前界面永久终止，不会仅因威名仍高而循环重发；飞升后的新界面独立计算。关系人物、弟子和当前同门不会替其它势力执行针对玩家的追杀令。

当前版本用于验证完整闭环：创建角色 → 选择行动与炼体 → NPC/师徒/道侣/后代/组队 → 战斗、威名与势力敌对 → 追杀或牢狱 → 概率冲关与服丹 → 联合破境/进阶事件链/天劫 → 偷渡灵界 → 动态天榜、两级外交投票、自创宗门、修仙家族、势力通缉与跨界返乡 → 存档。玩家取得种族、宗门或家族任意一方的话语权后，即可单独以该势力名义发布通缉；系统会从该势力实际存活的 NPC 中编成追缉队，持续结算目标与打手的重伤、逃脱、阵亡和缴获。元婴起一个操作单位依境界扩大为 5–100 年，引擎仍逐年结算正向收益、NPC 突破/寿尽/飞升和大事件；剧情链的未触发加成按“行动单位”而非所跨年份增加。主动行动的 HP/MP 等成本只在本行动单位支付一次，主动战斗也只产生一次目标遭遇。本体常规修炼路线当前以大乘九层为终点；启用妖修血脉 DLC V4 后，妖修路线可继续至幽冥界的大罗境。

## 内容扩展约定

游戏内容与执行逻辑分离。新增物品、功法、坊市货物、宗门 NPC、世界 NPC、种族或调整数值时修改 `content/` 下的 JSON，不需要改动 `rules.py` 或 `engine.py`。程序启动时会校验 schema 版本、重复 ID、功法四维属性、世界与种族规则、坊市跨表引用，以及事件中的物品、功法、NPC 和宗门引用；断链内容会直接给出明确错误，不会带着脏数据进入存档。
